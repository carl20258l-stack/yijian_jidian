# 一、管道安装

## （一）管道敷设及连接

### 1. 管道与大型/动设备连接

> 适用于空压机、制氧机、汽轮机等。应在设备安装定位并紧固地脚螺栓后进行。**无论焊接还是法兰连接，都不应使动设备承受附加外力。**

| 程序 | 要求 |
|------|------|
| 连接前 | 管道内部清理干净；**自由状态下**法兰的平行度和同轴度符合设计要求 |
| 连接时 | 在联轴器上架设**百分表**监视动设备**位移** |
| 试压、吹扫合格后 | 对该管道与机器的接口进行**复位检验** |
| 安装完成、检验合格后 | 不得承受设计以外的**附加载荷** |

### 2. 大型储罐管道连接

- 大型储罐的管道与泵或其他有独立基础的设备连接，或储罐底部管道沿地面敷设在支架上时
- 应在储罐**液压（充水）试验合格后**安装
- 或在储罐液压（充水）试验及**基础初阶段沉降后**，再进行储罐接口处法兰的连接

### 3. 伴热管及夹套管安装

- **伴热管**与主管**平行安装**，应能自行排液；多根伴热管时相对位置应固定
- 水平伴热管宜安装在主管的**下方一侧或两侧**，或靠近支架的侧面；铅垂伴热管应**均匀分布**在主管周围
- **不得**将伴热管**直接点焊**在主管上
- 不允许与主管直接接触的伴热管，应在伴热管与主管间设置**隔离垫**
- 伴热管经过主管法兰、阀门时，应设置**可拆卸的连接件**
- **夹套管**外管剖切后安装时，纵向焊缝应设置于**易检修部位**
- 夹套管的**连通管不得存液**
- 夹套管支承块的材质应与主管内管的**材质相同**，支承块不得妨碍管内介质流动

## （二）阀门安装

- 安装前按设计文件核对型号，按**介质流向**确定安装方向
- 检查填料，压盖螺栓应留有调节余量

| 连接方式 | 阀门状态 | 备注 |
|----------|----------|------|
| **法兰**或**螺纹**连接 | **关闭**状态下安装 | — |
| **焊接**连接 | **开启**状态下安装 | 对接焊缝底层应采用**氩弧焊**，并采取防变形措施 |

> 记忆口诀：**热开冷关**（焊接→热→开启；法兰/螺纹→冷→关闭）

- **安全阀**：**垂直安装**；出口管道接向安全地点；进出管道上设置截止阀时，应加**铅封**，且锁定在**全开启状态**

## （三）常用补偿装置安装

### 1. "Ⅱ"型和"Ω"型膨胀弯管

- 安装前按设计文件规定进行**预拉伸或预压缩**
- 预拉伸/预压缩在**两个固定支架之间的管道安装完毕、与固定支架连接牢固后**进行
- 预拉伸/预压缩的焊口位置与膨胀弯管起弯点距离**应大于 2m**
- **水平安装**：平行臂与管道坡度相同，两垂直臂相互平行
- **垂直安装**：设**排气装置**（弯管在管道上方）或**疏水装置**（弯管在管道下方）

### 2. 波纹管膨胀节

- 安装前按设计文件规定进行**预拉伸或预压缩**，受力应均匀
- 安装时设**临时约束装置**（自带约束装置的产品保持约束状态）
- 临时约束装置待管道安装固定或**压力试验合格后**再拆除或解除
- 内套管焊接固定的一端：水平管道上位于**介质流入端**，垂直管道上位于**上部**
- 与管道**保持同心**，不得偏斜，避免周向扭转
- 需合理设置**导向支座**和**固定支座**
- 安装时避免波节受机械损伤：避免焊渣飞溅、不得在波节上焊接临时支撑件、不得将钢丝绳绑扎在波节上

## （四）支吊架安装

- 安装位置准确，平整牢固，与管子接触紧密
- **无热位移管道**：吊杆**垂直安装**
- **有热位移管道**：吊点向位移**相反方向**偏置；设计无规定时，按位移值的 **1/2** 偏位安装

| 支架类型 | 关键要求 |
|----------|----------|
| **固定支架** | 按设计/标准图安装；在补偿器**预拉伸或预压缩之前**固定；无补偿装置冷热管道直管段上**不得同时安装 2 个及以上**固定支架 |
| **导向支架**（轴向） | 滑动面洁净平整，不得歪斜和卡涩 |
| **滑动支架**（径向+轴向） | 同上；有热位移时向位移反方向偏移，偏移量 = 位移值 **1/2** |
| **弹簧支吊架** | 弹簧高度按设计；调整至**冷态值**（未受热、无负荷）并记录；临时固定件在系统安装、试压、绝热完毕后拆除 |

## （五）静电接地安装

- 有静电接地要求的管道，各段管子间应**导电**
- 每对法兰或螺纹接头间电阻值 > **0.03Ω** 时，应设**导线跨接**
- 静电接地引线宜采用**焊接形式**
- **不锈钢和有色金属管道**：导线跨接或接地引线不得与管道直接连接，应采用**同材质连接板过渡**
- 安装完毕后必须进行**测试**，电阻值超标时检查与调整

# 考点：管道工厂化预制技术（★）

## 管道工厂化预制的一般工作流程

```mermaid
flowchart LR
    A[深化设计] --> B[管道加工图]
    B --> C[管段切割]
    C --> D[坡口加工]
    D --> E[管段组对]
    E --> F[焊接]
    F --> G[无损检测]
    G --> H[热处理]
    H --> I[压力试验/严密性试验]
    I --> J[吹扫/清洗]
    J --> K[防腐]
    K --> L[管口封闭/包装]
    L --> M[现场安装]
```

**流程顺序：** 深化设计 → 管道加工图 → 管段切割 → 坡口加工 → 管段组对 → 焊接 → 无损检测 → 热处理 → 压力试验、严密性试验 → 吹扫、清洗 → 防腐 → 管口封闭、包装 → 现场安装

# 例题与解析

## 【单选题】有热位移管道的导向支架需反向偏移安装，偏移量应是位移值的？【2025】

A. 1/5　　B. 1/4　　C. 1/3　　**D. 1/2**

> **解析：** 导向支架或滑动支架的滑动面应洁净平整；有热位移管道，支架安装位置从支承面中心向位移反方向偏移，设计无规定时偏移量为位移值的 1/2。

## 【单选题】管道滑动支架以支承面中心为起点进行反方向安装的偏移量应为位移值的？

A. 1/5　　B. 1/4　　C. 1/3　　**D. 1/2**

> **解析：** 安装位置从支承面中心向位移反方向偏移，偏移量应为位移值的 1/2 或符合设计文件规定。

## 【多选题】关于阀门的安装要求，正确的说法有？

A. 截止阀安装时应按介质流向确定其安装方向
B. 阀门与管道以螺纹方式连接时，阀门应处于关闭状态
C. 阀门与管道以焊接连接时，阀门应处于关闭状态
D. 闸阀与管道以法兰方式连接时，阀门应处于关闭状态
E. 安全阀应水平安装以方便操作

**答案：ABD**

## 【单选题】关于阀门安装时的说法，正确的是？【2023】

A. 螺纹连接时阀门应开启
B. 安全阀门应该水平布置
C. 焊接连接时阀门应关闭
**D. 按介质流向定安装方向**

> **解析：** 法兰或螺纹连接 → 关闭状态；焊接连接 → 开启状态，底层宜用氩弧焊。安全阀应垂直安装。

## 【案例节选 2017】不锈钢阀门应进行哪些试验？试验介质要求？

**参考答案：**
- 试验：壳体压力试验、密封试验、光谱分析
- 介质：以洁净水为介质，不锈钢阀门试验时水中氯离子含量不得超过 **25×10⁻⁶**

## 【案例节选 2018】如何复验合金钢部件的材质？

**参考答案：** 可采用**光谱分析**进行材料复验。

## 【案例节选 2019】15CrMo 钢管的进场验收要求？

**参考答案：**
1. 有取得制造许可的制造厂的产品质量证明文件
2. 对钢管进行外观质量和几何尺寸的检查验收
3. 对钢管材质采用**光谱分析方法**复查，并做好标识

## 【案例节选 2016】制氧机法兰与管道法兰的偏差应在何种状态下进行试验？检验的内容有哪些？

**参考答案：**
- 应在**自由状态**下进行检查
- 检查内容：法兰的**平行度和同轴度**，偏差应符合设计要求

## 记忆要点汇总

| 项目 | 关键数字/口诀 |
|------|--------------|
| 阀门安装状态 | **热开冷关**（焊接开 / 法兰螺纹关） |
| 安全阀 | **垂直**安装 |
| 预拉伸焊口与起弯点距离 | > **2m** |
| 有热位移偏移量 | 设计无规定时 = 位移值 **1/2** |
| 法兰电阻临界值 | > **0.03Ω** 设导线跨接 |
| 不锈钢试验水氯离子 | ≤ **25×10⁻⁶** |
| 管道工厂化流程 | 深化设计 → 加工图 → 切割 → 坡口 → 组对 → 焊接 → 无损 → 热处理 → 试压 → 吹洗 → 防腐 → 封口包装 → 安装 |
