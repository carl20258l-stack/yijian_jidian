# 4.2 管道系统试压

## 一、管道试验的主要类型

根据管道系统不同的使用要求，管道试验主要有三类：

| 试验类型 | 目的 | 介质 | 试验压力 |
|---------|------|------|---------|
| **压力试验** | 检验管道**强度**和**严密性** | 液体（首选）/ 气体 | 液压 1.5P~设~ / 气压 1.15P~设~ |
| **泄漏性试验** | 检查密封点泄漏 | 气体（发泡剂/显色剂/气体分子感测仪） | P~设~ |
| **真空度试验** | 检验管道系统严密性（增压率） | 抽真空 | 24h 增压率 ≤ 5% |

### 建筑管道试验（补充对比）

| 管道类型 | 试验名称 |
|---------|---------|
| 室内给水管道 / 建筑饮用水 | 水压试验 |
| 隐蔽或埋地的排水管道 | 灌水试验 |
| 排水主立管及水平干管管道 | 通球试验 |
| 室外排水 | 灌水试验、通水试验 |

> 记忆口诀：**亚冠通水球**（压力→灌水→通球→水压），**公鸭写真**（给水→水压→排水→灌水/通水）

## 二、管道试验应具备的条件（13/15/17/18/20/23年考点）

1. **安装完成**：试验范围内管道安装工程已按设计图纸全部完成，热处理和无损检测合格，安装质量符合设计及有关标准规定。
   - 管道的防腐和绝热**在试验前可部分完成或不完成**
   - **焊缝和管道的待检部位在试验前不得进行防腐、绝热**

2. **方案与交底**：试验方案已经过批准，并已进行技术和安全交底；试验介质已准备充足。

3. **资料复查**：压力试验前，相关资料已经建设单位和有关部门复查。
   > 提示：**1图2文件4记录**
   > - 管道元件的**质量证明文件**
   > - 管道元件的**检验或试验记录**
   > - 管道加工和**安装记录**
   > - **焊接检查记录**、检验报告和**热处理记录**
   > - 管道**轴测图**
   > - **设计变更及材料代用文件**

4. **临时措施**：
   - 管道上的**膨胀节**已设置了**临时约束装置**或采用**临时短管代替**
   - 管道上的**安全阀、爆破片及仪表元件**等已经**拆下或已隔离**

5. **压力表要求**（高频考点）：
   - 已经校验并在检验周期内
   - 精度不得低于 **1.6级**（误差 ±1.6%）
   - 满刻度值应为被测最大压力的 **1.5～2倍**
   - 压力表不得少于 **两块**
   - 其中至少 **1块**压力表安装于液体**最高点**，且以安装于液位**最高点的压力表读数**为准
   - 试压时应至少在系统的**始端**和系统**最高点（末端）** 各装 1 块压力表

   > 精度等级补充：0.1/0.2/0.4（高精度）→ 1.0（中高）→ **1.6（通用）** → 2.5（一般）→ 4.0（低精度）

6. 管道已按试验方案进行了**加固**

7. 待试管道与无关系统已用**盲板**或其他隔离措施隔开

> 试验前操作口诀：**装临时装置、装盲板；拆安全阀、拆爆破片**
> 试验后，**反过来**（拆临时装置、拆盲板；装安全阀、装爆破片）

## 三、管道压力试验

### 3.1 基本要求

- 压力试验以**液体或气体**为介质，对管道逐步加压到试验压力，以检验管道**强度**和**严密性**
- 压力试验在**管道安装完毕、热处理和无损检测合格后**进行
- 以液体为试验介质为**首选**（安全）
- 当管道设计压力 **≤ 0.6MPa** 时，也可采用**气体**为试验介质，但须采取可靠安全措施
- **脆性材料**（铸铁、陶瓷、玻璃）**严禁**使用气体进行试验，压力试验温度严禁接近金属材料的脆性转变温度
- 试验过程发现泄漏时，**不得带压处理**，消除缺陷后应**重新进行试验**
- 试验结束后，应及时**拆除盲板、膨胀节临时约束装置**
- 试验介质的排放应符合**环保要求**
- 压力试验完毕，**不得在管道上进行修补或增添物件**。若需修补或增添物件，应**重新进行压力试验**；经设计或建设单位同意，对采取了预防措施并能保证结构完好的**小修和增添物件**，可不重新进行压力试验

### 3.2 压力试验的替代（20年考点）

替代试验必须取得**建设单位和设计单位**的同意（建设单位是安全生产主体责任，设计单位对安全可靠性负责）。

**情形一：输送无毒、无害、非可燃流体介质，温度/压力工况较低，现场条件不允许单独试验**
- 可**结合试车**用管道输送的流体进行压力试验
- 输送气体介质的管道，需按照**气压试验**的要求进行**预试验**

**情形二：设计压力 > 0.6MPa，液压试验不切实际**（如管道设计未考虑充水载荷、生产中不允许残留微量水渍等）
- 可按设计要求和施工技术标准的规定**以气压试验代替液压试验**

**情形三：现场条件不允许进行液压和气压试验**
可同时采用以下方法代替压力试验：
1. **内部检测**：所有环向、纵向对接焊缝和螺旋缝焊缝 → **100%射线检测**或**100%超声检测**
2. **表面检测**：其他焊缝（包括管道组成件与管道支承件连接的焊缝） → **100%渗透检测**或**100%磁粉检测**
3. **柔性分析**：由设计单位进行管道系统的**柔性分析**（计算机模拟，如有限元分析）
4. **泄漏试验**：管道系统采用敏感气体或浸入液体的方法进行泄漏试验

### 3.3 管道液压试验（首选，18/21/22年考点）

#### 试验介质
- 应使用**洁净水**
- 对不锈钢管、镍及镍合金管道，或连有不锈钢管、镍及镍合金管道或设备的管道，水中**氯离子含量 ≤ 25×10⁻⁶**
- 试验前注入液体时应**排尽空气**

#### 环境要求
- 环境温度不宜低于 **5℃**，低于 5℃ 时应采取防冻措施

#### 试验压力

| 管道类型 | 试验压力 |
|---------|---------|
| 承受内压的**地上**钢管道及有色金属管道 | 设计压力的 **1.5倍** |
| 承受内压的**埋地**钢管道 | 设计压力的 **1.5倍**，且 **≥ 0.4MPa** |
| 承受内压的**埋地铸铁**管道（P~设~ ≤ 0.5MPa） | 设计压力的 **2倍**（小乘） |
| 承受内压的**埋地铸铁**管道（P~设~ > 0.5MPa） | 设计压力 **+ 0.5MPa**（大加） |
| 承受**外压**的管道 | 内外压力之差的 **1.5倍**，且 **≥ 0.2MPa** |
| **夹套管**内管 | 按内部或外部试验压力的**最高值**确定 |
| **夹套管**外管 | 设计无规定时按式(4.2-1)计算 |

#### 设计温度高于试验温度时的压力计算

公式 **4.2-1**：
```
PT = 1.5 × P × [σ]T / [σ]t
```
- P~T~ —— 试验压力（表压，MPa）
- P —— 设计压力（表压，MPa）
- [σ]~T~ —— 试验温度下管材的许用应力（MPa）
- [σ]~t~ —— 设计温度下管材的许用应力（MPa）
- 当 [σ]~T~/[σ]~t~ **> 6.5** 时，应取 **6.5**
- 当试验压力产生超过管材屈服强度的应力时，应降至不超过屈服强度的应力

#### 管道与设备作为一个系统试验

| 条件 | 试验压力 |
|-----|---------|
| 管道试验压力 ≤ 设备试验压力 | 按**管道**的试验压力进行 |
| 设备试验压力 < 管道试验压力，且设备试验压力 > 管道试验压力的 **77%**，设计或建设单位同意 | 按**设备**的试验压力进行 |

> 原则：**取小的**，避免损坏设备或管道

#### 位差较大管道的处理
- 将试验介质的**静压计入试验压力**
- 液体管道的试验压力以**最高点**的压力为准
- **最低点**的压力不得超过管道组成件的承受力

#### 试验过程与合格标准

```
缓慢升压 → 试验压力稳压10min → 降至设计压力稳压30min → 检查
```

| 阶段 | 压力 | 时间 | 检查内容 |
|-----|------|-----|---------|
| 升压 | → 试验压力 | 缓慢 | - |
| 稳压 | 试验压力 | **10min** | - |
| 稳压 | 设计压力 | **30min** | 压力表有无压降、管道所有部位有无渗漏和变形 |

#### 合格标准
- 压力表无压降
- 管道所有部位无渗漏和变形

### 3.4 管道气压试验（20年考点）

> 提示：**危险**，需特别注意安全

#### 试验压力
- 承受内压钢管及有色金属管道：设计压力的 **1.15倍**
- 真空管道：**0.2MPa**

#### 试验介质
- **干燥洁净的空气、氮气**或其他不易燃和无毒的气体

#### 安全装置
- 装设**压力泄放装置**，设定压力不得高于试验压力的 **1.1倍**

#### 试验过程与合格标准

```
预试验(0.2MPa) → 缓慢升压至50% → 每级10%逐级升压(每级稳压3min) → 试验压力稳压10min → 降至设计压力 → 发泡剂检验
```

| 阶段 | 操作要求 |
|-----|---------|
| **预试验** | 用空气进行，试验压力**0.2MPa** |
| **升压至50%** | 缓慢，如未发现异常或泄漏则继续 |
| **逐级升压** | 按试验压力的 **10%** 逐级升压，每级稳压 **3min** |
| **试验压力稳压** | **10min** |
| **降至设计压力** | 采用**发泡剂**或其他手段检验应**无泄漏** |

> 口诀：**步步惊心**（逐级升压、谨慎操作）

## 四、管道泄漏性试验（10年考点）

### 定义
以气体为试验介质，在**设计压力**下，采用发泡剂、显色剂、气体分子感测仪或其他手段检查管道系统中泄漏点的试验。

### 适用范围
- 输送**极度**和**高度危害介质**以及**可燃介质**的管道，**必须进行泄漏性试验**

### 试验要求
1. **时机**：在压力试验**合格后**进行（先强后漏）
2. **介质**：宜采用**空气**
3. **压力**：**设计压力**
4. **可结合试车一并进行**

### 试验过程
```
逐级缓慢升压 → 达到试验压力 → 停压10min → 检查所有密封点
```

### 合格标准
所有密封点应**无泄漏**

### 重点检查部位（记忆口诀：**法空罗汉排**气）
对应：**法兰**、**放空阀**、**螺纹连接处**、**阀门填料函**、**排净阀**、**排气阀**

> 经**气压试验合格**且在试验后**未经拆卸**过的管道可不进行泄漏性试验

## 五、管道真空度试验

### 定义
对管道系统抽真空，检测管道系统在规定时间内的**增压率**，以检验管道系统的**严密性**。

### 试验要求
- 真空系统在压力试验合格后，还**应按设计文件规定**进行
- 试验时间：**24h**
- 合格标准：**增压率 ≤ 5%**

### 增压率计算公式（4.2-2）

```
△P = [(P₂ - P₁) / P₁] × 100%
```

- △P —— 24h的增压率
- P₁ —— 试验初始压力（表压，MPa）
- P₂ —— 试验最终压力（表压，MPa）

## 六、核心对比表格

### 工业管道四大试验对比

| 试验类型 | 试验过程 | 试验压力 | 合格标准 | 重点检查部位 |
|---------|---------|---------|---------|------------|
| **液压试验** | 缓慢升压 → 试验压力稳压10min → 降至设计压力稳压30min | **1.5P~设~** | 压力表无压降、管道所有部位无渗漏和变形 | 管道所有部位 |
| **气压试验** | 预试验0.2MPa → 升压至50% → 每级10%逐级(3min) → 试验压力稳压10min → 降至设计压力 | **1.15P~设~** | 发泡剂检验无泄漏 | 管道所有部位 |
| **泄漏性试验** | 逐级缓慢升压 → 试验压力停压10min → 涂刷发泡剂巡回检查 | **P~设~** | 密封点无泄漏 | 法兰、放空阀、螺纹连接处、阀门填料函、排净阀、排气阀 |
| **真空度试验** | 抽真空 → 24h观测增压率 | 24h后 △P ≤ 5% | 增压率 ≤ 5% | - |

### 阀门与管道试验压力对比

| 类别 | 试验名称 | 试验压力 |
|-----|---------|---------|
| **工业阀门** | 壳体压力试验 | 工作压力的 **1.5倍** |
| | 密封试验 | 工作压力的 **1.1倍** |
| **工业管道** | 液压试验 | 设计压力的 **1.5倍**（埋地 ≥ 0.4MPa） |
| | 气压试验 | 设计压力的 **1.15倍** |
| | 泄漏性试验 | 设计压力 |
| **建筑阀门** | 强度试验 | 公称压力的 **1.5倍** |
| | 严密性试验 | 公称压力的 **1.1倍** |
| **建筑管道** | 水压试验 | 工作压力的 **1.5倍**，且 ≥ **0.6MPa** |

## 七、易混淆点总结

1. **液压 vs 气压试验压力**：液压 1.5倍 vs 气压 1.15倍 —— 气比液压低，因为气体危险
2. **泄漏性试验压力** = 设计压力（不是倍数）
3. **阀门试验压力**用工作压力，**管道试验压力**用设计压力，**建筑管道水压**用工作压力
4. **液压稳压**：试验压力10min → 设计压力30min（先高压后低压）
5. **气压升压**：50%检查 → 每级10%/3min → 逐级谨慎
6. **不锈钢管道**：水中氯离子 ≤ 25×10⁻⁶（防止氯离子应力腐蚀开裂）
7. **位差**：以最高点压力为准，最低点不超过承受力
8. **替代试验**：必须建设单位和设计单位**双同意**
9. **试验顺序**：压力试验 → 泄漏性试验 → 真空度试验（先强后漏再真空）
