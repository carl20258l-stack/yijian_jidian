## 一、防雷装置

### 1.1 输电线路的防雷装置

500kV 输电线路常用防雷方法及作用：

| 序号 | 方法 | 作用 |
|:----:|------|------|
| 1 | 架设接闪线 | 使雷直接击在接闪线上，保护输电导线不受雷击 |
| 2 | 增加绝缘子串的片数加强绝缘 | 当雷电落在线路上，绝缘子串不会有闪络 |
| 3 | 降低杆塔的接地电阻 | 快速将雷电流泄入地下，不使杆塔电压升太高，避免绝缘子被反击而闪络 |
| 4 | 装设管型接闪器或放电间隙 | 限制雷击形成过电压 |
| 5 | 装设自动重合闸 | 预防雷击造成的外绝缘闪络使断路器跳闸后的停电现象 |
| 6 | 采用消弧圈接地方式 | 使单相雷击的接地故障电流能被消弧圈所熄弧，从而故障被自动消除 |

### 1.2 不同电压等级输电线路的接闪线设置

**记忆口诀：** "500 双全线，220~330 双全线保 20~30，110 很灵活"

| 电压等级 | 接闪线设置规定 |
|----------|----------------|
| **500kV 及以上** | 全线装设**双接闪线**；输电线路愈高，保护角愈小 |
| **220～330kV** | 全线装设**双接闪线**，保护角为 **20～30°** |
| **110kV** | 全线装设接闪线；雷电特别强烈地区采用**双接闪线**；少雷区或雷电活动轻微地区可不沿线架设，但杆塔仍应随基础接地 |

**结构示意（杆塔）：**
```
  ① 导线
  ② 避雷线（接闪线）
  ③ 绝缘子
  ④ 杆塔
  ⑤ 基础
```

### 1.3 发电厂和变电站的防雷装置

| 措施 | 说明 |
|------|------|
| 预防直击雷 | 采用**接闪针**和**接闪线** |
| 限制入侵雷电波过电压幅值 | 利用**接闪器**；变电站采用**阀型接闪器**，发电厂采用**金属氧化物接闪器** |
| 进线保护 | 靠近变电站的进线，必须架设 **1～2km 的接闪线保护**，用于限制流经接闪器的雷电流和限制入侵波的陡度 |

## 二、接地装置安装要求

### 2.1 接地极安装

#### （1）金属接地极

| 项目 | 内容 |
|------|------|
| 材料 | 镀锌角钢、镀锌钢管、铜棒或铜排 |
| 类型 | 垂直接地极、水平接地极 |
| 制作方式 | 按技术要求现场加工制作 |

#### （2）接地模块（同建筑电气）

| 项目 | 要求 |
|------|------|
| 材料性质 | 导电能力优越的非金属材料，经复合加工而成 |
| 顶面埋深 | 不应小于 **0.6m** |
| 模块间距 | 不应小于模块长度的 **3～5 倍** |

### 2.2 接地线安装

#### （1）室外接地线安装

| 项目 | 要求 |
|------|------|
| 敷设方式 | 安装在沟内 |
| 沟深 | 不得小于 **0.6m** |
| 沟宽 | 不得小于 **0.5m** |
| 连接方式 | 接地干线与接地极、接地支线与接地干线之间应采用**焊接** |
| 末端露出 | 接地干线与支线末端应露出地面 **0.5m 以上** |

#### （2）室内接地线安装

| 敷设位置 | 方式 |
|----------|------|
| 明线安装 | 纵、横敷设在**墙壁上**，或敷设在母线或电缆桥架的**支架上** |
| 设备连接支线（需经过地面时） | 埋设在**混凝土内** |

## 三、真题演练

**【2013 单选】** 在雷电特别强烈地区采用双避雷线，少雷地区不设避雷线的防雷方式适合于（ ）的高压输电线路。

A. 500kV 及以上
B. 220～330kV
C. **110kV**
D. 35kV

> **答案：C**
>
> **解析：** 110kV 线路沿全线装设接闪线，在雷电特别强烈地区采用双接闪线；在少雷区或雷电活动轻微的地区，可不沿线架设接闪线。本题题干描述的正是 110kV 的规定。

## 四、核心记忆卡片

### 接闪线设置速记表

```
500kV 及以上  →  全线双接闪线（线越高保护角越小）
220～330kV    →  全线双接闪线（保护角 20～30°）
110kV         →  全线接闪线（特别强烈→双，少雷区→可不架设）
```

### 接地装置关键数字

| 项目 | 数值 |
|------|:----:|
| 接地模块顶面埋深 | ≥ 0.6m |
| 接地模块间距 | ≥ 模块长度 × 3～5 |
| 接地沟深度 | ≥ 0.6m |
| 接地沟宽度 | ≥ 0.5m |
| 接地线末端露出地面 | ≥ 0.5m |
| 变电站进线接闪线保护长度 | 1～2km |

### 防雷装置 6 种方法（助记）

"**线片阻器闸圈**" —— 接闪线、绝缘片（增加片数）、降低电阻、管型接闪器、自动重合闸、消弧圈
