## 考点1：工业管道种类与施工程序（★★）

**真题分布**：2013单 / 2015案 / 2016多 / 2019案

### 一、工业管道的种类

#### 1. 按管道材质分类
- **金属管道**
- **非金属管道**

#### 2. 按管道设计压力分类

| 类别 | 压力范围 |
|------|----------|
| 真空管道 | 低于标准大气压 |
| 低压管道 | 0 ≤ P ≤ 1.6 MPa |
| 中压管道 | 1.6 < P ≤ 10 MPa |
| 高压管道 | 10 < P ≤ 100 MPa |
| 超高压管道 | P > 100 MPa |

> 对比：石油化工设备的压力分类与此类似，注意区分。

#### 3. 按管道输送介质的设计温度分类

| 序号 | 管道类别 | 温度 t（℃） |
|:----:|----------|:------------:|
| 1 | **低温管道** | t ≤ -40 |
| 2 | **常温管道** | -40 < t ≤ 120 |
| 3 | **中温管道** | 120 < t ≤ 450 |
| 4 | **高温管道** | t > 450 |

### 二、工业管道的施工程序

#### 1. 工业管道一般施工程序（修改版）

```
测量定位 → 支架制作安装 → 管道元件、材料检查 → 管道加工（预制）、安装
→ 焊缝检测 → 管道试验 → 防腐绝热 → 管道吹扫、清洗
→ 调试及试运行 → 竣工验收
```

**记忆口诀**：~~安检师傅热情~~（已修改）

> 箭头序列记忆法：**定支检加焊试腐吹调试验**
> 定(定位) → 支(支架) → 检(检查) → 加(加工安装) → 焊(焊缝检测) → 试(试验) → 腐(防腐绝热) → 吹(吹扫清洗) → 调试(调试试运行) → 验(竣工验收)

#### 对比：室内给水系统施工程序（建筑管道）

```
预留、预埋 → 管道测绘放线 → 管道元件检验 → 管道支吊架制作安装
→ 管道加工预制 → 给水设备安装 → 管道及配件安装
→ 系统水压试验 → 防腐绝热 → 系统通水试验 → 系统冲洗、消毒
```

> 区别要点：
> - 工业管道先做支架再检查元件；建筑管道先检验元件再做支吊架
> - 工业管道有"焊缝检测"环节；建筑管道无此独立环节
> - 工业管道有"调试及试运行"；建筑管道为"通水试验"

#### 2. 工程交接验收文件

| 分类 | 内容 |
|------|------|
| **技术文件** | 管道元件产品合格证、质量证明文件、复检/试验报告；管道安装竣工图、设计修改文件及材料代用单；施工检查记录；无损检测和焊后热处理的管道，在管道轴测图上准确标明焊接工艺信息（焊缝位置、焊缝编号、焊工代号、无损检测方法、无损检测焊缝位置、焊缝补焊位置、热处理和硬度检验的焊缝位置等） |
| **施工记录** | 管道元件检查记录、阀门试验记录、管道弯管加工记录、管道焊接检查记录、焊缝返修检查记录、管道安装记录、管道隐蔽工程（封闭）记录、管道补偿装置安装记录、管道支吊架安装记录、管道静电接地测试记录、安全保护装置安装检查记录、管道系统压力试验和泄漏性试验记录、管道系统吹扫与清洗记录、管道防腐绝热施工检查记录等 |
| **试验报告** | 安全阀校验报告、磁粉检测报告、渗透检测报告、射线检测报告、超声检测报告、管道热处理报告、硬度检测报告、光谱分析及其他理化试验报告等 |

### 三、典型例题

**【例题·案例节选 2015】**

**问题**：氧气管道施工还应包括哪几道关键工序？

**参考答案**：氧气管道施工还应包括的关键工序有：管道加工（预制）、安装、焊缝检测、管道试验、防腐绝热、管道吹扫、清洗、调试及试运行、竣工验收。

> 解题思路：氧气管道属于工业管道，按工业管道一般施工程序作答即可。

### 二、工业金属管道安装前的检验（人机料法环）

#### 1. 管材及管件的检验（18、19、20）

##### （1）产品质量证明文件
- 管材及管件应有取得制造许可的制造厂的**产品质量证明文件**
- 产品质量证明文件应符合国家现行材料标准、管道元件标准、专业施工规范和设计文件的规定
- 产品质量证明文件包括：**产品合格证**和**质量证明书**
- 应盖有制造单位**质量检验章**
- 当对性能数据或检验结果**有异议时**，在异议未解决之前，**该批管道元件或材料不得使用**

##### （2）使用前检查
- 核对：**材质、规格、型号、数量和标识**
- 进行**外观质量和几何尺寸**的检查验收（直径、壁厚、结构尺寸）
- 标识应清晰完整，能够追溯到产品的质量证明文件

##### （3）材质复查（光谱分析）
- 需要进行光谱分析或其他方法复查材质的管道组成件：
  - **铬钼合金钢**
  - **含镍低温钢**
  - **镍及镍合金钢**
  - **不锈钢**
  - **钛及钛合金材料**

> 记忆：**铬含镍不钛**（铬钼合金钢、含镍低温钢、镍合金、不锈钢、钛合金）

- 材质为**不锈钢、有色金属**的管材及管件，在**运输和储存**期间**不得与碳素钢、低合金钢接触**

##### （4）特殊试验
- 设计文件规定进行**低温冲击韧性试验**的管道元件和材料
- 进行**晶间腐蚀试验**的**不锈钢、镍及镍合金钢**的管道元件或材料
- 供货方应提供试验结果文件，且试验结果不得低于设计文件的规定

---

#### 2. 阀门检验（09、10、11、17）

##### （1）外观检查
阀门应完好，开启机构应灵活，阀门应无歪斜、变形、卡涩现象，标牌应齐全。

##### （2）壳体压力试验和密封试验
试验不合格者不得使用。

###### 工业管道阀门试验参数

| 试验项目 | 介质及要求 | 试验压力 | 试验时间 | 试验温度 |
|----------|-----------|:---------:|:---------:|:---------:|
| **壳体压力试验** | 洁净水；不锈钢阀门试验时，水中氯离子含量不得超过 **25ppm**（25×10⁻⁶） | 20℃时最大允许工作压力的 **1.5倍** | 不得少于 **5min** | 5～40℃；低于5℃时应采取升温措施 |
| **密封试验** | 同上 | 20℃时最大允许工作压力的 **1.1倍** | 不得少于 **5min** | 同上 |

##### （3）特殊阀门（大尺寸低压闸阀）
- 公称压力 **< 1.0MPa**，且公称尺寸 **≥ 600mm** 的闸阀
- 壳体压力试验可按管道系统的试验压力与系统一并进行试压
- 闸板的密封试验可用**色印**等方法对密封面进行检查，结合面上的色印应连续

##### （4）安全阀校验
- 应按照设计文件和有关特种设备安全技术规范的规定
- 委托**有资质的检验机构**进行整定压力调整和密封试验
- 校验应做好**记录、铅封**，并出具校验**报告**

---

### 对比记忆：工业管道 vs 建筑管道阀门试验

| 项目 | 工业管道 | 建筑管道（严强建） |
|:----|:---------|:------------------|
| 试验名称 | 壳体压力试验 / 密封试验 | 强度试验 / 严密性试验 |
| 检验数量 | — （逐个） | 每批（同牌号、同型号、同规格）抽查10%，且不少于一个；主干管上起切断作用的闭路阀门逐个做 |
| 压力基准 | 20℃时最大允许工作压力的 1.5倍 / 1.1倍 | 公称压力的 1.5倍 / 1.1倍 |

> 记忆技巧：**建筑管道 = 严强建**（严密性试验、强度试验、建筑管道）
> 注意工业管道用"壳体压力试验"和"密封试验"，建筑管道用"强度试验"和"严密性试验"——名称不同、抽查比例不同、压力基准不同。

## 复习提示

1. **施工程序**是高频考点，注意工业管道与建筑管道的程序差异，以及2015年案例中对于改造后工序的考察形式
2. **基本识别色**八类颜色要重点记忆，2025年刚考过单选，仍有再考可能
3. **阀门检验**参数表中数字（1.5倍 / 1.1倍 / 5min / 25ppm / 5～40℃）极易出单选和案例填空
4. **对比表格**是案例题常用出题方式，尤其是工业管道与建筑管道在阀门试验要求上的差异
5. **安全阀校验关键词**：有资质机构、整定压力、密封试验、记录、铅封、报告
