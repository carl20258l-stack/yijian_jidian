## 一、金属储罐的分类及其结构特点

### 1.1 金属储罐的分类

**按顶部结构形式分类：**

| 大类 | 细类 | 说明 |
|------|------|------|
| 固定顶储罐 | 拱顶储罐 | 带肋壳拱顶罐 / 网壳顶拱顶罐 |
| 浮顶储罐 | 外浮顶储罐 | 浮顶暴露于大气 |
| | 内浮顶储罐 | 浮顶位于固定顶内 |

**按本体结构形式分类：**

| 类型 | 说明 |
|------|------|
| 单层储罐 | 罐壁为单层，如一般金属油罐 |
| 双层储罐 | 平底双壁圆柱形，内外壁不同材质，如 LNG 常压低温储罐（-162℃） |

### 1.2 金属储罐的结构特点

| 序号 | 类型 | 分类 | 特点 / 应用 |
|:---:|------|------|-------------|
| 1 | **固定顶拱顶储罐** | 带肋壳拱顶罐 | 施工容易、造价低 |
| | | 网壳顶拱顶罐 | 特大型拱顶罐（尤其是特大型内浮顶罐）已较多采用 |
| 2 | **浮顶储罐** | 外浮顶储罐 | 可减少/防止罐内液体蒸发损失；大型储油罐大多采用 |
| | | 单盘式浮顶罐 | 浮顶周边为环形密封舱（浮船），浮船内设径向隔板分隔为若干独立舱室；浮船中间为单层盘板，与船舱通过环形角钢相接，单层板底部用数道环形型钢圈加固 |
| | | 双盘式浮顶罐 | 稳定性好，能承受较大载荷，绝热性能较好，但钢材用量大 |
| 3 | **内浮顶储罐** | — | 非金属整体式内浮顶造价昂贵，国内很少采用；主要用于储存汽油、航空煤油等 |
| 4 | **LNG（常压低温）储罐** | — | 单容罐、双容罐、全容罐 |

## 二、气柜分类及结构结构特点

### 2.1 金属气柜的分类

| 类别 | 细类 | 说明 |
|------|------|------|
| **湿式气柜** | 直升式气柜 | 导轨为带外导架的直导轨 |
| | 螺旋式气柜 | 导轨为螺旋形 |
| | *按活动塔节* | 单节气柜 / 多节气柜 |

| | 橡胶膜密封干式气柜 | 同上 |

## 三、金属储罐的安装方法和施工要求

金属储罐的安装方法主要有 **正装法** 和 **倒装法** 两种。

### 3.1 正装法施工

**原理**：罐底板铺设完成后，罐壁板 **自下而上** 依次组装焊接，最后组焊完成顶层壁板、抗风圈及顶端包边角钢等。

**适用范围**：较适用于 **大型浮顶罐**。

**施工方法**：

| 方法 | 施工特点 |
|------|------|
| 水浮正装法 | — |
| 外搭脚手架正装法 | 脚手架 **随罐壁板升高而逐层搭设**；壁板内侧挂设 **移动小车** 进行内侧施工；用吊车吊装壁板；适合于 **大型和特大型储罐**，便于自动焊作业 |
| 内挂脚手架正装法 | 对一圈壁板就在壁板内侧沿圆周挂上一圈 **三脚架**，铺设跳板组成环形作业平台；一台储罐施工宜用 **2层至3层脚手架**，脚手架 **从下至上交替使用**；罐壁外侧挂设 **移动小车** 进行外侧施工；用吊车吊装壁板 |

> **记忆口诀**（特别提示）：
> - 外搭脚手架正装法 → **"外搭内小车"**（外搭脚手架 + 内侧移动小车）
> - 内挂脚手架正装法 → **"内挂外小车"**（内挂脚手架 + 外侧移动小车）

#### 外搭脚手架正装法 vs 内挂脚手架正装法对比

| 项目 | 外搭脚手架正装法 | 内挂脚手架正装法 |
|------|:---:|:---:|
| 脚手架搭设方式 | 随壁板升高逐层搭设 | 沿圆周挂设三脚架并铺跳板 |
| 内侧施工 | 内侧挂设移动小车 | 在三脚架跳板上作业 |
| 外侧施工 | 在外侧脚手架上作业 | 外侧挂设移动小车 |
| 适用 | 大型和特大型储罐 | 各类储罐 |
| 自动焊 | 便于自动焊 | — |

### 3.2 倒装法施工

**原理**：罐底板铺设 → 完成底板边缘板外侧 300mm 对接焊缝焊接及无损检测 → 组装焊接顶层壁板及包边角钢、罐顶 → **自上而下** 依次组装焊接每层壁板，直至底层壁板。

**施工方法**：

| 方法 | 说明 |
|------|------|
| 中心柱组装法 | — |
| 边柱倒装法 | 液压提升 / 葫芦提升等 |
| 充气顶升法 | — |
| 水浮顶升法 | — |

### 4.2 罐底安装

| 步骤 | 要求 |
|:---:|------|
| 定位划线 | 基础上用经纬仪划出十字线，划出底板外圆周线；按排版图在基础圈梁上标出底板、边缘板位置 |
| 底板铺设 | **由中心向外铺设**，做好中心标志，留出伸缩缝 |
| 中幅板尺寸 | 宽度 ≥ **500mm**，长度 ≥ **1000mm** |
| 焊缝间距 | 相邻两焊接接头距离及边缘板焊接接头至底圈罐壁纵焊缝距离 ≥ **300mm** |
| 边缘板外侧 | 300mm 对接焊缝先行组焊并进行 **射线探伤检测**；焊后按罐体半径在罐内侧焊好限位铁 |

### 4.3 顶圈壁板安装

**组装精度要求**：

| 检查项目 | 允许偏差 | 测量方法 |
|----------|:--------:|:--------:|
| 垂直度（组装时） | ≤ 3mm | 磁力线锤 |
| 垂直度（立缝焊接后） | ≤ 4mm | 磁力线锤 |
| 相邻壁板上口水平度 | ≤ 2mm | 每3m间隔测一点 |
| 任意两点水平度偏差 | ≤ 6mm | — |
| 底部半径偏差（椭圆度） | ±13mm | 圆周上均匀测量 8 点 |

**壁板立缝组对**：
- 采用专用组对工具，每道立缝设置 **3 块以上弧形加强板**
- 待立缝内侧 **清根**（清除焊缝根部的杂质、缺陷）后焊接完毕才能拆除
- 顶圈壁板组对留 **一道活动口**，其他立缝焊接后根据周长误差处理
- 活动口组对时严格控制壁板垂直度，用带加减丝的斜撑调节找正

### 4.4 包边角钢安装

| 项目 | 要求 |
|------|------|
| 对接缝位置 | 包边角钢本身对接缝须离开壁板立缝 **300mm 以上**（**一建说法，不同于二建**） |
| 水平度测量 | 用 **U型管** 或 **水准仪** 测量，允许偏差与壁板相同 |
| 焊接顺序 | **先焊内侧断续焊，后焊外侧角缝** |
| 焊高要求 | 焊接高度 ≥ 壁板厚度 |
| 焊工布置 | 焊工 **均匀分布，同向施焊** |

### 4.5 顶板安装

**安装步骤**：
1. 设立临时立柱和中心支撑圈
2. 对称吊装 **瓜皮板**

**焊接要求**：

| 顺序 | 要求 |
|:---:|------|
| 第一步 | **先焊内侧的短焊缝，后焊外侧的搭接角缝**，焊角高度必须符合要求 |
| 第二步 | 径向长缝 **由中心向外分段退步焊** |
| 第三步 | 与包边角钢的角缝：焊工 **均布，沿同一方向分段退步焊接** |

### 4.6 圈板组焊

- 按排版图吊装第二圈板
- 其后各圈罐壁纵向焊缝宜 **向同方向错开板长的 1/3，且 ≥ 300mm**
- 用连接板、楔铁及加强板连接
- 垂直度、局部凹凸度及上口水平度要求与顶圈壁板相同

### 4.7 焊接要求汇总

#### （1）环缝焊接
- 焊工 **均布**，焊接层次和焊接方向同步
- **严禁**在同一地方焊接若干层
- 焊接顺序：**先外侧后内侧**，焊内侧时应先 **清根**
- 切除调节焊缝处多余的钢板预留量，完成调节焊缝和相连环缝焊接

#### （2）底板焊接顺序（**高频考点**）
```
先焊中幅板 → 后焊边缘板
先焊短缝   → 后焊长缝
焊工均布，隔缝焊接，分段退焊，严禁一遍成型
罐底收缩缝 → 在底圈壁板和罐底板之间的角缝施焊完后才能进行
```

> **注意**：底板排板图上注明焊接顺序，并向班组交底。

#### （3）拱顶焊接顺序
```
先焊内侧断续焊 → 后焊外部连续焊
先焊环向短缝   → 再焊径向长缝
由拱顶中心向外分段退步焊
包边角钢与顶板的环缝：焊工均布，沿同一方向分段退步焊，不得超量焊接
```

### 4.8 预防变形的技术措施（★★★ **高频考点** 23/24）

#### 组装技术措施

| 序号 | 措施 |
|:---:|------|
| 1 | 储罐排板要符合规范要求，焊缝要 **分散、对称布置** |
| 2 | 底板边缘板对接接头采用 **不等间隙**，间隙 **外小内大** |
| 3 | 采用 **反变形措施**，在边缘板下安装楔铁，补偿焊缝的角向收缩 |
| 4 | 用 **弧形护板** 定位控制纵缝的角变形 |

#### 焊接技术措施
- 根据 **焊接工艺评定报告**，编制合理的 **焊接作业指导书**
- 采取 **对称焊、分段焊、跳焊** 等方法减少焊接变形

### 4.9 矫正焊接变形技术措施

| 方法 | 说明 |
|------|------|
| **机械矫正** | 龙门架、千斤顶、锤击法 |
| **火焰加热矫正** | 火焰加热急冷，局部收缩；矫正壁板时可采用 **梅花点状加热** 增强效果 |

### 4.10 罐外观尺寸检查（验收标准）

| 检查项目 | 允许偏差 |
|----------|:--------:|
| 罐壁铅垂 | ≤ 罐壁高的 **4/1000**，且 ≤ **50mm** |
| 壁板局部凹凸变形及底圈板半径 | **±13mm** |
| 高度偏差 | ≤ **50mm** |
| 底板焊接后局部凹凸变形 | ≤ 变形长度的 **2%**，且 ≤ **50mm** |
| 罐顶局部变形（弦长 > 2m 样板检查） | ≤ **15mm** |
| 罐壁工卡具焊迹 | 清除干净，焊疤打磨平滑 |

### 4.11 储罐试验

#### （1）罐底严密性试验

| 项目 | 要求 |
|------|------|
| 方法 | **真空箱试漏法** |
| 真空度 | ≥ **53kPa** |
| 检查方式 | 焊缝表面涂刷肥皂水 |
| 合格标准 | 无气泡、无渗漏 |

#### （2）罐壁的严密性和强度试验

**试验前准备**：
- 所有储罐附件安装完毕并检验合格
- 补强板圈进行 **0.15MPa 表压气密性试验** 并合格

**充水试验要求**：

| 项目 | 要求 |
|------|------|
| 试验介质 | 洁净淡水 |
| 水温 | ≥ **5℃** |
| 氯离子含量（不锈钢罐） | ≤ **25×10⁻⁶**（ppm） |
| 沉降观测 | 充水试验中应进行基础沉降观测 |

**沉降控制指标**：

| 情况 | 处理措施 |
|:---:|----------|
| 圆周任何 **10m 范围内不均匀沉降 ≥ 13mm** | **立即停止充水**，采取有效处理后方可继续 |
| 整体均匀沉降 ≥ **50mm** | **立即停止充水**，采取有效处理后方可继续 |

**充水试验步骤**：

```
Step 1: 打开透光孔，不得使基础浸水
Step 2: 先注水至罐高 1/2，观察 24h，确认基础沉降差值在设计范围内
Step 3: 继续注水至设计充水高度，静置 48h
Step 4: 罐壁无异常变形、焊缝无渗漏 → 严密性和强度试验合格
```

## 五、经典真题

### 【2023 单选】

**题目**：关于金属立式拱顶罐底板施工的说法，正确的是（ ）。

A. 储罐底板排版应考虑焊缝要集中  
B. 中幅板焊接先焊长缝，后焊短缝  
C. 在边缘板下安装楔铁，补偿焊缝的角向收缩  
D. 底板边缘板对接接头采用外大内小不等间隙  

**答案**：**C**

**解析**：
- A 错误：焊缝应 **分散、对称布置**
- B 错误：中幅板焊接先焊 **短缝**，后焊 **长缝**
- C 正确：采用反变形措施，在边缘板下安装楔铁，补偿焊缝角向收缩
- D 错误：间隙 **外小内大**

### 【2024 多选】

**题目**：圆柱形金属储罐制作时，为防止变形而采用的措施有（ ）。

A. 储罐排板时应尽量使焊缝集中  
B. 储罐排板时安排焊缝对称布置  
C. 采取对称焊方法减少焊接变形  
D. 边缘板对接接头间隙外大内小  
E. 用弧形板定位控制纵缝角变形  

**答案**：**BCE**

**解析**：
- A 错误：焊缝应 **分散** 布置
- B 正确：焊缝 **对称布置**
- C 正确：对称焊、分段焊、跳焊等焊接技术措施
- D 错误：间隙 **外小内大**
- E 正确：用弧形护板定位控制纵缝角变形
