# 4.7 金属球罐、设备钢结构制作安装

---

## 考点一：金属球罐安装技术（★）

> **真题分布**：2022 单选

### 一、球形罐的构造及形式

#### 1. 构造
球形罐由 **球罐本体、支座（或支柱）及附件** 组成。

#### 2. 形式（三种）
| 形式 | 说明 |
|------|------|
| 桔瓣式球形罐 | 按桔瓣形状分片 |
| 足球式球形罐 | 按足球皮形状分片 |
| 混合式球形罐 | 桔瓣与足球混合 |

---

### 二、球壳和零部件的检查验收

#### 1. 质量证明文件检查

球形罐质量证明书包括：
- 制造竣工图样
- 压力容器产品合格证
- 产品质量证明文件
- 特种设备制造监督检验证书

#### 2. 球壳板及零部件检查

球壳板的型式与尺寸应符合图样要求，表面不允许存在 **裂纹、气泡、结疤、折叠和夹杂** 等缺陷，球壳板不得有 **分层**。

#### 3. 球壳板超声波测厚

| 项目 | 要求 |
|------|------|
| 抽查数量 | ≥ 球壳板总数的 **20%**，且每带 ≥ **2块**，上、下极 ≥ **1块** |
| 每张测点 | ≥ **5点** |
| 判定 | 实测厚度 ≥ 设计厚度 |
| 不合格处理 | 加倍抽查 → 仍不合格 → **100%** 超声波测厚检查 |

#### 4. 球壳板超声波探伤

| 项目 | 要求 |
|------|------|
| 检查范围 | 球壳板周边 **100mm** 范围 |
| 被抽查数量 | ≥ 球壳板总数的 **20%**，且每带 ≥ **2块**，上、下极 ≥ **1块** |
| 超标处理 | 加倍抽查 → 仍有超标 → **100%** 检验 |

#### 5. 产品试板检查

| 项目 | 要求 |
|------|------|
| 数量 | 每台球罐 **6块** 焊接试板 |
| 尺寸 | **600mm × 180mm** |
| 检测标准 | NB/T 47016-2023《承压设备产品焊接试件的力学性能检验》 |
| 材料要求 | 与球罐材料 **相同标准、相同牌号、相同厚度、相同热处理状态** |
| 坡口形式 | 与球壳板 **相同** |

---

### 三、球形罐组装

#### 组装方法

| 方法 | 说明 |
|------|------|
| **散装法** | 以单块球壳板（或几块球壳板）为最小组装单元 |
| **分带组装法** | 分带组装 |

#### 散装法施工程序（5带球形罐）

> **记忆口诀**：中间 → 两端，先下后上

```
支柱和赤道板组对 → 赤道带板组装 → 中心柱安装
  → 下温带板组装 → 上温带板组装 → 中心柱拆除
  → 下极板组装 → 上极板组装 → 内外脚手架搭设
  → 调整及组装质量总体检查
```

---

### 四、焊接要求（22单）

> **核心原则**：先纵后环、先短后长、先深后浅、对称同步

| 要求 | 具体内容 |
|------|---------|
| **焊接程序** | 先焊 **纵缝**，后焊 **环缝**；先焊 **短缝**，后焊 **长缝**；先焊 **坡口深度大** 的一侧，后焊 **坡口深度小** 的一侧 |
| **焊工分布** | **对称分布、同步焊接** |
| **长度差控制** | 同等时间内超前或滞后的长度 ≤ **500mm** |
| **第一层焊道** | 焊条电弧焊的第一层焊道应采用 **分段退焊法** |
| **多层多道焊** | 每层焊道引弧点宜依次错开 **25～50mm** |

> **2022 真题**：球形罐壁板焊接措施不包括（  ）
> A. 先纵缝后环缝  B. 同一方向施焊  C. 定位板固定  D. 分段退焊
> **答案：C**
> 解析：定位板固定不属于焊接措施选项中的直接焊接工艺措施。

---

### 五、球形罐焊后整体热处理

#### 热处理工艺实施

##### （1）热处理方法——内燃法

| 方法 | 适用范围 |
|------|---------|
| **负压内燃法** | 2000m³ **以下** 的球形罐 |
| **正压内燃法** | 2000m³ **及以上** 的球形罐 |

**原理**：用燃烧产生的烟气在球形罐内部加热并进行温度控制，球罐外部保温而达到热处理要求的工艺温度。

**测温**：在罐体上安装 **热电偶** 测量加热温度，采用智能化微电脑操作温控仪。

##### （2）外保温材料
宜采用 **岩棉** 或 **超细玻璃棉**。

## 考点二：设备钢结构制作与安装技术（★★★）

> **高频考点**！真题分布：2009单、2017单、2019多、2020多、2021单、2022案、2023案

---

### 一、钢结构制作（22单）

#### 1. 制作内容

| 类别 | 内容 |
|------|------|
| **零（部）件加工** | 各种杆件、节点板、筋板、支座、焊接球、螺栓球等 |
| **钢结构预制** | H型钢、钢柱、钢梁（吊车梁）、钢桁架、墙架、檩条、支撑、钢平台板、钢梯、金属压型板等 |

#### 2. 制作程序

```
原材料检验（钢材、焊材、连接用紧固件等）
  → 排料、拼接
  → 放样与号料
  → 切割、下料
  → 制孔
  → 矫正和成型
  → 构件装配
  → 焊接
  → 除锈、涂装（油漆）
  → 构件编号、验收出厂
```

#### 3. 变形矫正

| 加工类型 | 钢种 | 温度要求 |
|---------|------|---------|
| **冷校正、冷弯曲** | 碳素结构钢 | 环境温度 **< -16℃** 时，不应进行冷矫正和冷弯曲 |
| **冷校正、冷弯曲** | 低合金结构钢 | 环境温度 **< -12℃** 时，不应进行冷矫正和冷弯曲 |
| **加热矫正** | 碳素结构钢 | 加热温度 **700～800℃**，最高 ≤ **900℃**，最低 ≥ **600℃** |
| **加热矫正** | 低合金结构钢 | 加热温度 **700～800℃**，最高 ≤ **900℃**，最低 ≥ **600℃**；加热后应 **自然冷却** |

> **矫正后质量要求**：表面不应有明显凹面或损伤，划痕深度 ≤ **0.5mm**，且 ≤ 钢材厚度允许负偏差的 **1/2**。

---

### 二、钢结构安装

#### 一般安装程序

> **记忆口诀**：钢之郎平（钢柱 → 支撑 → 梁 → 平台板）

```
钢柱安装 → 支撑安装 → 梁安装 → 平台板（层板、屋面板）、钢梯、防护栏安装 → 其他构件安装
```

#### 高强度螺栓连接要求（高频考点）

> **真题分布**：2017单、2019多、2020多、2023案

##### （1）摩擦面处理
| 项目 | 要求 |
|------|------|
| 抗滑移系数试验 | 制作和安装单位应 **分别** 进行试验和复验 |
| 现场处理 | 摩擦面应 **单独** 进行抗滑移系数试验 |
| 手工砂轮打磨 | 打磨方向应与 **受力方向垂直** |

##### （2）施拧方法

| 螺栓类型 | 施拧方法 |
|---------|---------|
| **高强度大六角头螺栓** | **扭矩法**（公斤数）或 **转角法**（角度） |
| **扭剪型高强度螺栓** | **专业电动扳手** 施拧 |

##### （3）施工要求

| 项目 | 要求 |
|------|------|
| 扭矩扳手校正 | 使用前校正，扭矩相对误差 ≤ **±5%** |
| 穿入方向 | **一致**，能自由穿入，不得强行穿入 |
| 修孔工具 | **铰刀或锉刀**，**不得**采用气割扩孔 |
| 扩孔 | 需征得 **设计单位** 同意 |

##### （4）拧紧流程

| 步骤 | 说明 |
|------|------|
| **初拧** | 取终拧扭矩的 **50%** |
| **复拧** | 大型节点增加，扭矩 = 初拧扭矩 |
| **终拧** | 完成最终紧固 |
| **标记** | 初拧（复拧）后对螺母涂刷颜色标记 |
| **时间** | 宜在 **24h内** 完成 |
| **施拧顺序** | 由螺栓群 **中央顺序向外** 拧紧 |

##### （5）终拧检查——高强度大六角头螺栓

| 项目 | 要求 |
|------|------|
| 检查时间 | 终拧 **1h后、48h之前** |
| 检查方法 | 扭矩法或转角法（与施工方法相同） |
| 检查数量 | 节点数的 **10%**，但 ≥ **10个节点** |
| 每个节点 | 按螺栓数抽查 **10%**，且 ≥ **2个** |

##### （6）终拧检查——扭剪型高强度螺栓

| 项目 | 要求 |
|------|------|
| 合格标准 | 终拧以 **拧断螺栓尾部梅花头** 为合格（不断不达标） |
| 未拧断情况 | 未扭断梅花卡头的螺纹数 ≤ 该节点螺栓数的 **5%** |
| 处理 | 对所有未拧掉的用扭矩法或转角法进行终拧并做标记 |
| 检查数量 | 节点数的 **10%**，但 ≥ **10个节点** |

##### （7）螺栓丝扣外露

| 要求 | 允许偏差 |
|------|---------|
| 正常外露 | **2～3扣** |
| 允许偏差 | **10%** 的螺栓可外露 **1扣或4扣** |

---

### 三、钢结构安装注意事项

| 序号 | 内容 |
|------|------|
| 1️⃣ | **多节柱安装**：每节柱的定位轴线应从 **地面控制轴线直接引上**，不得从下层柱的轴线引上（避免累积误差） |
| 2️⃣ | **钢网架结构**：总拼完成后 **及** 屋面工程完成后应分别测量其 **挠度值**，所测挠度值 ≤ 相应设计值的 **1.15倍** |
| 3️⃣ | **涂装**：涂料、涂装遍数、涂层厚度均应符合设计要求 |
| 4️⃣ | **防火涂料厚度**：薄涂型 → 符合耐火极限设计要求；厚涂型 → **80%及以上面积** 符合要求，且 **最薄处 ≥ 设计要求的 85%** |

> **2009 真题**：钢网架结构总拼完成后应测量其挠度值，所测挠度值不应超过相应设计值的（  ）倍
> A. 1.10  B. 1.15  C. 1.20  D. 1.25
> **答案：B**

## 例题精讲

### 例题 1（2022 单选）
球形罐壁板焊接措施不包括（  ）
- A. 先纵缝后环缝
- B. 同一方向施焊
- C. 定位板固定
- D. 分段退焊
- **答案：C**
- **解析**：焊接程序为先纵缝后环缝、先短缝后长缝、先坡口深度大一侧后坡口深度小一侧；焊工对称分布同步焊接；焊条电弧焊第一层用分段退焊法。定位板固定不属于焊接工艺措施。

### 例题 2（2020 多选）
关于高强度螺栓连接紧固的说法，正确的有（  ）
- A. 紧固用的扭矩扳手在使用前应校正
- B. 高强度螺栓安装的穿入方向应一致
- C. 高强度螺栓的拧紧宜在 24h 内完成
- D. 施拧宜由螺栓群一侧向另一侧拧紧
- E. 高强度螺栓的拧紧应一次完成终拧
- **答案：ABC**
- **解析**：
  - A ✅ 扭矩扳手使用前校正，误差 ≤ ±5%
  - B ✅ 穿入方向应一致，能自由穿入
  - C ✅ 拧紧宜在 24h 内完成
  - D ❌ 应由螺栓群中央顺序向外拧紧
  - E ❌ 分为初拧和终拧（大型节点增加复拧）
