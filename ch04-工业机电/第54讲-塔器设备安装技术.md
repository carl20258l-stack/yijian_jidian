## 1. 塔器设备

### 1.1 塔器结构

- 塔器为**长细圆筒形焊接结构**的**固定式压力容器**
- 组成：**筒体、封头、人孔、接管、裙座**

### 1.2 生产工艺

- 塔器是专门为某种生产工艺要求而设计、制造的非标准设备
- 用途：用于**蒸馏、抽提、吸收、精制**等分离过程的直立式工艺设备

### 1.3 到货状态（三种）

| 到货状态 | 说明 |
|----------|------|
| **整体**到货 | 工厂制造，整体运输到现场安装 |
| **分段**到货 | 体积（几何尺寸）大，受运输条件限制，分段运输到现场组装 |
| **分片**到货 | 同上，分片运输到现场组装；或为节约运输成本，制造商直接在现场建设超限厂房进行设备制造 |

> **记忆口诀**：整体小，分段中，分片大——看尺寸和运输条件确定。

---

## 2. 安装前工序内容

### 2.1 开箱检验

#### （1）核对装箱单

- 塔体、内件和安全附件应符合**设计文件和订货合同**的要求
- 开箱检验应在相关人员参加下按照装箱单清点并检查：
  - **箱号、箱数及包装**
  - **产品名称、型号及规格**
  - **产品质量证明文件**
  - **塔内件及安全附件的规格、型号、数量**

#### （2）塔体外观质量检查

- 无表面损伤、变形及锈蚀
- 塔体采用不锈钢或复合钢板材料的**腐蚀介质接触面**，低温设备表面**不应有刻痕**和各类钢印标记
- **奥氏体不锈钢、钛、锆、铝**材料的塔体表面，应**无铁离子污染**
- 塔体方位线标记、重心标记及吊挂点等**标记清晰**

#### （3）分段到货验收（2024案）

| 检查项目 | 要求 |
|----------|------|
| 塔体分段处的**圆度** | 符合相关规定 |
| **外圆周长偏差** | 符合相关规定 |
| **端口不平度** | 符合相关规定 |
| **坡口质量** | 符合相关规定 |
| 筒体**直线度** | 符合相关规定 |
| 筒体**长度** | 符合相关规定 |
| 筒体上接管**中心方位和标高**的偏差 | 符合相关规定 |
| **组装标记** | 清晰 |

**裙座底板地脚螺栓孔允许偏差**（全部为 2mm）：

| 项目 | 允许偏差 |
|------|----------|
| 地脚螺栓孔**中心圆直径** | 2mm |
| **相邻**两孔弦长 | 2mm |
| **任意**两孔弦长 | 2mm |

> **【2024案例】** 丙烷制冷塔长度71m，分两段到货，现场组焊，整体吊装。
>
> **问题**：塔体现场验收还应检查哪些项目？地脚螺栓孔中心圆直径允许偏差是多少？
>
> **答案**：
> 1. 还应检查：**外圆周长偏差、端口不平度、组装标记清晰**
> 2. 地脚螺栓孔中心圆直径允许偏差为 **2mm**

### 2.2 基础验收

| 验收项目 | 要求 |
|----------|------|
| 基础外观 | 不得有**裂纹、蜂窝、空洞及露筋**等缺陷 |
| 混凝土强度 | 不得低于设计强度的 **75%**，同期养护 |
| 外形尺寸、标高、表面平整度、中心线 | 复查，符合设计文件和施工规范 |
| 沉降观测点 | 有沉降观测要求的应设置 |
| 预埋地脚螺栓（数量、方位） | 符合设计文件和规范，螺纹无损坏、无锈蚀，有保护措施，螺母和垫圈齐全 |
| 基础表面处理 | 无油渍及疏松层；放置垫铁处**铲平**，以外凿成**麻面**（每100mm×100mm面积内3~5个深度不小于10mm的麻点） |

## 3. 塔器就位安装

### 3.1 整体安装程序

> **记忆口诀**：检→基→垫→吊→固→焊→灌

```
塔器检查验收 → 基准线标识 → 运放至吊装要求位置
→ 基础验收 → 设置垫铁 → 整体吊装、找正
→ 紧固地脚螺栓 → 垫铁点固 → 二次灌浆
```

### 3.2 塔器就位

- 取塔设备**任意相邻的方位线**作为**垂直找正基准**
- 测量点1与塔中心线的连线与测量点2与塔中心线的连线成 **90°夹角**（2024案）

#### 垂直度允许偏差

| 塔高条件 | 垂直度允许偏差 |
|----------|---------------|
| 塔高 ≤ 30m | ≤ 塔高的 **1/1000** |
| 塔高 > 30m | ≤ 塔高的 **1/1000**，且 **不大于 50mm** |

> 高度 ≥ **20m** 的塔，垂直度测量**不应**在一侧阳光照射或风力大于 **4级** 的条件下进行。

## 4. 塔器产品焊接试件（关键词：相同）

> 依据：《固定式压力容器安全技术监察规程》TSG 21—2016

### 4.1 试板制备的要求

| 序号 | 要求 |
|------|------|
| 1 | 应由施焊塔器的**焊工**，在与施焊**相同的条件**下采用与施焊塔器**相同的焊接工艺**焊接试板 |
| 2 | 试板材料应与塔器用材具有**相同标准、相同牌号、相同厚度和相同热处理状态**（**四个相同**） |
| 3 | 试板焊接后及时打上**焊工钢印代号**，经检验员外观检查合格后，打上**检验员钢印号** |
| 4 | 塔器焊后需热处理时，试件应随焊缝一起进行**热处理** |

> **【2025多选】** 关于焊接试板材料与塔器现场组焊用材的说法正确的是？
>
> **答案**：**ABCE**（相同标准、相同牌号、相同厚度、相同热处理状态——D选项"存储地点相同"为干扰项）

### 4.2 试板的检验与评定

#### （1）外观检查和无损检测

- 合格标准与设备焊接接头的合格标准相同
- 评定依据：《承压设备产品焊接试件的力学性能检验》**NB/T 47016—2023**

#### （2）拉伸试验合格指标

| 情况 | 合格指标 |
|------|---------|
| 同一母材 | 抗拉强度 ≥ 母材标准抗拉强度最低值 |
| 不同强度等级母材组成的焊接接头 | 抗拉强度 ≥ 两种母材标准抗拉强度最低值中的**较小者** |

#### （3）弯曲试验合格指标

- 试验弯曲到规定的角度后
- **拉伸面上沿任何方向不得有单条长度大于 3mm 的开口缺陷**
- 棱角开口（除未熔合、夹渣或其他内部缺陷引起的）缺陷不计

#### （4）冲击试验合格指标

| 条件 | 要求 |
|------|------|
| 每组 | **3个**标准试件 |
| 平均值 | 符合设计文件或相关技术文件规定 |
| 母材抗拉强度下限值 ≤ 450MPa | 冲击功平均值 ≥ **20J** |
| 低于规定值 | 至多允许 **1个** 试样低于规定值，且不低于规定值的 **70%** |

### 4.3 焊接产品试件的复验

| 试验类型 | 复验规则 |
|----------|---------|
| **拉伸、弯曲**不合格 | 取**双倍**试样进行复验，达到合格指标为合格 |
| **冲击**不合格 | 再取**一组（3个）**试样进行试验；前后两组**6个**试样的冲击功平均值 ≥ 规定值；允许有 **2个** 试样小于规定值，其中小于规定值70%的只允许有 **1个** |

> **【2015单选】** 属于钢制压力容器产品焊接试板力学性能试验的是？
>
> **答案**：**D. 弯曲试验**
>
> **解析**：试板的试验项目至少包括**拉伸试验、弯曲试验、冲击试验**，不合格项目应进行复验。

## 5. 耐压试验

### 5.1 水压试验

| 项目 | 要求 |
|------|------|
| 试验介质 | 宜采用**洁净淡水** |
| 氯离子限制 | 奥氏体不锈钢制塔器，水中氯离子含量 **≤ 25×10⁻⁶** |
| 水温 | 不得低于 **5℃** |
| 压力表 | 最高点与最低点各设置一块，量程相同，精度 **≥ 1.6级**，量程 **1.5~3倍试验压力** |
| 试验压力取值 | 以装设在设备**最高处**的压力表读数为准 |
| 升压过程 | 排净气体 → 充满液体 → 外表面保持干燥 → 壁温与液体温度接近时升压至设计压力 → 确认无泄漏 → 升至试验压力 |
| 保压时间 | 不少于 **30min** |
| 降压检查 | 降至设计压力，保压足够时间，全面检查焊接接头和连接部位 |
| 合格标准 | 无渗漏、无可见变形、试验过程中无异常声响 |
| 试验后处理 | 排尽液体，用**压缩空气**将内部吹干 |

### 5.2 气压试验

#### （1）代替液压试验的条件

| 容器类型 | 检测要求 |
|----------|---------|
| **压力容器** | 对塔筒体对接焊缝进行 **100%** 射线或超声检测，符合原设计文件合格标准 |
| **常压设备** | 对接焊缝进行 **25%** 射线或超声检测，射线检测**Ⅲ**合格，超声检测**Ⅱ**合格 |

- 本单位**技术总负责人**批准的安全技术措施
- 试压系统应设置**安全泄放装置**并进行**压力整定**

#### （2）试验介质

- 宜为**干燥洁净的空气**，也可用**氮气或惰性气体**
- 脱脂后的容器进行气压试验时，必须采用**不含油气体**

#### （3）程序要求

| 步骤 | 压力 | 操作 |
|------|------|------|
| 1 | 试验压力的 **10%**（且≤0.05MPa） | 保压 **5min**，初次泄漏检查 |
| 2 | 试验压力的 **50%** | 观察有无异常现象 |
| 3 | 按 **10%** 逐级升压至试验压力 | 保压 **10min**，全面检查 |
| 4 | 检查期间 | 保持压力不变，**不得**采用继续加压维持压力 |

#### （4）合格标准

- 试验过程中**无异常的响声**
- 经过**肥皂液或其他检漏液**检验**无漏气**
- **无可见变形**
- 对标准抗拉强度下限值 ≥ **540MPa** 的塔器，泄压后进行**表面无损检测**抽查未发现裂纹

## 知识对比总结

### 水压试验 vs 气压试验

| 对比项 | 水压试验 | 气压试验 |
|--------|---------|---------|
| 介质 | 洁净淡水（氯离子≤25×10⁻⁶） | 干燥洁净空气/氮气/惰性气体 |
| 安全性 | 较安全 | 危险性大，需批准 |
| 检测要求 | 无额外要求 | 压力容器100% RT/UT；常压25% RT/UT |
| 保压时间 | ≥30min（试验压力） | 10min（试验压力） |

### 塔器验收核心数字速记

| 数字 | 对应内容 |
|------|---------|
| **2mm** | 裙座地脚螺栓孔偏差（中心圆直径、相邻弦长、任意弦长） |
| **75%** | 基础混凝土强度要求 |
| **1/1000** | 塔器垂直度允许偏差（≤30m时） |
| **50mm** | 塔器垂直度允许偏差上限（>30m时） |
| **20m** | 垂直度测量避免阳光/大风的条件界限 |
| **4级** | 风力大于4级不测垂直度 |
| **5℃** | 水压试验最低水温 |
| **25×10⁻⁶** | 奥氏体不锈钢水压试验氯离子限值 |
| **30min** | 水压试验保压时间 |
| **10min** | 气压试验保压时间 |
| **0.05MPa** | 气压试验初次检查压力上限 |
| **3mm** | 弯曲试验拉伸面开口缺陷上限 |
| **20J** | 冲击功平均值下限（抗拉强度≤450MPa时） |
| **70%** | 冲击功单个试样最低占比 |
| **6个** | 冲击复验前后组总试样数 |
| **540MPa** | 气压试验后需表面无损检测的抗拉强度界限 |

## 本章易混淆点提醒

1. **四个相同**（试板材料）：相同标准、相同牌号、相同厚度、相同热处理状态——注意不包括"相同存储地点"
2. **拉伸/弯曲 vs 冲击**的复验规则不同：前者取双倍试样，后者取一组（3个）
3. 水压试验压力表取**最高处**读数为准；两块表精度不低于**1.6级**
4. 塔器垂直度偏差异步：30m分界，>30m有50mm上限
5. 气压试验代替液压试验时，压力容器和常压设备的检测比例不同（100% vs 25%）
