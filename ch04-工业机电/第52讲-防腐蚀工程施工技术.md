## 4.5.1 防腐蚀措施和施工方法（★★★）

**真题分布**：2010单 / 2018单、案 / 2019单 / 2021单 / 2022单 / 2024单 / 2025单

### 一、材料腐蚀

材料腐蚀是指材料受其周围环境介质的**化学、电化学和物理作用**下引起失效破坏的现象。

### 二、金属腐蚀的分类和特点

#### 1. 按破坏形式分类

| 分类 | 子类 | 特点 |
|------|------|------|
| **全面腐蚀** | 均匀腐蚀、不均匀腐蚀 | 发生在金属材料**整个表面**，导致金属**减薄** |
| **局部腐蚀** | 点蚀（孔蚀）、缝隙腐蚀、电偶腐蚀、晶间腐蚀、选择性腐蚀 | 集中发生在**特定局部区域**，其余部分轻微或未发生 |

#### 2. 按机理分类

| 分类 | 定义 | 特点 |
|------|------|------|
| **化学腐蚀** | 金属与环境介质直接发生化学反应 | 单纯的化学反应，**无电流产生**，腐蚀产物直接覆盖 |
| **电化学腐蚀** | 金属与环境介质发生电化学作用 | **有电流产生** |
| **物理腐蚀** | 金属由于单纯的物理溶解作用 | 在**液态金属**中可发生 |

> **2024年考过**：按机理分类的判断题。

### 三、金属材料的防腐蚀方法

| 方法 | 具体内容 | 举例 |
|------|----------|------|
| **介质处理** | 去除有害成分、调节 pH 值、改变湿度 | 锅炉给水除氧；原油脱出水及腐蚀性成分 |
| **覆盖层** | 涂料涂层、金属涂层、衬里 | — |
| **电化学保护** | 阴极保护（强制电流 / 牺牲阳极） | — |
| **添加缓蚀剂** | 在介质中添加少量物质抑制腐蚀 | — |

### 四、防腐蚀施工方法

#### （一）表面处理

表面处理指在涂装前，**除去工件表面附着物、生成的氧化物以及提高表面粗糙度**，提高附着力或赋予表面耐蚀性能的过程。

表面处理的质量等级包括：**除锈等级**及**表面粗糙度**。

##### 1. 钢材表面锈蚀程度（A~D 四级）

| 等级 | 内容（由轻到重） |
|------|------------------|
| **A** | 大面积覆盖氧化皮，**几乎没有铁锈** |
| **B** | 已发生锈蚀，氧化皮已开始**剥落** |
| **C** | 氧化皮因锈蚀剥落或可刮除，可见**轻微点蚀** |
| **D** | 氧化皮因锈蚀剥落，可见**普遍发生点蚀** |

##### 2. 表面除锈处理方法

| 方法 | 具体内容 |
|------|----------|
| **化学除锈** | 酸洗除锈、碱洗除锈（浸泡、喷淋） |
| **工具除锈** | 手动：钢丝刷、粗砂纸、铲刀、刮刀；动力：旋转钢丝刷、电动砂轮 |
| **喷（抛）射除锈** | 干喷射、湿喷射、喷砂、喷丸、喷粒、高压水 |
| **火焰除锈** | — |

> **2018案例考过**：钢筒外表面除锈应采取的方法——喷射或抛射除锈。

##### 3. 工具除锈技术要点

- 工具除锈分为**手动**和**动力**工具除锈两种
- 质量等级：
  - **St2级**：彻底的手工和动力工具除锈
  - **St3级**：非常彻底的手工和动力工具除锈

> 💡 **记忆技巧**：St = 手（手工/手动工具）

##### 4. 喷射除锈技术要点

**磨料选择**：根据钢号、种类、锈蚀程度、涂料类型、除锈方法及所要求的表面粗糙度选择。常用磨料有：**铸钢丸、铸铁丸、铸钢砂、铸铁砂及钢丝段**。

**喷射方式**：

| 方式 | 关键要点 |
|------|----------|
| **敞开式干喷射** | 压缩空气通过喷射清洁干燥磨料；压缩空气需**无油、干燥**；金属表面温度应**高于露点 3℃** |
| **封闭式循环喷射** | 封闭式循环磨料系统，干燥无油压缩空气通过**喷嘴喷射** |
| **封闭式循环抛射** | 封闭式循环磨料系统，用**离心式叶轮抛射** |
| **湿喷射** | 喷射掺水的非金属磨料；水中应掺入足量**缓蚀剂**，否则喷射后用淡水冲洗并做防锈处理 |

**喷射处理质量等级**（Sa1~Sa3）：

| 等级 | 内容 |
|------|------|
| **Sa1级** | 轻度的喷射或抛射除锈 |
| **Sa2级** | 彻底的喷射或抛射除锈 |
| **Sa2.5级** | 非常彻底的喷射或抛射除锈 |
| **Sa3级** | 使金属表观洁净的喷射或抛射除锈 |

> 💡 **记忆技巧**：Sa = 砂（喷射除锈）；St = 手（工具除锈）

##### 5. 酸洗除锈技术要点

- 酸洗前，先用工具或喷射除锈除掉大部分氧化皮、锈和旧涂层，以缩短酸洗时间
- 将金属浸入常温酸洗液，直至氧化皮和锈全部除掉；酸洗液中应加入足够**缓蚀剂**
- 金属表面达到要求后，用淡水充分冲洗干净，然后分别浸入**磷化液和钝化液**进行磷化和钝化处理
- 酸洗液中溶入铁的含量**不超过 10%**
- 酸洗后金属表面应用干净的**高压空气吹干水分**，且不应码垛堆放

#### （二）涂料涂层防腐施工方法

| 方法 | 特点 | 适用范围 |
|------|------|----------|
| **刷涂法** | 漆膜渗透性强，工具简单，适应性强；但劳动强度大、效率低、易有刷痕 | **小面积**涂装（2025真题） |
| **滚涂法** | 较刷涂法效率高 | **较大面积**工件 |
| **空气喷涂法** | 应用**最广泛**；涂层厚薄均匀、光滑平整；但涂料利用率低、污染严重（2022真题） | 几乎适用于一切涂料品种 |
| **高压无气喷涂法** | **节省漆料、减少污染、效率高、涂膜质量好**（2021真题）；无涂料回弹和漆雾飞扬 | **大面积**物体涂装 |

> **⚠️ 高频考点**：高压无气喷涂法在 2018、2021、2022 年连续出现，所有优点全部掌握。

**高压无气喷涂原理**：涂料通过加压泵加压后经喷嘴小孔喷出，高速离开喷嘴扩散成极细颗粒涂敷于工件表面。

#### （三）金属涂层防腐施工方法

**金属热喷涂分类**（按热源）：
- **燃烧法**
- **电加热法**

**工艺过程**：基体表面预处理 → 热喷涂 → 后处理 → 精加工

**常用材料**：**锌、锌铝合金、铝和铝镁合金**，分为金属丝和金属粉末两种形式。

**设备组成**：喷枪、热源、涂层材料供给装置、控制系统、冷却系统。

#### （四）衬里防腐施工方法

衬里是一种综合利用不同材料特性、具有较长使用寿命的防腐方法。

| 衬里类型 | 施工方法 | 关键要点 |
|----------|----------|----------|
| **块材衬里** | 胶泥衬砌法 | 常用胶泥：**水玻璃胶泥**和**树脂胶泥** |
| **纤维增强塑料衬里** | 铺贴法 / 喷射法 | 以树脂为粘结剂，纤维及其织物为增强材料 |
| **橡胶衬里** | 粘贴法（搭边粘合） | 包括：**加热硫化**、**自然硫化**、**预硫化**三种 |
| **塑料衬里** | 焊接、粘贴 | 软聚氯乙烯板、氟塑料板、塑料管道 |
| **铅衬里** | 衬铅 / 搪铅 | 适用于常压或压力不高、温度较低、静载荷；不适用于真空、受振动和有冲击设备（如硫酸泵、管道、阀） |
| **氯丁乳胶水泥砂浆衬里** | 整体面层涂覆 | 结构复杂的不宜选用 |

> **铅衬里提示**：铅熔点低、强度低、脆。

#### （五）阴极保护施工方法

| 系统 | 组成部分 |
|------|----------|
| **强制电流阴极保护** | 4部分：**电源设备、辅助阳极、被保护管道与附属设施** |
| **牺牲阳极阴极保护** | 3部分：**牺牲阳极、被保护管道与附属设施** |

**常用牺牲阳极材料**：镁及镁合金阳极、锌及锌合金阳极、**铝合金阳极**（主要用于海洋环境）、镁锌复合式阳极。

## 4.5.2 设备及管道防腐蚀施工技术（★）

**真题分布**：2023单

### 一、防腐蚀施工的基本要求

| 项目 | 要求 |
|------|------|
| **施工环境温度** | 10~30℃ |
| **相对湿度** | 不大于 **85%** |
| **基体表面温度** | 应比露点温度高 **3℃** |
| **涂层养护** | 全部涂装结束后按规定时间养护 |
| **基体表面处理** | 凹凸不平、焊接波纹和非圆弧拐角处用耐腐蚀树脂配制的**腻子修补** |
| **涂料使用** | 在储存期内使用；双组份涂料按质量比配制、搅拌均匀 |
| **涂层质量** | 均匀、无漏涂误涂；层数、厚度、间隔时间按工艺要求确定 |

### 二、地上设备及管道涂层施工

**底漆与面漆的涂装时机**：

| 工序 | 时机 |
|------|------|
| **底漆** | 宜在焊接施工前涂装，但**焊道两侧各 50mm 留出**；焊道底漆在焊接施工（含热处理、焊道检验）完毕、系统试验合格、办理工序交接后进行 |
| **中间漆、面漆** | 宜在焊接施工完毕、系统试验合格并办理工序交接后进行；也可在焊接施工前涂装，但焊道留出，试验合格后按要求涂装 |

**其他要点**：

- 防腐蚀涂料质量证明文件应包括：**合格证、质量检验报告和产品技术文件**
- 涂漆前应对**标识、焊接坡口、螺纹**等特殊部位加以保护
- 前一道漆膜**表干后**方可涂下一道漆
- 涂层施工方法：刷涂法、滚涂法、空气喷涂法、高压无气喷涂法

**喷涂距离与喷幅搭接**：

| 方法 | 喷嘴距被喷面 | 喷幅搭接宽度 |
|------|-------------|-------------|
| **空气喷涂** | 大口径喷枪 200~300mm；小口径 150~250mm | 有效喷幅宽度的 **1/4~1/3** |
| **高压无气喷涂** | 300~500mm（太近→堆积流挂；太远→干喷过喷） | 有效喷幅宽度的 **1/6~1/4** |

**高压无气喷涂距离不当的后果**：
- 太近 → 涂料堆积，漆膜厚度过大甚至流挂
- 太远 → 干喷或过喷，涂料不能有效呈液态附着形成连续漆膜

**涂层质量检查**：

| 检查项目 | 质量要求 | 检查方法 |
|----------|----------|----------|
| **外观质量** | 表面平整、色泽一致，无流挂、起皱、脱皮、返锈、漏涂 | 目测、5~10倍放大镜 |
| **干膜厚度** | 均匀一致，层数和厚度符合设计规定 | 磁性（涡流）测厚仪 |
| **附着力**（如需） | 符合设计及相关规范要求 | 划格法、拉开法 |
| **漏涂**（如需） | 针孔漏点数量符合要求 | 电火花检测仪 |

### 三、衬里

#### 1. 块材衬里

- 设备接管内部衬管施工应在设备本体衬砌前进行
- 采用树脂胶泥衬砌块材时，先在设备、管道表面均匀涂刷树脂封底料一遍
- 块材衬砌前宜先**试排**，衬砌时顺序**由低到高**
- **阴角处**：立面块材压住平面块材；**阳角处**：平面块材压住立面块材
- 立面衬砌时一次高度以不变形为限，待凝固后再继续；平面衬砌时采取防滑措施

#### 2. 纤维增强塑料衬里

| 工艺 | 要点 |
|------|------|
| **手工糊制** | 封底层和修补层自然固化时间不宜少于 **24h** |
| **间断法** | 上一层固化 **24h** 后修整表面，再铺衬以下各层 |
| **连续法** | 平面和立面 1 次连续铺衬**层数不超过 3 层**，厚度以不产生滑移、固化后不起壳或脱层确定 |
| **喷射法** | 玻璃纤维切成 **25~30mm**，与树脂一起喷射到金属表面 |

#### 3. 橡胶衬里

- **加热硫化橡胶衬里**：加热工艺、硫化温度及硫化时间符合要求
- **自然硫化橡胶衬里**：胶板衬砌时用专用压滚或刮板依次压合，排净空气，不得漏压；用力程度以见到压（刮）痕为限；前后两次滚压有一定重叠
- **预硫化橡胶衬里**：胶板下料准确，减少贴衬应力；形状复杂工件应制作样板并按样板下料

> **补充**：橡胶加入硫化剂后不变黏、不易折断，也叫熟橡胶。硫化是橡胶制品最后一道工序。

### 四、内衬水泥砂浆防腐钢管

**施工前提条件**：完成清扫、组对、焊接、无损检测、强度试验、严密性试验、外防腐层补口补伤并验收合格。

**技术要点**：

| 项目 | 要求 |
|------|------|
| **水泥强度** | 不小于 **32.5MPa** |
| **摊铺方式** | 边摊铺边压抹，**宜一次抹平**，不宜反复抹压；气泡刺破压紧 |
| **立面/仰面分层** | 厚度大于 **10mm** 时分两层施工，每层 5~10mm；前一层干至不粘手再施工下一层 |
| **养护** | 表面干至不粘手时喷雾或覆盖塑料薄膜，潮湿养护 **7d**，再自然养护 **21d** |
| **补口（DN≥1000）** | 可采用**手工涂抹** |
| **内衬短节法** | 不锈钢内衬短节与钢管焊接；短节端头伸出钢管端头 **1~1.5mm**；用强度等级**不低于原衬里**的水泥砂浆填充空隙 |

## 真题精选

### 【2025 单选】形状不规则的小面积金属表面防腐施工宜采用（ ）。

A. 刷涂法施工

B. 空气喷涂法施工

C. 滚涂法施工

D. 高压无气喷涂法施工

**答案**：A

**解析**：刷涂法漆膜渗透性强，可深入细孔、缝隙；工具简单，适应性好。缺点：劳动强度大、效率低、易有刷痕。常用于小面积涂装。

### 【2021 单选】下列防腐施工方法中，漆料省、效率高的是（ ）。

A. 高压无气喷涂法

B. 刷涂法

C. 空气喷涂法

D. 滚涂法

**答案**：A

**解析**：高压无气喷涂克服了空气喷涂的涂料回弹和漆雾飞扬，节省漆料、减少污染、改善劳动条件，效率提高数倍至十几倍，涂膜质量好。

### 【2022 单选】在涂料涂层施工时会发生涂料回弹和大量漆雾飞扬现象的是（ ）。

A. 空气喷涂法

B. 刷涂法

C. 滚涂法

D. 高压无气喷涂法

**答案**：A

**解析**：高压无气喷涂正好克服了空气喷涂的这些缺点。

### 【2018 案例节选】钢筒外表面除锈应采取哪一种方法？

**答案**：喷射或抛射除锈。

## 总结与记忆口诀

### 表面除锈质量等级

```
Sa（砂）→ Sa1 轻度 → Sa2 彻底 → Sa2.5 非常彻底 → Sa3 表观洁净
St（手）→ St2 彻底 → St3 非常彻底
```

### 喷涂方法对比

| 方法 | 关键词 | 适用场景 |
|------|--------|----------|
| 刷涂 | 渗透强、小面积、效率低 | 形状不规则小面积 |
| 滚涂 | 效率较高 | 较大面积 |
| 空气喷涂 | 最广泛、均匀、污染大 | 通用 |
| 高压无气喷涂 | 省料、高效、无回弹、大面积 | 大面积 |

### 防腐蚀方法体系

```
介质处理（除氧、脱酸）
覆盖层（涂料/金属/衬里）
电化学保护（强制电流/牺牲阳极）
添加缓蚀剂
```

### 施工环境和温度口诀

```
施工温度 10~30，湿度不超 85
基体表面比露点，高出 3℃ 才安全
```
