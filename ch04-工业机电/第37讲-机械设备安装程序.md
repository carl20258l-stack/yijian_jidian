# 4.1 机械设备安装程序

> [!summary] 本节速览
> 机械设备安装程序是工业机电的 **绝对核心流程题**，历年真题覆盖案例、单选、多选全题型。一般程序共 **11 个步骤**（口诀：香茶现点，就调浆，不加食盐），需 **按顺序准确默写**。每个子工序的细节（如灌浆分类、润滑方式、装配步骤、试运行三阶段）是选择题高频陷阱。

---

## 1. 机械设备安装的一般程序

**11 步顺序（必须按序记忆）：**

```
开箱检查 → 基础检查验收 → 基础测量放线 → 垫铁设置 → 吊装就位
→ 安装调整 → 固定与灌浆 → 零部件清洗与装配 → 润滑与加油
→ 试运行 → 验收
```

> [!tip] 记忆口诀
> **香茶现点，就调浆，不加食盐**
>
> 香（箱→开箱检查）→ 茶（查→基础检查验收）→ 现（线→基础测量放线）→ 点（垫→垫铁设置）→ 就（吊装就位）→ 调（安装调整）→ 浆（固定与灌浆）→ 不（零部件清洗与装配）→ 加（润滑与加油）→ 食（试→试运行）→ 盐（验→验收）

---

## 2. 主要工序详解

### 2.1 开箱检查（实体 + 资料）

> [!tip] 类比：收快递
> 检查包裹外观 → 核对商品规格数量 → 检查说明书/质保卡 → 有问题拍照记录

| 检查项目 | 内容 | ★ |
|---------|------|----|
| 外观检查 | 表面有无损坏和锈蚀，有无缺损件 | ★ |
| 规格型号数量 | 设备名称、规格和型号，重要零部件按标准检查验收 | ★★ |
| 随机技术文件 | 使用说明书、合格证明书、装箱清单、专用工具 | ★★ |
| 记录 | 其他需要记录的事项 | ★ |

> 记忆：**一看外观、二对型号、三查文件、四做记录**

---

### 2.2 基础测量放线

#### 基准线和基准点

- **基准线**：平面定位依据
- **基准点**：高程定位依据
- 土建施工单位移交厂房和基础条件时，应同时移交 **测量网点及重要的主轴线**

#### 设定基准线和基准点的原则（3 条）

1. 安装检测使用 **方便**
2. 有利于 **保持而不被毁损**
3. 标记 **清晰**，容易 **辨识**

> 记忆：**方便、保损、清晰**（三条原则）

---

### 2.3 垫铁设置

**作用（2 个）：**
1. **找平**——调整厚度使设备达到设计或规范要求的标高和水平度
2. **传递力**——将设备重量、工作负载荷、地脚螺栓预紧力均匀传递到基础

**常见垫铁类型：**

| 类型 | 特点 |
|------|------|
| 平垫铁 | 最基础，上下两平面平行 |
| 斜垫铁 | 斜面配合，成对使用，便于调整 |
| 开孔垫铁 | 中间开孔，配合地脚螺栓 |
| 开口垫铁 | 侧面开口，可侧向插入 |
| 钩头成对斜垫铁 | 钩头结构，便于定位调整 |

> 垫铁应按 **规范、设计图纸、制造厂家规定** 设置。

---

### 2.4 吊装就位

- 根据 **设备特点、作业条件、可利用的起重机械** 选择吊装方案
- 关键要求：**安全可靠、经济可行**
- **特殊作业场所、大型或超大型设备** → 编制 **专项施工方案**

> [!abstract] 新技术应用
> 大型或超大型构件和设备吊装中，推广应用 **计算机控制和无线遥控液压同步提升** 技术。
>
> **典型应用场景：** 电视塔钢天线、大型轧机牌坊、超大型龙门式起重机、石化反应塔

---

### 2.5 安装调整 ★★★

> [!danger] 高频考点
> 每年必考！注意区分 **"设备调整"** 与 **"精度检测"** 的范围。

**设备调整：**
- 依据：设备技术文件或规范要求的 **精度等级**
- 调整对象：设备自身和相互位置状态
- 调整内容：**中心位置、水平度、垂直度、平行度** 等

**精度检测：**
- 对象：设备、零部件之间的相对位置误差
- 检测内容：**垂直度、平行度、同轴度** 等

| | 设备调整 | 精度检测 |
|--|---------|---------|
| 对象 | 设备自身位置状态 | 设备/零部件之间相对误差 |
| 内容 | 中心位置、水平度、垂直度、平行度 | 垂直度、平行度、同轴度 |
| 目的 | 使设备达到规范位置 | 验证配合关系是否合格 |

---

### 2.6 固定与灌浆 ★★★

【真题 2010 单】

#### 灌浆分类

| 分类 | 阶段 | 内容 |
|------|------|------|
| **一次灌浆** | 设备粗找正后 | 对 **地脚螺栓孔** 进行灌浆 |
| **二次灌浆** | 设备精找正、地脚螺栓紧固、检测项目合格后 | 对 **设备底座和基础之间** 进行灌浆 |

> 记忆：**一灌孔、二灌底**——一次灌浆灌地脚螺栓孔，二次灌浆灌底座和基础间隙

#### 常用灌浆料

- 细石混凝土
- 无收缩混凝土
- 微膨胀混凝土
- 其他灌浆料：CGM 高效无收缩灌浆料、RG 早强微胀灌浆料

---

### 2.7 零部件清洗与装配

【真题 2023 单】

**设备装配步骤（3 步顺序）：**

```
组合件装配 → 部件装配 → 总装配
```

> 记忆：**组→部→总**

**复查要点：**
- 配合尺寸
- 配合面、滑动面
- 相关精度
- 齿轮啮合
- 滑动轴承侧间隙、顶间隙（做好记录）

---

### 2.8 润滑与加油

【真题 2023 案、2025 单】

**按加注方式分类：**

| 分类 | 方式 | 特点 |
|------|------|------|
| **分散润滑** | 人工加注 | 手工操作，适用于润滑点少的设备 |
| **集中润滑** | 润滑站 + 管路 + 附件组成系统 | 管道输送定量有压力的润滑剂到各润滑点 |

> 记忆：**分散靠人手，集中靠管路**

---

### 2.9 试运行

**三大步骤（顺序不可颠倒）：**

```
单体试运行 → 联动试运行 → 负荷试运行
```

| 阶段 | 说明 |
|------|------|
| 单体试运行 | 单台设备独立试车，检验安装质量 |
| 联动试运行 | 多台设备联动，检验系统配合 |
| 负荷试运行 | 带负载运行，检验实际工作能力 |

---

### 2.10 验收

**验收条件：** 试运行合格 + 工程验收合格 + 符合合同/设计/验收规范

**即时办理**交工验收。

**交工验收技术资料（8 项）：**

> 记忆：前期积累，过程留痕

| 序号 | 技术资料 |
|:---:|---------|
| 1 | 开箱检验记录 |
| 2 | 安装中经修改的零部件图说明 |
| 3 | 施工图设计变更文件 |
| 4 | 质量证明文件及其他随机技术资料 |
| 5 | 隐蔽工程施工记录 |
| 6 | 安装记录 |
| 7 | 试运行记录 |
| 8 | 重大问题及其处理的文件 |

> 记忆：**一记二图三变更，四证五隐六安装，七试八大**（八项关键词串记）
