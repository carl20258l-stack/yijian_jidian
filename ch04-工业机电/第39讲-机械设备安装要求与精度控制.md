## 二、机械设备安装要求

### 2.1 设备安装的基准线和基准点

#### （1）基准线和基准点的设置要求

| 序号 | 要求 | 关键数据 |
|------|------|----------|
| ① | 设备就位前，按**工艺布置图**并依据测量控制网或相关建筑物轴线、边缘线、标高线，划定安装的基准线和基准点 | — |
| ② | 用测量仪器按测量规程设定 | — |
| ③ | 与**其他设备有机械联系**的 → 划定**共同**的安装基准线和基准点 | — |
| ④ | 平面位置安装基准线与基础实际轴线或厂房墙/柱实际轴线、边缘线的距离允许偏差 | **20mm** |
| ⑤ | **无机械联系**：定位基面/线/点与安装基准线允许偏差 **20mm**，与安装基准点允许偏差 **-10～+20mm** | 20mm / -10~+20mm |
| ⑥ | **有机械联系**：定位基面/线/点与安装基准线允许偏差 **2mm**，与安装基准点允许偏差 **1mm** | 2mm / 1mm |

> **提示：10倍关系** — 有机械联系时精度要求是无机械联系时的10倍（20mm→2mm，20mm→1mm）

#### （2）永久基准线和基准点的设置要求

| 序号 | 要求 |
|------|------|
| ① | 需长期保留 → 设置**永久中心标板和永久基准点**；最好用**铜材或不锈钢材**；普通钢材需防腐（涂漆或镀锌） |
| ② | 通常设置在**主轴线和重要的中心线部位**，埋设在设备基础或现浇楼板框架梁的混凝土内 |
| ③ | 必须先绘出**布置图**，对各中心标板和基准点**编号**，由测量人员测量和刻线，提交测量成果 |
| ④ | **重要、重型、特殊设备**需设置**沉降观测点**（如汽轮发电机组、透平压缩机组、大型储罐） |

### 2.2 垫铁的设置要求（16、21）

| 序号 | 要求 | 要点 |
|------|------|------|
| ① | 垫铁与设备基础之间**接触良好**，放置整齐平稳 | 接触质量 |
| ② | 每个地脚螺栓旁边**至少一组**垫铁，设置在靠近地脚螺栓和底座**主要受力部位下方** | 位置要求 |
| ③ | 设备底座有接缝处的两侧各设一组，每组垫铁块数**不宜超过5块** | 块数限制 |
| ④ | 平垫铁：**厚的放在下面，薄的放在中间**，厚度**不宜小于2mm**；调平后每组垫铁均应**压紧** | 摆放顺序 |
| ⑤ | 垫铁端面露出设备底面外缘：平垫铁 **10~30mm**，斜垫铁 **10~50mm**；伸入底座长度应超过地脚螺栓中心 | 露出长度 |
| ⑥ | **除铸铁垫铁外**，调整完毕后各垫铁相互间用**定位焊焊牢** | 固定方式 |

### 2.3 设备无垫铁安装施工要求

采用**无收缩灌浆料或环氧树脂**做二次灌浆的机器设备宜采用无垫铁安装。

| 序号 | 要求 |
|------|------|
| ① | 根据设备重量、底座结构，确定**临时支撑件或调整螺钉**的位置和数量 |
| ② | 调整螺钉支承板上表面**水平度允许偏差不大于1/1000**，与基础接触面积**不小于50%**；相邻支承板顶面标高偏差宜**小于±2mm** |
| ③ | 灌浆层达到**设计强度75%以上**时，撤出调整工具，再次紧固地脚螺栓，复查设备精度，将空隙用灌浆料填实 |
| ④ | 二次灌浆前对调整螺钉和临时垫铁采取**保护措施**，防止被灌浆料污染 |

### 2.4 二次灌浆的技术要求

| 序号 | 要求 | 关键数据 |
|------|------|----------|
| ① | 一般采用**细碎石混凝土或水泥浆**，强度等级**比基础混凝土等级高一级** | 强度↑1级 |
| ② | 灌浆时应**捣实**，不使地脚螺栓倾斜或影响安装精度 | — |
| ③ | 要求较高时宜用**无收缩混凝土或水泥砂浆**；灌浆层厚度**不应小于25mm**（仅固定垫铁或防油水进入时可小于25mm） | ≥25mm |
| ④ | 外模板至设备底座面外缘距离**不宜小于60mm**；设备底座下不需全部灌浆且灌浆层需承受负荷时，应设内模板 | ≥60mm |
| ⑤ | **一次灌完**；精平后**24h内**灌浆，否则重新检查测量 | 24h内 |

## 三、机械设备安装精度控制

### 3.1 影响设备安装精度的因素（人机料法环）

| 序号 | 影响因素 | 主要因素 |
|:----:|----------|----------|
| 1 | **设备基础** | 强度、沉降、抗振性能 |
| 2 | **地脚螺栓** | 紧固力和垂直度 |
| 3 | **垫铁埋设** | 承载面积和接触情况 |
| 4 | **设备灌浆** | 强度和密实度 |
| 5 | **设备制造** | 加工精度和装配精度 |
| 6 | **设备基准件** | 相互位置精度和相对运动精度 |
| 7 | **测量误差** | 仪器精度和基准精度 |
| 8 | **环境因素** | 设备基础温度变形、设备温度变形、恶劣环境场所 |

> **记忆：基础→螺栓→垫铁→灌浆→制造→基准件→测量→环境**（按施工工序顺序记忆）

#### （5）设备制造对安装精度的影响

| 概念 | 说明 |
|------|------|
| **加工精度** | 设备制造质量不达标直接影响安装精度，出厂前质量检验至关重要 |
| **装配精度** | 解体设备的装配精度直接影响运行质量 |
| **相对运动精度** | 包括**直线运动精度、圆周运动精度、传动精度** |
| **配合精度** | 配合表面达到规定间隙或过盈的接近程度（如轴承装配） |
| **接触质量** | 配合表面接触面积大小和分布情况（如齿轮啮合） |

#### （6）设备基准件对安装精度的影响

设备基准件的安装精度包括：**标高差、水平度、铅垂度、直线度、平行度**等，直接影响设备各部件间的**相互位置精度和相对运动精度**。

> 例：龙门刨床床身导轨的直线度和导轨之间的平行度 → 影响工作台的直线运动精度

#### （7）测量误差对安装精度的影响

| 项目 | 内容 |
|------|------|
| 主要影响因素 | **仪器精度** 和 **基准精度** |
| 测量四要素 | 测量对象、计量单位、测量方法、测量精度 |
| **形状误差**（自己和自己比） | 直线度、平面度、**圆度、圆柱度** |
| **位置误差**（自己和别人比） | 平行度、垂直度、倾斜度、同轴度、对称度 |
| 仪器选择 | 测量仪器精度必须**高于**被测量装置精度 |
| 人员操作 | 主观性、视差、技能不足、压力过大 → 影响安装精度 |

> ⚠️ **重点区分**：
> - 形状误差：直线度、平面度、圆度、圆柱度（2015多选）
> - 位置误差：平行度、垂直度、倾斜度、同轴度、对称度

#### （8）环境因素对安装精度的影响

| 环境因素 | 具体表现 |
|----------|----------|
| 设备基础温度变形 | 大型精密机床、大型连轧机组、大型透平压缩机基础尺寸大，上下温度变化不一致 |
| 设备温度变形 | 设备本身温度变化导致变形 |
| 恶劣环境场所 | 不利环境条件 |

**基础温度变形的规律：**

| 温度变化 | 上部 vs 下部 | 基础变形 |
|----------|-------------|----------|
| 气温升高 | 上部温度 > 下部温度 | 基础**中间上拱** |
| 气温下降 | 上部温度 < 下部温度 | 基础**中间下陷** |

### 3.2 安装精度的控制方法

#### （1）提高安装精度的方法

| 方法 | 要点 |
|------|------|
| 人机料法环 | 尽量排除和避免影响安装精度的诸因素 |
| 装配调整 | 根据设备设计精度、结构特点，选择合理方法；采用可补偿件或固定补偿件抵消**安装累积误差** |
| 检测方法 | 测量器具和测量方法的精度等级与被检测设备相适应 |
| **修配法** | 对补偿件进行**补充加工**，抵消过大的安装累积误差（调整法解决不了时使用） |
| 允许偏差 | 设备安装允许有一定偏差，可用于抵消各种不利影响 |

**允许偏差的四大用途（记忆：孕妇抹油）：**

| 序号 | 用途 |
|:----:|------|
| ① | 有利于抵消设备**附属件安装后重量**的影响 |
| ② | 有利于抵消设备**运转时产生的作用力**的影响 |
| ③ | 有利于抵消**零部件磨损**的影响 |
| ④ | 有利于抵消**摩擦面间油膜**的影响 |

#### （2）设备安装偏差方向的控制

| 偏差控制类型 | 说明 | 示例 |
|-------------|------|------|
| ① 补偿温度变化 | 温差影响，调整安装偏差方向 | 汽轮机/干燥机（温度高）应**低于**发电机/电动机（温度低）；上部间隙<下部间隙；选较大端面间隙 |
| ② 补偿受力影响 | 受力后向下/向前倾斜 | 带悬臂转动机构 → **悬臂应上扬** |
| ③ 补偿磨损影响 | 间隙因磨损增大，引起振动或冲击 | 齿轮啮合间隙、可调轴承间隙、轴封间隙、滑道与导轮间隙、导向键与槽间隙等 |
| ④ 偏差相互补偿 | 控制偏差方向，合理排列分布，不产生累积 | 控制相邻辊道轴线与机组中心线垂直度偏差方向**相反**；控制相邻设备水平度偏差方向**相反** |

## 四、真题实战

### 【2011 单选】影响机械设备安装精度的因素不包括？

A. 地脚螺栓因素  
B. 测量因素  
C. **基础的硬度**  
D. 设备制造因素  

> **答案：C**。影响设备安装精度的因素包括：设备基础（强度、沉降、抗振性能）、地脚螺栓（紧固力和垂直度）、垫铁埋设、设备灌浆、设备制造、设备基准件、测量误差、环境因素。不包括"基础的硬度"。

### 【2015 多选】安装精度调整与检测中，属于形状误差的有？

A. **圆柱度**  
B. 平行度  
C. 垂直度  
D. **平面度**  
E. **直线度**  

> **答案：ADE**。形状误差：直线度、平面度、圆度、圆柱度（自己和自己比）。  
> 平行度和垂直度属于**位置误差**。

### 【2018 二级单选】现场组装的大型设备，各运动部件之间的相对运动精度不包括？

A. 直线运动精度  
B. 圆周运动精度  
C. 传动精度  
D. **配合精度**  

> **答案：D**。相对运动精度包括直线运动精度、圆周运动精度、传动精度。配合精度属于装配精度的另一个方面。

### 【2023 单选】修配法是对补偿件进行补充加工，其目的是？

A. 补充设计工艺不足  
B. 修补设备制造缺陷  
C. 修复使用后的缺陷  
D. **抵消安装积累误差**  

> **答案：D**。修配法用于抵消过大的安装累积误差，在调整法解决不了时使用。

### 【2014 单选】采用修配法对补偿件进行补充加工的目的是？

A. 解决设计存在的问题  
B. **抵消过大的安装累计误差**  
C. 修补制造的加工缺陷  
D. 补偿零部件的装配偏差  

> **答案：B**。（同上）

### 【2022 案例节选】扶梯制造对安装精度产生影响的原因？哪些直接影响扶梯设备运行质量？

> **参考答案：**
> （1）扶梯制造对安装精度的影响主要是**加工精度**和**装配精度**。
> （2）直接影响自动扶梯设备运行质量的原因：各运动部件之间的**相对运动精度**，配合面之间的**配合精度**和**接触质量**。
