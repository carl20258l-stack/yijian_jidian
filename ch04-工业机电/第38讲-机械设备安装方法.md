# 4.1 机械设备安装方法

> 历年考题：09、10、11、12、17、18、21、23、24

---

## 一、机械设备的整体安装和解体安装

### 1. 整体安装

- **适用**：体积和重量不大的设备，运输条件允许整体运输到安装现场
- **定义**：直接安装到设计指定的位置
- **优点**：能确保设备的位置精度和各设备间相互位置精度

### 2. 解体安装

- **适用**：大型设备，运输条件限制无法整体运输
- **方式**：出厂时分解成部件运输，到现场重新按设计、制造要求进行装配和安装
- **模块化安装**：利用模块化制造原理，将大型复杂设备分解为多种系统功能的大型模块，进行"工厂化"建造、现场安装
- **模块化安装优点**：能保证制造、组装精度，还能保证安装精度要求，达到制造厂的标准要求

## 二、典型零部件的装配

### （一）螺纹连接件装配

#### 1. 基本要求

| 要求 | 说明 |
|------|------|
| 足够的拧紧力矩 | 螺纹牙齿间有一定摩擦力矩，应有测力装置，使螺纹牙齿间产生足够的预紧力 |
| 可靠的防松装置 | 振动、冲击和交变载荷（随周期变化）下螺纹会松动，必须有防松装置 |
| 配合精度 | 由螺纹公差和旋合长度两因素决定，分为精密、中等、粗糙三种 |

> ⚠️ 静载荷下螺纹一般不会松脱，但在**振动、冲击和交变载荷**下会松动

#### 2. 紧固力矩与紧固顺序

- 成组螺钉、螺母紧固时，按正确顺序逐次（一般两三次）拧紧
- **力矩分配**：
  - 第一次：25%
  - 第二次：50%
  - 第三次：100%

**紧固顺序规律（对比记忆）**：

| 零件类型 | 原则 | 记忆 |
|---------|------|------|
| 长条形零件 | 从中间开始向两边对称紧固 | 长条↔中间 |
| 对称零件（方形、圆形） | 从对角开始紧固 | 对称↔对角 |
| 多孔零件 | 从中心开始紧固 | 多孔↔中心 |

> 口诀：**长条中间、对称对角、多孔中心**

#### 3. 有预紧力矩要求的螺纹连接装配（5种方法）

| 方法 | 原理 | 误差 | 特点 |
|------|------|------|------|
| ①定扭矩法 | 用扭力扳手或扭矩扳手控制 | 误差较大 | 方法简单，扳手使用前需校核 |
| ②扭角法（转角法） | 拧紧消除间隙后，再拧转一定角度 | 误差较大 | 不需专业工具，操作简单 |
| ③扭断螺母法 | 螺母上切环形槽，扭断螺母控制预紧力 | 误差较小 | 操作方便，但制造和修理重装不方便 |
| ④液力拉伸法 | 液力拉伸器使螺栓达到需要伸长量 | 误差较小 | 螺栓不受附加力矩 |
| ⑤加热法 | 加热（一般<400℃）使螺栓伸长，用垫片或热紧法控制伸长量 | 误差较小 | — |

> **记忆口诀**：一定扭断叶嘉（定扭法、扭角法、扭断螺母法、液力拉伸法、加热法）
>
> **误差对比**：
> - **误差较大**（前2个）：定扭矩法、扭角法（转角法）
> - **误差较小**（后3个）：扭断螺母法、液力拉伸法、加热法
> - 记法：**前2大后3小**

### （二）过盈配合件装配 ↔ 间隙配合

| 方法 | 说明 |
|------|------|
| ①压入装配 | 用压力机压入 |
| ②低温冷装配 | 将轴置于干冰或液氮中冷却 |
| ③加热装配法 | 对孔件进行加热（安装现场主要采用此法） |

> 记忆口诀：**冷热鸭**（冷装配、热装配、压入装配）

### （三）齿轮装配

#### 1. 基准面要求

- 齿轮基准面端面与轴肩或定位套端面应**靠紧贴合**
- 用 **0.05mm 塞尺**检查不应塞入
- 基准端面与轴线的垂直度应符合传动要求

#### 2. 啮合间隙检查——压铅法

| 参数 | 要求 |
|------|------|
| 铅丝直径 | 不宜超过间隙的 **3倍** |
| 铅丝长度 | 不应小于 **5个齿距** |
| 放置方式 | 沿齿宽方向均匀放置至少 **2根** |

#### 3. 接触斑点检查——着色法

- 将着色材料涂在 **小齿轮齿侧**
- 用小齿轮驱动大齿轮，使大齿轮转动 **3~4转**

**各类齿轮接触斑点要求**：

| 齿轮类型 | 接触斑点位置 |
|----------|-------------|
| 圆柱齿轮 | 趋于齿侧面**中部** |
| 蜗轮、蜗杆 | 趋于齿侧面**中部** |
| 圆锥齿轮 | 趋于齿侧面**中部并接近小端** |

> ⚠️ 齿顶和齿端棱边不应有接触

### （四）联轴器装配

#### 1. 测量项目

两轴心的**径向位移、两轴线倾斜和端面间隙**。

#### 2. 测量要求

- 两个半联轴器暂时互相连接，在圆周上画出对准线或装设专用工具
- 可采用：塞尺直接测量、塞尺和专用工具测量、百分表和专用工具测量
- 将两个半联轴器一起转动，**每转 90° 测量一次**
- 记录 **5个位置**的径向位移测量值和位于同一直径两端测点的轴向测量值
- 两轴心径向位移、两轴线倾斜计算值应符合规定
- 测量端面间隙时，将两轴轴向相对施加适当推力，消除轴向窜动间隙后再测量

> **关键数据**：每转 **90°**、记录 **5个位置**

---

### （五）滑动轴承装配（承载能力高）

#### 1. 基本检查

- 瓦背与轴承座孔的接触要求、上下轴瓦中分面的接合情况、轴瓦内孔与轴颈的接触点数，应符合随机技术文件规定

#### 2. 厚壁轴瓦 vs 薄壁轴瓦

| 类型 | 检查方法 | 标准 |
|------|---------|------|
| 厚壁轴瓦 | 未拧紧螺栓时，用 **0.05mm 塞尺**从外侧检查上下轴瓦接合面 | 任何部位塞入深度 ≤ 接合面宽度的 **1/3** |
| 薄壁轴瓦 | 装配后，在中分面处用 **0.02mm 塞尺**检查 | 不应塞入 |

> 薄壁轴瓦的接触面不宜刮研

#### 3. 轴承间隙的检测及调整

| 间隙类型 | 检测方法 | 要求 |
|---------|---------|------|
| **顶间隙** | 压铅法 | 铅丝直径 ≤ **3倍**顶间隙 |
| **侧间隙** | 塞尺检查 | 单侧间隙 = 顶间隙的 **1/2 ~ 2/3** |

---

### （六）滚动轴承装配（摩擦阻力小）

#### 1. 装配方法

| 方法 | 说明 |
|------|------|
| 压力装配法 | 压入力通过专用工具或在固定圈上垫以软金属棒、金属套传递 |
| 温差法 | 均匀改变轴承温度 |

> ⚠️ **不得**通过轴承的滚动体和保持架传递压入力

#### 2. 温度控制

| 工况 | 温度限值 |
|------|---------|
| 加热温度 | 不应高于 **120°C** |
| 冷却温度 | 不应低于 **-80°C** |

#### 3. 接触要求

- 轴承外圈与轴承座孔：对称于中心线 **120°** 范围内均匀接触
- 与轴承盖孔：对称于中心线 **90°** 范围内均匀接触
- 用 **0.03mm** 塞尺检查时，塞尺不得塞入轴承外圈宽度的 **1/3**

#### 4. 装配后检验

- 轴承装配后应转动灵活

## 三、历年真题

### 【2017·单选】关于齿轮装配的说法，正确的是（ ）

A. 齿轮的端面与轴肩端面不应靠紧贴合
B. 圆柱齿轮和蜗轮的接触斑点，应趋于齿侧面上部
C. 用压铅法检查传动齿轮啮合的接触斑点
D. 基准端面与轴线的垂直度应符合传动要求

> **答案**：D
>
> **解析**：
> - A错误：齿轮基准端面与轴肩或定位套端面应靠近贴合
> - B错误：圆柱齿轮和蜗轮的接触斑点应趋于齿侧面**中部**
> - C错误：用**着色法**检查传动齿轮啮合的接触斑点

B. 圆柱齿轮和蜗轮的接触斑点，应趋于齿侧面边缘
C. 滑动轴承的轴颈和轴瓦侧间隙可用塞尺检查
D. 采用温差法装配滚动轴承时，轴承的加热温度不应高于 100°C

## 四、考点总结

### 关键数据速查表

| 项目 | 数据 |
|------|------|
| 齿轮基准面塞尺检查 | 0.05mm |
| 齿轮压铅法：铅丝直径 | ≤ 间隙的3倍 |
| 齿轮压铅法：铅丝长度 | ≥ 5个齿距 |
| 齿轮压铅法：铅丝数量 | ≥ 2根 |
| 着色法：大齿轮转动 | 3~4转 |
| 联轴器：每转测量 | 90° |
| 联轴器：记录位置数 | 5个 |
| 厚壁轴瓦塞尺 | 0.05mm |
| 薄壁轴瓦塞尺 | 0.02mm |
| 滚动轴承加热温度 | ≤ 120°C |
| 滚动轴承冷却温度 | ≥ -80°C |
| 滚动轴承座孔接触范围 | 120° |
| 滚动轴承盖孔接触范围 | 90° |
| 滚动轴承塞尺检查 | 0.03mm |
| 侧间隙 | 顶间隙的 1/2~2/3 |

### 易混淆点

1. **压铅法 vs 着色法**
   - 压铅法：检查齿轮**啮合间隙**
   - 着色法：检查齿轮**接触斑点**

2. **各零件紧固顺序**
   - 长条形：中间→两边
   - 对称件：对角
   - 多孔件：中心

3. **有预紧力矩的螺纹连接装配误差分类**
   - 误差大（前2）：定扭矩法、扭角法
   - 误差小（后3）：扭断螺母法、液力拉伸法、加热法
