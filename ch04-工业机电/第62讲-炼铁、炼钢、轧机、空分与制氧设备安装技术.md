## 4.9.1 炼铁设备安装技术（★）

### 一、高炉炼铁设备

**核心原理**：炼铁过程实质上是将铁从矿石等含铁化合物中（其自然形态）还原出来的过程。

#### 1. 高炉炼铁五大系统

| 系统 | 包含设备 |
|------|---------|
| **高炉本体** | 炉体框架、炉壳、冷却设备、炉喉钢砖、炉顶保护板、炉顶装料设备 |
| **原料系统** | 矿槽设备、焦槽设备、中间料仓设备、料车上料设备、上料主皮带机 |
| **送风系统** | 鼓风设备、热风炉设备、风口装置 |
| **煤气系统** | 煤气除尘器设备、环缝洗涤塔设备 |
| **渣铁系统** | 炉前设备、铸铁机、水力冲渣设备 |

> **记忆口诀**：本体原送煤渣铁
> **2025多选提示**：注意区分本体设备 vs 其他系统设备——炉体框架属于**高炉本体设备**，不是原料/煤气/渣铁系统。

#### 2. 高炉炉体结构

高炉是横断面为圆形的炼铁竖炉，自上而下分为5部分：

```
炉喉 → 炉身 → 炉腰 → 炉腹 → 炉缸
```

高炉本体结构包括**炉体框架**和**炉壳**，在现场组合安装。

#### 3. 高炉炉体框架安装程序

**自下而上**安装：

```
基础检查放线 → 下部框架柱 → 框架梁 → 下部平台梁、板 → 上部框架柱 → 柱间支撑 → 上部平台梁、板 → 炉顶平台 → 炉顶框架柱 → 炉顶框架梁 → 炉顶悬臂吊车梁
```

> **记忆**：柱→梁→平台，先下后上

#### 4. 高炉炉壳安装

##### （1）炉壳焊接要求

| 项目 | 要求 |
|------|------|
| 工艺文件 | 应有焊接工艺评定报告 → 据此编制焊接作业指导书 |
| 焊接顺序 | 先焊内侧→后焊外侧；**先各带立焊缝、后横焊缝** |
| 焊接方法 | 多名焊工**均布圆周**，采用**对称方向、多层多焊道、分段退焊** |

##### （2）炉壳安装方法

| 安装工艺 | 适用说明 |
|---------|---------|
| 正装法 | 炉壳安装与框架安装**同步进行** |
| 倒装法 | 框架应先于炉壳安装 |
| 上部倒装下部正装法 | 框架应先于炉壳安装 |
| 线外拼装整体滑移法 | 框架应先于炉壳安装 |

> **2025真题**：高炉炉壳安装方法可采用 BCDE（正装法、倒装法、上部倒装下部正装法、线外拼装整体滑移法）。**A选项"上部正装下部倒装法"为干扰项**，注意正确说法是"上部倒装下部正装法"。

##### （3）**正装法**炉壳安装程序

```
炉底钢结构安装 → 炉底板铺设 → 炉底板压力灌浆 → 炉缸段炉壳 → 风口段炉壳 → 炉腹段炉壳 → 炉腰段炉壳 → 炉身段炉壳 → 炉喉直段炉壳 → 炉顶封板段炉壳 → 炉顶法兰安装
```

#### 5. 高炉本体主要设备安装

##### （1）炉体冷却设备——冷却壁试验

| 试验项目 | 要求 |
|---------|------|
| 通球试验 | 合格后进行压力试验 |
| 压力试验 | 试验压力 = **工作压力的1.5倍**，稳压10min，再降至工作压力，停压30min |
| 合格标准 | 压力不降、无渗漏 |

> **对比记忆**：与工业管道液压试验相同（1.5倍工作压力）。

##### （2）风口装置安装

- 风口大套、中套、小套：采用高炉热风环管下电动单轨吊 + 链式起重机
- 中套及小套：可采用**配重平衡法**吊装
- 固定装置顶紧后，顶板与大套法兰间隙 ≥ **10.0mm**
- 大套与中套密合面：用**0.1mm塞尺**检查，塞入深度 ≤ 接触长度的**1/3**

##### （3）高炉无料钟炉顶设备安装程序

**自下而上**安装：

```
炉顶法兰安装 → 布料溜槽齿轮箱安装 → 波纹管阀箱安装 → 炉顶设备支撑钢架安装 → 称量料罐安装 → 下密封阀安装 → 上料阀门安装 → 固定受料罐安装 → 受料斗下料阀箱安装 → 布料溜槽安装
```

#### 6. 热风炉安装技术

- **作用**：向高炉连续输送温度高达**1100～1300℃**的热风
- **分类**：**内燃式**、**外燃式**、**顶燃式**
- **安装内容**：各类阀门和补偿器、助燃风机、检修设备、换热器、炉箅子及其支柱

##### 热风炉炉壳安装允许偏差

| 安装部位 | 检查项目 | 允许偏差要求 |
|---------|---------|------------|
| 直筒段炉壳 | 炉壳钢板圈中心与炉底中心重合度 | H/1000，且≤30.0mm |
| | 炉壳钢板圈上口高度差 | ≤4.0mm |
| | 最大直径与最小直径之差 | 热风炉直径的2/1000 |
| 炉顶炉壳 | 炉顶中心与炉底中心重合度 | 热风炉直径的1/1000，且≤30.0mm |
| | 炉顶固定圈中心与炉体中心重合度 | ≤5.0mm |
| | 炉顶固定圈任意两点直径差 | ≤10.0mm |
| | 炉顶固定圈标高 | ±5.0mm |

## 4.9.2 炼钢设备安装技术（★）

### 一、转炉炼钢工艺

**核心原理**：将高炉供应的铁水经脱硫、脱磷、脱碳、合金化及过程中的升温，冶炼出合格的钢水供应给连铸，生产出成品或半成品。

> 转炉因其炉身周向固定在托圈上并可绕耳轴旋转而得名。

### 二、转炉四大系统

| 系统 | 设备 |
|------|------|
| **原料供应系统** | 铁水预处理、铁水倒罐站、混铁炉、废钢间、铁合金供应及石灰供应 |
| **吹炼、精炼与出钢系统** | 转炉本体、托圈、倾动装置、出钢、出渣及钢水精炼设备 |
| **供氧系统** | 氧枪、氧枪横移小车、氧枪升降设备及滑道、氧气阀门间、副枪系统 |
| **烟气净化与煤气回收系统** | 烟气冷却设备、煤气回收设备、蒸汽回收设备、烟气除尘及净化设备 |

### 三、转炉本体设备吊装方式

**三种方法**（口诀：配溜滑车）：
1. **台车法**
2. **滑移法**
3. **流动式起重机或卷扬机与滑轮组相配合吊装**

### 四、转炉本体安装技术

#### 1. 安装程序

```
基础交接验收 → 基准线、点设置 → 坐浆垫板设置 → 转炉支撑装置安装 → 托圈与轴承座装配 → 托圈吊装找正 → 炉壳组对 → 整体移动就位 → 倾动装置安装 → 炉体附属管道配管 → 调整、试车
```

#### 2. 轴承座安装

**固定端轴承座**：
- 以底座上水平面的十字中心线为精找正基准
- 测量：**中心线、标高及水平度**的偏差
- 调整合格→拧紧地脚螺栓→安装轴承座→复测

**游动端轴承座**：
- 底座一般为**铰接底座**
- 先找正铰接底板→底板固定后安装轴承座底座+临时支撑调整
- 调整：轴承座中分面水平→按中分面加工面调整**标高、中心线及水平度**

> 固定端、游动端轴承座找正后做好标记，拆除，准备与托圈、耳轴组装。

#### 3. 托圈与轴承座装配——水冷系统试验

| 试验项目 | 要求 |
|---------|------|
| **水压试验** | 试验压力 = **工作压力的1.25倍**，稳压10min，降至工作压力，停压30min |
| **通水试验** | 进出水应畅通无阻，连续通水时间 ≥ **24h**，无渗漏 |

> **关键对比：高炉冷却壁 vs 转炉托圈水冷系统**

| 对比项 | 高炉炼铁（冷却壁） | 转炉炼钢（托圈水冷系统） |
|--------|-------------------|-----------------------|
| 试验压力倍数 | 工作压力的**1.5倍** | 工作压力的**1.25倍** |
| 特殊试验 | 通球试验 | 通水试验（≥24h） |
| 稳压时间 | 10min→降至工作压力停压30min | 相同 |

> **记忆技巧**：铁球（高炉冷却壁→通**球**试验，1.5倍）、水钢（转炉托圈→**通水**试验，1.25倍）

#### 4. 托圈吊装找正

- 托圈吊装到临时台架上
- 以台架上投测的纵、横向中心线为基准调整中心位置和倾动轴水平度
- 倾动轴承座下底面标高比转炉支承装置上表面**高约50mm**
- 以**传动耳轴轴线**为基准轴线
- 检查工具：**激光准直仪**或**挂线千分尺**
- 两耳轴同轴度允许偏差：**1.5mm**

#### 5. 炉壳组对安装

| 安装方法 | 条件 |
|---------|------|
| **倒装法** | 连接装置位于托圈下表面，且托圈**上面无定位装置** |
| **正装法** | 连接装置位于托圈下表面，托圈**上面有定位装置**，且连接装置适合由下部安装 |

#### 6. 倾动装置

**组成**：电动机、一次减速机、二次减速机、扭力杆装置

**试运行要求**：
- 一次减速器正反向单独运转各 ≥ **1h**
- 运行平稳，无异常振动和噪声，轴承温升正常
- 试运行后检查：炉壳、托圈及连接装置焊缝（无裂纹）、螺栓连接（无松动）

#### 7. 连铸机安装要求

##### （1）钢包回转台安装

| 检查项 | 允许偏差 |
|--------|---------|
| 底座纵、横向中心线 | 2.0mm |
| 标高 | ±1.0mm |
| 水平度（底座与回转轴承结合面，平尺+框架水平仪） | 0.05/1000 |

**试运行**：
- 回转机构全行程回转 ≥ **5次**（平稳、停位准确、无异响）
- 回转臂全行程升降 ≥ **5次**（平稳、停位准确）
- 回转臂进行**冷满负荷**和**冷超负荷**试验

##### （2）连续铸钢设备试运行

| 部件 | 试运行要求 |
|------|-----------|
| 结晶器振动机构 | 连续运行 ≥ **2h**，无异常噪声，频率和振幅符合设计要求 |
| 扇形段辊组 | 连续运行 ≥ **2h**，无异常振动和噪声，轴承温升正常 |
| 扇形段更换装置传动机构减速器 | 单独运行 ≥ **30min** → 各机构全行程动作 ≥ **5次** |

## 4.9.3 轧机设备安装技术（★）

### 一、轧钢工艺概述

**核心原理**：轧钢生产是将钢锭或钢坯轧制成钢材的生产环节。从炼钢厂出来的钢坯还仅仅是半成品，必须到轧钢厂去进行轧制以后，才能成为合格的产品。

### 二、轧钢设备的组成

#### 1. 主要设备（主机列）

使轧件产生塑性变形的机器称为**轧机**，由以下组成：

| 部件 | 说明 |
|------|------|
| 工作机座 | 核心工作部件 |
| 机架 | 支撑结构 |
| 传动装置 | 接轴、齿轮座、减速机、联轴器 |
| 主电机 | 动力源 |
| 轧辊 | 直接接触轧件 |

> **2024超纲考点**：轧机主要设备组成曾作为超纲题出现。

#### 2. 辅助设备

| 类别 | 设备 |
|------|------|
| **运输设备** | 辊道（纵向运输）、升降台（垂直运输）、拉钢机/移钢机（横向运输） |
| **加工设备** | 剪切机/锯机（切断）、矫直机、卷取机 |
| **其他精整设备** | 翻钢机、回转台、冷床 |
| 其他 | 收集、酸洗、打印、包装等设备 |

### 三、轧机的分类

| 分类方式 | 类别 |
|---------|------|
| **按用途** | 开坯轧机、型钢轧机、板带轧机、钢管轧机、特殊轧机（横轧机、轮箍轧机等） |
| **按轧辊布置形式** | 水平轧辊轧机、立式轧辊轧机、水平+立式组合轧机、倾斜轧辊轧机、其他（共5种）—— **2024案例考点** |
| **按布置形式** | 单机架式、多机架顺列式、横列式、连续式、半连续式、串列往复式、布棋式 |
| **按安装精度等级** | Ⅰ级精度、Ⅱ级精度（见下表） |

#### 按安装精度等级分类

| 等级 | 包含的轧机类型 | 记忆 |
|------|--------------|------|
| **Ⅰ级精度** | 板带轧机、粗轧与精轧的带材连轧机、平整机、管材连轧机、高速线材轧机、棒材轧机、型材连轧机、中厚板成品轧机 | **精度Ⅰ级：成品/连轧** |
| **Ⅱ级精度** | 开坯机、钢坯轧机、穿孔机、焊管轧机 | **精度Ⅱ级：粗加工** |

### 四、轧机机架吊装方法

1. **桥式起重机吊装法**（行车吊装）
2. **流动式起重机吊装法**
3. **专用起重装置吊装法**

### 五、主机设备安装程序

```
基础验收 → 基准点基准线设置 → 垫板安装 → 轧机底座安装 → 机架安装 → 上下横梁安装 → 轧辊调整装置安装 → 轧辊平衡装置安装 → 换辊装置安装 → 轧机主传动装置安装 → 设备机体配管 → 二次灌浆 → 支撑辊/工作辊安装 → 试运行
```

### 六、轧机机架安装

#### 1. 检查参数

机架安装应检查：**垂直度、水平度、纵横中心线、机架窗口水平方向扭斜、两机架窗口中心线水平偏斜**

#### 2. 中心线测量

以**轧机机列中心线**和**轧制中心线**为基准，在轧机机架窗口面和内侧面测量。

#### 3. 测量位置——记忆表

| 测量项目 | 测量位置 | 记忆口诀 |
|---------|---------|---------|
| **机架垂直度** | 传动侧、操作侧两个机架窗口出口方向的**衬板面**、机架内侧面或外侧面 | 垂直度→看**立面**，两侧都要测 |
| **机架水平度** | 机架窗口**底面** | 水平度→看**底面**，只测底部 |
| **机架窗口中心线水平偏斜** | 传动侧、操作侧机架窗口**出口侧衬板面** | 偏斜/扭斜→都看**出口衬板**，两侧同步测 |

#### 4. 地脚螺栓紧固

**方法**：**液压螺母拉伸法**
- 将螺栓紧固力矩值→转换为相应**液压值**
- 紧固力应达到设计要求

> **2024案例考点**：轧机地脚螺栓紧固方法

#### 5. 机架精调

- **依据**：**以基础沉降观测**为依据
- 若基础沉降均匀且精度在标准内 → 不需精调，直接二次灌浆
- 若基础沉降不均匀、产生偏沉 → 待沉降基本稳定后进行精调

### 七、试运行

#### 1. 试运行时间要求

| 试运行项目 | 时间要求 |
|-----------|---------|
| 低速压下装置、高速压下装置往返运转 | ≥ **5次**，高低极限位置准确 |
| 主传动电动机空载试运行 | ≥ **0.5h** |
| 电动机+减速机试运行 | ≥ **0.5h** |
| 电动机+减速机+齿轮机座试运行 | ≥ **0.5h** |
| 电动机+减速机+齿轮机座+轧机试运行（按25%/50%/75%/100%额定转速） | ≥ **2h（2024案例考点）** |
| 换辊装置及其他设备往返运行 | ≥ **5次** |

#### 2. 轴承温升要求

| 轴承类型 | 温升 | 最高温度 |
|---------|------|---------|
| 滚动轴承 | ≤ **40℃** | ≤ **80℃** |
| 滑动轴承 | ≤ **35℃** | ≤ **70℃** |

> **记忆**：滚4滑3（滚动40/滑动35），滚8滑7

### 八、辅助设备安装要求

#### 1. 卷取机、开卷机精度等级

| 卷取速度 | 精度等级 | 示例 |
|---------|---------|------|
| ≥ **10m/s** | **Ⅰ级** | 酸连轧机组、酸洗涂层机组、连续退火机组、热镀机组、冷轧重卷横切机组 |
| < **10m/s** | **Ⅱ级** | 热连轧地下卷取机 |

#### 2. 开卷机安装偏差

| 项目 | Ⅰ级 | Ⅱ级 |
|------|-----|-----|
| 开卷机水平度 | **0.05/1000** | **0.10/1000** |
| 卷筒相对机组中心线垂直度 | **0.05/1000** | **0.10/1000** |

> **记忆**：Ⅰ级精度高，偏差小（0.05/1000）；Ⅱ级精度低，偏差大（0.10/1000）

#### 3. 卷取机安装偏差

- 卷筒相对机组中心线**垂直度**：**0.10/1000**，且卷筒悬臂端**偏向出料方向**
- 卷筒**水平度**：**0.10/1000**，且悬臂端**高于固定端**

> **方向记忆**：卷筒悬臂端→**偏出料、高于固定端**

#### 4. 卷取机、开卷机试运行

| 项目 | 要求 |
|------|------|
| 卷筒试运行前 | 应安装安全套筒，外置轴承架处于工作位置 |
| 卷筒涨缩液压缸和机体移动液压缸 | 往返运行各 ≥ **5次** |
| 冷轧回转式双卷筒卷取机回转机构 | 反复运行 ≥ **5次**，停止位置准确 |
| 卷筒连续运转 | ≥ **2h** |

## 4.9.4 空分与制氧设备安装技术（★）

### 一、冷箱内铝镁合金管道安装

#### 1. 管道清洗脱脂检验方法

| 检验方法 | 操作 | 合格标准 |
|---------|------|---------|
| **滤纸擦拭法** | 用清洁干燥的白色滤纸擦抹脱脂件表面 | 纸上无油脂痕迹 |
| **紫光灯照射检查法** | 脱脂后用波长**320～380nm**的紫外光检查表面 | 无油脂荧光 |
| **樟脑检查法** | 蒸汽吹扫脱脂时，盛少量蒸汽冷凝液于器皿内，放入数颗粒度<1mm的纯樟脑 | 樟脑不停旋转 |
| **溶剂分析法** | 用有机溶剂脱脂后，取样检查脱脂剂 | 油脂含量≤**125mg/m²** |

#### 2. 管道试压

空分塔内压力等级不同，必须按系统、压力等级设置不同的试压回路分别试压。
**试验介质**：宜采用干燥无油的**压缩空气**、**氮气**。

| 试验类型 | 试验压力 | 稳压时间 | 合格标准 |
|---------|---------|---------|---------|
| **强度试验** | 工作压力的**1.15倍** | 10min | 压力不降 |
| **严密性试验** | 降至工作压力 | 30min | 发泡剂检验，不泄漏 |
| **泄漏量试验** | 工作压力 | 停压**12h**，起点稳定30min后记录 | 泄漏率≤**2.5%** |

> **泄漏率计算公式**：Q = [1 - (P₂·T₁)/(P₁·T₂)] × 100%
> - P₁：起始绝对压力(MPa)
> - T₁：起始热力学温度(K)
> - P₂：终点绝对压力(MPa)
> - T₂：终点热力学温度(K)

#### 3. 管道吹扫要求

| 项目 | 要求 |
|------|------|
| 吹扫气源 | 洁净、干燥、无油的压缩空气 |
| 低压系统压力 | 0.04～0.05MPa |
| 高压系统压力 | 0.25～0.40MPa |
| 流速 | ≥ **20m/s** |
| 吹扫顺序 | **先冷箱外系统、后冷箱内系统** |
| 吹扫时间 | ≥ **4h**，反复多次 |
| 合格检验 | 沾湿白色滤纸或白布放在吹扫出口处，**5min**后无机械杂质 |

> **重要安全提示**：吹扫压力不得超过容器和管道的工作压力。冷箱外管道吹扫时，凡与冷箱内相连接的阀门应关闭。吹扫后系统恢复应符合清洁度要求，不得再进行影响管内清洁的其他作业。

## 历年真题回顾

### 2025年真题（多选）

**题目**：高炉炉壳安装的方法可采用（ ）。

**答案**：B. 正装法 C. 线外拼装整体滑移法 D. 倒装法 E. 上部倒装下部正装法

**解析**：高炉炉壳安装可采用正装法、倒装法、上部倒装和下部正装法、线外拼装整体滑移法等。A选项"上部正装下部倒装法"为错误干扰项。

### 2024年案例考点

1. **轧机分类**：按轧辊在机座中的布置形式分为：水平轧辊轧机、立式轧辊轧机、水平+立式组合轧机、倾斜轧辊轧机、其他轧机五种形式。

2. **轧机地脚螺栓紧固**：采用**液压螺母拉伸法**，将螺栓紧固力矩值转换为相应液压值。

3. **轧机试运行**：电动机带减速机、齿轮机座和轧机试运行，按25%/50%/75%/100%额定转速分别试运行≥2h。

4. **机架精调依据**：以基础沉降观测为依据。

### 2025年案例（二级）

**转炉水冷炉口水压试验问题**：
- 水冷炉口水压试验压力应为工作压力的**1.5倍**（0.4×1.5=0.6MPa），稳压10min，再降至工作压力停压30min
- 水冷炉口还应做**通水试验**
- 氧枪安装前应检查：水压试验记录、脱脂记录
