## 一、发电机设备安装程序

### 安装程序（口诀：找旧水船，请盖茨夫妻）

```
台板（基架）就位、找正 → 定子就位、找正 → 定子及转子水压试验 → 发电机穿转子
→ 氢冷器安装 → 端盖、轴承、密封瓦调整安装 → 励磁机安装 → 对轮复找中心并连接
→ 整体气密性试验
```

> **记忆口诀**：**找旧水船，请盖茨夫妻**
> - 找 → 台板找正
> - 旧 → 定子就位
> - 水 → 水压试验
> - 船 → 穿转子
> - 请 → 氢冷器
> - 盖 → 端盖
> - 茨 → 磁（励磁机）
> - 夫 → 复找中心
> - 妻 → 气密性试验

> **注意**：定子及转子的**冷却水系统**需要作水压试验。

### 安装程序先后关系（常考排序）

| 紧前 | 工序 | 紧后 |
|------|------|------|
| 定子及转子水压试验 | **发电机穿转子** | 氢冷器安装 |
| 定子就位 | 定子及转子水压试验 | 发电机穿转子 |
| 发电机穿转子 | 氢冷器安装 | 端盖、轴承、密封瓦调整安装 |

## 三、发电机转子安装技术要求

### 3.1 转子穿装前试验

**转子穿装前必须进行单独气密性试验。**

**试验目的**：防止发电机膛内的氢气进入发电机转子内部，经转子漏入励磁装置外罩内而产生爆炸危险。

**重点检查部位**：
- ✅ **集电环下导电螺钉** 的密封状况
- ✅ **中心孔堵板** 的密封状况

**后续处理**：
- 消除泄漏后应再经 **漏气量试验**
- 试验压力和允许漏气量应符合**制造厂规定**

> **转子安装必做的 3 个试验**：
> 1. **气密性试验** — 穿装前单独进行
> 2. **漏气量试验** — 消除泄漏后进行
> 3. **压力试验** — 整体系统试验
>
> 记忆：**气密→漏气→压力**（三步走）

### 3.2 转子穿装前准备工作（4 项要求）

| 序号 | 要求 | 关键词 |
|:----:|------|--------|
| ① | 完成**机务**工作（支架、千斤顶、吊索等服务准备） | 机务 |
| ② | 完成**电气与热工仪表**各项工作 | 仪表 |
| ③ | 对定子和转子进行最后**清扫检查**，确保内部清洁无杂物 | 清扫 |
| ④ | **经签证**后方可进行 | 签证 |

> **关键词记忆**：**机务、仪表、清扫、签证**（4 项前提条件）

### 3.3 转子穿装时机要求

- 必须在 **定子找正完**、**轴瓦检查结束** 后进行
- 穿装工作应**连续完成**
- 专用工具由**发电机制造厂**提供

### 3.4 转子穿装方法（口诀：滑接座车）

| 方法 | 适用说明 |
|------|----------|
| **滑**道式方法 | 常用方法 |
| **接**轴的方法 | 常用方法 |
| 用后轴承座作**平衡**重量的方法 | 落地轴承座，适用于小机组 |
| 用两台**跑车**的方法 | 常用方法 |

> **记忆口诀**：**滑接座车**（滑道式、接轴、后轴承座作平衡重量、两台跑车）
>
> **注意**：不同机组有不同穿转子方法，由制造厂提供专用工具。

## 四、轴系对轮中心找正

### 4.1 找正原则

轴系对轮中心找正时，**以低压转子为基准**。

### 4.2 找正次数（共 6 次）

| 序号 | 找正阶段 | 备注 |
|:----:|----------|------|
| 1 | **轴系初找** | — |
| 2 | **凝汽器灌水至运行重量后**复找 | 灌水至运行重量的状态下进行 |
| 3 | **汽缸扣盖前**复找 | — |
| 4 | **基础二次灌浆前**复找 | — |
| 5 | **基础二次灌浆后**复找 | — |
| 6 | **轴系联结时**复找 | — |

> **记忆**：初找→灌水→扣盖→一次灌浆→二次灌浆→联结，共 **6 次**。

### 4.3 找正调整要点

| 要点 | 说明 |
|------|------|
| 找正基准 | 首先以**低压转子**为基准 |
| 调整状态 | 通常以**全实缸**、**凝汽器灌水至模拟运行状态**进行调整 |
| 预留值 | 各对轮找中心时的端面张口和圆周高低差要有**预留值** |
| 复查 | 各不同阶段要进行多次对轮中心的**复查和找正** |

### 4.4 凝汽器灌水试验注意事项

| 项目 | 要求 |
|------|------|
| 弹簧支座处理 | 已就位的凝汽器，灌水试验前应加**临时支撑** |
| 试验后处理 | 灌水完成后**应及时把水放净** |
| 灌水高度 | 宜在**汽封洼窝以下 100mm** |
| 持续时间 | **维持 24h** 应无渗漏 |
| 找正状态 | 轴系中心复找工作在**凝汽器灌水至运行重量**的状态下进行 |

### 4.5 汽缸找中心基准方法

低压外下缸组合时，汽缸找中心的基准方法有：
- ✅ **激光**
- ✅ **拉钢丝**
- ✅ **假轴**
- ✅ **转子**

> **记忆**：激光拉钢丝，假轴转子找中心（4 种方法）

### 【2025·多选】转子穿装前完成工序

**题目**：发电机转子穿装前，必须完成的工序有（ ）。
A. 定子已找正　B. 轴瓦检查合格　C. 氢冷器已安装就位　D. 转子气密性试验合格　E. 定转子内部清洁无杂物并签证

**答案**：**ABDE**

**解析**：
- 转子穿装前进行单独**气密性试验** ✅ → D
- 转子穿装要求在**定子找正完**、**轴瓦检查**结束后进行 ✅ → A、B
- 完成机务、仪表工作，最后**清扫检查**并**签证** ✅ → E
- ❌ C 氢冷器安装是在穿转子**之后**的工序（紧后工序），不属于穿装前必须完成

### 【2020·案例】凝汽器灌水试验

**问题**：写出凝汽器灌水试验前后的注意事项，灌水水位应高出哪个部件？轴系中心复找工作应在凝汽器什么状态下进行？

**参考答案**：
1. **注意事项**：
   - 已就位在弹簧支座上的凝汽器，灌水试验前应加**临时支撑**
   - 灌水完成后**应及时把水放净**
2. **灌水高度**：宜在**汽封洼窝以下 100mm**，维持 **24h** 应无渗漏
3. **找正状态**：轴系中心复找工作都是在**凝汽器灌水至运行重量**的状态下进行的
