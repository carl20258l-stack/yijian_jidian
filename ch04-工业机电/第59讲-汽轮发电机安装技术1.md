## 1. 汽轮发电机系统设备组成

### 1.1 汽轮机设备组成

```
汽轮机
├── 汽轮机本体设备
│   ├── 静止部分：汽缸、喷嘴组、隔板、隔板套、汽封、轴承、紧固件
│   └── 转动部分：动叶栅、叶轮、主轴、联轴器、盘车器、推力盘、机械危急保安器
├── 蒸汽系统设备
├── 凝结水系统设备
├── 给水系统设备
└── 其他辅助设备
```

> **记忆口诀：给您他真笨** — 汽(轮机)、您(凝—凝结水系统)、他(给—给水系统)、真(蒸—蒸汽系统)、笨(本—本体设备)

#### 汽轮机本体分类
| 大类 | 组成部件 |
|------|----------|
| 静止部分 | 汽缸、喷嘴组、隔板、隔板套、汽封、轴承、紧固件 |
| 转动部分 | 动叶栅、叶轮、主轴、联轴器、盘车器、推力盘、机械危急保安器 |

### 1.2 发电机设备组成

```
发电机
├── 定子（静止部分）→ 机座、定子铁芯、定子绕组、端盖
│   记忆：绕铁盖坐定（绕组→铁芯→端盖→机座→定子）
└── 转子（转动部分）→ 转子锻件、励磁绕组、护环、中心环、风扇
```

#### 发电机组成

| 部分 | 组成部件 |
|------|----------|
| 定子 | 机座、定子铁芯、定子绕组、端盖 |
| 转子 | 转子锻件、励磁绕组、护环、中心环、风扇 |

### 1.3 锅炉本体与辅助设备（此处对比补充）

| 类别 | 组成 |
|------|------|
| 锅炉本体设备 | 锅炉钢架、汽包(或汽水分离器及储水箱)、水冷壁、过热器、再热器、省煤器、燃烧器、空气预热器、烟道 |
| 锅炉辅助设备 | 送引风设备、给煤制粉设备、吹灰设备、除灰排渣设备 |

> **记忆口诀（锅炉辅助）：风吹煤渣** — 风(送引风)、吹(吹灰)、煤(给煤制粉)、渣(除灰排渣)

### 1.4 三大热力设备对比速记

| 设备 | 组成 | 记忆口诀 |
|------|------|----------|
| 锅炉 | 本体 + 辅助（风吹煤渣） | 风吹煤渣 |
| 汽轮机 | 本体(静止+转动) + 蒸汽+凝结水+给水+其他辅助 | 给您他真笨 |
| 发电机 | 定子(绕铁盖坐定) + 转子 | 绕铁盖坐定 |

## 2. 汽轮机主要设备的安装技术要求

### 2.1 汽轮机设备安装程序

**安装顺序（完整流程）：**

```
基础和设备验收
  → 底座(台板)安装
  → 汽缸和轴承座安装
  → 轴承安装
  → 转子安装
  → 导叶持环或隔板安装
  → 汽封及通流间隙检查与调整
  → 上、下汽缸闭合
  → 二次灌浆
  → 联轴器安装
  → 变速齿轮箱和盘车装置安装
  → 汽缸保温
  → 调节系统安装
  → 调节系统和保安系统的整定与调试
```

> **记忆口诀：基座刚周转，环间必贯连，变温调整试**
> - 基（基础验收）→ 座（底座）→ 刚（汽缸）→ 周（轴承）→ 转（转子）
> - 环（导叶持环/隔板）→ 间（间隙检查）→ 必（闭合汽缸）→ 贯（灌浆）→ 连（联轴器）
> - 变（变速齿轮箱）→ 温（保温）→ 调（调节系统）→ 整（整定）→ 试（调试）

| 序号 | 安装步骤 | 状态/要点 |
|------|----------|-----------|
| 1 | 基础和设备验收 | 前期准备 |
| 2 | 底座(台板)安装 | 基础就位 |
| 3 | 汽缸和轴承座安装 | 主体框架 |
| 4 | 轴承安装 | 转动支撑 |
| 5 | 转子安装 | 核心部件 |
| 6 | 导叶持环或隔板安装 | 通流部分 |
| 7 | 汽封及通流间隙检查与调整 | 关键质量控制 |
| 8 | 上、下汽缸闭合 | 扣盖 |
| 9 | 二次灌浆 | 固定 |
| 10 | 联轴器安装 | 轴系连接 |
| 11 | 变速齿轮箱和盘车装置安装 | 辅助设备 |
| 12 | 汽缸保温 | 热防护 |
| 13 | 调节系统安装 | 控制系统 |
| 14 | 调节系统和保安系统整定与调试 | 最终调试 |

### 2.2 基础和设备的验收

> 安装前的准备工作，基础尺寸、标高、中心线等应符合设计要求。

### 2.3 汽缸和轴承座安装

#### (1) 低压缸组合安装

**核心原则：先下后上，先外后内**

| 组合步骤 | 内容 | 操作要点 |
|----------|------|----------|
| ① 低压外下缸组合 | 后段(电机侧) + 前段(汽侧) | 分别就位→调整水平/标高/中心→试组合→分两段重新检查垂直结合面→正式组合 |
| ② 低压外上缸组合 | 外上缸 | 试组合→检查水平/垂直结合面间隙→正式组合 |
| ③ 低压内缸组合 | 内缸 | 就位找正→隔板调整→吊入低压转子→通流间隙调整 |

> **关键工艺：** 低压外下缸组合时，前段和后段先试组合确认合格，然后分开一段距离，**再次清理检查垂直结合面**，确认清洁无异物后再正式组合。

**汽缸找中心基准方法（有4种）：**

> **记忆口诀：垃圾转嫁**
> - 拉（拉钢丝）
> - 激（激光）
> - 转（转子）
> - 假（假轴）

| 方法 | 说明 |
|------|------|
| 激光 | 激光对中仪 |
| 拉钢丝 | 拉钢丝进行隔板找中 |
| 假轴 | 假轴找中心 |
| 转子 | 以转子为基准 |

#### (2) 高、中压缸安装技术要点

> 汽轮机高、中压缸 **整体到货**，现场 **不需要** 组合装配。

### 2.4 转子安装

#### 核心工序

```
转子安装 → 转子吊装 + 转子测量 + 转子、汽缸找中心
```

#### 吊装要求

> 转子吊装应使用由 **制造厂提供** 并具备 **出厂试验证书** 的 **专用横梁和吊索**。

#### 转子测量内容（4项）

> **记忆口诀：联轴不弯就退票**
> - 联（联轴器端面止口配合间隙测量）
> - 轴（轴颈椭圆度和不柱度的测量）
> - 不（不柱度——轴颈不柱度）
> - 弯（转子弯曲度测量）
> - 退（推—推力盘瓢偏，属转子跳动测量范围）

| 测量项目 | 细分内容 |
|----------|----------|
| ① 轴颈椭圆度和不柱度测量 | 轴颈截面椭圆度、轴向不柱度 |
| ② 转子跳动测量 | 径向跳动、端面跳动、推力盘瓢偏 |
| ③ 转子弯曲度测量 | 轴线的弯曲程度 |
| ④ 联轴器端面止口配合间隙测量 | 联轴器配合精度 |

### 2.5 隔板安装

#### 找中心方法（3种）

| 方法 | 说明 |
|------|------|
| 假轴找中心 | 用假轴模拟转子找中心 |
| 拉钢丝找中心 | 用钢丝找中心（需修正垂弧） |
| 激光准直仪找中心 | 激光准直仪定位 |

#### 钢丝找中心技术要求

| 参数 | 要求 |
|------|------|
| 钢丝直径 | **不宜超过 0.40mm** |
| 钢丝拉力 | 应为 **破坏应力的 3/4** |
| 垂弧修正 | 测量时 **应对钢丝垂弧进行修正** |
| 制造厂要求 | 有明确要求时，按其要求执行 |

### 2.6 汽封及通流间隙的检查与调整

> **补充原理：** 汽封齿越多，每个齿前后的压差就越小，漏汽量也越小。当汽封齿数足够多时，漏汽量接近零。

#### 基本要求

> 汽封径向及轴向间隙应符合 **制造厂要求**，现场安装 **不得随意改动** 制造厂提供的有关数据。

#### 间隙检查方法（贴医用胶布法）

**操作流程：**
1. 在每道汽封环的 **两端及底部** 贴白色医用胶布（共贴3个点）
2. 胶布厚度标准：
   - 1层: 0.25mm
   - 2层: 0.55mm
   - 3层: 0.80mm
   - 4层: 1.10mm
3. 在与汽封块相对应的 **转子凸槽内涂上红丹油**
4. 盘动转子，检查胶布接触痕迹

**间隙判断标准：**

| 胶布状态 | 对应间隙 |
|----------|----------|
| 三层胶布未接触 | > 0.75mm（间隙过大） |
| 三层刚见红色痕迹 | 0.75mm |
| 三层有较深红色痕迹 | 0.65～0.70mm |
| 三层表面压光颜色变紫 | 0.55～0.60mm |
| 三层磨光呈黑色/磨透，第二层刚见红色 | 0.45～0.50mm |

> 检查完 **下半轴封** 后检查 **上半轴封**。

#### 间隙调整方法

| 问题 | 处理方法 |
|------|----------|
| 径向间隙 **过大** | 修刮汽封块在洼窝中承力的接触部位 |
| 径向间隙 **过小** | 修刮或加工汽封片边缘，使其尖薄平滑（用细锉修整） |
| 通流部分间隙 **及** 汽封轴向间隙 **不合格** | 由 **制造厂确定处理方案**（不得自行处理） |

### 2.7 上、下汽缸闭合（扣盖）

#### 扣盖施工要求

> 扣盖工作从向下汽缸吊入第一个部件开始，至上汽缸就位且紧固连接螺栓为止，**全程工作应连续进行，不得中断**。

#### 扣盖前准备工作

1. **试扣**：汽轮机正式扣盖前，应将内部零部件全部装齐后进行试扣，以便对汽缸内零部件的配合情况全面检查
2. **清洁**：试扣前应用 **压缩空气吹扫** 汽缸内各部件及其空隙，确保：
   - 汽缸内部 **清洁无杂物**
   - 结合面 **光洁**
   - 各孔洞通道部分 **畅通**
   - 需堵塞隔绝部分 **堵死**

#### 螺栓紧固要求

**低压缸螺栓（冷紧）：**

| 顺序 | 力矩 | 方式 |
|------|------|------|
| 预紧 | 50%～60%规定力矩 | 左右对称进行 |
| 紧固 | 100%规定力矩 | 继续紧固 |

**高压缸螺栓（热紧）：**

| 项目 | 要求 |
|------|------|
| 加热工具 | 使用 **专用工具** |
| 受热要求 | 螺栓均匀受热，**避免直接烘烤**螺栓部位 |
| 紧固顺序 | 与冷紧时 **相同顺序** |
| 完成要求 | 加热后热紧工作 **一次完成** |
| 未达标处理 | 若一次性达不到规定值，应待螺栓 **完全冷却后，再重新加热** |

#### 扣盖施工总结顺序

> 压缩空气吹扫汽缸 → 试扣 → 塞尺检查 → 汽缸中分面抹涂料 → 正式扣盖

### 2.8 凝汽器安装（20/23年考点）

#### 壳体就位和连接

> 凝汽器结构尺寸庞大，支承方式多采取通过 **弹簧支座** 坐落在凝汽器基础上的支承形式。

#### 内部设备安装

> 包括 **管板、隔板、冷却管束** 的安装、连接。

#### 灌水试验

| 项目 | 要求 |
|------|------|
| 灌水高度 | 在 **汽封洼窝（汽封内圆）以下 100mm** |
| 持压时间 | 维持 **24h** |
| 合格标准 | **无渗漏** |
| 注意事项 | 已就位在弹簧支座上的凝汽器，灌水试验前应加 **临时支撑**；试验完成后 **及时把水放净** |

### 2.9 轴系对轮中心的找正（14/16/17/20年考点）

#### 找正对象（4个对轮中心）

| 序号 | 对轮中心 | 说明 |
|------|----------|------|
| ① | 高中对轮中心 | 高压转子—中压转子 |
| ② | 中低对轮中心 | 中压转子—低压转子 |
| ③ | 低低对轮中心 | 低压转子—低压转子 |
| ④ | 低发对轮中心 | 低压转子—发电机转子 |

#### 找正基本原则

| 原则 | 说明 |
|------|------|
| 基准选择 | 首先以 **低压转子** 为基准（低压转子体积最大） |
| 调整状态 | 通常以 **全实缸、凝汽器灌水至模拟运行状态** 进行调整 |
| 预留值 | 各对轮找中心时的端面张口和圆周高低差要有 **预留值** |
| 多次复查 | 一般在各 **不同阶段** 要进行多次对轮中心的复查和找正 |

#### 轴系中心找正阶段（6个阶段）

| 序号 | 找正阶段 | 状态 |
|:----:|----------|:----:|
| 1 | 轴系初找 | 空负荷 |
| 2 | 凝汽器灌水至运行重量后的复找 | 灌水至运行重量 |
| 3 | 汽缸扣盖前的复找 | 扣盖前 |
| 4 | 基础二次灌浆前的复找 | 二次灌浆前 |
| 5 | 基础二次灌浆后的复找 | 二次灌浆后 |
| 6 | 轴系联结时的复找 | 轴系联结时 |

> **记忆口诀：复出前后灌溉**
> - 复（复找，共6次）→ 初（初找）→ 前（扣盖前）→ 后（灌浆后）→ 灌（灌浆前）→ 溉（灌水/凝汽器灌水后）→ 联结时
