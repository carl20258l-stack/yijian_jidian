## 一、炉窑分类

### 按生产过程分类

| 类别 | 说明 |
|------|------|
| **动态炉窑** | 回转窑等转动炉窑 |
| **静态炉窑** | 固定式炉窑 |

---

## 二、炉窑砌筑施工条件

1. 炉窑的砌筑工程应于**炉体骨架结构**和**有关设备安装完毕**，经检查**合格**并**签订交接证明书**后，方可进行施工。

> **记忆点**：骨架完成 → 设备安装完 → 检查合格 → 签交接书 → 施工

---

## 三、耐火砖砌筑施工程序

### 基本砌筑顺序

```
从热端向冷端（或从低端向高端）
    → 分段作业划线
    → 选砖 → 配砖
    → 分段砌筑
    → 分段进行修砖及锁砖
    → 膨胀缝的预留及填充
```

> **记忆口诀**：热端到冷端 → 划线 → 选配砖 → 分段砌 → 修锁砖 → 留膨胀缝

### 动态炉窑 vs 静态炉窑

| 对比项 | 动态炉窑 | 静态炉窑 |
|--------|----------|----------|
| 试运行要求 | 必须**单机无负荷试运行**合格并验收后方可进行 | **不必**进行无负荷试运行 |
| 砌筑顺序 | 可自下而上或根据窑体特点 | 必须**自下而上**进行 |
| 起拱部位砌筑 | 按设计要求 | 从两侧向中间砌筑，需采用拱胎压紧固定，锁砖完成后拆除拱胎 |

> **记忆口诀**：动态→先试运行；静态→无试运行、自下而上、两侧向中间

## 四、炉窑砌筑施工技术要求

### 1. 炉窑底砌筑

| 要点 | 技术要求 |
|------|----------|
| **可动炉底** | 砌体与有关部位之间的间隙，按规定尺寸留设 |
| **斜坡炉底（水平砖层）** | 工作层可退台或错台砌筑，三角部分用不定形耐火材料找齐 |
| **反拱底** | 从**中心向两侧对称砌筑**；砌筑前用**样板**找准弧形拱基面 |
| **斜坡炉底（一般）** | 应**放线砌筑** |

### 2. 炉窑墙砌筑

| 墙类型 | 技术要求 |
|--------|----------|
| **圆形炉墙** | 按**中心线**砌筑；炉壳中心线垂直/半径误差符合要求时，可以炉壳为**导面**砌筑 |
| **弧形墙** | 按**样板放线**砌筑，砌筑时经常用样板检查 |
| **通用要求** | 砌砖用**木槌或橡胶锤**找正，不用铁锤；砌砖中断或返工拆砖时，应做**阶梯形斜槎** |

### 3. 炉窑拱和拱顶砌筑

| 要点 | 技术要求 |
|------|----------|
| **拱脚** | 表面平整，角度正确；**不得加厚砖缝**找平拱脚；拱脚砖紧靠拱脚梁砌筑 |
| **砌缝** | 错缝砌筑，沿纵向缝拉线砌筑，保持砖面平直 |
| **砌筑方向** | 必须从**两侧拱脚同时向中心对称砌筑** |
| **砖的方向** | **严禁**将拱砖的大小头倒置 |
| **锁砖分布** | 按拱和拱顶的**中心线对称均匀分布** |
| **锁砖深度** | 砌入深度宜为砖长的 **2/3 ~ 3/4**，深度应一致 |
| **拱胎拆除** | 跨度 > **5m** 的拱胎拆除前，应**设置测量拱顶下沉的标志**；拆除后做**下沉记录** |

> **易混淆对比**：
> - **反拱底**：中心向两侧对称砌筑
> - **拱和拱顶**：两侧拱脚同时向中心对称砌筑
> - **静态炉窑起拱**：从两侧向中间砌筑

> **锁砖补充**：锁砖不当会使锁砖区成为窑衬中最易损坏的环节，各砖圈的正确锁缝极为重要。

## 五、不定形耐火材料施工技术要求

1. **搅拌用水**：应采用**洁净水**
2. **搅拌机械**：应采用**强制式搅拌机**
3. **浇注时限**：搅拌好的耐火浇注料应在 **30min 内**浇注完成（或按产品说明书）；**已初凝的浇注料不得使用**
4. **浇注连续性**：应**连续进行**
5. **养护**：按设计规定的方法和要求养护

> **⚠️ 高频考点（2014单选）**：搅拌均匀后应在 30min 内完成浇注。

## 六、耐火喷涂料施工技术要求

| 序号 | 技术要求 |
|------|----------|
| 1 | 采用**半干法喷涂** |
| 2 | 料和水应**均匀连续喷射**，喷涂面上不允许出现干料或流淌 |
| 3 | 喷涂方向**垂直于受喷面**，喷嘴距受喷面 **1~1.5m**，喷嘴**螺旋式移动**使粗细颗粒分布均匀 |
| 4 | 大面积喷涂**分单元连续进行**，本单元内一次达到设计厚度；内衬厚度 > **300mm** 需分层喷涂时，前层凝结前喷完次层 |
| 5 | 喷涂完毕后**及时开设膨胀缝线**，用 **1~3mm 厚楔形板压入 30~50mm** 而成 |

> **⚠️ 高频考点（2016单选）**：喷涂完毕后应及时开设膨胀缝。

## 七、耐火陶瓷纤维施工技术要求

### 分类（按制品形状）

| 类型 | 说明 |
|------|------|
| **层铺式内衬** | 纤维毯/毡/板层铺 |
| **叠砌式内衬** | 纤维制品叠砌 |
| **折叠式模块内衬** | 模块折叠组合 |

### 1. 层铺式内衬

| 部位 | 锚固钉中心距 |
|------|-------------|
| 炉顶 | **200~250mm** |
| 炉墙 | **250~300mm** |
| 锚固钉与受热面边缘距离 | **50~75mm**，最大 ≤ **100mm** |

- 锚固钉在钢板上**垂直焊牢**，逐根**锤击检查**
- 采用陶瓷杯或转卡垫圈固定时，锚固钉断面排列方向应一致

### 2. 叠砌式内衬

- 施工方法：**销钉固定法** 或 **粘贴法**
- 每扎纤维毯/毡均应预压缩，压缩程度相同，压缩率 ≥ **15%**
- 销钉固定法：支撑板水平，固定销钉垂直焊接牢固，接缝挤紧
- 粘贴法：排列正确，粘贴平直、紧密、压紧

### 3. 折叠式模块内衬

| 要点 | 技术要求 |
|------|----------|
| 固定方式 | 与焊在炉壳上的金属锚固件连接，常为**中心孔吊挂式结构** |
| 体积密度 | **190~220 kg/m³** |
| 无预埋锚固件时 | 用**穿钉固定**，穿钉垂直插入相邻支撑板孔内 |
| 排列方向 | 沿折叠方向**顺次同向排列** |
| 非折叠方向/连接处 | 铺设同级纤维毯，压缩率 ≥ **15%** |

## 九、烘炉技术要求

| 序号 | 技术要求 |
|------|----------|
| 1 | 工业炉投入生产前**必须烘干烘透**；烘炉前**先烘烟囱及烟道** |
| 2 | 耐火浇注料内衬应按规定**养护后**才可烘炉 |
| 3 | 烘炉在生产流程有关的**机电设备联合试运行**及调整合格后进行 |
| 4 | 根据炉窑结构、用途、耐火材料性能、建筑季节等制定**烘炉曲线和操作规程** |
| 5 | **烘炉曲线内容**：烘炉期限、升温速度、恒温时间、最高温度、更换加热系统的温度、烘炉措施、操作规程及应急预案 |
| 6 | 烘炉应**按烘炉曲线**进行 |
| 7 | 故障处理：主要设施故障影响升温 → 立即**保温和停炉** → 故障消除后按曲线继续升温 |
| 8 | 烘炉缺陷处理后，才可投料生产 |

> **⚠️ 高频考点（2020单选）**：烘炉前应先烘烟囱及烟道。

## 十、易混点对比总结

### 砌筑方向对比

| 项目 | 砌筑方向 |
|------|----------|
| 反拱底 | 中心向两侧对称砌筑 |
| 拱和拱顶 | 两侧拱脚同时向中心对称砌筑 |
| 静态炉窑砌筑顺序 | 自下而上 |
| 动态炉窑砌筑顺序 | 热端向冷端 |

### 关键数字记忆

| 数字 | 对应内容 |
|------|----------|
| **30min** | 耐火浇注料搅拌后应完成浇注的时间 |
| **1~1.5m** | 喷嘴与受喷面的距离 |
| **> 300mm** | 喷涂内衬需分层喷涂的厚度阈值 |
| **2/3 ~ 3/4** | 锁砖砌入拱内的深度（占砖长比例） |
| **> 5m** | 拱胎跨度，拆除前需设下沉标志 |
| **1~3mm** | 膨胀缝楔形板厚度 |
| **30~50mm** | 楔形板压入深度 |
| **200~250mm** | 炉顶锚固钉中心距 |
| **250~300mm** | 炉墙锚固钉中心距 |
| **50~75mm（≤100mm）** | 锚固钉与纤维毯边缘距离 |
| **≥ 15%** | 叠砌式/折叠式纤维毯压缩率 |
| **190~220 kg/m³** | 折叠式模块体积密度 |

### 禁止项

| 禁止内容 | 说明 |
|----------|------|
| 禁止用铁锤 | 砌砖用木槌或橡胶锤找正 |
| 禁止加厚砖缝找平拱脚 | 拱脚表面应平整 |
| 禁止将拱砖大小头倒置 | 拱和拱顶砌筑时 |
| 禁止使用初凝浇注料 | 已初凝的浇注料不得使用 |
| 禁止喷涂面出现干料或流淌 | 料和水应均匀连续喷射 |

> **答案**：B

**【2021 单选】** 关于耐火砖砌筑施工的说法，正确的是（ ）。
A. 砌砖时应使用铁锤找正
B. 反拱底应从中心向两侧对称砌筑
C. 砌砖中断时应做成断面平齐的直槎
D. 拱的砌筑应从拱脚一侧依次砌向另一侧

> **答案**：B
> **解析**：反拱底应从中心向两侧对称砌筑。砌砖应使用木槌或橡胶锤找正，不应使用铁锤。砌砖中断或返工拆砖时，应做成阶梯形的斜槎。拱和拱顶必须从两侧拱脚同时向中心对称砌筑。

## 十二、复习要点

1. **动态 vs 静态炉窑**的区分：动态需无负荷试运行、静态不必
2. **砌筑方向**的三种模式：反拱底（中心→两侧）、拱顶（两侧→中心）、静态炉窑（下→上）
3. **30min** 浇注时限是经典考点
4. **膨胀缝开设**是喷涂后的关键步骤
5. **烘炉前先烘烟囱及烟道**、烘炉在联合试运行之后
6. **销钉固定法**和**粘贴法**的区别
7. 各种**数字参数**（深度比例、距离、压缩率、密度等）易出单选
