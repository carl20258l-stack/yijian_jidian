# 4.1 设备基础种类及验收

> **考频：★★★**（2007单 / 2009多 / 2010单 / 2011单、案 / 2012多 / 2013单 / 2021单 / 2023案 / 2024单）

---

## 一、设备基础的种类及应用（分类题）

### 1.1 按材料组成不同

| 名称 | 材料 | 用途 |
|------|------|------|
| **素混凝土基础** | 砂、石、水泥 | 荷载较小、变形不大的设备基础 |
| **钢筋混凝土基础** | 砂、石、水泥、钢筋 | 荷载较大、变形较大的设备基础 |
| **垫层基础** | 在基底上直接填砂，外围设钢筋混凝土圈梁挡护填砂 | 使用后允许产生沉降的结构，如大型储罐 |

### 1.2 按埋置深度不同（分界：5米）

| 大类 | 子类 | 说明 |
|------|------|------|
| **浅基础**（<5m） | **扩展基础** | 将上部荷载进行扩散并传递到地基上的基础形式（p = F/S） |
| | **联合基础** | 由组合混凝土结构组成，适用于底面积受限、地基承载力较低、对允许振动线位移控制较严格的大型动力设备基础，如 **轧机、铸造生产线、玻璃生产线**（刚性整体，整体抗弯、整体受力） |
| | **独立基础** | 配置于上部设备之下的无筋或有筋的整体基础形式 |
| **深基础**（≥5m） | **桩基础** | 由承台、桩组成，分预制桩和灌注桩两大类。适用于需要 **减少基础振幅、减弱基础振动** 或控制基础沉降和沉降速率的 **精密、大型设备**。桩基础一般需要预压。如 **透平压缩机、汽轮发电机组、锻压设备** |
| | **沉井基础** | 用混凝土或钢筋混凝土制成的 **井筒式基础**。适用于 **冶炼、石油化工工程的烟囱和火炬，发电厂的洗涤塔** |

> **记忆口诀：浅基础→"扩联独"**；**深基础→"装深沉"（桩基础、沉井基础）**

### 1.3 按结构形式不同

- **大块式基础**
- **箱式基础**
- **框架式基础**

> **记忆口诀：大相框**（大块式、箱式、框架式）

### 1.4 按使用功能不同

- **减振基础**
- **绝热层基础**

---

### 分类速记表

| 分类维度 | 包含类型 |
|----------|----------|
| **材料组成不同** | 素混凝土基础、钢筋混凝土基础、垫层基础 |
| **埋置深度不同** | 浅基础（扩展基础、联合基础、独立基础）← "欠债炼毒"；深基础（桩基础、沉井基础）← "装深沉" |
| **结构形式不同** | 大块式基础、箱式基础、框架式基础 ← "大相框" |
| **使用功能不同** | 减振基础、绝热层基础 |

## 二、设备基础施工质量验收要求（强度 + 尺寸 + 附件）

### 2.1 混凝土强度的验收要求

1. 基础施工单位应提供 **设备基础质量合格证明文件**，主要检查验收：
   - **混凝土配合比**
   - **混凝土养护**
   - **混凝土强度**
   - 是否符合设计要求

2. 对设备基础强度有怀疑时 → 可请 **有检测资质的工程检测单位** 对基础强度进行 **复测**

3. 重要的设备基础应做 **预压强度试验**，预压合格并有 **预压沉降详细记录**，如：
   - 大型锻压设备
   - 汽轮发电机组
   - 大型油罐

> **真题（2009多选）：** 验收混凝土强度合格证明，主要检查 **配合比、养护、强度**（ACE）

### 2.2 位置、标高和几何尺寸的验收要求

- 基础的位置、标高、几何尺寸应符合 **设计图规定**，并有验收资料或记录

主要检查项目：

| 检查类别 | 具体项目 |
|----------|----------|
| 基础位置 | 基础的坐标位置 |
| 标高 | 不同平面的标高 |
| 外形尺寸 | 平面外形尺寸；凸台上平面外形尺寸；凹槽尺寸 |
| 平整度/垂直度 | 平面的水平度；基础的垂直度 |
| 地脚螺栓（预埋） | 预埋地脚螺栓的标高和中心距 |
| 地脚螺栓孔 | 中心线位置、深度、孔壁垂直度 |
| 锚板（活动地脚螺栓） | 预埋活动地脚螺栓锚板的标高、中心线位置；带槽锚板和带螺纹孔锚板的平整度 |

### 2.3 外观质量检查验收要求

- 基础外表面应：**无裂纹、空洞、掉角、露筋**
- 基础表面和预留孔应：**干净**
- 预留孔洞内：**无露筋、凹凸** 等缺陷
- 放置垫铁的基础表面应：**平整**
- 中心标板和基准点：埋设牢固、标记清晰、编号准确

### 2.4 地脚螺栓检查验收要求

#### （1）直埋地脚螺栓

| 项目 | 内容 |
|------|------|
| 适用设备 | 用来固定 **没有强烈振动和冲击** 的设备 |
| 常见形式 | 直钩螺栓、弯钩螺栓、弯折螺栓、U形螺栓、爪式螺栓、锚板螺栓 |
| 检查要求 | 中心距、标高及露出基础长度符合设计或规范要求 |
| 测量方法 | 中心距：在根部和顶部沿纵、横两个方向测量；标高：在顶部测量 |
| 配套要求 | 螺母和垫圈应配套，螺纹和螺母应保护完好 |

#### （2）活动地脚螺栓（长地脚螺栓）

| 项目 | 内容 |
|------|------|
| 适用设备 | 固定工作时 **有强烈振动和冲击的重型机械设备** |
| 特点 | **可拆卸** |
| 常见形式 | T形头螺栓、拧入式螺栓、对拧式螺栓 |
| 安装要求 | T形头地脚螺栓与基础板应按规格配套使用；基础板应牢固、平正；光杆部分和基础板应刷 **防锈漆** |

#### （3）胀锚地脚螺栓

| 项目 | 内容 |
|------|------|
| 适用设备 | 部分 **静置的简单设备或辅助设备** |
| 安装要求 | ①中心到基础边缘距离 ≥ **7倍** 胀锚地脚螺栓直径 |
| | ②安装时基础强度 ≥ **10MPa** |
| | ③钻孔处不得有裂缝 |
| | ④钻孔直径和深度应与胀锚地脚螺栓相匹配 |

#### （4）粘接地脚螺栓

- 与胀锚地脚螺栓基本相同

---

### 地脚螺栓分类速记

| 类型 | 适用环境 | 记忆点 |
|------|----------|--------|
| **直埋地脚螺栓** | 没有强烈振动和冲击的设备 | 与基础浇灌在一起，不可拆卸 |
| **活动地脚螺栓** | 有强烈振动和冲击的重型机械设备 | 可拆卸、长地脚螺栓 |
| **胀锚地脚螺栓** | 静置的简单设备或辅助设备 | 7倍直径、10MPa、无裂缝 |
| **粘接地脚螺栓** | 与胀锚基本相同 | — |

## 三、例题精讲

### 【例题·多选】2009年
验收施工单位提供的设备基础混凝土强度的质量合格证明书。主要检查（ ）是否符合设计要求。

A. 强度  
B. 水泥  
C. 配合比  
D. 砂石  
E. 养护  

**答案：ACE**  
**解析：** 基础施工单位应提供设备基础质量合格证明文件，主要检查验收其混凝土配合比、混凝土养护及混凝土强度是否符合设计要求。

---

### 【例题·单选】2013年
按埋置深度分类的机械设备基础是（ ）。

A. 箱式基础  
B. 垫层基础  
C. 减振基础  
D. 联合基础  

**答案：D**  
**解析：**
- 浅基础：扩展基础、联合基础、独立基础
- 深基础：桩基础、沉井基础

A（箱式基础）→ 按结构形式不同  
B（垫层基础）→ 按材料组成不同  
C（减振基础）→ 按使用功能不同

---

### 【例题·单选】2021年
下列设备基础中，属于按使用功能划分的是（ ）。

A. 垫层基础  
B. 联合基础  
C. 减振基础  
D. 箱式基础  

**答案：C**  
**解析：** 使用功能不同的基础分类及应用：减振基础、绝热层基础。

- 垫层基础 → 按材料组成不同
- 联合基础 → 按埋置深度不同
- 箱式基础 → 按结构形式不同

---

### 【例题·单选】2024年（改编）
下列地脚螺栓中，属于活动地脚螺栓的是（ ）。

A. 弯钩螺栓  
B. U形螺栓  
C. 对拧螺栓  
D. 爪式螺栓  

**答案：C**  
**解析：** 活动地脚螺栓是一种可拆卸的地脚螺栓，用于固定工作时有强烈振动和冲击的重型机械设备。如 **T形头螺栓、拧入式螺栓、对拧式螺栓** 等。

A、B、D 均属于直埋地脚螺栓。

## 四、易混淆辨析

| 容易混淆点 | 区分关键 |
|------------|----------|
| 联合基础 vs 桩基础 | 联合基础是 **浅基础**（底面积受限、地基承载力低）；桩基础是 **深基础**（精密大型、控制振动/沉降） |
| 直埋 vs 活动地脚螺栓 | 直埋 ← 无强烈振动；活动 ← 有强烈振动和冲击（可拆卸） |
| 垫层基础 vs 其他材料基础 | 垫层基础是用 **砂** 填筑，外形设圈梁，适用于允许沉降的结构（大型储罐） |
| 胀锚地脚螺栓 → 粘接地脚螺栓 | 粘接与胀锚基本相同，可归为一类记忆 |
