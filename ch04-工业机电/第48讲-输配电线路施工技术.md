# 4.3 输配电线路施工技术

> **考频：★★**（2007单 / 2010单 / 2013多 / 2016多、案）

---

## 一、架空线路施工技术

### 1.1 施工一般程序

```
线路测量 → 基础施工 → 杆塔组立 → 放线、架线 → 导线连接 → 线路试验 → 竣工验收检查
```

> **记忆口诀：立放导师**（谐音：**立**放导**师** → 杆塔组**立**、**放**线架线、**导**线连接、线路试**验**——取后四步的联想起头）

### 1.2 线路测量

- 依据设计提供的数据 **复核** 设计给定的 **杆塔位中心桩**，并以此作为测量基准

### 1.3 基础施工

#### 电杆基础坑

| 项目 | 允许偏差 |
|------|----------|
| 双杆基坑根开中心偏差 | ≤ **30mm** |
| 两杆坑深度偏差 | ≤ **20mm** |

- 混凝土电杆底盘的 **圆槽面应与电杆轴线垂直**，找正后填土夯实至底盘表面

#### 试块留置

| 塔型 / 条件 | 试块组数要求 |
|-------------|--------------|
| **耐张塔** 和 **悬垂转角塔**（混凝土现浇基础） | **每基取一组** |
| **悬垂直线塔**（一般线路，同一施工队） | **每5基** 或不满5基取一组 |
| 单基或连续浇筑混凝土量超过 **100m³** | 取一组 |

### 1.4 杆塔施工

#### （1）混凝土电杆

| 构件类型 | 裂缝控制 |
|----------|----------|
| **预应力**混凝土电杆及构件 | 不得有 **纵向、横向裂缝** |
| **普通钢筋**混凝土电杆及细长构件 | 不得有 **纵向裂缝**；横向裂缝宽度 ≤ **0.05mm** |

- 杆塔拉线应对称调整并收紧，防止过紧或受力不均使杆塔 **倾斜或局部弯曲**
- 横担安装应 **平正**；绝缘子安装应 **牢固**

#### （2）铁塔——组立方法

| 大类 | 具体方法 | 记忆 |
|------|----------|------|
| **整体组立法** | 倒落式人字抱杆法、座腿式人字抱杆法等 | "**落座整人**"（落/座→整体→人字） |
| **分解组立法** | 内/外拉线抱杆分解组塔、倒装组塔等 | — |

### 1.5 放线、架线

#### 放线方式选择

| 电压等级 | 放线方式 |
|----------|----------|
| **220kV及以上** | **应采用** 张力放线（导线保持张力、脱离地面、架空状态） |
| **110kV** | **宜采用** 张力放线 |
| 条件限制或改建、扩建 | 可采用 **非张力放线**（人力/机械牵引，拖地放线） |

- 张力放线过程中须防止：**松股、断股、鼓包、扭曲**

#### 放线要求

- 放铝线或钢芯铝线时，每根电杆横担上预挂 **3只开口滑轮**，将导线提起嵌入滑轮，沿滑轮移动
- **导线应一根一根地施放**，线盘处留专人检查质量

### 1.6 导线连接

#### 连接禁忌（"三不同一严禁"）

> **不同金属、不同规格、不同绞制方向的导线或架空地线，严禁在一个耐张段内连接**

- 应使用 **配套接续管及耐张线夹** 进行连接

#### 握着强度试验

| 项目 | 要求 |
|------|------|
| 试件数量 | 不得少于 **3组** |
| 检测单位 | 应有 **资质** 的检测单位 |
| 连接方式 | 螺栓式耐张线夹及钳压管连接时，分别制作试件 |

#### 握着强度最小值

| 连接方式 | 握着强度要求 |
|----------|-------------|
| **液压** 握着强度 | ≥ 导线设计使用拉断力的 **95%** |
| **螺栓式耐张线夹** 握着强度 | ≥ 导线设计使用拉断力的 **90%** |
| **钳压管直线连接** 握着强度 | ≥ 导线设计使用拉断力的 **95%** |

> 架空地线的连接强度应与导线相对应

#### 档距内接续管和补修管数量

| 电压等级 | 接续管 | 补修管 |
|----------|--------|--------|
| **66kV及以下** | ≤ **1个** | ≤ **3个**（张力放线时 ≤ **2个**） |
| **110～750kV** | ≤ **1个** | ≤ **2个** |

### 1.7 架空电力线路试验

#### （1）绝缘电阻测量

| 绝缘子类型 | 电压等级 | 绝缘电阻值 | 测量工具/方式 |
|-----------|----------|-----------|--------------|
| **悬式绝缘子** | 330kV及以下 | ≥ **300MΩ** | 2500V兆欧表；按同批数量 **10%抽查** |
| | 500kV及以上 | ≥ **500MΩ** | 同上 |
| **支柱绝缘子** | 35kV及以下 | ≥ **500MΩ** | 同上 |

#### （2）交流耐压试验

- **35kV及以下** 支柱绝缘子：可在母线安装后一起进行
- **35kV多元件支柱绝缘子**：

| 元件数 | 每元件交流耐压试验值 |
|--------|---------------------|
| 两个胶合元件（双元件） | **50kV**（100） |
| 三个胶合元件（三元件） | **34kV**（102） |
| **悬式绝缘子** | **60kV** |

#### （3-6）其他试验项目

| 项目 | 要求 |
|------|------|
| 35kV以上线路工频参数 | 符合设计要求 |
| 线路各相两侧 **相位** | 应 **一致** |
| 杆塔 **接地电阻值** | 符合设计要求 |
| **冲击合闸试验** | 额定电压、空载、**3次** |

> **冲击合闸次数对比：** 架空线路 3次 ←→ 变压器交接试验 5次 ←→ 送电试运行 5次

### 1.8 竣工验收

- 额定电压下对空载线路 **冲击合闸 3次**，无问题

## 二、电缆线路施工技术

### 2.1 电缆保护管施工要求

> 在电缆进入建筑物、隧道、穿过楼板及墙壁处，从地面引至电杆、设备、墙外表面、行人易接近处（距地面 **2m以下**）及其他可能受机械损伤处，应设保护管或保护罩

#### （1）电缆金属保护管

| 项目 | 要求 |
|------|------|
| 管口处理 | 无毛刺和尖锐棱角 |
| 连接方式 | **不应直接对焊**，应采用 **螺纹接头连接** 或 **套管密封焊接** |
| 弯制后弯扁程度 | ≤ 管子外径的 **10%** |
| 内径 | ≥ 电缆外径的 **1.5倍** |
| 明敷支点间距（设计无要求时） | ≤ **3m** |
| 与桥架连接 | 宜由桥架 **侧壁引出**，采用 **管接头固定** |

#### （2）电缆排管

**材料：** 钢管、塑料管、陶瓷管、石棉水泥管或混凝土管（管内必须光滑）

**排管孔数：** 2、4、6、8、10、12、14、16孔等形式（管子接头错开，混凝土浇成整体）

| 项目 | 要求 |
|------|------|
| 电力电缆排管孔径 | ≥ **100mm** |
| 控制电缆排管孔径 | ≥ **75mm** |
| 埋深（人行道上） | ≥ **500mm** |
| 埋深（一般地区） | ≥ **700mm** |
| 直线距离超 **100m**、转弯和分支处 | 设置 **排管电缆井** |
| 排管通向井坑坡度 | ≥ **0.1%**（以便水流井坑） |

### 2.2 电缆支架施工要求

| 项目 | 要求 |
|------|------|
| 水平安装支架各层横档 | 在同一水平面上，偏差 ≤ **5mm** |
| 电缆沟内/建筑物上安装支架 | 与电缆沟/建筑物 **相同坡度** |
| 电缆桥架固定 | 牢固，连接板螺栓紧固，螺母位于 **桥架外侧** |
| 金属支架、桥架及竖井（全长） | **必须可靠接地** |

### 2.3 电缆敷设前检查

1. 电缆型号、规格、电压等级符合设计要求；外观无损伤、绝缘良好
2. 充油电缆接头 **无渗漏油**，油样试验合格
3. 按设计和实际路径计算每根电缆长度，**合理安排每盘电缆，减少电缆接头**
4. 电缆封端应严密，并根据要求做绝缘试验

#### 电缆绝缘试验分类

| 电压等级 | 试验项目 |
|----------|----------|
| **6kV以上** | 做 **交流耐压试验** 和 **直流泄漏性试验** |
| **1kV以下** | 用兆欧表测试 **绝缘电阻**，并做好记录 |

### 2.4 电缆敷设

#### （1）支架上敷设电缆

**排列顺序：** "**由上而下**" 按电压等级由高至低

```
上 → 电力电缆（高电压→低电压）
    ↓
    控制和信号电缆（强电→弱电）
    ↓
下 → 通信电缆
```

- **35kV及以下** 相邻电压级电力电缆可排列于 **同一层支架**
- **1kV及以下** 电力电缆（采取防火分隔和有效抗干扰措施后）可与强电控制、信号电缆配置于 **同一层支架**
- **工作与备用电缆** 应配置在不同层或不同侧支架上，并实行 **防火分隔**

#### （2）直埋电缆敷设要求

| 项目 | 要求 |
|------|------|
| 铠装电缆金属层接地电阻 | ≤ **10Ω** |
| 一般埋深 | ≥ **0.7m** |
| 穿越农田埋深 | ≥ **1m** |
| 电缆上方铺软土或细沙 | **100mm** 厚 |
| 覆盖保护板（或砖）宽度 | 超出电缆两侧各 **50mm** |

> **埋深对比记忆：**
> - 直埋：一般 0.7m / 穿越农田 1m
> - 排管：人行道 0.5m / 一般地区 0.7m

**方位标志（标桩）设置位置：** 直线段每隔 **50～100m**、电缆接头处、转弯处、进入建筑物等处

**保护管要求：**
- 电缆互相交叉、与非热力管和管道交叉、穿越公路 → 穿保护管
- 保护管长度超出交叉点 **1m**
- 交叉净距 ≥ **250mm**
- 保护管内径 ≥ 电缆外径的 **1.5倍**

#### （3）电缆施放

| 敷设方式 | 要求 |
|----------|------|
| **人工施放** | 每隔 **1.5～2m** 放置滑轮；用绳子扣住向前拖拽，**不得放在地上拖拉** |
| **机械敷设** | 速度 ≤ **15m/min**；牵引头加装钢丝套 |
| 大截面电缆（长度 ≤ **300m**） | 可直接绑住电缆芯牵引 |
| **交流单芯电缆** | **不得单独穿入钢管内**（涡流发热→火灾风险） |

#### （4）标志牌的装设

**装设位置：** 电缆终端头、电缆接头、拐弯处、夹层内、隧道及竖井的两端、人井内

**标志牌内容：** 线路编号、电缆 **型号、规格及起讫地点**；并联使用的电缆应有 **顺序号**

### 2.5 电缆的防火阻燃措施

| 部位 / 场景 | 措施 |
|-------------|------|
| 电缆引至柜、盘的开孔，贯穿隔墙/楼板孔洞，工作井电缆管孔 | **防火封堵** |
| 电缆沟/桥架主通道分支处、多段配电装置分段处、长距离每 **100m** 处、入口处 | 设 **防火墙或阻火段** |
| 防火墙两侧长度 ≥ **2m** 内电缆 | 涂刷 **防火涂料** 或缠绕 **防火包带** |
| 与电力电缆同通道的控制电缆/非阻燃通信光缆 | 穿入 **阻燃管或耐火电缆槽盒**，或设置 **防火板材** |
| 电缆竖井 | 每隔 **7m** 或按楼层设置 **防火封堵** |

### 2.6 电缆线路试验

#### （1）主绝缘及外护层绝缘电阻测量

| 测量对象 | 标准 | 仪表 |
|----------|------|------|
| 橡塑电缆 **外护套、内衬层** 绝缘电阻 | ≥ **0.5MΩ/km** | **500V** 兆欧表 |
| 电缆绝缘（一般） | — | **2500V** 兆欧表 |
| 6/10kV及以上电缆备选 | — | **5000V** 兆欧表 |

#### （2）油浸纸（充油）绝缘电缆直流耐压试验

**试验电压（表4.3-6）：**

| 电缆额定电压 U₀/U | 48/66 | 64/110 | 127/220 | 190/330 | 290/500 |
|-------------------|-------|--------|---------|---------|---------|
| 直流试验电压（kV） | 162 | 275 | 510 | 650 | 840 |

**试验程序：**
- 分 **4～6阶段** 均匀升压，每阶段停留 **1min**，并读取泄漏电流值
- 电压升至规定值后维持 **15min**，读取 1min 和 15min 时泄漏电流

**泄漏电流判断：**

| 指标 | 标准 |
|------|------|
| **不平衡系数**（最大值/最小值） | ≤ **2** |
| 6/10kV及以上电缆泄漏电流 < **20μA** 时 | 不平衡系数可不作规定 |
| 6kV及以下电缆泄漏电流 < **10μA** 时 | 不平衡系数可不作规定 |
| 泄漏电流 **很不稳定** / 随电压 **急剧上升** / 随试验时间 **有上升现象** | 电缆绝缘可能有缺陷，需处理 |

#### （3-5）其他试验

| 项目 | 要求 |
|------|------|
| 额定电压 **0.6/1kV** 电缆线路 | 用 **2500V兆欧表** 测量导体对地绝缘电阻 **代替耐压试验**，试验时间 **1min** |
| 交流单芯电缆 **外护套** | 进行 **直流耐压试验** |
| **66kV及以上** 橡塑绝缘电力电缆 | 安装完成后结合交流耐压试验进行 **局部放电测量** |

## 四、易混淆辨析

| 易混点 | 区分关键 |
|--------|----------|
| 张力放线 vs 非张力放线 | 张力放线：导线 **脱离地面**（架空状态）；非张力放线：**拖地放线**，基本不受力 |
| 整体组立法 vs 分解组立法 | 整体：一次立起整塔；分解：分节吊装组立 |
| 3种握着强度 | 液压/钳压管 **95%** > 螺栓式 **90%** |
| 66kV及以下 vs 110～750kV 补修管 | 前者≤3个（张力≤2个），后者≤2个 |
| 冲击合闸次数比较 | 架空线路 **3次** / 变压器交接 **5次** / 送电试运行 **5次** |
| 直埋埋深 vs 排管埋深 | 直埋：一般 0.7m，农田 1m；排管：人行道 0.5m，一般 0.7m |
| 悬式 vs 支柱绝缘子耐压 | 悬式 **60kV**；双元件 **50kV/元件**；三元件 **34kV/元件** |
| 不同兆欧表用途 | 电缆绝缘 → **2500V**（6/10kV以上可选5000V）；外护套 → **500V**；0.6/1kV代替耐压 → **2500V** |

## 五、例题精讲

### 【例题·多选】2016年
关于电缆排管敷设要求的说法，正确的是（ ）。

A. 排管孔径应不小于电力电缆外径的 1.5倍  
B. 埋入地下的电力排管至地面距离应不小于 0.4m  
C. 交流三芯电力电缆不得单独穿入钢管内  
D. 敷设电力电缆的排管孔应不小于 100mm  
E. 电力排管通向电缆井时应有不小于 0.1%坡度

**答案：ADE**

**解析：**
- A ✅ 排管孔径 ≥ 电力电缆外径的1.5倍（与金属保护管内径通用要求一致）
- B ❌ 排管埋深：人行道上 ≥ 500mm，一般地区 ≥ 700mm，不是0.4m
- C ❌ **交流单芯**电缆不得单独穿入钢管（涡流发热），交流三芯可穿入
- D ✅ 敷设电力电缆的排管孔径应 ≥ 100mm
- E ✅ 排管通向井坑应有 ≥ 0.1%的坡度
