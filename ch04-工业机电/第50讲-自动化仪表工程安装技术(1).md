## 考点：自动化仪表设备安装技术（★★★）

**真题分布**：2007单 / 2014单 / 2016多 / 2019单 / 2021案 / 2023单

### 1. 取源部件安装要求

> **取源部件定义**：在被测对象上，为安装连接检测元件所设置的专用管件、引出口和连接阀等元件。

#### 1.1 取源部件安装的一般要求

| 序号 | 要求 | 关键数字 / 关键词 |
|------|------|-------------------|
| ① | 安装应在工艺**设备制造**或工艺管道**预制、安装的同时**进行 | 同步施工 |
| ② | **开孔和焊接**必须在工艺管道或设备的**防腐、衬里、吹扫和压力试验前**进行 | 防腐衬里吹扫试压**前** |
| ③ | 高压、合金钢、有色金属管道上开孔 → **机械加工**方法 | 机械加工 |
| ④ | 不应在设备或管道的**焊缝及其边缘上**开孔及焊接 | 避开焊缝 |
| ⑤ | 取源阀门与设备或管道的连接**不宜采用卡套式接头** | 不宜卡套 |
| ⑥ | 有绝热层时，取源部件应**露出绝热层外** | 露出绝热层 |
| ⑦ | 砌体和混凝土浇筑体上安装 → 砌筑或浇筑**同时埋入**；无法同时时**预留安装孔** → 按设计填充密实、封堵严密 | 同时埋入 / 预留孔 |
| ⑧ | 安装完毕后，应与设备和管道**同时进行压力试验** | 同步试压 |

#### 1.2 温度取源部件安装

| 安装方式 | 要求 |
|----------|------|
| **垂直安装** | 取源部件轴线与管道轴线**相垂直** |
| **拐弯处安装** | 宜**逆着物料流向**，取源部件轴线与管道轴线**相重合** |
| **倾斜角度安装** | 宜**逆着物料流向**，取源部件轴线与管道轴线**相交** |

> 记忆口诀：垂直→垂直，拐弯→重合（逆流），斜装→相交（逆流）

#### 1.3 压力取源部件安装要求

**（1）位置选择**
- 选在被测物料**流束稳定**的位置
- 与温度取源部件在同一管段上时 → 压力取源部件应安装在**温度取源部件的上游侧**

> 理解：压力优先于温度，先测压力再测温度，避免温度插入件干扰流束影响压力测量

**（2）混浊物料时的安装方位**
- 当检测带有**灰尘、固体颗粒或沉淀物等混浊物料**的压力时：
  - 垂直和倾斜的设备和管道上 → **倾斜向上**安装
  - 水平管道上 → 宜**顺物料流束**安装

**（3）水平/倾斜管道上安装方位（★★★★★）**

| 测量介质 | 安装方位 |
|----------|----------|
| **气体**压力 | 管道的**上半部** |
| **液体**压力 | 管道的**下半部**与水平中心线成 **0°~45°** 夹角范围 |
| **蒸汽**压力 | 管道的**上半部**，以及管道的**下半部**与水平中心线成 **0°~45°** 夹角范围 |

> 记忆逻辑：气体轻在上半部；液体向下沉，在下半部0°~45°；蒸汽兼顾两侧（冷凝水和蒸汽共存）

#### 1.4 流量取源部件安装

**（1）直管段要求**
- 上、下游直管段**最小长度**应符合设计要求
- 规定范围内**不得设置其他取源部件或检测元件**
- 直管段内表面应**清洁，无凹坑或凸出物**

**（2）温度计与节流件的距离**（★★★★）

> 提示：节流原理→调控流量和压力，局部收缩，降流降压，流速增加

| 位置 | 条件 | 要求距离 |
|------|------|----------|
| 节流件**上游** | 温度计插套/套管直径 ≤ 0.03D | ≥ **5D** |
| 节流件**上游** | 温度计插套/套管直径 在 0.03D ~ 0.13D 之间 | ≥ **20D** |
| 节流件**下游** | 任意 | ≥ **5D** |

> D = 管道内径

**（3）节流装置取压口方位（★★★★★）**

| 测量介质 | 取压口方位 |
|----------|------------|
| **气体**流量 | 管道的**上半部** |
| **液体**流量 | 管道的**下半部**与水平中心线成 **0°~45°** 夹角范围 |
| **蒸汽**流量 | 管道的**上半部**与水平中心线成 **0°~45°** 夹角范围 |

**（4）其他要求**
- 均压环取压：取压孔在同一截面上**均匀设置**，上、下游取压孔数量**相等**
- 皮托管、均速管等流量检测元件：取源部件轴线应与管道轴线**垂直相交**

#### 1.5 物位取源部件安装

| 序号 | 仪表类型 | 安装要求 |
|------|----------|----------|
| ① | **通用要求** | 选在物位**变化灵敏**，且不使检测元件受到物料**冲击**的部位 |
| ② | **内浮筒/浮球液位计** | 导向管或导向装置应**垂直安装**，管内液流应**畅通** |
| ③ | **浮球式液位仪表** | 法兰短管应使浮球能在全量程范围内**自由活动** |
| ④ | **电接点水位计** | 测量筒应**垂直安装**；筒体**零水位电极**中轴线与被测容器正常工作时的**零水位线处于同一高度** |
| ⑤ | **静压液位计** | 取源部件安装位置应**远离液体进出口** |
| ⑥ | **重锤料位计** | 在容器中心与侧壁之间，应**垂直安装** |
| ⑦ | **雷达、超声波** | 检测元件与被测对象区域内**无遮挡物**，并应**远离物料进出口** |

#### 1.6 分析取源部件安装

**（1）位置选择**
- 安装位置要求：**压力稳定、能灵敏反映真实成分变化、取得具有代表性的分析样品**
- 取样点周围**不应有**：层流、涡流、空气渗入、死角、物料堵塞或非生产过程的化学反应

**（2）含杂质气体的情况**
- 被分析的气体内含有**固体或液体杂质**时 → 取源部件轴线与水平线之间的**仰角应大于15°**

> 理解：倾斜向上防止杂质堵塞取样口

**（3）安装方位**
- 在水平和倾斜的管道上安装分析取源部件时 → 安装方位与**安装压力取源部件的要求相同**

| 测量介质 | 安装方位 |
|----------|----------|
| **气体** | 管道**上半部** |
| **液体** | 管道**下半部**与水平中心线成 **0°~45°** 夹角范围 |
| **蒸汽** | 管道**上半部**，以及管道**下半部**与水平中心线成 **0°~45°** 夹角范围 |

## 横向对比总结

### 取源部件方位速查表（★★★★★ 核心考点）

| 测量类型 | 介质 → 气体 | 介质 → 液体 | 介质 → 蒸汽 |
|----------|-------------|-------------|-------------|
| **压力取源** | 上半部 | 下半部 0°~45° | 上半部 + 下半部 0°~45° |
| **流量取源（节流装置取压口）** | 上半部 | 下半部 0°~45° | 上半部 0°~45° |
| **分析取源** | 上半部（同压力） | 下半部 0°~45°（同压力） | 上半部 + 下半部 0°~45°（同压力） |

### 易混淆点

| 对比项 | 关键差异 |
|--------|----------|
| 压力取源 vs 流量取源（蒸汽） | 压力：上半部 **+** 下半部0°~45°；流量：**仅**上半部0°~45° |
| 上游温度计 vs 下游温度计 | 上游按直径分5D/20D；下游统一5D |
| 混浊物料压力取源方向 | 垂直/倾斜管→**倾斜向上**；水平管→**顺物料流束** |

### 时间点要求

| 动作 | 时间节点 |
|------|----------|
| 取源部件安装 | 设备制造或管道预制、安装的**同时** |
| 开孔和焊接 | 防腐、衬里、吹扫和压力试验**前** |
| 砌体/混凝土取源部件 | 砌筑或浇筑**同时埋入** |
| 压力试验 | 取源部件安装完毕后，与设备和管道**同时**进行 |

## 备考提示

- **选择题常考**：取压口方位（上半部/下半部/0°~45°）、距离数字（5D/20D）、时间顺序
- **案例题应用**：2021年考过案例分析，注意将知识点融入实际施工场景理解
- **记忆线索**：气体轻→上半部；液体重→下沉（下半部0°~45°）；蒸汽是气体+冷凝水→兼顾两侧
