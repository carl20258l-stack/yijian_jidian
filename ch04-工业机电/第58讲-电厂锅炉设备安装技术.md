## 考点：电厂锅炉设备安装技术

### 1. 电厂锅炉设备的组成

电厂锅炉系统主要设备由**锅炉本体设备**及**锅炉辅助设备**两部分组成。

#### 锅炉本体设备

包括：锅炉钢架、汽包（或汽水分离器及储水箱）、水冷壁、过热器、再热器、省煤器、燃烧器、空气预热器、烟道等主要部件。

#### 锅炉辅助设备

> **记忆口诀：风吹煤渣**

包括：
- **风** — 送引风设备
- **吹** — 吹灰设备
- **煤** — 给煤制粉设备
- **渣** — 除灰排渣设备

#### ⭐ 汽包的作用

汽包既是自然循环锅炉的一个主要部件，又是将锅炉各部分受热面（如下降管、水冷壁、省煤器和过热器等）连接在一起的构件；其储热能力可以提高锅炉运行的安全性；在负荷变化时，可以减缓气压变化的速度，保证蒸汽品质。

### 2. 电厂锅炉主要设备的安装技术

#### 2.1 锅炉安装一般程序

```
设备清点、检查和验收
  → 基础验收
  → 基础放线
  → 设备搬运及吊装
  → 钢架及梯子平台安装
  → 汽水分离器及储水箱（或汽包）安装
  → 锅炉前炉膛受热面安装      ← 前部（炉膛）
  → 尾部竖井受热面安装        ← 后部（尾部受热面：省煤器、预热器）
  → 燃烧设备安装
  → 附属设备安装
  → 热工仪表保护装置安装
  → 单机试运行
  → 报警及联锁试验
  → 水压试验
  → 锅炉风压试验
  → 锅炉酸洗
  → 锅炉吹管
  → 锅炉热态调试与试运行
```

> **提示：** 前部指炉膛（前炉膛受热面），后部指尾部竖井受热面（省煤器、预热器）

#### 2.2 锅炉钢架安装

**组成与连接方式：**
锅炉钢架是炉体的**支撑构架**，全钢结构，承载着受热面、炉墙及炉体其他附件的重量，并决定炉体的外形。

**主要组成：** 立柱、横梁、水平支撑、垂直支撑和斜支撑、平台、扶梯、顶板梁。

#### 2.3 锅炉受热面组合安装

##### （1）受热面施工程序

> **记忆口诀：电光球找对面，球吊高踢光**

```
设备及其部件清点检查
  → 合金设备（部件）光谱复查
  → 通球试验与清理
  → 联箱找正划线
  → 管子就位对口焊接
  → 组件地面验收
  → 组件二次通球试验
  → 组件吊装
  → 组件高空对口焊接
  → 组件整体找正
  → 合金设备（部件）、焊口安装后光谱复查
```

> **提示：** 进行通球试验是因为锅炉本体受热面由大量管路组成（如水冷壁、下降管等）。

##### （2）受热面施工要求

- **施工场地**：根据设备组合后体积、重量以及现场施工条件来决定
- **组合形式**：根据设备的结构特征及现场的施工条件来决定

**两种组合形式对比：**

| 组合形式 | 优点 | 缺点 |
|----------|------|------|
| **直立式**（按安装状态组合，联箱在上、管屏在下） | ① 组合场占用面积少<br>② 便于组件的吊装 | ① 钢材耗用量大<br>② 安全状况较差 |
| **横卧式**（管排横卧摆放与联箱组合，竖立后吊装） | ① 钢材耗用量小<br>② 安全状况好 | ① 占用组合场面积多<br>② 竖立时易造成设备永久变形或损伤 |

##### （3）受热面组件吊装原则和程序

**吊装原则：** 锅炉一般为悬吊式，整个受热面通过吊杆吊挂。因此：
> **先上后下**，即**先吊杆 → 后联箱 → 再到管屏**

因为锅炉的过热器、再热器管屏受力由联箱承受，所以**先吊挂联箱**。

#### 2.4 锅炉密封（防止漏风漏灰）

| 阶段 | 时间节点 |
|------|----------|
| **一次密封** | 锅炉水压试验**前**完成 |
| **二次密封** | 炉膛严密性试验**前**完成 |

> **顺序：** 一次密封 → 水压试验 → 二次密封 → 严密性试验

**炉膛气密性试验（风压试验）：**
- 试验压力按设备技术文件规定
- 如无规定：按炉膛**工作压力 + 0.5kPa** 进行正压试验
- 一般负压锅炉的风压试验值选择 **0.5kPa**

#### 2.5 ⭐ 锅炉水压试验

锅炉受热面系统安装完成后应进行**整体水压试验**，超压试验压力按制造厂规定执行。若无规定：

##### 试验压力

| 设备类型 | 试验压力 |
|----------|----------|
| **汽包锅炉**一次系统 | 汽包设计压力的 **1.25 倍** |
| **直流锅炉**一次系统 | 过热器出口联箱设计压力的 **1.25 倍**，且不小于省煤器进口联箱设计压力的 **1.1 倍** |
| **再热器** | 进口联箱设计压力的 **1.5 倍** |

**详细对照表：**

| 项次 | 设备名称 | 锅筒（壳）工作压力 (MPa) | 试验压力 |
|------|----------|--------------------------|----------|
| 1 | 汽包锅炉本体 | < 0.8 | 1.5 倍工作压力，但不小于 0.2 MPa |
| | | 0.8 ~ 1.6 | 工作压力 + 0.4 MPa |
| | | > 1.6 | 1.25 倍工作压力 |
| 2 | 直流锅炉本体 | 任何压力 | 介质出口工作压力的 1.25 倍，且不小于省煤器进口工作压力的 1.1 倍 |
| 3 | 再热器 | 任何压力 | 1.5 倍再热器工作压力 |
| 4 | 省煤器 | 任何压力 | 1.5 倍省煤器工作压力 |

##### 合格标准

受压元件金属壁和焊缝**无泄漏及湿润现象**，受压元件没有明显的**残余变形**。

### 3. 锅炉热态调试与试运行

**四步流程：**
1. 锅炉化学清洗
2. 锅炉蒸汽吹管
3. 蒸汽严密性试验及安全阀调整
4. 锅炉试运行

#### 3.1 锅炉化学清洗

#### 3.2 锅炉蒸汽吹管

- 临时管道系统应由具有**设计资质**的单位进行设计
- 排汽口处加装**消声器**
- 吹管范围包括：
  > **记忆口诀：2 热 2 蒸**
  - 锅炉过热器
  - 再热器
  - 主蒸汽管道
  - 再热蒸汽管道
- 吹洗过程中，至少有一次停炉冷却（时间 **12h 以上**），以提高吹管效果

#### 3.3 蒸汽严密性试验及安全阀调整

#### 3.4 锅炉试运行

- 锅炉启动时**升压应缓慢**，升压速度应控制，尽量减小壁温差以保证分离器储水箱（汽包）的安全工作
- 认真检查**人孔、焊口、法兰**等部位，如发现泄漏应及时处理
- 仔细观察各联箱、分离器储水箱（汽包）、钢架支架等部位的热膨胀及其位移是否正常
- 对于 **300MW 级及以上**的机组，锅炉应连续完成 **168h 满负荷试运行**
- 试运行完毕后，按规定办理**移交签证**手续

## 历年真题

### 例题 1（2015 年改编）

**题目：** 锅炉蒸汽管道的冲洗与吹洗范围，不包括（ ）。

A. 主蒸汽管道
B. 锅炉过热器
C. 再热器
D. 凝汽器

**答案：** D

**解析：** 锅炉吹管应包括：锅炉过热器、再热器、主蒸汽管道及再热蒸汽管道（2 热 2 蒸）。凝汽器属于汽轮机系统的辅助设备，不属于锅炉蒸汽吹管范围。

---

### 例题 2

**题目：** 下列有关锅炉试运行的说法中，错误的是（ ）。

A. 锅炉吹管的临时管道系统应由建设单位审批
B. 锅炉试运行启动时升压应缓慢，尽量减小壁温差
C. 检查人孔、焊口、法兰等部位，发现有泄漏时及时处理
D. 观察各联箱锅筒钢架支架等的热膨胀及其位移是否正常

**答案：** A

**解析：** A 选项错误。锅炉吹管的临时管道系统应由具有**设计资质**的单位进行设计，而非由建设单位审批。设计资质是关键词，建设单位审批不具备专业设计能力。
