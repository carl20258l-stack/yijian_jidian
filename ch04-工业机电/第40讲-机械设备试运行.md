# 4.1 机械设备试运行

## 一、考情分析

| 项目 | 内容 |
|------|------|
| 重要性 | ★★（两星，中频考点） |
| 真题分布 | 2017 案例、2019 单选 |
| 考查形式 | 案例问答（试运行目的/检测项目）、单选题（数字/温度/时间） |
| 难点 | 多种设备的温度限值、时间要求容易混淆 |

---

## 二、设备试运行的四个步骤

```
设备调试 → 单机试运行 → 联动试运行 → 负荷试运行
```

**单机试运行操作口诀：**

> **先手动，后电动；先点动，后连续；先低速，后高速。**

| 步骤 | 说明 |
|------|------|
| 设备调试 | 单台设备安装后的初步调试 |
| 单机试运行 | 考核单台设备的机械性能、制造和安装质量 |
| 联动试运行 | 多台设备联动测试 |
| 负荷试运行 | 带负荷运行，考核综合性能 |

---

## 三、设备试运行前应完成的工作（人机料法环）

| 维度 | 具体要求 |
|------|----------|
| **机** | 机器及附属设备、管道等安装工作全部完成，施工记录及资料齐全 |
| **料** | 与试运行有关的工艺管道及设备**吹扫、清洗、气密**完成 |
| **法** | 保温、保冷及防腐等工作基本完成（有碍试运行检查部位除外） |
| **环** | 土建、水、气、汽等公用工程及电气、仪表控制系统施工结束 |
| **人** | 参加试运行人员熟知设备构造、性能、技术文件、试运行工艺，掌握操作规程 |

> **记忆框架：** 按"人机料法环"五个维度展开，考试可能以多选题或案例补充题形式考查。

---

## 四、设备单机试运行通用要求

### 4.1 试运行时间

- 机器单机试运行时间宜为 **2h**（一般规定）
- 具体时间以产品技术文件或设计文件为准

### 4.2 试运行介质

- 若无特殊规定，宜以 **水、空气或氮气** 为介质（根据设计文件及实际条件决定）

### 4.3 轴承温度（核心数字考点）

| 轴承类型 | 温升上限 | 最高温度 |
|----------|----------|----------|
| **滚动轴承** | ≤ 40℃ | ≤ **80℃** |
| **滑动轴承** | ≤ 35℃ | ≤ **70℃** |

> **记忆口诀：滑 7 滚 8**
>
> - 滑动轴承 → 最高 70℃
> - 滚动轴承 → 最高 80℃

### 4.4 辅助系统

- 润滑、密封、液压、气（汽）动、冷却等辅助系统工作正常，**无渗漏**
- **油箱温度最高不得超过 60℃**

---

## 五、单机试运行结束后应及时完成的工作（收尾流程）

| 序号 | 工作内容 |
|:----:|----------|
| ① | **切断电源**和其他动力源 |
| ② | 卸掉各系统中的压力及负荷，进行**排气、排水或排污**；对蓄势器和蓄势腔及机械设备内剩余压力卸压 |
| ③ | 检查各紧固部件；**拆除临时管道及设备**，将正式管道进行复位安装 |
| ④ | 检查各阀门**开关在规定状态** |
| ⑤ | 检查润滑剂清洁度，清洗过滤器；必要时更换新的**润滑剂** |
| ⑥ | **拆除临时装置**和恢复拆卸的设备部件及附属装置；复查设备几何精度，复紧紧固部件 |
| ⑦ | **清理和清扫**现场，将机械设备盖上防护罩 |
| ⑧ | 整理试运转各项**记录**，运行合格后由参加单位在规定的表格上共同**签字确认** |

> **考查角度：** 案例题常考"试运行结束后应完成哪些工作"，需按条目完整默写。

## 六、典型设备单机试运行要求（数字考点密集）

### 6.1 离心通风机

| 要点 | 参数 |
|------|------|
| 启动前 | 关闭进气调节门 |
| 小负荷试运行 | 调节门开度 **0°~5°**，达到正常转速后进行 |
| 连续运行时间 | 轴承达到稳定温度后 ≥ **20min** |
| 滑动轴承大型风机 | 带负荷 2h 后停机检查 → 修整后再连续运行 ≥ **6h** |
| 高温离心通风机 | 升温速率 ≤ **50℃/h** |
| 轴承温度 | 不得高于环境温度 + **40℃** |
| 振动速度 | ≤ **6.3mm/s**；矿井用 ≤ **4.6mm/s** |

---

### 6.2 离心鼓风机

| 要点 | 参数 |
|------|------|
| 试运行顺序 | 先试驱动机、增速器，后试整机 |
| 整机小负荷 | 进气节流阀开至 **10°~15°** |
| 轴承润滑油进油温度 | **(40 ± 5)℃** |
| 启动时油温 | ≥ **25℃** |
| 进油压力 | **0.1~0.15MPa** |
| 报警油压 | < **0.08MPa** → 启动辅助油泵 |
| 停机油压 | < **0.05MPa** |
| 浮环密封油进油温度 | **(40 ± 5)℃** |
| 浮环油压高于气封压力 | **50kPa** |
| 高位罐液面报警 | ± **150mm** 报警；- **250mm** 过低报警；- **300mm** 停机 |
| 轴承箱油温温升 | ≤ **28℃** |
| 轴承出口温度 | ≤ **82℃** |
| 带负荷连续运行 | 轴承稳定后 ≥ **2h** |
| 停机后停油泵 | **20min** 后或回油温度 < **40℃** 后 |

**轴承温度和轴承排油温度（表4.1-1）：**

| 项目 | 滚动轴承 | 滑动轴承 |
|------|----------|----------|
| 轴承体温度 | ≤ 环境温度 + 40℃ | ≤ 70℃ |
| 轴承的排油温度 | — | ≤ 进油温度 + 28℃ |
| 轴承合金层温度 | — | ≤ 进油温度 + 50℃ |

---

### 6.3 无润滑压缩机

| 要点 | 要求 |
|------|------|
| 运转监测 | 活塞杆表面温度、各级排气温度、排液温度符合规定 |
| 刮油情况 | 良好，曲轴箱和十字头润滑油不得带入填料函和汽缸内 |
| 逐级升压 | 待排气温度稳定、填料函密封良好、无卡阻后，再逐级升高 |
| 暂停/完工防锈 | 吸气管通入无油干燥氮气 → 缓慢转动压缩机 → 放空阀排出 → 关闭吸排气管阀门 |
| 冷却水 | 汽缸夹套内冷却水应放空 |

---

### 6.4 离心式压缩机

| 要点 | 参数 |
|------|------|
| 齿轮静态接触迹线 | ≥ 齿长的 **65%** |
| 齿轮动态接触斑点 | ≥ 齿长的 **60%** |
| 试运行介质 | 采用**空气**（除非另有规定） |
| 浮环密封 | 用空气试运行时应取出浮环，更换梳齿形试车密封 |
| 排气升压速度 | 每 **5min** 升压 ≤ **0.1MPa** |
| 连续运行时间 | 轴承稳定后 **4~8h** |
| 轴承壳振动速度 | ≤ **6.3mm/s** |

---

### 6.5 泵试运行

#### （1）基本要求

| 要点 | 参数 |
|------|------|
| 试运行介质 | 宜采用**清水**；非清水时按密度折算，流量 ≥ 额定值 **20%** |
| 电流 | 不得超过电动机额定电流 |
| 轴承温升 | ≤ 环境温度 + **40℃** |
| 滑动轴承温度 | ≤ **70℃** |
| 滚动轴承温度 | ≤ **80℃** |
| 机械密封泄漏量 | ≤ **5mL/h** |
| 高压锅炉给水泵机械密封 | ≤ **10mL/h** |

**额定工况下连续试运行时间（表4.1-2）：**

| 泵的轴功率 | 连续试运行时间 |
|------------|----------------|
| ≤ 50 kW | 30 min |
| > 50 ~ ≤ 100 kW | 60 min |
| > 100 ~ ≤ 400 kW | 90 min |
| > 400 kW | 120 min |

**填料密封泄漏量（表4.1-3）：**

| 设计流量 (m³/h) | 泄漏量 (mL/min) |
|------------------|-----------------|
| Q ≤ 50 | 15 |
| 50 < Q ≤ 100 | 20 |
| 100 < Q ≤ 300 | 30 |
| 300 < Q ≤ 1000 | 40 |
| Q > 1000 | 60 |

#### （2）停泵后的要求（2019 单选考点）

| 泵类型 | 操作要点 |
|--------|----------|
| **离心泵** | 关闭**入口阀门** → 冷却后依次关闭附属系统阀门 |
| **高温泵** | 按技术文件操作；停机后每 **20~30min** 盘车半圈，直至泵体温度降至 **50℃** |
| **低温泵** | 泵内常充满液体；吸入阀和排出阀保持**常开**；密封液保持灌泵压力 |
| **易结晶/凝固/沉淀泵** | 停泵后防止堵塞，及时用清水或其他介质**冲洗泵和管道** |
| **通用** | 放净泵内积存的液体 |

---

### 6.6 输送设备

| 要点 | 参数 |
|------|------|
| 空负荷试运行时间 | ≥ **1h**，且 ≥ **2个循环** |
| 可变速设备高速空负荷时间 | ≥ 全部试运行时间的 **60%** |
| 负荷试运行 | 逐渐增加至额定负荷；额定负荷连续运行 ≥ **1h**，且 ≥ **1个工作循环** |

---

### 6.7 桥式起重机

#### 空载试验

- 分别进行各档位下的起升、小车运行、大车运行和取物装置动作试验
- 次数 ≥ **3次**

#### 静载试验

| 要点 | 参数 |
|------|------|
| 试验位置 | 小车停在主梁跨中或有效悬臂处 |
| 试验荷载 | 额定起重量的 **1.25倍** |
| 悬吊高度 | 距地面 **100~200mm** |
| 悬吊时间 | **10min** |
| 合格标准 | 无失稳现象 |
| 永久变形处理 | 重复试验，但不得超过 **3次** |

#### 动载试验

| 要点 | 参数 |
|------|------|
| 试验荷载 | 额定起重量的 **1.1倍** |
| 电动起重机累计运行 | ≥ **1h** |
| 手动起重机累计运行 | ≥ **10min** |
| 动作要求 | 灵敏、平稳、可靠；安全保护、联锁装置和限位开关灵敏准确 |

## 七、案例真题

### 【2017 案例节选】

**问题：** 离心水泵单体试运行的目的何在？应主要检测哪些项目？

> **参考答案：**
>
> **单体试运行的目的：** 主要考核单台设备的机械性能，检验设备的制造、安装质量和设备性能等是否符合规范和设计要求。
>
> **应主要检测的项目：**
> - 机械密封的泄漏量
> - 填料密封的泄漏量
> - 温升
> - 泵的振动值
