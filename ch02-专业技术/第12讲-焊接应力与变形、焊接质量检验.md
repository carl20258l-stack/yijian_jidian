# 2.3 焊接应力与变形、焊接质量检验

> **本讲速览** | ★★★ 高频考点（2009单/2011单/2015多/2017案/2018单/2021多 + 2013单/2017案/2018案）
> - **焊接应力与变形**（★★★）：降低焊接应力的措施（设计3条 + 工艺9条）→ 焊接变形分类（面内/面外）→ 预防焊接变形措施（结构设计 + 装配工艺 + 焊接工艺）
> - **焊接质量检验**（★★）：检验方法分类（破坏性/非破坏性）→ 三阶段检验（焊前/焊中/焊后）

## 2.3.1 焊接应力与焊接变形（★★★）

### 一、降低焊接应力的措施

#### 1）设计措施

| 序号 | 措施 | 关键要点 |
|:---:|:---:|:---|
| ① | **减少焊缝的数量和尺寸** | 可减小变形量，同时降低焊接应力。如：厚壁金属管道→窄间隙焊；大型低温储罐厚壁立缝→双"U"形坡口 + 氩弧焊焊接工艺（新增） |
| ② | **避免焊缝过于集中** | 避免焊接应力峰值叠加 |
| ③ | **优化设计结构** | 如将容器的接管口设计成翻边式，少用承插式 |

#### 2）工艺措施

| 序号 | 措施 | 要点说明 |
|:---:|:---:|:---|
| ① | **采用较小的焊接线能量** | — |
| ② | **合理安排装配焊接顺序** | 使焊缝有自由收缩的余地，降低焊接中的残余应力。★ **典型例**：大型储罐底板焊接→先焊**短焊缝**，再焊**长焊缝** |
| ③ | **层间进行锤击（焊后）** | 焊后用小锤轻敲焊缝及邻近区域→使金属晶粒间的应力得以释放→有效减少焊接残余应力 |
| ④ | **预热拉伸补偿焊缝收缩** | 机械拉伸或加热拉伸 |
| ⑤ | **选用塑性较好的焊条** | 焊接高强钢时选用 |
| ⑥ | **预热** | 焊前对构件进行预热→减小温差 + 减慢冷却速度→减小焊接残余应力 |
| ⑦ | **消氢处理** | 主要目的：使焊缝金属中的**扩散氢逸出**，降低焊缝及热影响区的含氢量→防止氢致冷裂纹 |
| ⑧ | **焊后热处理** | — |
| ⑨ | **利用振动法消除焊接残余应力** | — |

> 【真题2015多选】降低焊接应力的正确措施有（ACE）
> - A. 构件设计时尽量减少焊缝尺寸 ✅
> - B. 将焊缝集中在一个区域 ❌（应为**避免**焊缝过于集中）
> - C. 焊接时采用较小的焊接线能量 ✅
> - D. 焊接过程中，层间锤击 ❌（**焊后**进行层间锤击）
> - E. 焊接前对结构件进行整体预热 ✅

### 三、预防焊接变形的措施

按实施阶段分为三类：

#### （1）进行合理的焊接结构设计（焊前）

| 措施 | 关键词 |
|:---|:---|
| ① 合理安排焊缝位置 | **焊缝** |
| ② 合理选择焊缝数量和长度 | **焊缝** |
| ③ 合理选择坡口形式 | **焊缝** |

> 提示：设计即布局，给焊缝布局

#### （2）采取合理的装配工艺措施（组装）

| 序号 | 措施 | 说明 |
|:---:|:---|:---|
| ① | **预留收缩余量法** | |
| ② | **反变形法** | 为了抵消焊接变形，在焊前装配时，先将构件向焊接加热产生变形的相反方向进行人为的预设变形 |
| ③ | **刚性固定法** | 广泛用于工程焊接**较小**的构件，对防止**角变形和波浪变形**有显著效果 |
| ④ | **合理选择装配程序** | 对于大型焊接结构，适当分成几个**部件**进行装配焊接，再**组焊成整体**。小部件可自由收缩，避免整体变形。**例**：压力容器分节制造 |

> **记忆**：玉刚饭庄（预留收缩余量法→**预**→玉；刚性固定法→**刚**；反变形法→**反**→饭；合理选择装配程序→**庄**→庄）

#### （3）采取合理的焊接工艺措施

| 序号 | 措施 | 要点 |
|:---:|:---|:---|
| ① | **合理的焊接方法** | 尽量用气体保护焊等**热源集中**的焊接方法；不宜用焊条电弧焊，特别不宜选用气焊 |
| ② | **合理的焊接线能量** | 尽量减小焊接线能量的输入→有效减小变形 |
| ③ | **合理的焊接顺序和方向** | ★ **储罐底板焊接顺序**：先焊中幅板、边缘板对接焊缝外 **300mm** 长 → 待焊接完壁板和边缘板**角焊缝**后 → 再焊接边缘板剩余**对接焊缝** → 最后焊接中幅板和边缘板的**环焊缝** |

> 关键词提示："焊接"（焊接方法、焊接线能量、焊接顺序和方向）

---

**三类措施对比一览**

| 措施类别 | 具体内容 | 提示 |
|:---|:---|:---|
| **焊接结构设计**（焊前） | ①合理安排焊缝位置 ②合理选择焊缝数量和长度 ③合理选择坡口形式 | 关键词"**焊缝**" |
| **装配工艺措施** | ①预留收缩余量法 ②反变形法 ③刚性固定法 ④合理选择装配程序 | 记忆：玉刚饭庄 |
| **焊接工艺措施** | ①合理的焊接方法 ②合理的焊接线能量 ③合理的焊接顺序和方向 | 关键词"**焊接**" |

> 【真题2011单选】预防焊接变形的装配工艺措施包括（B）
> - A. 合理选择焊缝尺寸和形状 ❌（结构设计）
> - B. 合理选择装配程序 ✅
> - C. 合理安排焊缝位置 ❌（结构设计）
> - D. 合理的焊接顺序和方向 ❌（焊接工艺）

---

> 【真题2017案例】
> **背景**：底板敷设完成后，焊工按技术人员的交底，点焊固定后，先焊长焊缝，后焊短焊缝，采用大焊接线能量分段退焊，在底板焊接工作进行到第二天时，出现了很明显的波浪形变形。
> **问题**：指出技术人员底板焊接中的错误之处，并纠正。
> **参考答案**：
> 1. 底板焊接过程中采用了**大焊接线能量**。应采用**较小的焊接线能量**。
> 2. 从长焊缝到短焊缝顺序不对，应先进行**短焊缝**的焊接。

## 2.3.2 焊接质量检验（★★）

### 一、焊接检验方法分类

| 破坏性检验 | 非破坏性检验 |
|:---|:---|
| **力学性能试验**：弯曲试验、拉伸试验、冲击试验、硬度试验、断裂性试验、疲劳试验 | **外观检验** |
| **化学分析试验**：化学成分分析、不锈钢晶间腐蚀试验、焊条扩散氢含量测试 | **无损检测**：渗透检测（PT）、磁粉检测（MT）、超声检测（UT）、射线检测（RT） |
| **金相试验**：宏观组织、微观组织 | |
| **焊接性试验** | |

---

### 二、焊接过程质量检验

#### 1）焊前质量检验（准备）

| 项目 | 内容 |
|:---|:---|
| ① 母材和焊材 | |
| ② 零部件结构尺寸 | |
| ③ 组对质量 | |
| ④ 坡口清理检查 | 在施焊前应对坡口及坡口两侧进行清理检查 |
| ⑤ 焊接前的确认 | |

#### 2）焊中质量检验

| 项目 | 要点 |
|:---|:---|
| **① 定位焊缝** | |
| **② 多层（道）焊** | 每层（道）焊完后，应立即对层（道）间进行**清理**，并进行**外观检查**，检查合格后方可进行下一层（道）的焊接。对多层（道）间温度有要求时，应测量多层（道）间的焊前**温度**，并形成记录 |
| **③ 后热** | 应检查**加热范围**、后热**温度**和后热**时间**，并形成记录 |

#### 3）焊后质量检验

##### （1）焊缝外观检验

- 焊缝表面的**形状尺寸及外观质量**应符合设计要求，设计无要求时应符合现行国家有关标准
- **不允许存在的缺陷**（6种）：**裂纹、未焊透、未熔合、表面气孔、外露夹渣、未焊满**
  - 记忆：裂透熔气渣满
- **允许存在的缺陷**：咬边、角焊缝厚度不足、角焊缝焊脚不对称

> 【真题2018案例】在焊缝外表面的质量检查中，不允许的质量缺陷还有哪些？
> **参考答案**：焊缝表面不允许存在的缺陷包括：裂纹、未焊透、未熔合、表面气孔、外露夹渣、未焊满。

- **几何尺寸检查**：容器焊接后应检查——同一端面最大内直径与最小内直径之差（椭圆度）、矩形容器截面上最大边长与最小边长之差、焊接接头棱角度（环向和轴向）等

##### （2）焊缝表面无损检测

- 设计文件无规定时，可选用**磁粉检测（MT）** 或**渗透检测（PT）** 方法
- **渗透检测前**：焊缝表面不得有铁锈、焊渣、焊接飞溅及各种防护层
- **磁粉检测前**：焊缝表面及其两侧 **25mm** 范围内，不得有油脂、污垢、焊渣、焊接飞溅或其他粘附磁粉的物质

##### （3）焊缝内部无损检测

主要方法：

| 检测方法 | 缩写 |
|:---|:---:|
| 射线检测 | RT |
| 超声检测 | UT |
| 数字射线检测技术 | DR + CR |
| 衍射时差法超声波检测 | TOFD |
| 相控阵超声检测 | PA |

**射线检测（RT）vs 超声检测（UT）对比**

| 对比维度 | 射线检测（RT） | 超声检测（UT） |
|:---|:---|:---|
| **优点** | 可获得缺陷的**投影图像**，缺陷定性、长度测量比较准确；对**体积型缺陷**和**薄壁工件**中的缺陷检测率较高 | **面积型缺陷**检出率较高；**穿透能力强**，适用于**厚壁工件**；定位准确，可测量缺陷自身高度；对人体和环境**无害**；检测成本较低、速度快 |
| **缺点** | 厚壁工件缺陷检出率偏低；缺陷在工件厚度方向的位置难以确定、自身高度难以测量；对**面积型**有时会**漏检**；射线对人体和环境有危害，防护成本、检测成本较高；检测速度较慢 | 缺陷定性困难、定量精度不高；常用脉冲反射法超声波检测结果**无直接见证记录**；**无缺陷直观图像**；薄壁工件检测困难 |

> 【真题2013单选】常用的焊接无损检测方法中，适合于焊缝内部缺陷检测的方法是（A）
> - A. 射线探伤 ✅
> - B. 涡流探伤 ❌
> - C. 磁性探伤 ❌
> - D. 渗透探伤 ❌

**数字射线（DR + CR）检测技术**

由**计算机控制**射线穿过被检测工件，经成像器件（探测器或成像板）接收后，将射线光子信号经过一系列**转换成数字信号**，并由计算机**重新建立图像**，可以进行一系列**图像后处理**的技术。

## 本讲总结

| 主题 | 核心考点 | 重要程度 |
|:---|:---|:---:|
| **降低焊接应力** | 设计措施3条 + 工艺措施9条（预热、锤击、消氢、热处理、振动法等） | ★★★ |
| **焊接变形分类** | 面内（纵/横/回转） vs 面外（角/弯/扭/失稳波浪） 记忆：脚扭弯失稳 | ★★ |
| **预防焊接变形措施** | 结构设计（焊缝）→ 装配工艺（玉刚饭庄）→ 焊接工艺（焊接） | ★★★ |
| **焊接检验方法分类** | 破坏性（力学/化学/金相/焊接性） vs 非破坏性（外观/无损检测） | ★★ |
| **焊接过程检验** | 焊前（准备）→ 焊中（定位焊/多层焊/后热）→ 焊后（外观/无损） | ★★ |
| **焊缝外观缺陷** | **不允许**：裂纹、未焊透、未熔合、表面气孔、外露夹渣、未焊满 **允许**：咬边、角焊缝厚度不足、角焊缝焊脚不对称 | ★★★ |
| **RT vs UT** | RT：体积型、薄壁好，厚壁差，有危害，成本高 UT：面积型、厚壁好，薄壁差，无害，成本低 | ★★ |
| **双相不锈钢** | 焊缝铁素体含量与母材一致，母材奥氏体含量40%～60% | ★ |
