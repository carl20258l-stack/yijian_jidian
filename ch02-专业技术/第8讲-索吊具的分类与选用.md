# 2.2 索吊具的分类与选用

> [!SUMMARY] 本节速览
> 本节覆盖机电工程常用索吊具的五大类：**钢丝绳**（规格、直径选用、安全系数）、**吊索**（外观检查、夹角要求、使用规定）、**吊具**（吊耳、卸扣）、**吊梁**（四大作用）、**起重滑车**（分类、穿绕方法）及**卷扬机、手拉葫芦**的基本参数与使用要求。真题覆盖 2009-2024 年，含单多选和案例，**高频考点**。

---

## 1. 钢丝绳、吊索、吊具（★★★）

### 1.1 钢丝绳

起重吊装作业常用钢丝绳为 **多个绳股** 围绕一根 **绳芯** 捻制而成的多股钢丝绳。

#### （1）钢丝绳钢丝的强度极限

公称抗拉强度级别：

| 强度级别 | 等效单位 |
|---------|---------|
| 1570 MPa | 1570 N/mm² |
| 1670 MPa | |
| 1770 MPa | |
| 1870 MPa | |
| 1960 MPa | |

#### （2）钢丝绳的规格

钢丝绳由 **高碳钢丝**（强度、硬度）制成。

常用规格：

| 规格 | 含义 |
|------|------|
| `6 × 19 + FC (IWR)` | 6 股 × 19 丝 + 纤维芯/钢芯 |
| `6 × 37 + FC (IWR)` | 6 股 × 37 丝 + 纤维芯/钢芯 |
| `6 × 61 + FC (IWR)` | 6 股 × 61 丝 + 纤维芯/钢芯 |

- **6** = 钢丝绳的股数
- **19 / 37 / 61** = 每股中的钢丝数
- **FC** = 纤维芯 | **IWR** = 钢芯

#### （3）钢丝绳的直径选用

| 规格 | 性能特点 | 应用场景 |
|------|---------|---------|
| **6×19+1** | 不受弯曲或可能遭受磨损处 | 缆风绳、拉索 |
| **6×37+1** | 承受弯曲的场合 | 滑轮组起重绳、吊索 |
| **6×61+1** | 柔性 | 滑轮组、吊索和捆绑吊物 |

> 记忆：19硬（拉索耐磨）、37弯（滑轮弯曲）、61软（捆绑柔性）

### 1.2 吊索

俗称 **千斤绳** 或 **绳扣**。

#### （1）钢丝绳吊索外观检查要求

- **插编钢丝绳吊索**：插编部分的绳芯 **不得外露**，各股要紧密，不能有松动；插编后的绳股切头要 **平整**，不得有明显的 **扭曲**。
- **压制钢丝绳吊索**：接头表面应 **光滑**，**无裂纹、飞边和毛刺**。钢丝绳端部应超出铝合金接头 **1～1.5 倍绳径**。

#### （2）吊索与铅锤线的夹角要求

| 条件 | 夹角要求 |
|------|---------|
| 一般情况 | **30°~45°** |
| 特殊情况，**不得大于** | **60°** |
| 2个以上吊点，吊索与 **水平线** 夹角 | **不宜小于 60°** |

> 【分析】注意区分：铅锤线夹角 vs 水平线夹角，两者互余关系。

#### （3）吊索的使用要求

1. 钢丝绳吊索主要根据 **吊物重量、吊索直径、根数、受力角度、钢丝绳公称抗拉强度及安全系数** 等参数进行选用。
2. 吊索选用钢丝绳的 **结构要求和基本参数** 应符合：
   - 《重要用途钢丝绳》 GB/T 8918-2006
   - 《钢丝绳通用技术条件》 GB/T 20118-2017
   - 《粗直径钢丝绳》 GB/T 20067-2017
3. 吊索钢丝绳的安全系数与 **被吊设备、构件的精密（重要）程度及吊索捆绑方式** 有关。
4. 钢丝绳在绕过不同尺寸的销轴或滑轮时，其强度应根据不同的 **弯曲情况进行折减**。

#### （4）钢丝绳环索（吊装带）不得使用的情况

- 禁吊标志处 **绳端露出** 且无法修复
- 绳股产生 **松弛或分离**，且无法修复
- 钢丝绳出现 **断丝、断股、钢丝挤出、单层股钢丝绳绳芯挤出、钢丝绳直径局部减小、绳股挤出或扭曲、扭结** 等缺陷
- **无标牌**，不得使用

### 1.3 钢丝绳安全系数（★ 16单 / 20案）

> 钢丝绳安全系数 = 标准规定的钢丝绳在使用中 **允许承受拉力的储备拉力**，即钢丝绳在使用中 **破断的安全裕度**。

| 使用场景 | 安全系数 |
|---------|---------|
| 拖拉绳 | **≥ 3.5** |
| 卷扬机走绳 | **≥ 5** |
| 捆绑绳扣使用 | **≥ 6** |
| 系挂绳扣 | **≥ 5** |
| 载人吊篮 | **≥ 14** |

> 记忆：**3.5 拉（拉索），5 走（卷扬系挂），6 绑，14 载人**

【2016 单选】考查安全系数数值。
【2020 案例】考查安全系数应用场景。

### 1.4 吊耳、卸扣的使用要求

#### （1）吊耳使用要求

- 产品标志
- 出厂文件
- 设备出厂前应按设计要求做 **吊耳检测**，并出具 **检测报告**
- 设备到场后应对吊耳 **外观质量** 进行检查，必要时进行 **无损检测**
- **现场焊接的吊耳**，其与设备连接的焊接部位应做 **表面渗透检测（开口缺陷）**
- 设备到场后，技术人员要对吊耳 **焊接位置及尺寸** 进行 **复测**

#### （2）卸扣使用要求

- **不得超载** 使用，**无额定负荷标记或标志不清的卸扣禁止使用**
- 使用前应进行 **外观检查**
- 卸扣表面应 **光滑，不得有毛刺、裂纹、尖角、夹层** 等缺陷
- 发现 **永久变形或裂纹** 应报废
- **不得利用焊接的方法修补** 卸扣的缺陷
- 卸扣只能承受 **纵向拉力**，**不得横向受力**

> 【易错点】卸扣只能承受 **纵向** 拉力，不得 **横向** 受力。

## 2. 吊梁（★★★ 20多 / 22案）

### 2.1 吊梁（平衡梁）的作用

| 序号 | 作用 | 核心关键词 |
|------|------|-----------|
| 1 | 减少被吊设备（构件）起吊时所承受的 **挤压力**，避免损坏设备 | 减少挤压力 |
| 2 | **缩短** 吊索的高度，减少动滑轮的起吊高度 | 缩短高度 |
| 3 | 构件刚度不满足而需要 **多吊点起吊受力时** 平衡和分配各吊点载荷 | 多吊点平衡 |
| 4 | **转换吊点** | 转换吊点 |

> 记忆：**减挤、缩短、平衡、转换**

## 3. 起重滑车

### 3.1 滑车的分类

| 分类依据 | 具体类型 |
|---------|---------|
| 按滑车头部结构形式 | 吊钩型、链环型、吊环型、吊梁型 |
| 按滑车的轮数 | 单轮滑车（闭口/开口）、双轮滑车、多轮滑车 |
| 按滑车的作用 | 定滑车、动滑车、导向滑车、平衡滑车 |

### 3.2 滑车的使用要求

- 滑车按其用途和装设目的有 **定滑车、动滑车和导向滑车** 3 种
- 定滑车和动滑车用绳索串联地穿绕于滑车之间组成 **滑车组**
- **滑车组**使用时：**定滑车位置不动**（只有滑轮转动），**动滑车随重物同步移动**，起 **省力** 作用
- 滑车组中 **滑轮愈多愈省力**，但重物的移动 **速度亦相应愈慢**

> 【原理】省力不省功——滑轮越多，省力越大，速度越慢。

### 3.3 滑车组钢丝绳穿绕方法

在选择起重滑车组钢丝绳穿绕方法时应 **综合考虑**。

| 滑车门数 | 推荐穿绕方法 |
|---------|-------------|
| **3 门及以下** | 顺穿（逐个绕过） |
| **4～6 门** | 花穿 |
| **7 门以上** | 双跑头顺穿 |

- 穿绕方法不正确，会引起滑轮组 **倾斜** 而发生事故。

> 记忆：**三顺有 7 双石榴花鞋**（3 顺 → 4-6 花 → 7 双）

## 4. 卷扬机

### 4.1 卷扬机的分类

| 分类维度 | 常用类型 |
|---------|---------|
| 动力类型 | **电动卷扬机** |
| 卷筒数量 | **单筒卷扬机** |
| 速度 | **慢速卷扬机** |

### 4.2 卷扬机的基本参数（★ 17单 / 18单）

| 基本参数 | 说明 |
|---------|------|
| **额定牵引拉力** | 卷扬机的额定拉力值 |
| **工作速度** | 卷筒卷入钢丝绳的速度 |
| **容绳量** | 卷扬机的卷筒允许容纳的钢丝绳工作长度的 **最大值** |

> 记忆：**公鹅绒**（拉力-速度-容绳量）

【2017 多选】吊装工程选用卷扬机应考虑的基本参数有：**额定牵引拉力、工作速度、容绳量**。
【2018 单选】容绳量的定义：卷筒允许容纳的钢丝绳工作长度的最大值。

## 5. 手拉葫芦

### 5.1 手拉葫芦使用检查

- 使用前须检查：
  - 起升结构的 **完好性**
  - 运转部分的 **灵活性** 及 **润滑** 是否良好
  - 拉链应灵活自如，不应有 **跑链、掉链和卡滞** 现象
- 使用时应将链条摆顺，逐渐拉紧，**两吊钩受力在一条轴线** 上

### 5.2 手拉葫芦使用要求

- 吊挂点承载能力不得低于 **1.05 倍** 的手拉葫芦额定载荷
- 当采用 **多台葫芦起重同一工件** 时：
  - 操作应 **同步**
  - 单台葫芦的最大载荷不应超过其额定载荷的 **70%**
- 在垂直、水平或倾斜状态使用时，手拉葫芦的 **施力方向应在链轮平面上**，以防卡链或掉链

> 【重要倍数】1.05 倍（吊挂点承载） / 70% 限载（多台同步）
