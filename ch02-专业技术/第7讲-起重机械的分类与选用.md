## 一、起重机械的分类

### 1. 轻小型起重设备

| 设备 | 说明 |
|:--|:--|
| 千斤顶 | 顶升设备 |
| 滑车（起重滑车、滑轮组） | 改变力方向或省力 |
| 起重葫芦 | 手拉/电动葫芦 |
| 卷扬机 | 牵引动力源 |

### 2. 起重机（三大类）

> **【2025真题】下列起重机中，属于桥架型起重机的是（ ）。**
> A. 塔式起重机
> B. 半门式起重机 ✅
> C. 流动式起重机
> D. 半门座式起重机
> *解析：桥架型起重机包括梁式、桥式、门式、半门式、装卸桥等。*

#### （1）桥架型起重机

| 类别 | 包含 |
|:--|:--|
| 梁式起重机 | 单梁/双梁 |
| 桥式起重机 | 天车 |
| **门式起重机** | 龙门吊 |
| **半门式起重机** | 一侧无支腿 |
| 装卸桥 | 散料装卸 |

#### （2）臂架型起重机

| 类别 | 包含 |
|:--|:--|
| 门座起重机 / 半门座起重机 | 码头常用 |
| 塔式起重机 | 建筑工地常用 |
| **流动式起重机** | ★重点：汽车吊、履带吊、全地面起重机 |
| **桅杆起重机** | ★重点：大型设备吊装 |
| 悬臂起重机 | 车间用 |

#### （3）缆索型起重机

- 缆索起重机
- 门式缆索起重机

## 二、常用起重机的特点及适用范围

### 1. 流动式起重机
> 汽车吊、履带吊、全地面起重机等，灵活机动，适用各种现场。

### 2. 塔式起重机
> 高层建筑施工，附着式可随建筑升高。

### 3. 桅杆起重机（★★★）

**组成**：桅杆本体 + 动力-起升系统 + 稳定系统

| 组成部分 | 具体内容 | 补充说明 |
|:--|:--|:--|
| **桅杆本体** | 桅杆、基座及其附件 | 大型→格构式截面；中小型→钢管截面 |
| **动力-起升系统** | 卷扬机、钢丝绳（跑绳）、起重滑车组、导向滑车 | — |
| **稳定系统** | **缆风绳、地锚** | **缆风绳与地面夹角：30°~45°**，应与供电线路、建筑物、树木保持安全距离 |

> 记忆：桅杆三系统——**本体（杆+座）+ 动力（卷扬+钢丝绳+滑车组）+ 稳定（缆风绳+地锚）**

### 4. 门式起重机
> 场站、货场、预制场常见。

### 5. 门座起重机
> 港口码头、船厂。

## 三、起重机的基本参数（★★★）

> **真题统计**：2009单 / 2011多 / 2013多、案 / 2017案 / 2021多 / 2022多 / 2023多 / 2025单、案

五大参数：**吊装载荷、额定起重量、幅度、起升高度**等

> 记忆：**高幅度重载**（取"高度"谐音——起升高度、幅度、重量、载荷）

### 1. 吊装载荷（起升载荷）

**定义**：吊挂在起升钢丝绳或起升链条下端起升的重物质量。

**包括**：
- 固定吊具质量
- 可分吊具质量（或无此类吊具）
- 吊挂在吊具上起升的重物质量

**计算公式**：
```
吊装载荷 = ①被吊设备 + ②吊钩、吊具、索具及其他附件
```

> **注意**：履带起重机的起升载荷**还包括挠性件（钢丝绳/链条）的质量**。

#### 【真题】2021多选
使用全地面起重机进行设备吊装，吊装载荷包括（ ）。
A. 吊钩重量 ✅
B. 设备重量 ✅
C. 吊索重量 ✅
D. 吊具重量 ✅
E. 吊臂重量 ❌
> **答案**：ABCD
> **解析**：吊装载荷 = 设备 + 吊钩组件 + 吊索（吊钩以上滑轮组间钢丝绳质量）+ 吊具及其他附件。吊臂重量属起重机自身结构，不计入。

#### 【真题】2022多选
起重机进行吊装作业时的吊装载荷包括（ ）。
A. 设备或构件重量 ✅
B. 起重机吊臂重量 ❌
C. 吊具和索具重量 ✅
D. 起重机吊钩重量 ✅
E. 设备加固件重量 ✅
> **答案**：ACDE
> *解析：设备加固件属于"其他附件"，应计入。*

### 2. 计算载荷

#### （1）动载荷系数 K₁
- 在吊装**运动过程中**产生的影响
- **一般取 K₁ = 1.1**

#### （2）不均衡载荷系数 K₂
- **两台及以上**起重机（或多套滑轮组）共同抬吊时考虑
- 原因：机械之间相互运动、工作不同步
- **一般取 K₂ = 1.1 ~ 1.25**

#### （3）吊装计算载荷 Qj

| 场景 | 是否考虑动载荷和不均衡载荷 |
|:--|:--:|
| **单台起重机吊装** | ❌ 不计入（起重机设计已考虑动载荷） |
| **双机抬吊** | ✅ 需计入 K₁ × K₂ |
| **吊索受力计算** | ✅ 需计入 K₁ × K₂ |
| **桅杆起重机设计计算** | ✅ 需计入 K₁ × K₂ |
| **缆索起重机设计计算** | ✅ 需计入 K₁ × K₂ |

**双机抬吊公式**：
```
Qj = K₁ × K₂ × Q
```
其中：
- Qj — 计算载荷
- K₁ — 动载荷系数（1.1）
- K₂ — 不均衡载荷系数（1.1~1.25）
- Q — 分配到一台起重机的吊装载荷（设备+索吊具重量）

### 3. 额定起重量

**定义**：起重机起吊额定起重量时能够吊运的**物品最大质量**与**吊具及索具质量的总和**（即总起升质量）的重力。

**双机抬吊限制规则**：

| 规则 | 数值 |
|:--|:--:|
| 宜选用 | **相同类型或性能相近**的起重机 |
| 起吊总重 ≤ 两台起重机额定起重量**总和的75%** | 举例：200t + 200t → 最多吊 **300t** |
| 单台负荷 ≤ 其安全负荷量的 **80%** | 举例：200t → 单台最多带 **160t** |

> 记忆口诀：**双机抬吊——同类型、75%总和、80%单台**

### 4. 幅度

**定义**：起重机的**吊装回转半径**，即起重机回转中心至吊钩之间的水平距离。

### 5. 起升高度

**公式**：
```
Hm > H₁ + H₂ + H₃ + H₄
```

| 符号 | 含义 |
|:--|:--|
| Hm | 起重机吊臂顶端下动滑轮的高度（m） |
| H₁ | 设备高度（m） |
| H₂ | 设备顶面到吊钩的索具高度（包括钢丝绳、平衡梁、卸扣等）（m） |
| H₃ | 基础或地脚螺栓顶面至就位时设备底面的高度（m） |
| H₄ | 基础或地脚螺栓顶面高度（m） |

## 四、三种载荷概念对比（★必背）

| 载荷种类 | 定义 | 性质 |
|:--|:--|:--:|
| **吊装载荷** | 固定吊具质量 + 可分吊具质量 + 吊挂在吊具上起升的重物质量之和 | **静态**被吊设备 |
| **计算载荷** | 吊装机具所承受的载荷与载荷系数的乘积 | **动态**（计入K₁/K₂） |
| **额定起重量** | 起重机起吊额定起重量时能够吊运的物品最大质量与吊具及索具质量的总和（即总起升质量）的重力 | **起重机自身能力** |

## 五、流动式起重机的选用（★★★）

### 1. 特性曲线

**两种曲线**：
- **起重量特性曲线** — 起重能力随臂长、幅度的变化
- **起升高度特性曲线** — 最大起重高度随臂长、幅度的变化

> 有的起重机将曲线**量化成表格**，称为**特性曲线表**（如起重量性能表）。特性曲线（表）一般随机附带，是选用流动式起重机的依据。

### 2. 选用五步骤

| 步骤 | 依据 | 确定内容 | 简记 |
|:--:|:--|:--|:--:|
| **1** | 被吊装设备（构件）的就位平面位置、现场情况 | **站车位置 → 幅度 R** | **R** |
| **2** | 就位高度、设备尺寸、吊索高度 | 设备吊装的最小起升高度 → **臂长 L** | **L** |
| **3** | 起重机的起重量性能表 | 查阅同一幅度时不同臂长的**额定起重量** | **查表** |
| **4** | 额定起重量 > 计算载荷 ✅ | 合格则通过，否则重选 | **能力＞被吊设备** |
| **5** | 计算吊臂与设备、吊臂与附近构筑物、设备与构筑物等的安全距离 | 符合规范则通过，否则重选 | **安全距离** |

> 记忆：**R → L → 查表 → 能力 → 安全**（站车定幅度 → 高度定臂长 → 查额定起重量 → 能力复核 → 安全距离复核）

### 3. 地基处理及耐压力测试（二级10/18/23案，新增修改）

#### （1）地基要求
- 流动式起重机必须在**水平坚硬**地面上进行吊装作业
- 吊车工作位置（含行走路线）的地基需处理
- 依据：项目所在地地质资料 + 吊装区域地面实际**地耐力**检测结果
- 地耐力不满足时须采取处理措施

#### （2）地基处理方法

> 记忆：**换脸强装**（换填法、碾压法、强夯法、桩基法）

| 方法 | 说明 |
|:--|:--|
| **碾压法** | 压实处理 |
| **换填法** | 开挖回填夯实，支腿下方垫**厚钢板**增加耐压力 |
| **强夯法（强夯置换法）** | 强力夯实 |
| **桩基法** | 打桩处理 |

> 履带起重机下方垫**枕木**以增加地面耐压力。

#### （3）耐压力测试

**测试方法**：
- 压重法
- 委托第三方测试机构

**压重法步骤**：

| 步骤 | 内容 |
|:--|:--|
| ①计算压重块数量 | 按公式 f = nG/S > 2fc |
| ②选择测试位置 | 起重机吊装时对地压强**最大**的位置叠放压重块，确定一个**基准点**，均布找出压重块上**4个位置**作为测量点，做好标志 |
| ③静置与测量 | 压重块静置 **24h**，测量4个位置的沉降量 |
| ④判定合格 | **4个点最大沉降量 ≤ 50mm** |

**压重法公式**：
```
f = nG/S > 2fc
```
- S — 压重块接地面积（m²）
- G — 每块压重质量（t）
- f — 压重块对地压强（t/m²）
- fc — 路基箱对地压强（t/m²）
- n — 每个测试点压重块的数量

> 记忆：**压重法——最大压强位置 + 4个测量点 + 静置24h + 最大沉降≤50mm**

## 本节核心考点速记

1. **起重机三大分类**：桥架型（梁/桥/门/半门式/装卸桥）→臂架型（门座/塔式/流动/桅杆/悬臂）→缆索型
2. **桅杆起重机三系统**：本体（桅杆+基座）→ 动力-起升（卷扬机+钢丝绳+滑车组）→ 稳定（**缆风绳30°~45°**+地锚）
3. **五大参数**：吊装载荷、额定起重量、幅度、起升高度 → 记忆：**高幅度重载**
4. **三种载荷对比**：吊装载荷（静态）→ 计算载荷（动态，×K₁K₂）→ 额定起重量（机械能力）
5. **双机抬吊**：75%总和限制 + 80%单台限制 + 同类优先
6. **流动式起重机选用五步**：R定幅度 → L定臂长 → 查表定起重量 → 能力复核 → 安全复核
7. **地基处理**：碾压法、换填法、强夯法、桩基法 → 记忆：**换脸强装**
8. **压重法**：最大压强位置 + 4点测量 + 静置24h + 最大沉降≤50mm
