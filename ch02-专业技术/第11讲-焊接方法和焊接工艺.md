# 2.3 焊接方法和焊接工艺

> [!summary] 本节速览
> **★ 重要度：★★★（三星，中等高频）**
> **真题分布：** 2007单 / 2016单 / 2017多
> **核心脉络：** 焊接方法分类（熔化焊/压力焊/钎焊） → 焊接工艺（接头/焊缝/预热后热） → 焊接工艺评定（PQR/PWPS/WWI/WPS 流程 + 评定规则）
> **核心口诀：** 焊艺评三步走：预→评→导→规；重要因素一变动→重新评定

---

## 1. 焊接方法分类

焊接方法按工艺特征分为三大类：

| 类别 | 核心原理 | 常见方法 | 代号速查 |
|:---:|:---|:---|:---:|
| **熔化焊** | 加热至熔化 + 不加压力 → 液态金属混合凝固 | 电弧焊、电渣焊、气焊、电子束焊、激光焊 | 见下表 |
| **压力焊** | 施加压力（加热或不加热） | 爆炸焊、冷压焊、摩擦焊、扩散焊、超声波焊、高频焊、电阻焊 | - |
| **钎焊** | 用低于母材熔点的钎料，加热至钎料熔化填充接头间隙 | 硬钎焊、软钎焊 | - |

> 记忆：熔化焊"融而不压"，压力焊"压可加温"，钎焊"借料搭桥"——三种方法区分的核心要点。

### 1.1 熔化焊

**定义：** 在焊接过程中，将焊接接头在焊接电弧等热源作用下加热至**熔化**状态，在温度场、重力等作用下，**不加压力**，两个工件熔化的**液态金属发生混合**现象，待温度降低后，熔化部分凝结，两个工件就被牢固地焊在一起的方法。

> 对比记忆：熔化焊 vs 摩擦焊——摩擦焊属于压力焊（加压），熔化焊不加压。

熔化焊 → 电弧焊（最常见）→ 焊条电弧焊、气体保护焊、埋弧焊、等离子焊

#### 常用的熔化焊分类及代号

| 焊接方法 | GB/T 5185-2005 代号 | TSG Z6002-2010 / NB/T 47014-2011 代号 |
|:---|:---:|:---:|
| **电弧焊** | | |
| 焊条电弧焊 | 111 | SMAW |
| 单丝埋弧焊 | 121 | SAW |
| 钨极气体保护焊 | 141 | GTAW |
| 熔化极气体保护焊 | 131（135） | GMAW（MAG） |
| 自保护药芯焊丝电弧焊 | 114 | FCAW |
| **其他** | | |
| 电渣焊 | 72 | ESW |
| 气电立焊 | 73 | EGW |
| 短路电弧螺柱焊 | 784 | SW |

> 记忆：数字代号 **111**（焊条电弧焊）、**141**（钨极气体保护焊 GTAW）、**131/135**（熔化极气体保护焊 GMAW/MAG）是高频选择题材料。字母代号缩写含义：S=Shielded(submerged/hielded)，G=Gas，T=Tungsten，A=Arc，W=Welding，M=Metal，F=Flux，C=Core。

### 1.2 压力焊

**定义：** 通过对焊件**施加压力（加热或不加热）**来完成焊接的方法。

**常见方法：** 爆炸焊、冷压焊、摩擦焊、扩散焊、超声波焊、高频焊、电阻焊

> 记忆：压力焊七兄弟——"爆冷摩扩超频阻"（爆炸焊→冷压焊→摩擦焊→扩散焊→超声波焊→高频焊→电阻焊）

### 1.3 钎焊

**定义：** 采用**比母材熔点低**的金属材料作钎料，在加热温度高于钎料而低于母材熔点的情况下，利用液态钎料润湿母材，**填充接头间隙，并与母材相互扩散**下连接焊件的方法。

**分类：** 硬钎焊、软钎焊

> 记忆：钎焊三要素——"熔点比母材低"、"填充间隙"、"相互扩散"。记住"钎"字有个"千"，联想千度高温，但实际上是低于母材的。

## 2. 焊接工艺

### 2.1 焊接接头

**组成：** **焊缝**、**熔合区**、**热影响区**和**母材金属**（共四部分）

| 组成部分 | 说明 |
|:---|:---|
| 焊缝 | 熔化凝固后形成的区域 |
| 熔合区 | 焊缝与热影响区的过渡区域 |
| 热影响区 | 受热影响但未熔化的母材区域 |
| 母材金属 | 未受焊接热影响的基体金属 |

**接头形式：** **对接接头**、**T形接头**、**角接接头**、**搭接接头**

> 记忆：四种接头形式——"对T角搭"（对接、T形、角接、搭接），由两个焊件**相对位置**决定。

### 2.2 焊缝形式

#### 焊缝坡口形式

| 坡口类型 | 特征 |
|:---|:---|
| I形（不开坡口） | 最简形式，薄板焊接 |
| V形 | 单面开V形坡口 |
| 单边V形 | 仅一侧开V形 |
| U形 | 圆弧底部，厚板适用 |
| 双U形 | 两面开U形 |
| J形 | 单侧J形坡口 |

#### 焊缝结合形式

- 对接焊缝、角焊缝、塞焊缝、槽焊缝、端接焊缝

#### 焊缝空间位置

| 位置 | 特征 | 难度 |
|:---|:---|:---:|
| **平焊** | 焊缝水平，焊条垂直向下 | 最容易 |
| **立焊** | 焊缝垂直或倾斜 | 较难 |
| **横焊** | 焊缝水平，焊条水平 | 中等 |
| **仰焊** | 焊条向上焊接 | 最困难 |

### 2.3 预热及焊后热处理

> 目的：为改善焊接接头的焊后组织和性能或**消除残余应力**而进行的热处理。

| 工艺 | 时机 | 作用 |
|:---|:---|:---|
| **预热** | 焊接开始前，对焊件全部（或局部）加热 | 减缓冷却速度，防止裂纹 |
| **后热** | 焊接后立即加热或保温，使其缓冷 | **≠ 焊后热处理**，属于中间措施 |
| **焊后热处理** | 焊接完成后进行 | 消除残余应力，改善组织性能 |

**延迟裂纹：** 具有孕育期的冷裂纹，可能在焊后数小时、数天或更长时间内出现。

**关键数值：** 若不能及时进行热处理，则应在焊后立即**后热 200~350℃保温缓冷**。

> ★ **高频考点：** 延迟裂纹 + 后热温度 200~350℃ 是常考填空/选择题。

## 3. 焊接工艺评定 ★★★

### 3.1 核心概念

**定义：** 焊接工艺评定是为验证所拟定的焊接工艺正确性而进行的**试验过程及结果评价**。

> 【真题·2015 二级】为验证拟定的焊件工艺的正确性所进行的试验过程及结果评价是（  **B**  ）
> A. 焊接作业卡　　B. 焊接工艺评定　　C. 焊接质量证明文件　　D. 焊接作业规程

### 3.2 焊接工艺评定实施要求

- **场所：** 应在**本单位**进行
- **设备仪表：** 处于正常工作状态
- **材料：** 金属材料、焊接材料应符合相应标准
- **人员：** 由**本单位操作技能熟练的焊接人员**使用**本单位设备**焊接试件

> 记忆：焊接工艺评定四大要求——"本单位的设备、本单位的人、标准的材料、正常的状态"

### 3.3 焊接工艺文件体系 ★★★

| 文件 | 英文缩写 | 作用 | 提示 |
|:---|:---:|:---|:---|
| **焊接工艺评定报告** | **PQR** | 记载验证性试验及其检验结果，对拟定的预焊接工艺规程进行评价的报告 | 试验结果 |
| **焊接工艺评定预规程** | **PWPS** | 为进行焊接工艺评定所拟定的焊接工艺文件 | 初步计划文件 |
| **焊接工艺指导书** | **WWI** | 与制造焊件有关的加工和操作细则性作业文件。焊工施焊时使用，可保证施工时质量的再现性 | **焊工现场指令**（范围很窄） |
| **焊接工艺规程** | **WPS** | 根据合格的焊接工艺评定报告编制，用于产品施焊的焊接工艺文件 | **标准工艺**（范围较广） |

**流程顺序：** 焊接工艺评定预规程（PWPS）→ 焊接工艺评定报告（PQR）→ 焊接工艺指导书（WWI）→ 焊接工艺规程（WPS）

> 记忆：**"预→评→导→规"**——先预规程，再评定，后指导书，最后成规程。

**WPS与WWI关系：**
- 一个焊接工艺评定报告可用于编制**多个**焊接作业指导书（WWI）
- 一个焊接作业指导书可以依据**一个或多个**焊接工艺评定报告编制

### 3.4 各行业焊接工艺评定规范要求

| 行业/设备 | 规范依据 | 要点 |
|:---|:---|:---|
| **锅炉** | 焊接工艺评定 → 焊接作业指导书 | 根据产品焊接接头形式进行 |
| **压力容器** | 焊接工艺评定 | 受压元件焊缝、与非受压元件相焊缝、定位焊缝、堆焊与补焊、返修焊缝均需评定 |
| **长输管道** | SY/T 0452-2021《石油天然气金属管道焊接工艺评定》<br>GB/T 31032-2023《钢质管道焊接及验收》 | 制定详细预焊接工艺规程 |
| **工业管道** | NB/T 47014-2023《承压设备焊接工艺评定》 | 承压件与承压件、承压件与非承压件均需评定合格 |
| **燃气/热力公用金属管道** | NB/T 47014-2023《承压设备焊接工艺评定》 | 同上 |
| **非金属PE管道** | TSG D2002-2006《燃气用聚乙烯管道焊接技术规则》 | 单独规范 |
| **钢结构** | GB 50661-2011《钢结构焊接规范》 | **首次采用的**钢材/焊接材料/方法/接头/位置/焊后热处理等参数及组合，需进行焊接工艺评定试验 |

> 记忆：七类焊接对象——"锅压管管管管钢"（锅炉→压力容器→长输管道→工业管道→燃气热力管道→PE管道→钢结构）

### 3.5 焊接工艺评定规则 ★★★

按照 **NB/T 47014-2023**《承压设备焊接工艺评定》，所有工艺参数分为三类：

| 分类 | 定义 | 举例 | 评定规则 |
|:---:|:---|:---|:---:|
| **重要因素** | 变化会影响焊接接头力学性能的参数 | 焊接方法、母材分类、母材厚度、焊丝类别、**预热**、**焊后热处理**、保护气体种类、**电流种类和极性** | ❗ **必须重新评定** |
| **补加因素** | 有冲击韧性要求时升级为重要因素，无要求时降为次要因素 | 线能量、平焊改立焊、多道焊改单道焊等 | 取决于**冲击韧性要求** |
| **次要因素** | 变化不影响接头力学性能 | 坡口形式尺寸、焊丝规格、保护气体流量等 | ✅ 无需重新评定，但需**重新编制焊接工艺规程** |

> 记忆：三类因素口诀——**"重要一变就重评，次要不评要重编，补加看韧性"**
>
> **补加因素口诀：** "一能一平一道焊" → 线能量 + 平焊改立焊 + 多道焊改单道焊

#### 重要因素变化需重新评定的典型参数

- 焊接方法
- 母材分类
- 母材厚度
- 焊丝类别
- **预热**（★★★★）
- **焊后热处理**（★★★★）
- 保护气体种类
- **电流种类和极性**（★★★★）

## 4. 【真题】精练

> 2015年二级真题
> 为验证拟定的焊件工艺的正确性所进行的试验过程及结果评价是（  ）
> A. 焊接作业卡　　B. 焊接工艺评定　　C. 焊接质量证明文件　　D. 焊接作业规程
> **【答案】B**
> **【解析】** AD都是焊接的依据。焊接工艺评定是为验证所拟定的焊接工艺正确性而进行的试验过程及结果评价。
