# 3.4 智能化系统的线缆和光缆、设备施工技术

## 一、线缆和光缆施工技术

> **考频：** ★ | **真题：** 2016多选、2022单选

### 1. 双绞线敷设要求

| 项目 | 要求 |
|------|------|
| 敷设方式 | 自然平直，不得扭绞、打圈，不应受外力挤压和损伤 |
| 接头 | **路由中不得接头**（路由 = 管线的走向位置） |
| 预留长度 | 工作区信息插座底盒内：**30~60mm**；电信间：**0.5~2m**；设备间：**3~5m** |
| 弯曲半径 | 非屏蔽和屏蔽 4 对双绞线缆 ≥ 电缆外径的 **4 倍** |

### 2. 信号线缆敷设要求

| 项目 | 要求 |
|------|------|
| 与电力电缆平行敷设间距 | ≥ **0.3m** |
| 与电力电缆交叉敷设 | **宜成直角** |
| 多芯线缆最小弯曲半径 | > 外径的 **6 倍** |
| 电源线布线 | 电源线与信号线、控制线应**分别穿管敷设**；**低电压**供电时可**同管**敷设 |
| 与强磁/强电场设备净距 | 明敷时 > **1.5m**；采用屏蔽线缆/穿金属保护管/金属封闭线槽时 > **0.8m** |

### 3. 光缆敷设要求

> 注意与建筑电气中光缆敷设做对比

| 项目 | 要求 |
|------|------|
| 敷设前检查 | 光纤应**无断点**，衰耗值符合设计要求；核对光缆长度，按施工图选配 |
| 最小动态弯曲半径 | > 光缆外径的 **20 倍** |
| 牵引端头 | 应做好**技术处理**，可采用自动控制牵引力的牵引机 |
| 牵引力 | 加在**加强芯**上，≤ 光缆允许张力的 **80%** |
| 牵引速度 | **10~15 m/min** |
| 一次牵引直线长度 | ≤ **1 km** |
| 光纤接头预留长度 | ≥ **8 m** |
| 2芯/4芯水平光缆弯曲半径 | > **25 mm** |
| 其他芯数光缆弯曲半径 | ≥ 光缆外径的 **10 倍** |
| 总配线架处预留长度 | **3~5 m** |
| 楼层配线架处预留长度 | **1.0~1.5 m** |
| 设备终端预留长度 | ≥ **0.5 m** |
| 敷设后检查 | 检查光纤有无损伤，抽测敷设损耗；确认无损伤后再接续；测量通道总损耗，用时域反射计观察全程波导衰减特性曲线 |

## 二、设备安装技术

> **考频：** ★★★ | **真题：** 2012案例、2019案例、2020多选、2021单选、2022案例

### （一）建筑监控设备的安装要求

#### 1. 施工深化

- 施工深化中应做好与以下设备的**接口确认**：建筑给水排水、电气、通风空调、防排烟、防火卷帘、电梯
- 做好与**建筑装修效果**的配合工作
- 从其他施工图中了解：建筑基本情况、设备位置、控制方式和技术要求等
- 深化图纸经审核后作为具体的施工图

#### 2. 产品选择考虑因素

> **记忆口诀：** 整（标准化程度）形（网络性能）模（系统规模）具（监控距离）平（品牌）地（生产地）起（供货渠道和供货周期）

| 考虑因素 | 说明 |
|----------|------|
| 品牌和生产地 | 应用实践 |
| 供货渠道和供货周期 | 供应保障 |
| 系统规模及监控距离 | 产品支持的容量 |
| 网络性能及标准化程度 | 互联互通能力 |

#### 3. 设备、材料、接口和软件检测

- 按**国家现行标准**检测功能、性能

**接口文件对比表：**

| 文件类型 | 依据 | 包含内容 |
|----------|------|----------|
| **接口技术文件** | 符合**合同**要求 | 接口概述、接口框图、接口位置、接口类型与数量、接口通信协议、数据流向、接口责任边界 |
| **接口测试文件** | 符合**设计**要求 | 测试链路搭建、测试用仪器仪表、测试方法、测试内容、测试结果评判 |

#### 4. 进口设备要求（通用答案）

进口设备应提供：
- 质量合格证明
- 检测报告
- 安装、使用、维护说明书（**中文译文**）
- **原产地证明**
- **商检证明**

#### 5. 主要输入设备安装要求

| 设备类型 | 安装要求 |
|----------|----------|
| **各类传感器** | 装在能正确反映检测性能的位置，远离强磁场或剧烈振动场所，便于调试和维护 |
| **风管型传感器** | 在风管**保温层完成**后进行安装 |
| **水管型传感器** | 开孔与焊接必须在管道**压力试验、清洗、防腐和保温前**进行 |
| **镍温度传感器** | 接线电阻 < **3Ω** |
| **铂温度传感器** | 接线电阻 < **1Ω** |
| **电磁流量计** | 安装在流量调节阀**上游**；上游 ≥ **10 倍**管径直管段；下游 **4~5 倍**管径直管段 |
| **涡轮式流量传感器** | **水平安装**；流向与壳体标志一致 |
| **空气质量传感器** | 选择能正确反映空气质量状况的地方 —— CO 传感器装**上部**（约 2000mm），CO₂ 传感器装**下部**（约 1200mm） |

> **对比记忆：** 生活给水水表前与阀门应有 ≥ 8 倍水表接口直径的直线管段（流量仪表通用要求）

#### 6. 主要输出设备安装要求

| 设备类型 | 安装前检查项目 |
|----------|----------------|
| **电磁阀/电动调节阀** | ① 线圈与阀体间的电阻 ② 模拟动作试验 ③ **压力试验**；箭头指向与水流方向一致 |
| **电动风阀控制器** | ① 线圈与阀体间的电阻 ② 供电电压 ③ 输入信号 ④ 模拟动作检查 |

### （二）安全防范工程的设备安装技术

#### 1. 摄像机安装要求

| 项目 | 要求 |
|------|------|
| 安装前 | 通电检测，工作正常 |
| 室内安装高度 | ≥ **2.5 m** |
| 室外安装高度 | ≥ **3.5 m**（考虑防雷、防雨） |
| 安装牢固度 | 摄像机及配套装置（镜头、防护罩、支架等）安装牢固，运转灵活 |

#### 2. 出入口控制设备安装要求

| 设备 | 要求 |
|------|------|
| 各类识读装置 | 安装高度离地 ≤ **1.5 m** |
| 感应式读卡机 | 注意感应范围，远离高频、强磁场、潮湿、腐蚀性环境 |
| 电控锁 | 符合产品技术要求，安装牢固，启闭灵活 |

#### 3. 对讲设备安装要求

| 设备 | 安装要求 |
|------|----------|
| **对讲主机（门口机）** | 安装在单元防护门或墙体主机预埋盒内；操作面板离地 ≤ **1.5 m**；面向访客，便于操作 |
| **对讲分机（用户机）** | 安装在住户室内内墙上；高度离地 **1.4~1.6 m** |

#### 4. 电子巡查设备安装要求

- 在线/离线巡查信息采集点（巡查点）数目符合设计使用要求
- 安装高度离地 **1.3~1.5 m**

### （三）综合布线系统的设备安装技术

#### 机柜安装要求

| 项目 | 要求 |
|------|------|
| 机柜数量规划 | 计算配线设备、网络设备、电源设备及理线设施占用空间，考虑冗余和散热 |
| **单排安装** | 前面净空 ≥ **1000 mm**；后面及侧面净空 ≥ **800 mm** |
| **多排安装** | 列间距 ≥ **1200 mm** |

## 四、经典真题

### 2021 单选 | 建筑设备监控系统输入设备安装

**题干：** 关于建筑设备监控系统输入设备安装的说法，正确的是（ ）
A. 铂温度传感器的连接电阻应小于 1Ω
B. 电磁流量计应安装在流量调节阀下游
C. 风管型传感器应在风管保温前安装
D. 涡轮式流量传感器应垂直安装

**答案：** **A**

**解析：** B 应安装在上游；C 风管型应在保温**后**安装；D 涡轮式应**水平**安装。

### 2025 单选 | 入侵报警系统被动型红外探测器

**题干：** 入侵报警系统中的被动型红外探测器（ ）
A. 可对着灯光的方向安装
B. 不能安装在易振动物体上
C. 能对着空调出风口安装
D. 安装高度通常为 1.5-1.8m

**答案：** **B**

**解析：** 不应安装在易振动物体上，不能对着发热体（灯泡、火炉、冰箱散热器、空调出风口），安装高度通常为 2.2~2.7m。

### 2023 二级案例（2.5小时）| 空气传感器安装

**问题：** CO 传感器和 CO₂ 传感器的安装位置分别有什么要求？

**答案要点：**
- CO 传感器安装在房间**上部**（约 2000mm）
- CO₂ 传感器安装在房间**下部**（约 1200mm）
- 空气质量传感器应装在能正确反映空气质量状况的地方

### 2019 案例 | 施工深化设计要求

**问：** 建筑设备监控系统深化设计应具有哪些基本要求？

**答案要点：** 施工深化中应做好与建筑给水排水、电气、通风空调、防排烟、防火卷帘和电梯等设备的接口确认，做好与建筑装修效果的配合工作。

### 2022 案例 | 进口设备验收

**问：** 恒温恒湿空调机组无中文说明是否符合验收要求？应如何改正？

**答案要点：**
- 不符合要求
- 进口设备应提供质量合格证明、检测报告、安装使用维护说明书（中文译文），还应提供原产地证明和商检证明
