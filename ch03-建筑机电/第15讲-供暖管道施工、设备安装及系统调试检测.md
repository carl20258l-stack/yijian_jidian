# 3.1 供暖管道施工、设备安装及系统调试检测

> 本讲涵盖三大块：供暖管道施工技术要求、给水排水与供暖设备安装技术、系统调试与检测试验。其中系统调试检测为高频考点（2012/2013/2022/2023/2025 单选），需重点掌握各类试验的参数对比。

---

## 一、建筑供暖管道施工技术 ★

**真题分布：** 2015 单选

### 1. 室内供暖管道施工技术要求

#### 1）管道及配件安装

##### （1）管道安装坡度

| 管道类型 | 坡度要求 | 说明 |
|-----------|----------|------|
| 汽水同向流动的热水供暖管道 / 蒸汽管道 / 凝结水管道 | 应为 **3‰**，不得小于 **2‰** | 同向流动 |
| 汽水逆向流动的热水供暖管道 / 蒸汽管道 | 不应小于 **5‰** | 逆向流动 |
| 散热器支管 | 应为 **1%** | 坡向应利于排气和泄水 |

> **记忆：** 3‰ + 2‰ = 5‰；3‰ + 2‰ + 5‰ = 1%

##### （2）方形补偿器安装

- 应 **水平安装**，并与管道的 **坡度一致**
- 如其臂长方向垂直安装，必须设 **排气及泄水装置**

##### （3）干管变径连接

| 系统 | 变径方式 | 记忆 |
|------|----------|------|
| 上供下回式热水干管（防 **气塞**） | **顶平偏心** 连接 | **底气**——底平是蒸汽（气=汽），顶平是热水 |
| 蒸汽干管（防 **水锤**） | **底平偏心** 连接 | |

#### 2）低温热水地板辐射供暖系统安装

- 地面下敷设的盘管埋地部分 **不应有接头**
- 盘管隐蔽前必须进行 **水压试验**
  - 试验压力 = 工作压力的 **1.5 倍**，但不小于 **0.6MPa**
  - 稳压 **1h** 内压力降不大于 **0.05MPa** 且不渗不漏

### 2. 室外供热管道施工技术要求

#### （1）架空敷设安装高度

| 场所 | 距地/轨顶高度 |
|------|---------------|
| 人行地区（设计无规定时） | 不小于 **2.5m** |
| 通行车辆地区 | 不小于 **4.5m** |
| 跨越铁路 | 距轨顶不小于 **6m** |

> 不得影响交通设施的使用功能和供热管道的安全。

#### （2）地沟内管道安装净距

| 位置 | 净距范围 |
|------|----------|
| 保温层外表面与沟壁 | 100～150mm |
| 保温层外表面与沟底 | 100～200mm |
| 保温层外表面与沟顶（不通行地沟） | 50～100mm |
| 保温层外表面与沟顶（半通行和通行地沟） | 200～300mm |

#### （3）焊接接头无损检测

- 供热管道焊接接头应按规定进行 **无损检测**
- 对于 **不具备强度试验条件** 的管道对接焊缝，应进行 **100% 射线或超声检测**（内部探伤）

## 二、建筑给水排水与供暖设备安装技术 ★

### 1. 给水设备安装（水泵安装水平度）

| 安装方式 | 检测位置 | 纵向偏差 | 横向偏差 |
|----------|----------|----------|----------|
| **整体安装** | 泵的进、出口法兰面或其他水平面 | ≤ **0.10/1000** | ≤ **0.20/1000** |
| **解体安装** | 水平中分面、轴的外露部分、底座水平加工面 | ≤ **0.05/1000** | ≤ **0.05/1000** |

> 整体安装的横向偏差比纵向大（2:1）；解体安装纵横一致且精度更高。

### 2. 卫生器具安装

- 固定方式：采用 **预埋螺栓或膨胀螺栓** 安装固定
- 排水栓和地漏：安装平正、牢固，**低于排水表面**，周边无渗漏
- 地漏 **水封高度不得小于 50mm**
- 支、托架：防腐良好，安装 **平整、牢固**，与器具接触 **紧密、平稳**

### 3. 散热器安装

- 散热器组对应 **平直紧密**
- 支架托架安装：位置 **准确**，埋设 **牢固**
- 散热器背面与装饰后的墙内表面安装距离：设计未注明时，应为 **30mm**

### 4. 水处理设备及控制设施安装

| 设备类型 | 试验方式 | 试验要求 |
|----------|----------|----------|
| **敞口水箱** | **满水试验** | 静置 **24h** 观察，不渗不漏 |
| **密闭水箱（罐）** | **水压试验**（工作压力的 **1.5 倍**） | 试验压力下观察 **10min**，压力不降、不渗不漏 |

> **中水高位水箱** 应与生活高位水箱 **分设在不同房间**；如只能设在同一房间，净距离应 **大于 2m**，且中水池（箱）、阀门、水表及给水栓均应有 **"中水"标志**

## 三、建筑给水排水与供暖系统调试和检测 ★★

**真题分布：** 2012 单 / 2013 单 / 2022 单 / 2023 单 / 2025 单

### 1. 建筑排水系统试验要求

#### 1）室内排水系统灌水试验

- **隐蔽或埋地的排水管道** 在隐蔽前必须做 **灌水试验**
  - 灌水高度 ≥ 底层卫生器具的上边缘或底层地面高度
  - 满水 **15min** 水面下降后，再灌满观察 **5min**，液面不降、管道及接口无渗漏为合格
- **室内雨水管道** 安装后应做灌水试验
  - 灌水高度必须到每根 **立管上部的雨水斗**
  - 持续 **1h**，不渗不漏

#### 2）室内排水系统通球试验

- 排水 **主立管及水平干管管道** 均应做通球试验
- 通球球径 ≥ 排水管道管径的 **2/3**
- 通球率必须达到 **100%**

#### 3）室外排水系统灌水、通水试验

- 管道埋设前必须做 **灌水试验和通水试验**
  - 排水应畅通，无堵塞，管接口无渗漏
- 按排水检查井 **分段试验**
  - 试验水头以设计和规范要求为准
  - 时间不少于 **30min**，逐段观察

### 2. 建筑给水系统试验要求

#### 1）室内给水系统水压试验、冲洗及消毒

> **记忆口诀：** 亚冠通水球（压力试验→灌水试验→通水试验→通球试验）

##### 水压强度试验

- 各种材质的给水管道系统强度试验压力均为工作压力的 **1.5 倍**，但不得小于 **0.6MPa**
- 试验应包含：**水压强度试验** 和 **严密性试验**

| 管道材质 | 试验参数 |
|----------|----------|
| **金属及复合管** | 试验压力下观测 **10min**，压力降 ≤ **0.02MPa** → 降至工作压力检查，不渗不漏 |
| **塑料管** | 试验压力下稳压 **1h**，压力降 ≤ **0.05MPa** → 在工作压力的 **1.15 倍** 状态下稳压 **2h**，压力降 ≤ **0.03MPa**，连接处不得渗漏 |

> **记忆：** 金属比塑料可靠性高。**金属以分钟记，塑料以小时记**。金属 10min-0.02MPa；塑料 1h-0.05MPa + 2h-0.03MPa（1.15 倍）

##### 冲洗与消毒

- 水压试验合格后 → 管道系统 **冲洗**
- 热水管道系统冲洗顺序：先冲洗 **底部干管** → 后冲洗各环路 **支管**
- 生活给水、热水系统及游泳池循环给水系统：交付使用前 **必须冲洗和消毒**
- 生活饮用水系统的水质应进行 **见证取样检验**

#### 2）建筑饮用水供应工程试压、冲洗及消毒

- 管道安装完成后，应分别对立管、连通管及室外管段进行 **水压试验**
- 试验压力 = 工作压力的 **1.5 倍**，且不得小于 **0.60MPa**
- **暗装管道** 必须在 **隐蔽前进行试压**
- **热熔连接管道**：水压试验应在连接完成 **24h 后进行**

### 3. 建筑供暖系统试验与调试

#### 1）供暖设备及辅助设备试验（新教材内容）

##### 锅炉水压试验

**锅炉水压试验压力（表 3.1-5）**

| 序号 | 设备名称 | 锅筒（壳）工作压力（MPa） | 试验压力（MPa） |
|------|----------|--------------------------|-----------------|
| 1 | 锅炉本体（汽包锅炉） | ＜0.8 | 1.5 倍工作压力，但不小于 0.2 |
| | | 0.8～1.6 | 工作压力 + 0.4 |
| | | ＞1.6 | 1.25 倍工作压力 |
| 2 | 直流锅炉本体 | 任何压力 | 介质出口工作压力的 1.25 倍，且 ≥ 省煤器进口工作压力的 1.1 倍 |
| 3 | 再热器 | 任何压力 | 1.5 倍再热器工作压力 |
| 4 | 省煤器 | 任何压力 | 1.5 倍省煤器工作压力 |

**试验步骤：** 缓升 → 停查 → 保压 → 降查
- 整体水压试验保压时间：**20min**
- 水压应 **缓慢地升降**
- 升到工作压力 → 暂停升压检查 → 升到试验压力（保压）→ 降到工作压力检查（检查期间压力保持不变）

**整体水压试验允许压降（表 3.1-6）**

| 锅炉类别 | 允许压降 △p（MPa） |
|----------|--------------------|
| 高压及以上 A 级锅炉 | ≤ 0.60（12） |
| 次高压及以下 A 级锅炉 | ≤ 0.40（8） |
| ＞20t/h（14MW）B 级锅炉 | ≤ 0.15（3） |
| ≤20t/h（14MW）B 级锅炉 | ≤ 0.10（2） |
| C、D 级锅炉 | ≤ 0.05（1） |

**水压试验合格要求：**
1. 受压元件金属壁和焊缝上 **没有水珠和水雾**
2. 降到工作压力后 **胀口处不滴水珠**
3. 铸铁锅炉、铸铝锅炉锅片的密封处降到额定工作压力后 **不滴水珠**
4. 水压试验后 **没有明显残余变形**

**电站锅炉特殊要求：**
- 亚临界及以上电站锅炉主蒸汽管道和再热蒸汽管道的水压试验按相关标准执行
- 水压试验用水质应满足相关行业标准要求

##### 阀门严密性试验

- 锅炉的 **阀门（尤其是安全阀）** 应逐个在其公称压力的 **1.25 倍** 下进行严密性试验
- 阀瓣与阀座密封面不应漏水

##### 供暖分汽缸（分水器、集水器）水压试验

- 安装前应进行 **水压试验**
- 试验压力 = 工作压力的 **1.5 倍**，但不得小于 **0.6MPa**
- 试验压力下 **10min** 内无压降、无渗漏

##### 箱、罐水压 / 满水试验

| 类型 | 试验方式 | 要求 |
|------|----------|------|
| **敞口箱、罐** | **满水试验** | 满水后静置 **24h** 不渗不漏 |
| **密闭箱、罐** | **水压试验**（工作压力的 1.5 倍，≥ 0.4MPa） | 试验压力下 **10min** 内无压降，不渗不漏 |

##### 散热器水压试验

- 散热器组对后 / 整组出厂散热器在安装之前应做 **水压试验**
- 试验压力：设计无要求时 = 工作压力的 **1.5 倍**，但不小于 **0.6MPa**
- 试验时间：**2~3min**，压力不降且不渗不漏

#### 2）室内供暖管道系统试压、冲洗及试运行和调试

##### （1）试压

- 供暖系统安装完毕、**管道保温之前**应进行水压试验
- 试验压力按设计要求；设计未注明时：

| 系统类型 | 试验压力 |
|----------|----------|
| **蒸汽、热水供暖系统** | 系统 **顶点工作压力 + 0.1MPa**，且顶点试验压力 ≥ **0.3MPa** |
| **高温热水供暖系统** | 系统 **顶点工作压力 + 0.4MPa** |
| **塑料管及复合管热水供暖系统** | 系统 **顶点工作压力 + 0.2MPa**，且顶点试验压力 ≥ **0.4MPa** |

> 顶点压力：供暖系统在正常工作状态下在最高点测得的水压力值

| 管道材质 | 保压要求 |
|----------|----------|
| **钢管及复合管** | 试验压力下 **10min** 内压力降 ≤ **0.02MPa** → 降至工作压力检查，不渗不漏 |
| **塑料管** | 试验压力下 **1h** 内压力降 ≤ **0.05MPa** → 降压至工作压力的 **1.15 倍**，稳压 **2h**，压力降 ≤ **0.03MPa**，各连接处不渗不漏 |

> **记忆：** 金属分钟，塑料小时。金属 10min-0.02；塑料 1h-0.05 + 1.15 倍-2h-0.03

##### （2）冲洗

- 系统试压合格后 → 对系统进行 **冲洗** 并清扫过滤器及除污器
- 合格标准：排出水不含泥沙、铁屑等杂质，且 **水色不浑浊**

##### （3）试运行和调试

- 系统冲洗完毕应 **充水、加热**，进行试运行和调试
- 观察、测量室温满足设计要求为合格
- **安全阀** 经最终调整后，整体出厂的锅炉应带负荷正常连续试运行 **4~24h**，并做好试运行记录

**【真题 2023 二建】** 室内供暖管道系统试压 → 冲洗（清扫过滤器及除污器）→ 充水加热试运行调试

#### 3）室外供热管道系统试压、冲洗及调试

| 项目 | 要求 |
|------|------|
| **水压试验** | 试验压力 = 工作压力的 **1.5 倍**，≥ **0.6MPa**；**10min** 内压力降 ≤ **0.05MPa**，降至工作压力检查不渗不漏 |
| **冲洗** | 试压合格后进行，以 **水色不浑浊** 为合格 |
| **调试** | 冲洗完毕 → **通水、加热** → 试运行和调试，测量各建筑物热力入口处供回水温度及压力 |

> 室外供热管道的阀门应开启，并应与非试验管道隔断

## 五、历年真题

### 【例题 2015 单选】安装坡度要求最大的采暖管道是？

A. 热水采暖管道
B. 蒸汽管道
C. **散热器支管管道** ✅
D. 蒸汽凝结水管道

> **解析：** 散热器支管坡度应为 **1%**，远大于其他管道的 ‰ 级坡度。

### 【例题 2013 单选】采暖管道冲洗完毕后，应（  ）、加热，进行试运行和调试。

A. 试压
B. **通水** ✅
C. 通球
D. 灌水

> **解析：** 供暖管道系统冲洗完毕应 **通水、加热**，进行试运行和调试。

### 【例题 2023 单选】当供暖工程的集水器工作压力为 0.6MPa，其试验压力为工作压力的（  ）？

A. 1.1 倍
B. 1.15 倍
C. 1.25 倍
D. **1.5 倍** ✅

> **解析：** 供暖分汽缸（分水器、集水器）安装前应进行水压试验，试验压力为工作压力的 **1.5 倍**，但不得小于 0.6MPa。

### 【例题 2022 单选】塑料管道的水压试验为工作压力的（  ）倍？

A. 1.15
B. 1.2
C. **1.5** ✅
D. 2

> **解析：** 室内给水管道各种材质的给水管道系统试验压力均为工作压力的 **1.5 倍**，但不得小于 0.6MPa。
