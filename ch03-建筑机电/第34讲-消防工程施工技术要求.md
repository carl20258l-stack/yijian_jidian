# 3.6 消防工程施工技术要求

**考点星级：★★（案例 / 单选）**

**真题分布：2016 案例、2019 案例、2021 单选、2023 单选**

---

## 1. 消防给水及消火栓系统施工技术要求

### 消防水泵安装

| 项目 | 要求 |
|------|------|
| 出水管上 | 应安装 **消声止回阀、控制阀和压力表** |
| 系统总出水管 | 还应安装 **压力表和压力开关** |
| 压力表安装 | 应加设 **缓冲装置** |
| 压力表与缓冲装置之间 | 应安装 **旋塞** |
| 压力表量程（无设计时） | 应为系统工作压力的 **2～2.5 倍** |

### 消防水泵接合器安装

安装顺序：**接口 → 本体 → 连接管 → 止回阀 → 安全阀 → 放空管 → 控制阀**

> 记忆口诀：**接本连止安防控**

止回阀安装方向应使消防用水能从消防水泵接合器进入系统。

### 消火栓安装

| 项目 | 要求 |
|------|------|
| **地下式消火栓** | 顶部进水口或顶部出水口应正对井口；与消防井盖底面距离 ≤ **0.4m** |
| **室内消火栓** | 栓口 **不应安装在门轴侧**；栓口中心距地面 **1.1m** |
| **试射试验** | 取 **屋顶层（或水箱间内）** 试验消火栓 + **首层两处** 消火栓做试射试验 |

### 消火栓系统调试内容

1. 水源调试和测试
2. **消防水泵**调试
3. 稳压泵或稳压设施调试
4. 减压阀调试
5. 消火栓调试
6. **自动控制探测器**调试
7. 干式消火栓系统的 **报警阀等快速启闭装置** 调试（含报警阀附件电动阀或电磁阀等阀门调试）
8. **排水设施**调试
9. **联锁控制**试验

## 2. 自动喷水灭火系统安装要求

### 管道与喷头

| 项目 | 要求 |
|------|------|
| 管道横向安装坡度 | **2‰～5‰**，坡向排水管 |
| 喷头安装时机 | 必须在系统 **试压、冲洗合格后** 进行 |
| 喷头安装工具 | 应使用 **专用扳手**，严禁利用喷头的框架施拧 |
| 报警阀组安装时机 | 在 **供水管网试压、冲洗合格后** 进行；先装水源控制阀、报警阀，再连接辅助管道 |

### 水流指示器

安装时应使电器元件 **竖直安装在水平管道上侧**，其动作方向应和 **水流方向一致**。

### 自动喷水灭火系统调试内容

1. 水源测试
2. **消防水泵**调试
3. 稳压泵调试
4. **报警阀**调试
5. **排水设施**调试
6. **联动试验**

6. 排水设施调试
7. 联动试验

## 6. 自动跟踪定位射流灭火系统安装要求

### 安装要求

| 项目 | 要求 |
|------|------|
| 气压稳压装置 | 四周设检修通道，宽度 ≥ **0.7m**；顶部至楼板或梁底距离 ≥ **0.6m** |
| 模拟末端试水装置 | 出水应采取 **间接排水** 方式，且具备良好的排水能力 |

### 系统调试内容

1. 水源调试和测试
2. 消防水泵调试
3. 气压稳压装置调试
4. 自动控制阀和灭火装置手动控制功能调试
5. 系统的主电源和备用电源切换测试
6. 系统自动跟踪定位灭火模拟调试
7. 模拟末端试水装置调试
8. 系统自动跟踪定位射流灭火试验
9. 联动控制调试

---

### 通用规律（多系统对比）

**规律一：报警阀组 / 消防炮的安装时机**
> 应在 **供水管网试压、冲洗合格后** 进行。

**规律二：喷头安装时机**
> 应在系统 **试压、冲洗、吹扫合格后** 进行。

**规律三：各系统调试的公共项**
| 调试公共项 | 适用系统 |
|-----------|----------|
| 水源测试 | 自动喷水、水喷雾、自动跟踪定位 |
| 消防水泵调试 | 自动喷水、水喷雾、自动跟踪定位 |
| 稳压泵调试 | 自动喷水、水喷雾、自动跟踪定位 |
| 报警阀调试 | 自动喷水 |
| 排水设施调试 | 自动喷水、水喷雾 |
| 联动试验 | 自动喷水、水喷雾、自动跟踪定位 |

## 7. 气体灭火系统施工技术要求

| 项目 | 要求 |
|------|------|
| 灭火剂储存装置 | 泄压装置的泄压方向 **不应朝向操作面** |
| 低压 CO₂ 系统安全阀 | 应通过专用泄压管接到 **室外** |
| 灭火剂输送管道 | 安装后应进行 **强度试验和气压严密性试验** |
| 不带装饰罩的喷嘴（吊顶下） | 连接管道管端螺纹 **不应露出吊顶** |
| 带装饰罩的喷嘴（吊顶下） | 装饰罩应 **紧贴吊顶** |

### 系统调试项目

> **模拟启动试验、模拟喷气试验、模拟切换操作试验**

## 8. 泡沫灭火系统施工技术要求

| 项目 | 要求 |
|------|------|
| **常压钢质泡沫液储罐** | 应进行 **盛水试验**；试验压力为储罐装满水后的 **静压力**；试验前清理烘干焊接接头；试验时间 ≥ **1h**，目测无渗漏 |
| 管线式比例混合器 | 安装在压力水的水平管道上或串接在消防水带上，靠近储罐或防护区；吸液口与泡沫液储罐最低液位高度 ≤ **1.0m** |
| 管道水压试验 | 试验压力为设计压力的 **1.5 倍**；试验前将泡沫产生装置、泡沫比例混合器 **隔离** |
| 地上式泡沫消火栓 | 应 **垂直安装**，大口径出液口应朝向 **消防车道** |

### 系统调试内容

1. 动力源和备用动力的切换试验
2. 水源的测试
3. 消防泵和稳压设备的试验
4. 泡沫比例混合装置的调试
5. 泡沫产生装置的调试
6. 报警阀的调试
7. 泡沫消火栓的 **冷喷试验**
8. 泡沫灭火系统的 **喷水和喷泡沫试验**

---

## 9. 干粉灭火系统施工技术要求

- 干粉灭火装置的联动控制组件应进行 **模拟启动试验**（含自动模拟启动和手动模拟启动试验）

## 10. 防排烟系统施工技术要求

| 项目 | 要求 |
|------|------|
| 排烟风管隔热层 | 厚度 ≥ **40mm** 的 **不燃** 绝热材料 |
| 排烟风管法兰垫片 | **不燃材料**，厚度 ≥ **3mm** |
| 排烟防火阀 | 应 **顺气流方向关闭**；距防火墙表面 ≤ **200mm**；应设 **独立的支吊架** |
| 防排烟风机基础 | 设在混凝土或钢架基础上，**不应设置减振装置** |
| 共用系统减振（与通风空调共用） | **不应使用橡胶减振装置** |
| 风管与风机连接 | 宜采用 **法兰连接**，或采用不燃材料的 **柔性短管** 连接；风机仅用于防排烟时，**不宜采用柔性连接** |
| 风管严密性检验 | 安装完成后应进行 **严密性检验**；防排烟风管按 **中压系统** 风管确定允许漏风量 |

### 防排烟系统调试内容

1. 排烟防火阀的调试
2. 常闭送风口、排烟阀或排烟口的调试
3. 活动挡烟垂壁的调试
4. 自动排烟窗的调试
5. 送风机、排烟风机的调试
6. 机械加压系统风速及余压的调试
7. 机械排烟系统风速和风量的调试
8. 机械加压送风系统、机械排烟系统、自动排烟窗和活动挡烟垂壁的 **联动调试**

## 11. 火灾自动报警及消防联动设备的施工技术要求

### 管路敷设

- 各类管路 **暗敷** 时，应敷设在 **不燃结构** 内，保护层厚度 ≥ **30mm**
- 火灾自动报警线应 **单独布线**，穿入 **金属管内或金属线槽中**

### 设备接线

- 控制与显示类设备应与消防电源、备用电源 **直接连接**，**不应使用电源插头**

### 探测器安装

| 探测器类型 | 要求 |
|-----------|------|
| 点型感烟（感温）、一氧化碳 | 至墙壁、梁边水平距离 ≥ **0.5m**；周围 0.5m 内 **无遮挡物** |
| 点型感烟（感温）至空调送风口 | 水平距离 ≥ **1.5m** |
| 点型感烟（感温）至多孔送风口 | 水平距离 ≥ **0.5m** |
| 点型火焰探测器、图像型火灾探测器 | 保证 **视场角覆盖探测区域**，避免光源直接照射探测窗口 |
| 可燃气体探测器 | 安装位置根据探测 **气体密度** 确定 |

### 手动火灾报警按钮

- 安装在 **明显和便于操作** 的部位
- 安装在墙上时：底边距地（楼）面高度宜为 **1.3～1.5m**

## 真题演练

### 例题 1（2025 单选）

**泡沫灭火系统应进行盛水试验的是（ ）。**

A. 泡沫液储罐
B. 泡沫比例混合器
C. 泡沫产生装置
D. 泡沫消防输送泵

> **【答案】A**
>
> **【解析】** 常压钢质泡沫液储罐应进行盛水试验，试验压力应为储罐装满水后的静压力，试验前应将焊接接头的外表面清理干净，并使之干燥，试验时间不应小于 1h，目测应无渗漏。

---

### 例题 2（2021 单选）

**下列设备安装时，不能采用橡胶减振垫的是（ ）。**

A. 冷水机组
B. 排烟风机
C. 空调机组
D. 冷却塔

> **【答案】B**
>
> **【解析】** 防排烟风机应设在混凝土或钢架基础上，且不应设置减振装置；若排烟系统与通风空调系统共用且需要设置减振装置时，不应使用橡胶减振装置。

---

### 例题 3（2019 案例节选）

**背景资料：** 在自动喷水灭火系统调试阶段，B 公司组织了相关人员进行了消防水泵、稳压泵和报警阀的调试，完成后交付 A 公司进行系统联动试验，但 A 公司认为 B 公司还有部分调试工作未完成。

**问题：B 公司还有哪些调试工作未完成？**

> **【答案】** 未完成的调试工作还包括：
> 1. 水源测试
> 2. 排水设施调试
> 3. 联动试验

---

### 例题 4（2022 二级真题 案例节选）

**背景资料：** 施工过程中，消防排烟系统设计工作压力为 750Pa，排烟风管采用角钢法兰连接。监理单位对排烟防火阀的安装和排烟风管法兰连接工艺提出整改要求。

**问题：写出排烟防火阀安装和排烟风管法兰连接的正确要求。**

> **【答案】**
>
> 1. **排烟防火阀距离隔墙距离太远**
>    正确做法：防火墙两侧的防火阀，距墙表面应不大于 **200mm**。
>
> 2. **排烟防火阀没有设置独立支、吊架**
>    正确做法：排烟防火阀应设置 **独立支、吊架**。
>
> 3. **风管法兰连接垫片厚度 2mm 不正确**
>    正确做法：根据《建筑防烟排烟系统技术标准》GB51251-2017，垫片厚度不应小于 **3mm**，不应凸入管内或法兰外；排烟风管法兰垫片应为 **不燃材料**。
>
> 4. **法兰连接处螺栓孔间距 250mm 不正确**
>    正确做法：本题中排烟管道为 **中压**（500＜P≤1500），中低压系统矩形风管法兰螺栓及铆钉间距应 ≤ **150mm**。
