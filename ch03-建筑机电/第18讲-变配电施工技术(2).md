# 3.2 变配电施工技术（2）——配电柜与箱式变电所安装

> [!summary] 本讲概要
> 本讲聚焦配电柜（开关柜）从进场到交接试验的全流程施工技术，以及箱式变电所的安装与试验要求。核心考点集中在：
> - ★★★ **配电柜安装 9 大工序**（进场→基础型钢→柜体固定→母线→二次配线→SPD→接地→检查→交接试验）
> - ★★★ **交接试验与绝缘试验参数**（兆欧表选型、绝缘电阻、耐压时间、吸收比/极化指数）
> - ★★ **真空断路器试验**（导电回路电阻、交流耐压、弹跳时间）
> - ★★ **金属氧化物避雷器试验**（三组电压等级对应的兆欧表与绝缘电阻要求）
> - ★ **箱式变电所安装与交接试验**

---

## 3．配电柜安装 ★★★

> [!tip] 配电柜功能
> 正常运行时用来**接受和分配电能**，发生故障时通过自动或手动操作，迅速**切除故障部分**，恢复正常运行。配电装置由**母线、开关设备、保护电器、测量仪表**和其他附件等组成。

### 3.1 进场验收

| 项目 | 要求 |
|------|------|
| 型号/规格/参数 | 符合设计要求 |
| 随机文件 | 查验**合格证和随带技术文件**；高低压成套配电柜、蓄电池柜、UPS柜、EPS柜等应有 **出厂试验报告** |
| 外观检查 | 柜体应有**吊环**，表面涂层完整、无明显碰撞凹陷；电器及部件无损伤和裂纹 |
| 联锁装置 | 具有机械、电气防误操作的**联锁装置** |
| 电池/充油充气 | 蓄电池壳体无碎裂、漏液；充油充气设备无泄漏 |

### 3.2 基础型钢框架制作安装 ★★

| 项目 | 要求 |
|------|------|
| 材料 | 一般采用 **10 号槽钢（型钢）** 制作 |
| 水平度/不平行度 | 允许偏差应符合规范要求 |
| 安装高度 | 一般基础型钢框架顶部宜**高出地坪 100mm** |
| 手车式开关柜 | 基础型钢框架顶面宜与**工作地面齐平** |
| 接地 | 每组型钢框架两端应采用 **≥100mm²镀锌扁钢** 与接地干线电焊连接，**不少于两处接地** |

> 记忆：100mm 高 / 100mm² 扁钢 / 两处接地 → "一百高一白扁，两处接地保平安"

### 3.3 柜体固定 ★★

| 项目 | 要求 |
|------|------|
| 排列顺序 | 按施工图配电柜**编号顺序**排列固定 |
| 安装顺序 | **先安装中间**位置的配电柜，调整水平度、垂直度后，再安装调整左右相邻两侧 |
| 固定方式 | 柜体与柜体之间、柜体与基础框架之间分别用**镀锌螺栓**固定 |
| 手车/抽屉式闭锁 | 机械闭锁、电气闭锁应**动作准确可靠**，触头接触紧密 |
| 拉出推进 | 轻便灵活，**无卡阻碰撞现象** |

### 3.4 柜内母线安装（配线） ★

> 母线绝缘子无损坏及裂纹，裸铜母线间有足够电气绝缘**安全距离**；柜间连接母线由厂家配套制作，现场安装；母线搭接接触面涂**导电膏**，用**力矩扳手**紧固连接螺栓。

### 3.5 柜内二次配线 ★★★

| 项目 | 参数 |
|------|------|
| 弯曲半径 | ≥ 线缆允许弯曲半径，导线连接不应损伤线芯 |
| 二次回路绝缘导线额定电压 | 除电子元件回路外，**≥ 450/750V**（导体对地/导体之间） |
| 铜芯导线截面积——电流回路 | **≥ 2.5mm²** |
| 铜芯导线截面积——其他回路 | **≥ 1.5mm²** |
| 线缆绑扎 | 不同电压等级、交流、直流线路及计算机控制线路应**分别绑扎**，有标识 |
| 固定后要求 | **不应妨碍**手车开关或抽出式部件拉出或推入 |
| 互感器接地 | 电流（电压）互感器安装就位后，各接地引出端子接地良好；**暂时不使用的电流互感器二次线圈应短路后再接地** |

> 记忆：电流 2.5 其他 1.5，450/750 绝缘线；不用的 CT 短接地

### 3.6 柜内电涌保护器（SPD）安装 ★

- SPD 的型号、规格、安装布置及接线形式应符合设计要求
- 连接导线应平直、足够短，**不宜大于 0.5m**
- 接地导线的位置**不宜靠近出线位置**

### 3.7 柜体接地 ★

| 项目 | 要求 |
|------|------|
| 金属框架及基础型钢 | 与**保护导体可靠连接** |
| 装有电器的可开启门 | 门和金属框架接地选用 **≥ 4mm²黄绿色绝缘铜芯软导线** 连接，并有标识 |
| 防电击保护 | PE排应有裸露的连接外部保护接地导体的端子，并可靠连接 |

### 3.8 安装后检查 ★

| 检查项 | 要求 |
|--------|------|
| 开关及保护装置 | 规格、型号符合设计要求 |
| 闭锁装置 | 动作准确、可靠 |
| 主开关辅助开关 | 切换动作与主开关**动作一致** |
| 标识 | 标明被控设备**编号及名称或操作位置**，接线端子有编号且清晰 |
| 手车/抽屉式推拉 | 灵活，**无卡阻碰撞** |
| 动/静触头 | 中心线一致，触头接触紧密 |
| **接地触头时序** | **投入时：接地触头先于主触头接触**；**退出时：接地触头后于主触头脱开** |

> [!important] 接地触头安全原则
> 始终保持接地，保证安全。投入时接地先通，退出时接地后断。

### 3.9 交接试验规定 ★★★

#### 基本规则

| 情形 | 规则 |
|------|------|
| 一般情况 | 将连接在一起的各种设备**分离，单独试验** |
| 同一试验标准 | 可连在一起试验 |
| 无法单独 + 有出厂报告 | **同一电压等级**不同试验标准的设备可连在一起，试验标准采用**最低标准** |

#### 交流耐压试验

- 加至试验标准电压后的持续时间：无特殊说明时为 **1min**

#### 绝缘试验环境条件

| 条件 | 要求 |
|------|------|
| 被试物及仪器周围温度 | **≥ 5℃** |
| 空气相对湿度 | **≤ 80%** |

> 记忆：5 度 8 湿，绝缘测试好时机

#### 绝缘电阻测量关键参数

| 参数 | 定义 | 用途 |
|------|------|------|
| R60s | 60s 时的绝缘电阻值 | 基本测量值 |
| 吸收比 | **R60s / R15s** | 测**小设备**受潮，＞1.33 表明绝缘良好 |
| 极化指数 | **R10min / R1min** | 测**大设备**受潮 |

> 记忆：吸收比测小（设备），极化指数测大（设备）；吸收比大于 1.33 说明电机绝缘不曾受潮或受潮不严重

### 3.10 配电柜（开关柜）试验 ★★★

#### 3.10.1 绝缘电阻值要求

| 回路 | 绝缘电阻值 |
|------|-----------|
| 低压馈电线路（线间/线对地） | **≥ 0.5MΩ** |
| 二次回路 | **≥ 1MΩ** |

#### 3.10.2 设备电压等级与兆欧表选用 ★★★

| 设备电压等级 | 兆欧表电压等级 | 兆欧表最小量程 |
|-------------|---------------|--------------|
| ＜100V | 250V | 50MΩ |
| ＜500V | 500V | 100MΩ |
| ＜3000V | 1000V | 2000MΩ |
| ＜10000V（10kV） | 2500V | 10000MΩ |
| ≥10000V | 2500V 或 5000V | 10000MΩ |

> 记忆：电压等级乘以 2~5 选兆欧表；10kV 以下配 2500V，10kV 以上配 2500/5000V

#### 3.10.3 高压成套配电柜 ★★

- 按规范规定进行**交接试验**
- 新型高压电气设备和继电保护装置投入使用前，按产品技术文件要求进行交接试验
- 回路中的**电子元件不应参加交流工频耐压试验**
- **50V 及以下**回路可不做交流工频耐压试验

#### 3.10.4 二次回路耐压试验 ★★

| 项目 | 参数 |
|------|------|
| 耐压试验电压 | **1000V** |
| 替代情形 | 回路绝缘电阻值 ＞ 10MΩ 时，用 **2500V 兆欧表** 代替 |
| 试验持续时间 | **1min** 或符合产品技术文件 |
| 免试 | **48V 及以下**电压等级回路可不做 |
| 电子元器件回路 | 试验时将插件拔出或将其两端短接 |

#### 3.10.5 末端回路保护

- 低压成套配电柜内末端用电回路中，所设**过电流保护电器**兼作故障防护时，应在回路末端测量**接地故障回路阻抗**

#### 3.10.6 剩余电流动作保护器（RCD）测试 ★★

| 项目 | 要求 |
|------|------|
| 测试方式 | 施加**额定剩余动作电流（I∆n）** 模拟漏电电流，测试是否跳闸 |
| 测试值 | 动作时间应符合设计要求 |
| 干线回路 RCD 测试 | 宜在 **RCD 出口处**进行 |
| 其他回路 RCD 测试 | 应在**回路末端**进行（插座最远处） |

> 记忆：干线测出口，其他测末端

### 3.11 真空断路器试验 ★★（新增）

#### 3.11.1 导电回路电阻

- 每相导电回路电阻值测量采用 **电流不小于 100A 的直流压降法**
- 测试结果符合产品技术文件规定（R = U / I）

#### 3.11.2 交流耐压试验

| 状态 | 要求 |
|------|------|
| **合闸状态** | 真空断路器交流耐受电压应符合表 3.2-4 规定 |
| **分闸状态** | 真空灭弧室断口间试验电压按产品技术条件；无规定时按表 3.2-4 |
| 试验中 | **不应发生贯穿性放电** |

**真空断路器交流耐受电压（表 3.2-4）**

> 注意标注：25/18 = 出厂试验/交接试验
>
> | 项目 | 含义 |
> |------|------|
> | 相对地 | 带电部件和外壳之间的绝缘 |
> | 相间 | 不同相导体间的绝缘 |
> | 断路器断口 | 分闸状态下动静触头间的绝缘 |
> | 隔离断口 | 隔离开关分闸后的绝缘 |

#### 3.11.3 机械特性测量

| 项目 | 要求 |
|------|------|
| 分/合闸时间 | 测量主触头分、合闸时间 |
| 同期性 | 测量分、合闸的同期性 |
| **弹跳时间**（合闸过程触头接触后） | **40.5kV 以下 ≤ 2ms**；**40.5kV 及以上 ≤ 3ms** |

> 记忆：40.5 是分水岭，以下 2ms 以上 3ms

#### 3.11.4 电气特性测量

| 项目 | 要求 |
|------|------|
| 绝缘电阻值 | 分、合闸线圈及合闸接触器线圈 **≥ 10MΩ** |
| 直流电阻值 | 与产品出厂试验值相比**无明显差别** |

### 3.12 金属氧化物避雷器试验 ★★

#### 3.12.1 绝缘电阻测量 ★★★

| 避雷器电压等级 | 兆欧表规格 | 绝缘电阻值要求 |
|---------------|-----------|--------------|
| 35kV 以上 | 5000V 兆欧表 | **≥ 2500MΩ** |
| 1~35kV | 2500V 兆欧表 | **≥ 1000MΩ** |
| 1kV 以下 | 500V 兆欧表 | **≥ 2MΩ** |
| 基座绝缘电阻 | — | **≥ 5MΩ** |

> 记忆：电压等级递降，兆欧表等级递降，电阻要求递降；基座统一 ≥ 5MΩ

**对比记忆：避雷器 vs 配电柜兆欧表选型**

| 设备类型 | 高电压 | 中电压 | 低电压 |
|---------|--------|--------|--------|
| 配电柜兆欧表 | ≥10000V→2500/5000V | ＜10000V→2500V | ＜500V→500V |
| 避雷器兆欧表 | 35kV↑→5000V | 1~35kV→2500V | 1kV↓→500V |

> 都可以记"高压配高压表，低压配低压表"的原则。

#### 3.12.2 其他试验内容

- 测量**工频参考电压和持续电流**（避雷器能耐受的安全电压及该电压下允许通过的微小电流）
- 测量**直流参考电压和 0.75 倍直流参考电压下的泄漏电流**

## 4．箱式变电所安装 ★

### 4.1 箱式变电所安装

| 项目 | 要求 |
|------|------|
| 基础 | **高于室外地坪**，周围排水通畅 |
| 地脚螺栓 | 螺帽齐全，拧紧牢固 |
| 接地 | 金属箱体**与保护导体可靠连接**，有标识 |
| 内部接线 | 高压和低压配电柜内部**接线应完整** |
| 低压输出回路 | **标记清晰，回路名称准确**；检查数量：按回路数量抽查 **10%**，且**≥ 1 个回路** |
| 涂层/通风 | 内、外涂层完整、无损伤；有通风口的，风口防护网应完好 |

### 4.2 箱式变电所交接试验

| 类型 | 要求 |
|------|------|
| 通用要求 | 变压器、电气设备及继电保护系统在投入运行前**应交接试验合格** |
| 由高压/低压成套开关柜 + 变压器**三个独立单元**组合 | 高压电气设备部分按规范完成交接试验且合格 |
| 高压开关、熔断器等与变压器组合在**同一密闭油箱**内 | 交接试验按**产品提供的技术文件**要求执行 |

## 通用施工要点总结

> [!abstract] 通用检查三原则（适用于各类配电装置）

| 阶段 | 要点 |
|------|------|
| **开箱/进场** | 型号、规格、外观、附件；随机文件齐全（合格证、技术文件） |
| **安装** | 连接牢固、符合规范（垂直度、间隙、水平度）；无卡阻；合闸指示正确；联动/动作正常/传动正确 |
| **接地** | （外露可导电）与保护导体**可靠连接** |

## 【真题】考点分析

### 高频计算/选择题考点
1. **兆欧表选型**（表 3.2-3）：必须掌握 5 个电压等级区间对应关系
2. **绝缘电阻值**：馈电线路 ≥ 0.5MΩ，二次回路 ≥ 1MΩ
3. **二次配线截面**：电流回路 ≥ 2.5mm²，其他回路 ≥ 1.5mm²
4. **RCD 测试**：干线出口处 vs 其他回路末端
5. **吸收比 vs 极化指数**：吸收比 = R60s/R15s（测小设备），极化指数 = R10min/R1min（测大设备）

### 高频案例考点
1. **接地触头时序**：投入时先于主触头，退出时后于主触头 —— 常考"先通后断"原则
2. **接地线截面积**：门和框架 ≥ 4mm²黄绿铜芯软线
3. **基础型钢接地**：≥ 100mm²镀锌扁钢，不少于两处
4. **SPD 连接导线长度**：≤ 0.5m
5. **真空断路器弹跳时间**：40.5kV 分界线

## 记忆卡

```text
配电柜安装九步走：
进场验收查文件 → 基础型钢一百高 → 先中后边柜体固
→ 母线涂膏力矩拧 → 二次配线分绑扎 → SPD 导线半米短
→ 门框接地 4 方软 → 检查接地先通断 → 交接试验按标准

交接试验三参数：
吸收比 = 60/15 → 测小设备受潮
极化指数 = 10min/1min → 测大设备受潮
耐压时间 = 1min

兆欧表选型口诀：
100 以下 250，500 以下 500，3000 以下 1000，
10kV 以下 2500，10kV 以上 2500 或 5000
```
