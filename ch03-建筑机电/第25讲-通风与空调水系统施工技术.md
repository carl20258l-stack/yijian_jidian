## 1. 水管道安装

### 1.1 冷冻、冷却水管道安装技术要求

**管道连接方式：** 螺纹连接、焊接、法兰连接、沟槽连接等。

**镀锌管道连接要求：**
- 螺纹或沟槽连接时：镀锌层破坏的表面及外露螺纹部分应进行**防腐处理**
- 螺纹连接：螺纹清洁规整，外露螺纹应为 **2~3扣**，不应有外露填料
- 焊接和法兰焊接连接时：对焊缝及热影响区表面应进行**二次镀锌或防腐处理**

**钢管焊接要求：**
- 宜采用**机械方法切割**，不得采用氧乙炔火焰切割
- 焊口表面：无烧穿、裂纹、结瘤、夹渣和气孔等缺陷
- 焊缝：平整、饱满，焊波均匀一致

**法兰连接要求：**
- 法兰面与管道中心线垂直、同心
- 连接螺栓长度一致，**螺母在同一侧**，均匀拧紧
- 紧固后螺母与螺栓端部平齐或略低于螺栓
- 法兰衬垫的材料、规格与厚度符合设计要求

**管道穿越要求：**

| 部位 | 要求 |
|------|------|
| 地下室/地下构筑物外墙 | 采取防水措施；有严格防水要求的，必须采用**柔性防水套管** |
| 穿越墙体或楼板处 | 设**钢制套管**，管道接口不得置于套管内 |
| 防火分区 | 采用**不燃材料**进行防火封堵 |
| 保温管道与套管四周缝隙 | 使用**不燃绝热材料**填塞紧密 |

**穿墙/穿楼板套管对比：**

| 管道类型 | 穿墙 | 穿楼板 |
|----------|------|--------|
| **风管** | 穿墙套管与墙体两侧平齐 | 套管底端与楼板底面平齐，顶端高出楼板面 **30mm** |
| **空调水管** | 钢制套管应与墙体饰面平齐 | 钢制套管与楼板底部平齐，上部高出楼层地面 **20~50mm** |
| **建筑管道** | 两端与饰面相平 | 楼板内套管：顶部高出装饰地面 **20mm**（普通）/ **50mm**（卫生间及厨房），底部与楼板底面平齐 |

**支吊架要求：**
- 固定在建筑结构上的管道支吊架，不得影响结构体的安全
- **无热位移**管道吊架：吊杆**垂直安装**
- **有热位移**管道吊架：吊杆向热膨胀（或冷收缩）的**反方向偏移**安装
- 竖井内立管：按每两层或三层设置**滑动支架**

**管道与支吊架衬垫要求：**
- 冷（热）水管道与支吊架之间应设置**衬垫**
- 衬垫承压强度应满足管道全重
- 采用**不燃与难燃硬质绝热材料**或**经防腐处理的木衬垫**
- 衬垫厚度 = 绝热层厚度，宽度 ≥ 支吊架支承面宽度
- 衬垫一般采用**下方上圆**方式，表面平整，接合面空隙应填实，用抱箍固定于型钢支架上

### 1.2 冷凝水管道安装技术要求

| 项目 | 要求 |
|------|------|
| 干管坡度 | ≥ **8‰**（设计无要求时） |
| 支管坡度 | ≥ **1%**（设计无要求时） |
| 坡向 | 坡向出水口 |
| 与设备连接 | 采用**软接**，软管牢固、顺直、无扭曲，保持畅通 |
| 存水弯 | 按设计要求安装 |
| 排水去向 | **不得直接接入生活污水管道**，且不应接入雨水管道 |

> **真题（2016、2022案例）：** 冷凝水管道坡度是高频考点。

## 2. 水系统阀部件安装

### 2.1 阀门安装

**阀门试验要求：**

| 项目 | 条件 | 要求 |
|------|------|------|
| 外观检查 | 所有阀门 | 安装前进行 |
| 壳体强度和阀瓣密封性能试验 | 工作压力 > **1.0MPa** 且在主干管上起切断作用 / 系统冷热水运行转换调节功能的阀门和止回阀 | 必须做 |
| 其他阀门 | 不满足上述条件 | 可不单独进行试验 |

**阀门试验参数：**

| 试验类型 | 试验压力 | 持续时间 | 判定标准 |
|----------|----------|----------|----------|
| **壳体强度试验** | 常温条件下公称压力的 **1.5倍** | ≥ **5min** | 壳体、填料无渗漏 |
| **严密性试验** | 公称压力的 **1.1倍** | 按规范要求 | 压力不变，泄漏量符合要求 |

## 3. 制冷剂管道、管件安装

**管道弯曲要求：**
| 项目 | 要求 |
|------|------|
| 弯管弯曲半径 | ≥ **3.5倍**管道直径 |
| 最大外径与最小外径之差 | ≤ **0.08倍**管道直径 |
| 禁止使用 | 焊接弯管及皱褶弯管 |

**分支管要求：**
- 按介质流向弯成 **90°** 与主管连接
- 不宜使用弯曲半径 < **1.5倍**管道直径的压制弯管

**铜管焊接连接：**
| 连接方式 | 要求 |
|----------|------|
| 承插钎焊焊接 | 承口应**迎着介质流动方向** |
| 套管钎焊焊接 | 插接深度符合规定 |
| 对接焊接 | 管道内壁齐平，错边量 ≤ **0.1倍壁厚**，且 ≤ **1mm** |

**制冷剂阀门试验：**

| 试验类型 | 试验压力 | 持续时间 |
|----------|----------|----------|
| 强度试验 | 公称压力的 **1.5倍** | ≥ **5min** |
| 严密性试验 | 公称压力的 **1.1倍** | **30s**，不漏为合格 |

## 4. 水系统管道强度、严密性试验及管道冲洗

### 4.1 冷冻、冷却水管道水压试验

**口诀：** 小乘大加（小陈一大家）

| 管道类别 | 条件 | 强度试验压力 | 严密性试验压力 |
|----------|------|-------------|---------------|
| **金属管道及金属复合管道** | 工作压力 ≤ 1.0MPa | **1.5倍**工作压力，且 ≥ **0.6MPa** | 设计工作压力 |
| | 工作压力 > 1.0MPa | 工作压力 **+ 0.5MPa** | 设计工作压力 |
| **各类耐压塑料管（冷水）** | — | **1.5倍**工作压力，且 ≥ **0.9MPa** | **1.15倍**设计工作压力 |

**试验方法：**
1. 系统最低点压力升至试验压力
2. **稳压10min**，压力下降 ≤ **0.02MPa**
3. 将系统压力降至工作压力
4. 外观检查无渗漏为合格

> 与建筑金属给水管试验方法相同。

### 4.2 空调水系统管路冲洗

- 时机：水压试验合格后，与制冷机组、空调设备**连接前**进行
- 合格条件：目测排出口的水色和透明度与入口**相近**，且**无可见杂物**
- 系统继续运行 **2h以上**，水质保持稳定后，方可与设备贯通

### 4.3 冷凝水管道通水试验

- 安装完毕后进行**通水试验**
- 合格标准：**不渗漏、排水畅通**

### 4.4 制冷剂管道试验要求

**记忆口诀：** **气枪真漏**（气密性试验、强度试验、真空试验、检漏试验）

制冷剂管道系统安装完毕，外观检查合格后，应进行：
1. **强度试验**
2. **气密性试验**
3. **真空试验**
4. **充注制冷剂检漏试验**

**吹扫排污：**
- 采用压力为 **0.5~0.6MPa**（表压）的干燥压缩空气或氮气
- 以**白色（布）标识靶**检查 **5min**，目测无污物为合格
- 系统吹扫干净后，阀芯应拆下清洗干净

### 4.5 试验综合对比表

| 序号 | 管道类别 | 试验类型 | 关键参数 |
|------|----------|----------|----------|
| 1 | 冷凝水排水管 | 坡度检查 | 干管 ≥ 8‰，支管 ≥ 1% |
| 2 | 冷（热）水、冷却水、蓄能（金属管道） | 强度试验 | P工≤1.0：1.5P工且≥0.6MPa；P工>1.0：P工+0.5MPa |
| 3 | 各类耐压塑料管 | 强度试验 | 1.5P工，且 ≥ 0.9MPa |
| | | 严密性试验 | 1.15P设工 |
| 4 | 空调水冲洗 | 冲洗检验 | 目测水色/透明度与入口相近，无可见杂物 |
| 5 | 冷凝水系统 | 通水试验 | 不渗漏、排水畅通 |
| 6 | 制冷剂管道 | 综合试验 | 强度、气密性、真空、充注制冷剂检漏、吹扫排污 |

## 5. 管道绝热施工

**绝热分类：** 保温、保冷、加热保护三种类型

**施工时机：** 管路系统强度与严密性试验合格和**防腐处理结束后**进行

**绝热材料进场复验性能（口诀：主导洗米）：**
- 导热系数或热阻
- 密度
- 吸水率

**材料要求：**
- 绝热层、绝热防潮层和保护层：采用**不燃或难燃材料**
- 材质、密度、规格与厚度应符合设计要求

**绝热层铺设要求：**

| 材料类型 | 固定方式 | 特殊要求 |
|----------|----------|----------|
| 硬质或半硬质绝热管壳 | 镀锌铁丝或抗腐织带捆扎 | 厚度 > 100mm 时分层铺设 |
| 橡塑管壳 | 粘接 | — |

**弯头处理：**
- 采用定型弯头管壳或直管壳加工成**虾米腰块**
- 每个弯头 ≥ **3块**
- 确保管壳与管壁紧密结合、美观平滑

**橡塑绝热材料施工：**
- 纵、横向**接缝应错开**，缝间无孔隙
- 与管道表面贴合紧密，无气泡
- 多重绝热层：层间**拼接缝应错开**

**玻璃棉或岩棉管壳保温：**
- 管壳规格与管道外径匹配
- 纵向接缝**错开**
- 采用金属丝、粘结带等捆扎，间距 **300~350mm**
- 每节至少捆扎**两道**

## 6. 金属保护壳施工

**施工顺序：** 管道**由下而上、由低到高**

**施工方法：** 咬口、铆接、搭接

**纵向接缝施工要求：**

| 结构类型 | 固定方式 | 间距 |
|----------|----------|------|
| **保温**结构 | 自攻螺钉或抽芯铆钉固定 | **150~200mm**，均匀一致，不得刺破防潮层 |
| **保冷**结构 | 镀锌铁丝或胶带等抱箍固定 | **250~300mm**，均匀一致 |

**圆形保护壳：**
- 贴紧绝热层
- 环向接缝**顺水流方向**设置搭接，有凸筋加强
- 搭接尺寸 **20~25mm**

**水平管道：** 纵向接缝设于管道的**侧下方**
**立管：** 环向接缝**必须上搭下**

## 典型例题

### 例题 1（2025单选题）

**题目：** 下列空调系统管道中，需要进行真空试验的是（ ）。

A. 冷冻水管道
B. 冷却水管道
C. 制冷剂管道
D. 冷凝水管道

**答案：** C

**解析：** 制冷剂管道系统安装完毕，外观检查合格后，应进行系统管路强度、气密性试验、真空试验和充注制冷剂检漏试验。

---

### 例题 2（2019案例节选）

**背景：** 空调供水管及开式冷却水系统施工完成后，项目部进行了强度和严密性试验，施工图中注明空调供水管的工作压力为 **1.3MPa**，开式冷却水系统工作压力为 **0.9MPa**。

**问题：** 计算空调供水管和开式冷却水的试验压力。试验压力最低不应小于多少 MPa？

**参考答案：**
- 空调供水管试验压力（P工 > 1.0MPa）：1.3 + 0.5 = **1.8MPa**
- 开式冷却水的试验压力（P工 ≤ 1.0MPa）：0.9 × 1.5 = **1.35MPa**（≥ 0.6MPa，满足要求）

---

### 例题 3（2025案例节选）

**问题：** 补检的闸阀应做哪些试验？并说明试验的压力值？

**参考答案：**
1. 闸阀应做：**壳体强度**和**阀瓣密封性能**试验
2. 壳体强度试验压力：常温条件下公称压力的 **1.5倍**
3. 严密性试验压力：公称压力的 **1.1倍**

---

### 例题 4（2021案例节选）

**问题：** 在制冷剂灌注前，制冷剂管道需要进行哪些试验？

**参考答案：**
制冷剂管道安装完毕，检查合格后，应进行系统管路：
1. **强度试验**
2. **气密性试验**
3. **真空试验**
4. **充注制冷剂检漏试验**

## 记忆口诀汇总

| 口诀 | 对应内容 |
|------|----------|
| **小乘大加（小陈一大家）** | 水压试验压力：P工≤1.0 时 ×1.5（且≥0.6）；P工>1.0 时 +0.5 |
| **气枪真漏** | 制冷剂管道试验：**气**密性、**强**度、**真**空、**漏**（检漏） |
| **主导洗米** | 绝热材料复验：**导**热系数、**主**（阻 - 热阻）、**洗**（吸水率）、**米**（密度） |
