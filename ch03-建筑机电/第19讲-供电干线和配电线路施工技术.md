# 3.2 供电干线和配电线路施工技术

> [!summary] 本节导览
> 本节覆盖建筑电气工程中干线及配电线路的五大施工环节：**母线槽**（★★★★★高频）、**梯架（槽盒）**、**导管**（★★★★）、**导管内穿线与槽盒内导线敷设**、**室内电缆敷设**。重点在安装连接要求、接地要求、弯曲半径、绝缘测试等细节，常以选择题和案例题形式考查。

---

## 1. 母线槽施工技术 ★★★★★

> 母线槽是由金属板（钢板或铝板）为保护外壳、导电排、绝缘材料及有关附件组成的母线系统。

### 1.1 检查验收

| 检查项目 | 要求 |
|---------|------|
| 外观 | 外壳无明显变形，附件齐全，螺栓搭接面平整、镀层完整，无起皮和麻面 |
| 绝缘电阻 | 用 **1kV 兆欧表** 测量每节母线槽，**绝缘电阻值 ≥ 20MΩ** |
| 防护等级 | 有防护等级要求的母线槽应检查产品及附件的防护等级，**连接部件防护等级应与本体一致** |
| 防火型 | 应有 **防火等级和燃烧报告** |

### 1.2 支架安装要求

| 项目 | 要求 |
|------|------|
| 防晃支架 | 采用金属吊架固定时，应设有 **防晃支架** |
| 抗震支架 | 重力 **≥ 150N/m**（≈ 每米 15kg）的母线槽应进行抗震设防，设置 **抗震支架** |
| 水平敷设支架间距 | 每节不少于 **1个支架**，距转角 **0.4~0.6m** 处应设支架 |
| 支架固定点禁忌 | 不应设置在母线槽的**连接处或分接单元处** |
| 圆钢吊架直径（配电） | **≥ 8mm** |
| 圆钢吊架直径（照明） | **≥ 6mm** |
> **记忆：** 配电8照明6，配电粗照明细

### 1.3 母线槽安装连接要求 ★★★★

#### 平直度与偏差

| 类型 | 水平度/垂直度 | 全长允许偏差 |
|------|-------------|-------------|
| **配电母线槽** | ≤ **1.5‰** | ≤ **20mm** |
| **照明母线槽**（水平） | — | 全长 ≤ **5mm** |
| **照明母线槽**（垂直） | — | 全长 ≤ **10mm** |
| **母线槽与外壳同心度** | ≤ **5mm** | — |

#### 交叉穿越与变形缝

- **与水管的交叉**：不宜平行安装在水管正下方；交叉时宜从水管**上方**穿越；从下方穿越时设 **防水挡板**
- **变形缝**：跨越建筑物变形缝时，应设 **补偿装置**
- **伸缩节**：直线敷设长度超过 **80m**，每 **50~60m** 设伸缩节

#### 楼板/墙体穿越

| 项目 | 要求 |
|------|------|
| 连接处位置 | 不应设置在穿越楼板或墙体处 |
| 垂直穿越楼板 | 设置 **弹簧支架**，孔洞四周设 **≥ 50mm 防水台**，并做 **防火封堵** |
| 连接后状态 | 不应受到额外应力 |
| 紧固工具 | **力矩扳手** |
| 搭接螺栓紧固力矩 | 符合产品技术文件或规范标准要求 |
| 接触电阻 | **< 0.1Ω** |

#### 接地要求

- 金属外壳间**连接可靠**
- 母线槽全长与接地保护导体连接 **≥ 2处**
- 分支母线槽金属外壳末端应与接地保护导体连接

### 1.4 母线槽通电前检查

| 项目 | 要求 |
|------|------|
| 绝缘电阻测试和耐压试验 | 应合格，**母线槽绝缘电阻 ≥ 0.5MΩ**（对比：每节母线槽 ≥ 20MΩ） |
| 分接单元插接（插入） | **接地触头先于**相线触头接触，触头连接紧密 |
| 分接单元退出 | 接地触头**后于**相线触头脱开，开关设备处于断路状态 |

> **记忆：** 插接时「**地先相后**」——接地触头始终保持优先接触、最后脱离，确保安全。

> **【真题 2020 多选】** 关于建筑电气工程母线槽安装的说法，正确的有（ABDE）
> - A. 绝缘测试应在母线槽安装前后分别进行 ✅
> - B. 照明母线槽的垂直偏差不应大于10mm ✅
> - C. 母线槽接口穿越楼板处应设置补偿装置 ❌（连接处不应设置在穿越楼板处）
> - D. 母线槽连接部件应与本体防护等级一致 ✅
> - E. 母线槽连接处的接触电阻应小于0.1Ω ✅
>
> 施工程序：检查验收→支架安装→单节母线槽绝缘测试→母线槽安装→插接单元安装→通电前绝缘测试→送电验收

## 2. 梯架（槽盒）施工技术 ★★★

> - **电缆梯架**：带有横向支撑构件的电缆支撑物，**散热好，防护差**
> - **电缆槽盒**：完全封闭的底座+可移动盖子，将绝缘导线、电缆、软电线完全包围

### 2.1 检查验收

| 材质 | 要求 |
|------|------|
| 钢制 | 涂层完整、无锈蚀；配件齐全，表面光滑、不变形 |
| 铝合金 | 涂层完整、无破损，无扭曲变形、压扁或表面划伤 |
| 塑料 | 无破损；对阻燃性能有异议时抽样送检 |

### 2.2 支架安装要求

| 项目 | 要求 |
|------|------|
| 建筑钢结构构件 | **不得熔焊支架**，且**不得热加工开孔** |
| 水平安装支架间距 | **1.5~3.0m** |
| 垂直安装支架间距 | **≤ 2m** |
| 金属吊架圆钢直径 | **≥ 8mm**，并设防晃支架 |
| 分支处/端部固定支架 | **0.3~0.5m** 处设置 |
| 抗震支架 | 重力 **≥ 150N/m** 的梯架（槽盒）应设置 |

### 2.3 金属梯架（槽盒）安装要求

- 连接螺栓、与支架的固定螺栓应采用 **方颈螺栓**，螺母位于梯架（槽盒）**外侧**（避免螺栓头损伤电缆）
- 转弯、分支处宜采用**专用连接配件**
- 穿越电气竖井楼板处和穿越不同防火区时，应有 **防火隔离** 措施
- 穿越楼板处的预留洞周边应砌筑 **防水台**

### 2.4 金属梯架（槽盒）接地要求 ★★

| 条件 | 要求 |
|------|------|
| 全长 **≤ 30m** | 与保护接地导体连接 **≥ 2处** |
| 全长 **> 30m** | 每隔 **20~30m** 增加一个接地连接点，**终端和起始端均应接地** |
| **非镀锌**金属梯架（槽盒）连接 | 两端应**跨接保护联结导体**，截面符合设计要求 |
| **镀锌**金属梯架（槽盒）连接（不跨接时） | 连接板每端 **≥ 2个** 有防松螺帽或防松垫圈的连接固定螺栓 |

> **记忆：** 30米分水岭——≤30m至少2处，>30m每20~30m加一处；非镀锌跨接，镀锌可不跨但螺栓要防松。

> **【真题 2022 多选】** 涉及梯架（槽盒）支架安装及接地内容

## 3. 导管施工技术 ★★★★

### 3.1 导管进场验收

（略——按常规验收流程）

### 3.2 支架安装要求（同梯架、槽盒）

| 项目 | 要求 |
|------|------|
| 金属吊架圆钢直径 | **≥ 8mm**，并设**防晃支架** |
| 箱（盒）/分支处/端部固定支架 | **0.3~0.5m** 处设置 |
| 抗震支架 | 内径 **≥ 60mm** 的导管应设置 |

> **【真题 2022 二建】** 涉及导管支架安装要求

### 3.3 金属导管敷设要求 ★★★

#### 焊接禁忌

| 导管类型 | 禁止做法 |
|----------|---------|
| 钢导管 | **不得对口熔焊连接** |
| 镀锌钢导管或壁厚 **≤ 2mm** 的钢导管 | **不得套管熔焊连接** |
| 镀锌钢导管、可弯曲金属导管、金属柔性导管 | **不得熔焊连接** |

#### 弯曲半径 ★★★★★

| 敷设方式 | 场景 | 弯曲半径 |
|---------|------|---------|
| **明配** | 一般情况 | ≥ 管外径 **6倍** |
| **明配** | 两个接线盒间只有一个弯曲 | ≥ 管外径 **4倍** |
| **暗配**（混凝土内） | — | ≥ 管外径 **6倍** |
| **暗配**（地下） | — | ≥ 管外径 **10倍** |

> **记忆：** 明6→4（一个弯），暗6→10（地下）；明配可更小（一个弯），地下必须更大

#### 其他敷设要求

| 项目 | 要求 |
|------|------|
| 暗配管表面埋设深度 | 与建筑物表面距离 **≥ 15mm** |
| 穿越防护密闭隔墙 | 设预埋套管，两端露出墙面 **30~50mm** |
| 穿越密闭穿墙套管 | 两侧设过线盒，并做好**封堵** |

### 3.4 金属导管接地要求 ★★★

| 导管类型 | 连接方式 | 接地要求 |
|----------|---------|---------|
| **非镀锌钢导管** | 螺纹连接 | 两端**焊接**保护联结导体，圆钢 **≥ φ6mm**，搭接长度为圆钢直径的 **6倍** |
| **镀锌钢导管** | 连接处 | 宜采用**专用接地卡**固定保护联结导体 |
| 可弯曲金属导管/金属柔性导管 | 连接处 | 宜采用**专用接地卡**固定保护联结导体 |

> 保护联结导体应为截面 **≥ 4mm²** 铜芯软导线（镀锌/可弯曲/柔性导管适用）

> **【真题 2023 案例二】** 涉及非镀锌钢导管焊接保护联结导体的计算

### 3.5 塑料导管敷设要求

- 墙体上剔槽埋设时，采用强度等级 **≥ M10** 的水泥砂浆抹面保护
- 砂浆厚度 **≥ 15mm**

### 3.6 柔性导管敷设要求 ★★★

| 场景 | 长度限制 |
|------|---------|
| **动力工程** | ≤ **0.8m** |
| **照明工程** | ≤ **1.2m** |

#### 连接要求

- 刚性导管 → 柔性导管 → 电气设备/器具，柔性导管与刚性导管/设备间连接应采用 **专用接头**
- 无专用接头时，可使用 **接线盒过渡连接**
- **金属柔性导管不应作为保护联结导体的接续导体**

> **【真题 2023 单选】** 关于柔性导管敷设的说法，正确的是（C）
> - A. 柔性导管的长度在动力工程中不宜大于0.9m ❌（应为0.8m）
> - B. 柔性导管的长度在照明工程中不宜大于1.3m ❌（应为1.2m）
> - C. 柔性导管与电气设备的连接应采用专用接头 ✅
> - D. 金属柔性导管可以作为保护导体的接续导体 ❌
>
> **【真题 2018 案例】** 涉及柔性导管长度

## 4. 导管内穿线和槽盒内导线敷设要求 ★★★

### 4.1 导管内穿线要求

| 项目 | 要求 |
|------|------|
| 管口保护 | 穿线前应装设 **护线口** |
| 接头位置 | **不得**设置在导管和槽盒内，应设在**专用接线盒（箱）或器具内**，且便于检修 |
| 同一交流回路 | 绝缘导线**不应**穿于不同金属导管内 |
| 不同回路/电压/交直流 | **不应**穿于同一导管内 |

### 4.2 槽盒内导线敷设要求

| 项目 | 要求 |
|------|------|
| 同一交流回路 | 不应敷设于不同的金属槽盒内 |
| 绝缘导线 + 电缆 | 同一槽盒内**不宜同时敷设** |
| 同一路径无抗干扰要求 | 可敷设于同一槽盒内 |
| 导线总截面积 | 不超过槽盒内截面积的 **40%** |

> **【真题 2015 单选】** 涉及导管内穿线要求

## 5. 室内电缆敷设要求 ★★★★（新增）

### 5.1 电缆检查验收

- 型号、规格符合设计要求
- 外观无损伤，外观和密封状态有怀疑时进行**受潮判断**
- 外护套有导电层的电缆，应进行外护套**绝缘电阻测试**并合格

### 5.2 电缆敷设前检查

- 电缆沟、隧道、排管、井、交叉跨越管道及直埋电缆沟的**深度、宽度、弯曲半径**等符合设计要求
- 电缆放线架放置平稳，钢轴的**强度和长度**应与电缆盘重量和宽度相适应
- 按设计和实际路径**计算每根电缆的长度，合理安排**每盘电缆，减少电缆接头
- 中间接头位置**避免**设置在倾斜处、转弯处、交叉路口、与其他管线交叉处

> **【真题 2018 案例二】** 涉及电缆中间接头位置选择

### 5.3 电缆敷设要求

| 项目 | 要求 |
|------|------|
| 引出方向 | 电缆从盘的**上端引出** |
| 机械损伤 | 不得有铠装压扁、电缆绞拧、护层折裂 |
| 机械敷设速度 | **≤ 15m/min**，大截面电缆在牵引头与牵引钢缆间装设**防捻器** |
| 并联电力电缆 | 额定电压、型号、规格和长度**应相同** |
| 并列敷设接头 | 接头位置宜**相互错开** |
| 电缆明敷接头 | 用**托板托置固定** |
| 共通道接头 | 宜用**防火隔板或防爆盒**隔离 |
| 终端头与接头附近 | 宜留有**备用长度** |
| 保护导管内径 | ≥ 电缆外径 **1.5倍** |

#### 交流单芯电缆特殊要求

- 交流单芯电缆或分相后的每相电缆 **不得单根穿于钢导管内**
- 固定用的夹具和支架**不应形成闭合磁路**

> **原理：** 单根导线的周围存在交变磁场，磁场会和钢管发生电磁感应，在钢管中产生**涡流**，导致钢管发热引起火灾。

#### 防火封堵部位

电缆出入下列部位应采取防火封堵或密封措施：
- 电缆沟
- 电气竖井
- 建筑物
- 配电（控制）柜、台、箱处
- 管子管口处

### 5.4 电缆线路试验（新增）★★★★

#### 绝缘电阻测量

| 测试对象 | 兆欧表额定电压 |
|---------|---------------|
| 电缆绝缘测量（基准） | **2500V** |
| 6/10kV及以上电缆 | 也可用 **5000V** |
| 橡塑电缆外护套、内衬层 | **500V** |

> **记忆：** 电缆绝缘2500V为基准，高至5000V，外护套用500V低压表

- 橡塑电缆外护套、内衬层绝缘电阻 **≥ 0.5MΩ/km**
- 耐压试验前后的绝缘电阻测量应无明显变化

#### 交流耐压试验

| 电压等级 | 试验电压（对地/导体间） | 时间 |
|---------|----------------------|------|
| 低压 | 2倍额定电压 | 15min |
| 高压 | 1.7倍额定电压 | 1h |

> 频率范围：20~300Hz

#### 电缆主绝缘试验方法

| 电缆类型 | 试验方法 |
|---------|---------|
| **统包绝缘三芯电缆**（低压） | 分别对每一相进行，其他两相导体、金属屏蔽/金属套/铠装层一起接地 |
| **分相屏蔽三芯电缆/单芯电缆**（高压） | 可一相或多相同时进行，非被试相导体等一起接地 |

#### 特殊试验要求

| 场景 | 要求 |
|------|------|
| 单芯电缆主绝缘耐压（护层保护器侧） | 将护层过电压保护器**短接**，使该端电缆金属屏蔽/金属套**临时接地** |
| 0.6/1kV 电缆线路 | 用 **2500V 兆欧表** 测量导体对地绝缘电阻**代替耐压试验**，试验 **1min** |
| 交流单芯电缆外护套 | 应进行**直流耐压试验** |
| 电缆线路两端相位 | 应与电网相位**一致** |
