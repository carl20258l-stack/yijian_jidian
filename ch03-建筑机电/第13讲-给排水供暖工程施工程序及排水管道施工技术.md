### 1.2 各系统施工程序对比表

#### 核心规律

| 维度 | 室内 | 室外 |
|:---:|:----:|:----:|
| 起点 | 预留、预埋 → 测绘放线 | 测量放线 → 管沟、井池开挖 |
| 支架 | 支吊架制作安装 | 支架制作安装（或垫层施工） |
| 试验 | 承压→水压试验 / 非承压→灌水试验 | 同室内 |
| 终点 | 通水/通球试验 | 管沟回填 |

> 记忆：
> - 室内 → **支架制作** ┃ 室外 → **管沟、井池开挖 + 回填**
> - 承压管道（给水、热水、供暖）→ **压力、通水试验**
> - 非承压管道（排水）→ **灌水、通水、通球试验**

#### 9 大系统施工程序明细

**【1】室内给水系统**
预留、预埋 → 管道测绘放线 → 管道元件检验 → 管道支吊架制作安装 → 管道加工预制 → 给水设备安装 → 管道及配件安装 → **系统水压试验** → 防腐绝热 → **系统通水试验** → 系统冲洗、消毒

**【2】室内排水系统**
预留、预埋 → 管道测绘放线 → 管道元件检验 → 管道支吊架制作安装 → 管道加工预制 → 排水泵等设备安装 → 管道及配件安装 → **系统灌水试验** → 防腐 → **系统通球试验**

**【3】室内供暖系统**
预留、预埋 → 管道测绘放线 → 管道元件检验 → 管道支吊架制作安装 → 管道加工预制 → 供暖设备安装 → 管道及配件安装 → 散热器及附件安装 → **系统水压试验** → 防腐绝热 → 系统冲洗 → **调试和试运行**

**【4】室外给水管网**
测量放线 → 管沟、井池开挖施工 → 管道支架制作安装（或垫层施工） → 管道预制 → 管道安装 → **系统水压试验** → 防腐绝热 → 系统冲洗、消毒 → 管沟回填

**【5】室外排水管网**
测量放线 → 管沟、井池施工 → 管道元件检验 → 管道支架制作安装（或垫层施工） → 管道预制 → 管道安装 → **系统严密性试验** → 防腐 → **系统通水试验** → 管沟回填

**【6】室外供热管网**
测量放线 → 管沟、井池开挖施工 → 管道支架制作（或垫层施工） → 管道预制 → 管道安装 → **系统水压试验** → 防腐绝热 → 系统冲洗 → **试运行和调试** → 管沟隐蔽

**【7】建筑饮用水供应系统**
预留、预埋 → 管道测绘放线 → 管道元件检验 → 管道支吊架制作安装 → 管道预制 → 水处理设备及控制设施安装 → 管道及配件安装 → **系统水压试验** → 防腐绝热 → 系统清洗、消毒 → **调试和试运行**

**【8】建筑中水系统给水管道**
管道测绘放线 → 管道元件检验 → 管道支吊架制作安装 → 管道预制 → 水处理设备及控制设施安装 → 管道及配件安装 → **系统水压试验** → 防腐 → 系统清洗 → **调试和试运行**

> 注意：中水系统 **无"预留、预埋"** 步骤，直接从测绘放线开始

**【9】卫生器具施工程序**
开箱检查 → 卫生器具安装 → 给水配件安装 → 排水管道安装 → **满水、通水试验**

> 记忆：**开箱→装具→配件→排水→试验**

#### 【真题】2021 单选

**题目：** 室内排水管道的施工程序中，防腐的紧后工序是（ ）。

A. 水压试验
B. 通水试验
C. 灌水试验
D. 通球试验

**答案：** D

**解析：** 室内排水工程施工程序：预留、预埋 → 管道测绘放线 → 管道元件检验 → 管道支吊架制作安装 → 管道加工预制 → 排水泵等设备安装 → 管道及配件安装 → 系统灌水试验 → 防腐 → **系统通球试验**

## 考点 2：建筑排水管道施工技术（★）

### 2.1 排水系统管道常用管材

#### 管材选用表

| 序号 | 场景 | 常用管材 |
|:---:|:----|:--------|
| 1 | 室内生活排水管道 | 建筑排水**塑料管**、柔性接口机制排水**铸铁管**及相应管件 |
| | 通气管 | 宜与排水管管材一致 |
| | 连续排水温度 > 40℃ | **金属排水管**或**耐热塑料排水管** |
| | 压力排水管道 | 耐压塑料管、金属管或钢塑复合管 |
| 2 | 雨水管道（一般） | 塑料管、铸铁管、镀锌钢管或混凝土管等 |
| | 虹吸雨水悬吊管道 | **HDPE 塑料管**、铸铁管或不锈钢管 |
| | 易受振动的雨水管道 | 钢管 |
| 3 | 高层建筑重力流雨水系统 | 镀锌焊接钢管 |
| | 超高层（>100m）重力流雨水系统 | 镀锌无缝钢管、球墨铸铁管 |
| | 高层/超高层虹吸式雨水系统 | HDPE 管、不锈钢管、衬塑钢管、镀锌钢管、铸铁管 |
| | （虹吸式管道要求） | 除承受正压外，还应能承受**负压** |

> 记忆：**高温用金属/耐热塑，压力用耐压/金属，虹吸用 HDPE**

#### 连接方式

| 连接方式 | 适用管材 | 特点 |
|:--------:|:--------:|:----:|
| **粘接连接** | 硬聚氯乙烯（PVC-U）室内排水管道 | 采用聚氯乙烯胶粘剂；有插入式粘接及搭接式粘接两种形式；胶粘剂由管材生产企业配套供给 |
| **承插连接** | 排水铸铁管及管件 | 分三类：**柔性连接**（橡胶圈密封）、**刚性连接**（石棉水泥或膨胀性填料密封，重要场合可用铅密封）、**法兰承插连接**（橡胶圈+螺栓紧固，多用于需快速安装和检修的场景） |

> 记忆：粘接连 PVC-U，承插连铸铁管

### 2.2 室内排水管道施工技术

#### 1) 管道支吊架安装

**金属排水管道固定件间距：**

- 横管 ≤ **2m**
- 立管 ≤ **3m**
- 楼层高度 ≤ 4m → 立管可安装 **1 个固定件**
- 立管底部弯管处 → 应设 **支墩** 或采取固定措施

**排水塑料管道支吊架最大间距：**

| 管径（mm） | 50 | 75 | 110 | 125 | 160 |
|:----------:|:--:|:--:|:---:|:---:|:---:|
| 立管 | 1.2 | 1.5 | 2.0 | 2.0 | 2.0 |
| 横管 | 0.5 | 0.75 | 1.10 | 1.30 | 1.6 |

> 记忆：立管间距 **1.2→1.5→2.0**，横管间距约 **管径 ÷ 100**（如 50mm→0.5m，75mm→0.75m，110mm→1.10m）

#### 2) 管道及配件安装

**排水坡度要求：**

> 室内生活污水管道按材质及管径设置排水坡度，**铸铁管的坡度应高于塑料管的坡度**

| 管道名称 | 50mm | 75mm | 100(110)mm | 125mm | 150(160)mm | 200mm |
|:--------:|:----:|:----:|:----------:|:----:|:----------:|:-----:|
| 生活污水铸铁管道（‰） | 25 | 15 | 12 | 10 | 7 | 5 |
| 生活污水塑料管道（‰） | 12 | 8 | 6 | 5 | 4 | — |
| 悬吊式雨水管道（‰） | | | **5**（不分管径） | | | |
| 埋地雨水管道（‰） | 20 | 15 | 8 | 6 | 5 | 4 |

> 记忆：塑料管道坡度 ≈ **铸铁管道的一半**（如 50mm：25‰→12‰，75mm：15‰→8‰）

**伸缩节：**
- 排水塑料管必须按设计要求及位置装设 **伸缩节**
- 设计无要求时，伸缩节间距 **不得大于 4m**
- 高层建筑中明装排水塑料管道应按设计要求设置 **阻火圈** 或 **防火套管**

**排水通气管：**

> 通气管 **不得** 与风道或烟道连接

| 场景 | 高度要求 |
|:----|:--------:|
| 一般要求 | 高出屋面 **300mm**，但必须大于 **最大积雪厚度** |
| 出口 4m 内有门、窗 | 高出门、窗顶 **600mm** 或引向无门、窗一侧 |
| 经常有人停留的平屋顶 | 高出屋面 **2m**，并应根据防雷要求设置 **防雷装置** |

> 记忆：通气管三组数字——**300mm**（基础）、**600mm**（有门窗）、**2m**（有人屋顶）
>
> 口诀：**三六二，门窗人要躲**

**间接排水要求：**
- 生活饮用水水箱（池）、中水箱（池）、雨水清水池的泄水管、溢流管
- **不得** 与污水管道直接连接 → 采用 **间接排水**
- 应留出 **不小于 100mm** 的隔断空间

#### 【真题】2012 二级多选

**题目：** 高层建筑排水通气管的安装要求有（ ）。

A. 通气管应高出斜顶屋面 0.3m
B. 在经常有人停留的平顶屋面，通气管应高出屋面 2m
C. 通气管应与风道或烟道连接
D. 通气管应按防雷要求设置防雷装置
E. 高出屋顶的通气管高度必须大于最大积雪高度

**答案：** B D E

**解析：**
- 排水通气管 **不得** 与风道或烟道连接 ❌（C 错）
- 通气管应高出屋面 300mm，但必须大于最大积雪高度（A 的"斜顶屋面"说法不准确，应为高出屋面 300mm，非针对斜顶）
- 出口 4m 内有门、窗 → 高出门、窗顶 600mm 或引向无门、窗一侧
- 经常有人停留的平屋顶 → 高出屋面 **2m** ✅，并应按防雷要求设置 **防雷装置** ✅
- 高出屋顶的通气管高度必须大于最大积雪高度 ✅

### 2.3 室外排水管道施工技术

| 序号 | 技术要求 | 要点 |
|:---:|:---------|:-----|
| 1 | 排水管道坡度 | 必须符合设计要求，**严禁无坡或倒坡** |
| 2 | 排水铸铁管水泥捻口 | 油麻填塞应密实，接口水泥应密实饱满；接口面凹入承口边缘且深度 **不得大于 2mm** |
| 3 | 承插接口安装方向 | 管道和管件的 **承口应与水流方向相反** |

> 记忆：承插接口 → **承口逆水流**（想象接水时承口朝上游接住来水）

## 考点对比总结

### 室内 vs 室外排水关键差异

| 对比项 | 室内排水 | 室外排水 |
|:------|:--------:|:--------:|
| 起点 | 预留、预埋 → 测绘放线 | 测量放线 → 管沟、井池施工 |
| 试验类型 | 灌水试验 + 通球试验 | 严密性试验 + 通水试验 |
| 终点 | 通球试验 | 管沟回填 |

### 各系统试验类型速查

| 系统 | 承压/非承压 | 主要试验 |
|:----|:----------:|:--------:|
| 室内给水 | 承压 | 水压试验 → 通水试验 → 冲洗、消毒 |
| 室内排水 | 非承压 | 灌水试验 → 通球试验 |
| 室内供暖 | 承压 | 水压试验 → 冲洗 → 调试和试运行 |
| 室外给水管网 | 承压 | 水压试验 → 冲洗、消毒 → 回填 |
| 室外排水管网 | 非承压 | 严密性试验 → 通水试验 → 回填 |
| 室外供热管网 | 承压 | 水压试验 → 冲洗 → 试运行和调试 → 隐蔽 |
| 建筑饮用水供应 | 承压 | 水压试验 → 清洗、消毒 → 调试和试运行 |
| 建筑中水系统 | 承压 | 水压试验 → 清洗 → 调试和试运行 |

> 规律：承压做 **水压**，非承压做 **灌水/严密性**；冲洗只出现在承压系统中
