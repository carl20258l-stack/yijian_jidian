### 一、建筑智能化系统的分部分项工程

| 分部工程 | 子分部工程 | 分项工程 |
|----------|------------|----------|
| **建筑智能化系统** | **信息网络系统** | 计算机网络设备安装，计算机网络软件安装，网络安全设备安装，网络安全软件安装，系统调试，试运行 |
| | **综合布线系统** | 梯架、托盘、槽盒和导管安装，线缆敷设，机柜、机架、配线架的安装，信息插座安装，链路或信道测试，软件安装，系统调试，试运行 |
| | **有线电视及卫星电视接收系统** | 梯架、托盘、槽盒和导管安装，线缆敷设，设备安装，软件安装，系统调试，试运行 |
| | **公共广播系统** | 梯架、托盘、槽盒和导管安装，线缆敷设，设备安装，软件安装，系统调试，试运行 |
| | **建筑设备监控系统** | 梯架、托盘、槽盒和导管安装，线缆敷设，传感器安装，执行器安装，控制器、箱安装，中央管理工作站和操作分站设备安装，软件安装，系统调试，试运行 |
| | **火灾自动报警系统** | 梯架、托盘、槽盒和导管安装，线缆敷设，探测器类设备安装，控制器类设备安装，其他设备安装，软件安装，系统调试，试运行 |
| | **安全技术防范系统** | 梯架、托盘、槽盒和导管安装，线缆敷设，设备安装，软件安装，系统调试，试运行 |
| | **机房工程** | 供配电系统，防雷与接地系统，空气调节系统，给水排水系统，综合布线系统，监控与安全防范系统，消防系统，室内装饰装修，电磁屏蔽，系统调试，试运行 |

> **记忆提示**：各子分部工程都有共通的**梯架托盘槽盒导管安装 → 线缆敷设 → 设备安装 → 软件安装 → 调试 → 试运行**，区别在于中间插入了各自特有的设备类型。

### 二、建筑智能化系统的施工程序

**一般施工程序（7 步）**：

```
施工图深化 → 设备、材料采购 → 管线敷设 → 设备、元件安装 → 系统调试 → 系统试运行 → 系统检测 → 系统验收
```

---

### 三、建筑智能化系统工程的组成

#### 1. 安全技术防范系统的组成

安全技术防范系统包括：

| 系统 | 说明 |
|------|------|
| 出入口控制系统 | 门禁、闸机等 |
| 入侵报警系统 | 红外探测、门窗磁等 |
| 视频监控系统 | 摄像头、录像机等 |
| 电子巡查系统 | 巡更点、巡更棒等 |
| 停车库（场）管理系统 | 车牌识别、道闸等 |
| 以防爆安全检查系统为代表的特殊子系统 | 安检机、安检门等 |

> **口诀**：出（出入口）侵（入侵）视（视频）巡（巡查）管（停车管理）防（防爆）

#### 2. 建筑设备监控系统的组成

建筑设备自动监控系统主要由以下部分组成：

- **中央工作站计算机**
- **外围设备**
- **现场控制器**
- **输入和输出设备**
- **相应的系统软件和应用软件**

---

#### 3. 主要输入设备（传感器）

| 类别 | 传感器类型 | 常见型式 / 说明 |
|------|------------|-----------------|
| **电量传感器** | 电压、电流、频率、有功功率、功率因数传感器 | 监测电力参数 |
| **非电量传感器** | 温度传感器 | 风管型、水管型；由传感元件和变送器组成，以热电阻或热电偶作为传感元件，有 1kΩ 镍电阻、1kΩ 和 100Ω 铂电阻等类型 |
| | 湿度传感器 | 氯化锂湿度传感器、碳湿敏元件、氧化铝湿度计、陶瓷湿度传感器 |
| | 压力、压差传感器 | 电容式压差传感器、液体压差传感器、薄膜型液体压力传感器 |
| | 流量传感器 | 叶片式、量芯式、热线式、热膜式、卡门涡旋式 |

> **口诀（湿度传感器）**：逃离绿潭（氯化锂、碳湿敏、氧化铝湿度计、陶瓷湿度传感器）
> **口诀（流量传感器）**：限量热卡片（叶片式、量芯式、热线式、热膜式、卡门涡旋式）

**压差开关**：随着空气压差引起开关动作的装置。一般压差范围 **20~4000Pa**。
> **重要应用**：压差开关可用于监视过滤网阻力状态的监测。

---

#### 4. 主要输出设备

| 设备 | 组成 | 工作原理 / 特点 |
|------|------|----------------|
| **电磁阀** | 电磁部件（铁芯、线圈）+ 阀体 | 利用电磁力带动阀塞来控制阀门打开与关闭。有**直动式**和**先导式**两种 |
| **电动调节阀** | 电动执行机构 + 阀体 | 将电信号转换为阀门的开度。输出方式：直行程（力-位移）、角行程（0~90°）、多转式（超过 360°），分别配合直线移动的调节阀、旋转的蝶阀、多转的调节阀 |
| **电动风阀** | 风门驱动器 + 蝶阀 | 调节风门以达到调节风管的**风量和风压**。技术参数：输出力矩、驱动速度、角度调整范围、驱动信号类型 |

> **记忆（电动风阀技术参数）**：两度句号（角度调整范围、驱动速度 → 句号 → 力矩、信号类型）

### 四、典型例题

#### 【例题 · 单选】建筑智能化安全技术防范系统不包括（  ）。【2017 真题】

A. 入侵报警系统  
B. 视频监控系统  
C. 出入口控制系统  
D. 火灾自动报警系统

**答案**：D

**解析**：安全技术防范系统主要包括：出入口控制系统、入侵报警系统、视频监控系统、电子巡查系统、停车库（场）管理系统以及以防爆安全检查系统为代表的特殊子系统等。**火灾自动报警系统**是另一个独立的子分部工程，不属于安全技术防范系统。

---

#### 【例题 · 案例节选】【2019 真题】

**背景资料**：某安装公司承接一商业中心的建筑智能化工程的施工。工程包括：建筑设备监控系统，安全技术防范系统，公共广播系统，防雷与接地和机房工程。

**问题**：该智能化工程有多少个子分部工程？

**参考答案**：该智能化工程由**四个子分部工程**：

1. 建筑设备监控系统
2. 安全技术防范系统
3. 公共广播系统
4. 机房工程

> **注意**：防雷与接地属于**机房工程**的分项工程内容，不单独作为子分部工程。
