## 1. 电梯的分部分项工程

**表：电梯的分部分项工程划分**（14 单、17 单、21 多）

| 分部工程 | 子分部工程 | 分项工程 |
|---------|-----------|---------|
| 电梯工程 | 曳引式、强制式电梯 | 设备进场验收，土建交接检验，驱动主机，导轨，门系统，轿厢，对重，安全部件，悬挂装置，随行电缆，补偿装置，电气装置，整机安装验收 |
| 电梯工程 | 液压电梯 | 设备进场验收，土建交接检验，液压系统，导轨，门系统，轿厢，安全部件，随行电缆，电气装置，整机安装验收 |
| 电梯工程 | 自动扶梯、自动人行道 | 设备进场验收，土建交接检验，整机安装验收 |

## 2. 电梯的分类和组成

### 2.1 电梯的分类

#### （1）按用途分类

乘客电梯、载货电梯、客货电梯、病床电梯、住宅电梯、消防电梯、观光电梯、施工电梯等。

#### （2）按机械驱动方式分类

曳引式电梯、强制式电梯、液压电梯、齿轮齿条电梯。

#### （3）按运行速度分类

| 类别 | 速度范围 |
|------|---------|
| 低速电梯 | v ≤ 1.0 m/s |
| 中速电梯 | 1.0 m/s < v ≤ 2.5 m/s |
| 高速电梯 | 2.5 m/s < v ≤ 6.0 m/s |
| 超高速电梯 | v > 6.0 m/s |

### 2.2 电梯的组成

#### （1）曳引式电梯的组成

**四大组成部分**：机房、井道、轿厢、层站。

**八大系统功能划分**：

| 系统 | 说明 |
|------|------|
| 曳引系统 | 驱动电梯升降的核心 |
| 导向系统 | 引导轿厢沿导轨运行 |
| 轿厢系统 | 运载乘客/货物的空间 |
| 门系统 | 层门和轿厢门 |
| 重量平衡系统 | 对重平衡轿厢重量 |
| 驱动系统 | 提供动力 |
| 控制系统 | 运行逻辑控制 |
| 安全保护系统 | 保障运行安全 |

**记忆口诀**：平安夜，去捣空轿门
- **平** → 重量**平**衡系统
- **安** → **安**全保护系统
- **夜(曳)** → **曳**引系统
- **去(驱)** → **驱**动系统
- **捣(导)** → **导**向系统
- **空(控)** → **控**制系统
- **轿** → **轿**厢系统
- **门** → **门**系统

#### （2）液压电梯的组成

泵站及液压系统、导向系统、轿厢系统、门系统、电气控制系统、安全保护系统等。

## 3. 自动扶梯的分类和组成

### 3.1 自动扶梯的分类

| 类型 | 说明 |
|------|------|
| 链条式 | 驱动梯级的元件为链条（多数采用） |
| 齿条式 | 驱动梯级的元件为齿条 |

### 3.2 自动扶梯的主要部件

梯级、牵引链条及链轮、导轨系统、主传动系统（包括电动机、减速装置、制动器及中间传动环节等）、驱动主轴、张紧装置、扶手系统、上下盖板、梳齿板、扶梯骨架、安全装置、电气系统等。

> **特别注意**：张紧装置属于自动扶梯的独立部件，不属于**主传动系统**。（2025 年真题考点）

## 4. 电梯技术资料 / 电梯安装资料

> **出题思路**：区分**制造厂家**和**安装单位**各自应提供的资料。

### 4.1 电梯制造厂提供的资料

1. 制造许可证明文件
2. 电梯整机型式检验合格证书或报告书
3. 产品质量证明文件
4. 安全保护装置和主要部件的型式试验合格证书，包括：
   - 门锁装置
   - 限速器
   - 安全钳
   - 缓冲器
   - **含有电子元件的安全电路**
   - 轿厢上行超速保护装置
   - 驱动主机
   - 控制柜
   - 以及限速器和渐进安全钳的调试证书
5. 机房或井道布置图
6. 电气原理图
7. 安装使用维护说明书

> **限速器 → 安全钳 → 缓冲器 的联动逻辑**：
> - **限速器**：时刻监测电梯轿厢运行速度。当轿厢速度超过额定速度的 **115%** 时触发——发出信号切断电梯动力，同时制动器紧急制动，迫使轿厢减速停止。
> - **安全钳**：在限速器操纵下，当电梯速度超过限速器设定的限制速度，或悬挂绳发生断裂/松弛时，将轿厢紧急制停并夹持在导轨上。
> - **缓冲器**：避免万一电梯失控轿厢冲顶，对重缓冲器没有坚实基础保证可能起不到缓冲作用。

### 4.2 安装单位提供的资料

1. **安装许可证和安装告知书**——许可证范围需覆盖所施工电梯的相应参数
2. **审批手续齐全的施工方案**
3. **施工现场作业人员持有的特种设备作业证**

## 5. 电梯准用程序（22 单、24 多）

**三检制流程**：

```
自检（安装单位） → 厂检（制造单位） → 专检（监督检验）
```

- **第一步**：电梯安装单位自检试运行结束后
- **第二步**：由**制造单位**（而非安装单位）负责进行校验和调试
- **第三步**：检验和调试符合要求后，经**监督检验合格**，可以交付使用
- **第四步**：获得**准用许可**后，按规定办理交工验收手续

## 历年真题精选

### 【例题·单选 2016】

下列电梯安装工程文件中，应由电梯制造单位提供的是（ ）。

A. 电梯安装告知书
B. 电梯安装许可证
C. 电梯安装方案
D. 电梯维修说明书

**【答案】 D**

**【解析】** 安装单位提供以下安装资料：①安装许可证和安装告知书；②审批手续齐全的施工方案；③施工现场作业人员持有的特种设备作业证。选项 D 属于由电梯制造单位提供的文件。

C. 安装使用说明
D. 电梯安装方案

**【答案】 D**

### 【例题·单选 2025】

下列设备中，不属于自动扶梯主传动系统的是（ ）。

A. 电动机
B. 张紧装置
C. 制动器
D. 减速装置

**【答案】 B**

**【解析】** 自动扶梯主要部件有：梯级、牵引链条及链轮、导轨系统、**主传动系统**（包括电动机、减速装置、制动器及中间传动环节等）、驱动主轴、**张紧装置**、扶手系统、上下盖板、梳齿板、扶梯骨架、安全装置和电气系统等。张紧装置是独立部件，不属于主传动系统。
