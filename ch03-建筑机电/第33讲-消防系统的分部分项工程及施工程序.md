### 二、各系统分类与功能详解

#### 1. 消防给水及消火栓灭火系统

##### (1) 消防给水系统
由**消防水源、消防给水管网、消防水泵、消防水箱、稳压设施及消防水泵接合器**等设施组成，是为各类水灭火系统供水的基础设施。

| 组件 | 功能要点 |
|------|---------|
| **消防水源** | 向水灭火设施、车载或手抬等移动消防水泵、固定消防水泵等提供消防用水的水源；包括市政给水、消防水池、高位消防水池和天然水源等 |
| **消防水箱** | 经常保持消防水量和水压要求，满足扑救**初期**火灾用水量和水压 |
| **消防水泵接合器** | 利用消防车的接口，向建筑物内消防给水管道送水加压，扑救火灾 |

##### (2) 消火栓灭火系统
由**供水设施、消火栓、配水管网和阀门**等设施组成，是一种被广泛应用的固定式消防设施。

- **室外**消火栓灭火系统
- **室内**消火栓灭火系统

#### 2. 自动喷水灭火系统

由**洒水喷头、报警阀组、水流报警装置（水流指示器或压力开关）**等组件，以及**管道、供水设施**等组成。

| 分类 | 特点 | 说明 |
|------|------|------|
| **湿式系统** | 准工作状态时配水管道内**充满有压水** | 闭式系统，最常用 |
| **干式系统** | 准工作状态时配水管道内**充满有压气体** | 闭式系统，用于寒冷地区 |
| **预作用系统** | 准工作状态时配水管道内**不充水**；火灾时由火灾自动报警系统、充气管道上压力开关联锁控制**预作用装置**和启动消防水泵 | 闭式系统，兼具干湿优点 |
| **重复启闭预作用系统** | 能在扑灭火灾后**自动关阀**、复燃时**再次开阀**喷水 | 预作用系统的升级版 |
| **防护冷却系统** | 用于冷却防火卷帘、防火玻璃墙等**防火分隔设施** | 闭式系统 |
| **雨淋系统** | 由**开式洒水喷头、雨淋报警阀组**等组成；由火灾自动报警系统或传动管控制 | **开式系统** |
| **水幕系统** | 由开式洒水喷头或水幕喷头、雨淋报警阀组或感温雨淋报警阀等组成 | **开式系统**，用于防火分隔或防护冷却 |

> **关键辨析**：闭式系统（湿式/干式/预作用）vs 开式系统（雨淋/水幕）

#### 3. 水喷雾灭火系统
由**水源、供水设备、管道、雨淋报警阀（或电动控制阀、气动控制阀）、过滤器和水雾喷头**等组成，向保护对象喷射水雾进行灭火或防护冷却。

#### 4. 细水雾灭火系统
由**供水装置、过滤装置、控制阀、细水雾喷头等组件和供水管道**组成，能自动和人工启动并喷放细水雾进行灭火或控火的固定灭火系统。

- **按供水方式（驱动源类型）划分**：泵组式、瓶组式及其他形式

#### 5. 固定消防炮灭火系统
由固定消防炮和相关系统组件组成的固定灭火系统。

| 分类 | 灭火剂 | 主要组成 |
|------|--------|---------|
| **水炮系统** | 水 | 水源、消防泵组、管道、阀门、水炮、动力源和控制装置 |
| **泡沫炮系统** | 泡沫 | 水源、泡沫液罐、消防泵组、泡沫比例混合装置、管道、阀门、泡沫炮、动力源和控制装置 |
| **干粉炮系统** | 干粉 | 干粉罐、氮气瓶组、管道、阀门、干粉炮、动力源和控制装置 |

#### 6. 自动跟踪定位射流灭火系统
以水为射流介质，利用探测装置对初期火灾进行自动探测、跟踪、定位，并运用自动控制方式来实现射流灭火的固定灭火系统。

**主要组件**：灭火装置、探测装置、控制装置、水流指示器、模拟末端试水装置，以及管网、供水设施等。

| 分类 | 流量范围 | 射流方式 |
|------|----------|---------|
| **自动消防炮灭火系统** | 流量 > 16 L/s | — |
| **喷射型自动射流灭火系统** | 5 L/s ≤ 流量 ≤ 16 L/s | 喷射型 |
| **喷洒型自动射流灭火系统** | 5 L/s ≤ 流量 ≤ 16 L/s | 喷洒型 |

#### 7. 气体灭火系统
以气体为主要灭火介质的灭火系统。

| 分类依据 | 类别 |
|----------|------|
| **按灭火介质** | 二氧化碳灭火系统、卤代烷灭火系统、惰性气体灭火系统 |
| **按应用方式** | 全淹没灭火系统、局部应用灭火系统 |

#### 8. 泡沫灭火系统
主要由**泡沫消防输送泵、泡沫液储罐、泡沫比例混合器、泡沫产生装置、控制阀门及管道**等组成。

| 分类依据 | 类别 | 说明 |
|----------|------|------|
| **按发泡倍数** | 低倍数泡沫灭火系统 | 发泡倍数 < 20 |
| | 中倍数泡沫灭火系统 | 20 ≤ 发泡倍数 ≤ 200 |
| | 高倍数泡沫灭火系统 | 发泡倍数 > 200 |
| **按安装方式** | 固定式系统 | 固定泡沫消防水泵 + 泡沫比例混合器 + 泡沫产生器 + 管道 |
| | 半固定式系统 | 固定泡沫产生器 + 部分管道，消防车/机动消防泵 + 泡沫比例混合器用水带连接 |
| | 移动式系统 | 消防车/机动消防泵 + 泡沫比例混合器 + 泡沫枪/炮，用水带连接 |

#### 9. 干粉灭火系统（碳酸氢钠）
由于干粉供应源通过输送管道连接到固定的喷嘴上，通过喷嘴喷放干粉的灭火系统。适用于**易燃、可燃液体、可燃气体和电气设备**。

| 分类依据 | 类别 | 说明 |
|----------|------|------|
| **按应用方式** | 全淹没灭火系统 | 将干粉均匀充满**整个防护区** |
| | 局部应用灭火系统 | 将灭火剂直接喷放到**着火物上**或认为危险的区域 |
| **按系统保护情况** | 组合分配系统 | 用**一套**灭火剂贮存装置保护**两个及以上**防护区 |
| | 单元独立系统 | 用**一套**干粉储存装置保护**一个**防护区 |

#### 10. 防排烟系统（防烟系统 + 排烟系统的总称）

| 系统 | 方式 | 作用 | 组成 |
|------|------|------|------|
| **防烟系统** | 自然通风 | 防止烟气在楼梯间、前室、避难层(间)等空间内积聚 | — |
| | 机械加压送风 | 阻止火灾烟气侵入楼梯间、前室、避难层(间)等空间 | — |
| **排烟系统** | 自然排烟 | 利用火灾热烟气流的浮力和外部风压 | — |
| | 机械排烟 | 将房间、走道等空间的火灾烟气排至建筑物外 | 排烟阀(口)、排烟防火阀、排烟管道、排烟风机 |

#### 11. 火灾自动报警及消防联动控制系统

##### 火灾自动报警系统
由**触发器件、火灾探测器和火灾警报装置**等组成。

**触发器件包括**：火灾探测器（感温探测器、感烟探测器、感光探测器、气体探测器、图像型探测器及复合探测器等）和手动火灾报警按钮。

| 系统类型 | 功能 | 适用范围 |
|----------|------|---------|
| **区域报警系统** | 仅需报警，不需联动 | 小型场所 |
| **集中报警系统** | 报警且联动自动消防设备 | 中型建筑 |
| **控制中心报警系统** | 报警+联动+集中管理 | 大型建筑、超高层 |

## 3.6.2 消防工程施工程序

### 各系统施工程序对照表

| 序号 | 灭火系统 | 施工程序 | 要点/助记 |
|------|---------|---------|-----------|
| 1 | **消防水泵（或稳压泵）** | 基础验收 → 泵体安装 → 吸水管路安装 → 出水管路安装 → 单机调试 | **泵吸出** |
| 2 | **消火栓系统** | 干管安装 → 立管、支管安装 → 箱体稳固 → 附件安装 → 强度和严密性试验 → 冲洗 → 系统调试 | 先管道再箱体；先箱体再附件 |
| 3 | **自动喷水灭火系统** | 干管安装 → 报警阀安装(接通、切断、报警) → 立管安装 → 分层干、支管安装 → 喷洒头支管安装 → **管道试压** → **管道冲洗** → 减压装置安装 → 报警阀配件及其他组件安装 → 喷洒头安装 → 系统通水调试 | 试压→冲洗→减压→配件→喷头 |
| 4 | **水喷雾灭火系统** | 支吊架制作、安装 → 管道安装 → 管道冲洗 → 管道试压 → 吹扫 → 喷头安装 → 控制阀组部件安装 → 系统调试 | 先冲洗再试压再吹扫再喷头 |
| 5 | **细水雾灭火系统** | 储水储气瓶组安装 → 泵组及控制柜安装 → 管道试压、冲洗、吹扫 → 细水雾喷头安装 → 系统调试 | 高压氮气 |
| 6 | **消防水炮灭火系统** | 干管安装 → 立管安装 → 分层干、支管安装 → 管道试压 → 管道冲洗 → 消防水炮安装 → 动力源和控制装置安装 → 系统调试 | — |
| 7 | **自动跟踪定位射流灭火系统** | 干管安装 → 立管安装 → 分层干、支管安装 → 管道试压 → 管道冲洗 → 灭火装置及附件安装 → 动力源和探测、控制装置安装 → 系统调试 | — |
| 8 | **气体灭火系统** | 设备和组件安装 → 管道安装 → 管道试压 → 吹扫 → 系统调试 | **有吹扫无冲洗** |
| 9 | **泡沫灭火系统** | 设备和组件安装 → 管道安装 → 管道试压 → 吹扫 → 系统调试 | **有吹扫无冲洗** |
| 10 | **干粉灭火系统** | 设备和组件安装 → 管道安装 → 管道试压 → 吹扫 → 系统调试 | **有吹扫无冲洗** |
| 11 | **防排烟系统** | 支吊架制作、安装 → 风管制作、安装 → 风管强度及严密性试验 → 风机及阀部件安装 → 防排烟风口安装 → 单机试运行 → 系统调试 | — |
| 12 | **火灾自动报警及联动控制系统** | 线管敷设 → 线缆敷设 → 线缆连接 → 绝缘测试 → 设备安装 → 单机调试 → 系统调试 → 系统检测、验收 | 与智能建筑施工程序对比记忆 |

> **对比：建筑智能化系统的一般施工程序**
> 施工图深化 → 设备、材料采购 → 管线敷设 → 设备、元件安装 → 系统调试 → 系统试运行 → 系统检测 → 系统验收

### 施工程序分类对比

| 类别 | 包含系统 | 程序特征 |
|------|---------|---------|
| **水管路型**（先干管后支管，有试压+冲洗） | 消火栓系统、自喷系统、水炮系统、跟踪定位射流系统 | 干管安装 → 立管/支管安装 → 试压 → 冲洗 → 组件安装 → 调试 |
| **气体/干粉型**（设备组件先装，有吹扫无冲洗） | 气体灭火、泡沫灭火、干粉灭火 | 设备和组件安装 → 管道安装 → 试压 → **吹扫** → 调试 |
| **风管型**（支架→风管→风机→风口） | 防排烟系统 | 支吊架 → 风管制作安装 → 强度严密性试验 → 风机阀部件 → 风口 → 试运行 → 调试 |
| **电气型**（管线→设备→调试） | 火灾自动报警及联动控制系统 | 线管敷设 → 线缆敷设 → 绝缘测试 → 设备安装 → 单机调试 → 系统调试 → 检测验收 |

> **注意**：水喷雾灭火系统的施工程序比较特殊——**管道冲洗在管道试压之前**，这与大多数系统不同。

## 历年真题精讲

### 【2014年真题】

**题目**：在消火栓系统施工中，消火栓箱体稳固的紧后工序是（ ）。

A. 支管安装<br/>
B. 附件安装<br/>
C. 管道试压<br/>
D. 管道冲洗

**答案**：B

**解析**：消火栓系统施工程序：干管安装 → 立管、支管安装 → **箱体稳固 → 附件安装** → 强度和严密性试验 → 冲洗 → 系统调试。口诀：先管道再箱体，先箱体再附件。

### 【2018年真题】

**题目**：自动喷水灭火系统的施工程序中，管道试压的紧后工序是（ ）。

A. 喷洒头安装<br/>
B. 管道冲洗<br/>
C. 报警阀安装<br/>
D. 减压装置安装

**答案**：B

**解析**：自动喷水灭火系统施工程序：干管安装 → 报警阀安装 → 立管安装 → 分层干、支管安装 → 喷洒头支管安装 → **管道试压 → 管道冲洗** → 减压装置安装 → 报警阀配件及其他组件安装 → 喷洒头安装 → 系统通水调试。

### 【2020年真题】

**题目**：消防灭火系统施工中，不需要管道冲洗的是（ ）。

A. 消火栓灭火系统<br/>
B. 泡沫灭火系统<br/>
C. 水泡沫灭火系统<br/>
D. 高压细水雾灭火系统

**答案**：B

**解析**：泡沫灭火系统的施工程序是：设备和组件安装 → 管道安装 → 管道试压 → **吹扫** → 系统调试，有吹扫无冲洗。而消火栓系统和水喷雾系统均有冲洗工序。

### 【2024年真题】

**题目**：下列分项工程中，不属于气体灭火系统的是（ ）。

A. 动力气体容器的安装<br/>
B. 预制灭火系统的安装<br/>
C. 灭火剂储存装置安装<br/>
D. 灭火剂输送管道安装

**答案**：A

**解析**：动力气体容器属于**干粉灭火系统**，不属于气体灭火系统。气体灭火系统的分项工程包括：材料及系统组件进场检验，灭火剂储存装置的安装，选择阀及信号反馈装置的安装，阀驱动装置的安装，灭火剂输送管道的安装，喷嘴的安装，预制灭火系统的安装，控制组件的安装，系统调试，系统验收。

## 易混淆点辨析

| 易混点 | 区分要点 |
|--------|---------|
| **气体灭火 vs 干粉灭火**的分项工程 | 气体灭火有"灭火剂储存装置""选择阀及信号反馈装置""阀驱动装置""灭火剂输送管道""喷嘴""预制灭火系统"；干粉灭火有"干粉储罐""动力气体容器""输气管""启动瓶""报警器""控制盘" |
| **吹扫 vs 冲洗** | 气体/泡沫/干粉灭火系统管道安装后是**吹扫**（无水系统）；水系统（消火栓/自喷/水喷雾/水炮）管道安装后是**冲洗** |
| **水喷雾程序特殊** | 水喷雾是**先冲洗再试压**（支吊架→管道安装→**管道冲洗**→管道试压→吹扫→喷头安装），与大多数系统先试压后冲洗的顺序不同 |
| **雨淋系统**归属 | 雨淋系统是**自动喷水灭火系统**的一种（开式系统），但水喷雾系统使用的是**雨淋报警阀** |
| **防烟 vs 排烟** | 防烟：防止烟气进入安全区域（楼梯间/前室/避难层）——自然通风或机械加压送风；排烟：将火灾烟气排至室外（房间/走道）——自然排烟或机械排烟 |

## 记忆口诀与思维导图

### 施工程序口诀

- **消防水泵**：基础→泵体→吸水管→出水管→调试 → **泵吸出**（注：基础验收→泵体安装→吸水管→出水管→单机调试）
- **消火栓系统**：干管→立支管→箱体→附件→试压→冲洗→调试
- **自喷系统**：干管→报警阀→立管→分层干支管→喷头支管→**试压→冲洗**→减压装置→报警阀配件→喷头→通水调试
- **水喷雾**：支吊架→管道→**冲洗→试压→吹扫**→喷头→控制阀组→调试
- **气体/泡沫/干粉**：设备组件安装→管道安装→试压→**吹扫**→调试（无冲洗）
- **防排烟**：支吊架→风管制作安装→强度严密性试验→风机阀部件→风口→单机试运行→系统调试
- **火灾报警联动**：线管敷设→线缆敷设→线缆连接→绝缘测试→设备安装→单机调试→系统调试→系统检测验收

### 冲洗 vs 吹扫对照

| 系统 | 管道试验后处理 | 说明 |
|------|--------------|------|
| 消火栓系统 | ✅ 冲洗 | 水系统 |
| 自动喷水灭火系统 | ✅ 冲洗 | 水系统 |
| 水喷雾灭火系统 | ✅ 冲洗（注意：冲洗在试压前） | 水系统 |
| 细水雾灭火系统 | ✅ 冲洗+吹扫 | 水系统 |
| 消防水炮、定位射流系统 | ✅ 冲洗 | 水系统 |
| 气体灭火系统 | ❌ **吹扫**（无冲洗） | 气体介质 |
| 泡沫灭火系统 | ❌ **吹扫**（无冲洗） | 泡沫介质 |
| 干粉灭火系统 | ❌ **吹扫**（无冲洗） | 干粉介质 |
