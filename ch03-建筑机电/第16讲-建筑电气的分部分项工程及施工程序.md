# 3.2 建筑电气的分部分项工程及施工程序

> [!SUMMARY] 本节概览
> 本节介绍了建筑电气工程的分部分项划分（7个子分部）和各子系统施工程序。重点记忆各程序的关键工序顺序，尤其是变配电、供电干线和照明工程。防雷接地自下而上施工是易错点。

### 一、建筑电气的分部工程划分

| 分部工程 | 子分部工程 | 分项工程（需重点掌握） |
|----------|-----------|----------------------|
| **建筑电气** | **室外电气** | 箱式变电所安装，导管敷设，电缆敷设，管内穿线，电缆头制作、导线连接和线路绝缘测试，灯具安装，照明通电试运行，接地装置安装等 |
| | **变配电室** | 变压器安装，成套配电柜、控制柜和配电箱安装，母线槽安装，梯架安装，电缆敷设，电缆头制作、导线连接和线路绝缘测试，接地干线敷设等 |
| | **供电干线** | 母线槽安装，梯架安装，导管敷设，电缆敷设，管内穿线，电缆头制作、导线连接和线路绝缘测试，接地干线敷设等 |
| | **电气动力** | 配电箱（控制箱）安装，电动机检查接线，电气设备试验和试运行，梯架安装，导管敷设，电缆敷设，管内穿线和槽盒内敷线，电缆头制作、导线连接和线路绝缘测试等 |
| | **电气照明** | 配电箱安装，槽盒安装，导管敷设，电缆敷设，管内穿线和槽盒内敷线，电缆头制作、导线连接和线路绝缘测试，灯具安装，开关、插座、风扇安装，照明通电试运行等 |
| | **自备电源** | 柴油发电机组安装，UPS及EPS安装等 |
| | **防雷及接地装置** | 接地装置安装，防雷引下线及接闪器安装，等电位联结等 |

> [!TIP] 分项规律
> - **导管/电缆敷设 + 电缆头制作 + 绝缘测试** 几乎出现在每个子分部（室外电气/变配电室/供电干线/电气动力/电气照明），是建筑电气最通用的分项
> - **照明通电试运行**只出现在 **室外电气** 和 **电气照明**（涉及灯具的子分部）
> - **自备电源** 和 **防雷及接地装置** 各自独立，分项较少，专注各自功能

### 二、建筑电气工程施工程序

#### 1. 变配电工程施工程序

**（1）干式变压器施工程序**

```
开箱检查 → 二次搬运 → 本体安装 → 附件安装 → 交接试验 → 送电前检查 → 送电运行验收
```

> **记忆：二本复交** 🧠
>
> 开箱(检)查 → **二**次搬运 → **本**体安装 → 附件安装(谐音"复") → **交**接试验 → 送电前检查 → 送电运行验收

**（2）配电柜（开关柜）安装程序**

```
开箱检查 → 二次搬运 → 基础框架制作安装 → 柜体固定 → 母线连接 → 二次线路敷设连接 → 试验调整 → 送电运行验收
```

> **记忆：姑母二条** 🧠
>
> 基础框架(谐音"姑") → 柜体固定(谐音"母") → 母**二**线连接(母线之后是二次线路) → 试验调**条**(谐音)→ 送电运行验收
>
> 完整口诀：开箱 → 二搬 → **姑** → **母** → 母线连 → **二**次线路 → **调**整 → 验收

#### 2. 供电干线及室内配线施工程序

**（1）母线槽施工程序**

```
检查验收 → 支架安装 → 单节母线槽绝缘测试 → 母线槽安装 → 插接单元安装 → 通电前绝缘测试 → 送电验收
```

> 注意：绝缘测试出现两次——安装前对单节测试，安装后通电前再做一次整体测试 🔑
>
> 记忆：**检支单母插通送**

**（2）梯架（槽盒）施工程序**

```
测量定位 → 支架安装 → 梯架（槽盒）安装 → 接地线跨接
```

> 提示：有金属梯架/槽盒才需要接地线跨接环节
>
> **此程序无绝缘测试环节**（与导管/管内穿线不同）⚡

**（3）梯架（托盘）内电缆施工程序**

```
电缆检查 → 电缆搬运 → 电缆敷设 → 绝缘测试 → 挂标志 → 验收
```

> **记忆：检搬敷试挂验** 🧠

**（4）槽盒内配线施工程序**

```
选择导线 → 槽盒内敷设导线 → 导线连接 → 绝缘测试
```

> **对比记忆：** 槽盒配线（4步）< 梯架内电缆敷设（6步），少了检查、搬运、挂标志

**（5）导管施工程序**

```
测量定位 → 支架安装（明敷时） → 导管预制 → 导管安装 → 接地线跨接（金属导管时）
```

> 关键点：
> - **支架安装** 仅在 **明敷** 时需要（暗敷埋入结构层，无需支架）
> - **接地线跨接** 仅在 **金属导管** 时需要（PVC导管绝缘，无需接地）

**（6）管内穿线施工程序**

```
选择导线 → 穿引线 → 放护圈（金属导管时） → 穿导线 → 导线连接 → 绝缘测试
```

> **记忆口诀：选穿放穿连测** 🧠
>
> 关键点：
> - **放护圈** 仅在 **金属导管** 时需要（防止导线被管口锋利边缘割伤）
> - 最后的 **绝缘测试** 是所有涉及线路程序的标准收尾工序

#### 3. 电气照明工程施工程序

**（1）暗装照明配电箱安装程序**

```
开箱检查 → 箱体固定 → 电器与导线连接 → 送电前检查 → 送电运行
```

> **对比记忆（vs 明装动力配电箱）：**
> - 暗装照明配电箱 **无** 基础框架制作安装（嵌入墙内）
> - 明装动力配电箱 **有** 基础框架制作安装（详见下方）

**（2）照明灯具施工程序**

```
灯具检查 → 灯具组装 → 安装接线 → 送电前检查 → 送电运行
```

> **记忆：检组装接线送** 🧠

#### 4. 电气动力设备施工程序

**（1）明装动力配电箱施工程序**

```
基础框架制作安装 → 箱体固定 → 电器与导线连接 → 送电前检查 → 送电运行
```

> [关键对比] 明装动力配电箱 vs 暗装照明配电箱：
>
> | 对比项 | 暗装照明配电箱 | 明装动力配电箱 |
> |--------|---------------|---------------|
> | 基础框架 | ❌ 无 | ✅ 有（先做框架） |
> | 开箱检查 | ✅ 有 | ❌ 无（注意差异！） |
> | 适用场景 | 住宅/办公照明 | 工业/动力设备 |

> [辨析] ⚠️ 明装动力配电箱 **"无开箱检查"** 是区别于其他程序的重要特征，并非所有程序都有检查环节。

**（2）电动机（风机、水泵等）施工程序**

```
电动机绝缘测试 → 电动机干燥（受潮时） → 电动机接线 → 送电前检查 → 送电运行
```

> 关键点：
> - **电动机干燥** 仅在 **受潮时** 进行（绝缘电阻不达标才需要），不是必有工序
> - **绝缘测试** 在最开始（判断是否受潮），干燥后还需再测试确认 🔑

#### 5. 防雷接地施工程序

```
接地体施工 → 接地干线施工 → 引下线敷设 → 均压环施工 → 接闪带（接闪杆、接闪网）施工
```

> **提示：自下而上** ⭐⭐⭐
>
> 防雷接地施工是从 **地下到地上** 的顺序：接地体（最底下）→ 接地干线 → 引下线 → 均压环 → 接闪装置（最顶上）。**千万别记反！**
>
> **记忆：体线下压接** 🧠

> [!WARNING] 高频易混点
> - ⚠️ 防雷接地 **自下而上** 施工，与一般自上而下的施工习惯相反
> - ⚠️ 导管程序：**明敷才有支架**，**金属导管才有接地线跨接**
> - ⚠️ 管内穿线：**金属导管**才需要 **放护圈**
> - ⚠️ 母线槽绝缘测试做 **两次**（单节安装前 + 通电前）
> - ⚠️ 明装动力配电箱 **无开箱检查** 环节（区别于暗装照明配电箱）

### 三、施工程序速查总表

| 子系统 | 程序 | 步骤数 | 特殊标记 |
|--------|------|--------|---------|
| 干式变压器 | 开→搬→装→附→交→前→验 | 7 | 二本复交 |
| 配电柜(开关柜) | 开→搬→基→柜→母→二→调→验 | 8 | 姑母二条 |
| 母线槽 | 检→支→绝→装→插→绝→验 | 7 | 两次绝缘测试 |
| 梯架(槽盒) | 测→支→装→跨 | 4 | 无绝缘测试 |
| 梯架内电缆 | 检→搬→敷→绝→挂→验 | 6 | 挂标志 |
| 槽盒内配线 | 选→敷→连→绝 | 4 | 最短 |
| 导管 | 测→支→预→装→跨 | 5 | 明敷/金属导管条件 |
| 管内穿线 | 选→引→护→穿→连→绝 | 6 | 金属导管放护圈 |
| 暗装照明配电箱 | 开→箱→连→前→验 | 5 | 无基础框架 |
| 照明灯具 | 检→组→接→前→验 | 5 | ⭐ |
| 明装动力配电箱 | 基→箱→连→前→验 | 5 | 无开箱检查 |
| 电动机 | 测→干→接→前→验 | 5 | 干燥有条件 |
| 防雷接地 | 体→干→引→均→接 | 5 | 自下而上 |

### 四、真题演练

#### 【真题 2020 多选】使用场景

> 此考点曾于 2020 年以多选题考查子分部/分项的对应关系，2014 年以案例题考查施工程序顺序。

#### 【例题 · 单选】

**题目：** 配电柜的安装程序中，柜体固定的紧后工序是（ ）。

A. 开箱检查
B. 母线连接
C. 二次线路连接
D. 试验调整

**答案：** **B**

**解析：** 配电柜（开关柜）安装程序：开箱检查 → 二次搬运 → 基础框架制作安装 → **柜体固定** → **母线连接** → 二次线路敷设连接 → 试验调整 → 送电运行验收。

> 注意审题：问的是 **"紧后工序"**，即紧随柜体固定的下一步，是 **母线连接**。二次线路连接在母线连接之后。
