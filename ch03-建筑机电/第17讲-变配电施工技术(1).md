# 3.2 变配电施工技术（1）

> [!SUMMARY] 本讲概要
> 本讲覆盖变配电施工四大子项的前两项：**变压器安装**（修改、新增，★★★）与**柴油发电机组安装**（新增，★★★）。高频考点集中在变压器接线组别、交接试验参数，以及柴油发电机组的接地与并列运行条件。
>
> **真题分布**：2016多 / 2018单 / 2021单 / 2022案 / 2025超案
>
> 配电柜安装与箱式变电所安装见下一讲。

---

## 通用要求（适用于变配电全系列）

> ⚙️ 所有变配电设备安装遵循以下共性原则：

| 环节 | 核心要求 |
|------|---------|
| **开箱/进场** | 型号、规格、外观、附件；随机文件齐全（合格证、技术文件） |
| **安装** | 连接牢固、符合规范（垂直度、间隙、水平度）；无卡阻、合闸指示正确；联动/动作正常、传动正确 |
| **接地** | 外露可导电部分与保护导体可靠连接 |

---

## 1. 变压器安装（修改、新增） ★★★

> 真题分布：2016多 / 2018单 / 2021单 / 2022案 / 2025超案

### 1.1 开箱检查

**实体+资料**双重确认：

- 变压器 **型号、规格** 应符合设计要求，有出厂 **合格证和技术文件**
- 外观无损伤，**分接开关、冷却风机、温度计**等附件齐全
- 铭牌应注明：制造厂名称、**额定容量**、一次/二次额定电压和电流、**阻抗电压**、**联结组别**

> 记忆：类比 **收快递** —— 外观检查 → 规格型号数量 → 技术文件 → 记录

### 1.2 本体及附件安装

- 安装位置**正确牢固**，分接开关、冷却风机、温度计等附件安装符合要求
- **变压器箱体、支架、基础型钢及外壳** 应分别**单独**与保护导体可靠连接，紧固件及防松零件齐全

### 1.3 三相变压器接线组别

```mermaid
graph LR
    A[10/0.4kV变压器] --> B[一次绕组 Δ接<br/>D 接线]
    A --> C[二次绕组 Y接 + 中性点引出<br/>yn11 接线]
    B --> D[常用接线组别: D, yn11<br/>(Δ/Yo-11)]
    C --> D
```

| 项目 | 内容 |
|------|------|
| **常用接线组别** | D, yn11（Δ/Yo-11）|
| **一次绕组** | △接（D）|
| **二次绕组** | Y接并引出中性点（yn），三相四线供电 |
| **D,yn11 的含义** | 11点钟 → 二次绕组线电压**超前**一次绕组线电压 **30°电角**（低压线电动势滞后高压线电动势330°）|
| **接线组别的作用** | 不同接线组别能改变二次绕组线电压与一次绕组线电压的相位差 |

> 记忆：D,yn11 —— "D" 是三角（Delta），"yn" 是星形带中性点，"11" 像指针指向11点（超前30°）

### 1.4 干式变压器交接试验（7项）

> [!IMPORTANT] 重点
> **7项试验**为案例分析高频考点。其中直流电阻的数值界限、电压比偏差、有载分接开关循环次数、冲击合闸次数为数字记忆关键。

| 序号 | 试验项目 | 关键要求 |
|:----:|---------|---------|
| ① | 测量绕组连同套管的**直流电阻** | 见下方详细数值表 |
| ② | 检查所有分接的**电压比** | 与铭牌数据相比，见下方电压比偏差表 |
| ③ | 检查变压器的三相**接线组别**和单相变压器引出线的**极性** | 应符合设计要求，与铭牌标记、外壳符号相符 |
| ④ | **有载调压切换装置**的检查和试验 | 无电压下手动≥2循环、电动≥5循环；带电下电动操作应正常 |
| ⑤ | 测量绕组连同套管的**绝缘电阻** | ≥出厂试验值70% 或 ≥10000MΩ（20℃） |
| ⑥ | 绕组连同套管的**交流耐压试验** | 35kV及以下干式变压器按表3.2-2实施 |
| ⑦ | **冲击合闸试验** | 额定电压下5次，间隔5min，高压侧进行 |

#### ① 直流电阻 —— 核心数值表

| 变压器容量 | 各相绕组相互间 | 无中性点引出的绕组（线间） |
|-----------|:-------------:|:------------------------:|
| **≤1600kVA** | ≤ **4%** | ≤ **2%** |
| **>1600kVA** | ≤ **2%** | ≤ **1%** |

> 知识点补充：
> - **直流电阻**：指导体的电阻，越小导电能力越好
> - **绝缘电阻**：指导体之间绝缘材料的电阻，越大绝缘性能越好
> - **交流耐压试验**：鉴定绝缘强度的方法，能发现隐藏缺陷，但会给绝缘造成一定损伤

#### ② 电压比允许偏差

| 条件 | 允许偏差 |
|-----|:-------:|
| 电压等级**35kV以下**，且电压比 **<3** | **±1%** |
| 其他变压器（额定分接下） | **±0.5%** |

> 记忆：35kV以下 + 变比<3 → ±1%；其他 → ±0.5%

#### ④ 有载调压切换装置 —— 操作循环数

| 操作条件 | 操作方式 | 最少循环次数 |
|---------|:-------:|:----------:|
| **无电压** | 手动 | **2** 个循环 |
| **无电压** | 电动（电源电压≥85%额定电压） | **5** 个循环 |
| **带电** | 电动操作 | 动作正常即可 |

#### ⑦ 冲击合闸试验

| 条件 | 要求 |
|------|------|
| 标准情况 | 额定电压下 **5次**，每次间隔 **5min**，无异常 |
| 冲击位置 | 变压器 **高压侧** 进行 |
| 中性点接地系统 | 试验时变压器中性点应**可靠接地** |
| 发电机-变压器组（中间无操作断开点） | **可不进行**冲击合闸试验 |
| 无电流差动保护的干式变压器 | 可冲击 **3次** |

> 记忆：5次，5分钟，高压侧，中性点接地

## 2. 柴油发电机组安装（新增） ★★★

### 2.1 进场验收

- 核对：主机、附件、专用工具、备品备件、随机技术文件
- **合格证和出厂试运行记录**应齐全完整
- 发电机及其控制柜应有**出厂试验记录**
- 设备外观：有铭牌、涂层完整、机身无缺件
- 随机的配电柜（控制柜）中：开关、保护装置的**型号、规格**正确；出厂试验的**锁定标记无位移**，有位移的应重新试验标定

### 2.2 安装流程

```
基础验收合格 → 安放 → 地脚螺栓固定 → 初平 → 螺栓孔灌浆 → 精平 → 紧固地脚螺栓 → 二次灌浆
```

| 步骤 | 内容 |
|-----|------|
| ① | 基础验收合格 |
| ② | 安放机组 |
| ③ | 地脚螺栓固定的机组应**初平** |
| ④ | 螺栓孔灌浆 |
| ⑤ | **精平** |
| ⑥ | 紧固地脚螺栓 |
| ⑦ | **二次灌浆** |

> 记忆：初平 → 灌浆 → 精平 → 紧固 → 二次灌浆

### 2.3 接线

- 发电机组、配电柜、控制柜接线正确，紧固件紧固无遗漏脱落
- 柴油发电机馈电线路连接后，输出端的**相序应与原供电系统的相序一致**
- 相序 = 相位的顺序（某时刻的位置）

### 2.4 接地

| 部位 | 要求 |
|------|------|
| **发电机中性点** | 接地连接方式及接地电阻值符合设计要求；接地螺栓防松零件齐全，有标识 |
| **发电机本体和机械部分外露可导电部分** | 分别与保护导体可靠连接，有标识 |
| **燃油系统设备及管道** | 防静电接地符合设计要求 |

### 2.5 交接试验

| 项目 | 要求 |
|------|------|
| 发电机组至配电柜馈电线路**绝缘电阻** | 低压馈电线 ≥ **0.5MΩ**；高压馈电线 ≥ **1MΩ/kV** |
| 绝缘电缆馈电线路**直流耐压试验** | 符合现行国家标准 |
| **并列运行**条件 | 电压、频率、**相位一致** |

> 记忆：并列运行三一致 —— **电压、频率、相位**

## 数字速记表

| 项目 | 数字/参数 |
|------|:---------:|
| 直流电阻 — 1600kVA及以下（相间） | ≤ **4%** |
| 直流电阻 — 1600kVA及以下（线间） | ≤ **2%** |
| 直流电阻 — 1600kVA以上（相间） | ≤ **2%** |
| 直流电阻 — 1600kVA以上（线间） | ≤ **1%** |
| 电压比偏差（35kV以下+变比<3） | **±1%** |
| 电压比偏差（其他，额定分接下） | **±0.5%** |
| 有载分接开关 — 手动（无电压） | ≥ **2** 循环 |
| 有载分接开关 — 电动（无电压） | ≥ **5** 循环 |
| 绝缘电阻 | ≥出厂值 **70%** 或 ≥ **10000MΩ**（20℃）|
| 冲击合闸 | **5**次 × 间隔**5min** |
| 无差动保护干变冲击次数 | **3**次 |
| 低压馈电绝缘电阻 | ≥ **0.5MΩ** |
| 高压馈电绝缘电阻 | ≥ **1MΩ/kV** |

## 考试常见陷阱

1. **直流电阻 vs 绝缘电阻**：前者越小越好（导体导电），后者越大越好（绝缘材料）
2. **交流耐压试验**：既能发现隐藏缺陷，也会给绝缘造成一定损伤 —— 双刃剑
3. **D,yn11接线**：11点表示二次超前一次30°，不要记反方向
4. **1600kVA界限**：直流电阻的允许偏差以1600kVA为分界线，记反则全错
5. **有载分接开关循环数**：手动2循环 / 电动5循环，在无电压下进行；带电下只要求 "动作正常"
6. **冲击合闸默认5次**，只有"无电流差动保护的干式变压器"才是3次
7. **相序一致**：柴油发电机与原供电系统相序必须一致，而非电压一致
