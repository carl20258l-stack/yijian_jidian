# 3.2 建筑防雷与接地施工技术

> [!SUMMARY]- 本讲速览
> 防雷与接地是建筑电气施工的重要安全环节，主要包括**接闪器、引下线、接地体、接地线、等电位联结**五大系统。
>
> **真题分布**：2018案例 / 2019案例 / 2022单选 / 2024案例
>
> **核心数据**：搭接长度（2倍/6倍）、埋深（0.6m）、间距（5m）、接地电阻（独立<4Ω / 共用<1Ω）
>
> **重难点**：① 各种型材的搭接焊接长度与施焊面数 ② 接地模块施工 ③ 接地电阻值对比

---

## 1. 建筑防雷与接地的材料与连接要求

### 1.1 材料要求

| 材料类型 | 规格要求 |
|---------|---------|
| 镀锌钢材 | 热镀锌，镀层厚度 **≥ 65μm**，镀层宜光滑连贯、无斑点 |
| 常用型材 | 镀锌角钢、镀锌钢管、镀锌扁钢、镀锌圆钢 |

### 1.2 连接要求

连接方式：**搭接焊接**

焊接质量：焊缝应饱满并有足够的机械强度，不得有夹渣、咬肉、裂纹、虚焊、气孔等缺陷

防腐处理：焊接处刷防锈漆和银粉漆或喷锌防腐处理

#### 各种型材搭接长度对比表

| 连接类型 | 搭接长度要求 | 施焊面数 |
|---------|------------|---------|
| **扁钢↔扁钢**（铜排↔铜排） | 扁钢宽度的 **2倍** | **≥ 三面**施焊 |
| **圆钢↔圆钢**（铜杆↔铜杆） | 圆钢直径的 **6倍** | 双面施焊 |
| **圆钢↔扁钢**（铜杆↔铜排） | 圆钢直径的 **6倍** | 双面施焊 |
| **扁钢↔钢管**（铜排↔铜管） | 紧贴 **3/4** 管外径表面 | **上下两侧**施焊 |
| **扁钢↔角钢** | 紧贴角钢外侧 **两面** | **上下两侧**施焊 |

> 记忆：**2饼6元** — 扁钢2倍（饼=扁），圆钢6倍（元=圆）

---

## 2. 接闪杆（线、网）的施工要求

### 2.1 接闪杆

| 项目 | 要求 |
|-----|------|
| 材质 | 不锈钢（或热镀锌）圆钢 / 不锈钢管（或热镀锌钢管） |
| 与接闪网关系 | 应连接成 **一个整体** |
| 独立接地装置 | 与其他接地网的地中距离 **≥ 3m** |
| 金属筒体作引下线 | 筒体厚度 **≥ 4mm**，底部应有 **两处** 与接地体连接 |

### 2.2 接闪带（网）

| 项目 | 要求 |
|-----|------|
| 常用材料 | **40mm×4mm** 镀锌扁钢 或 **φ12mm** 镀锌圆钢 |
| 固定支架高度 | **≥ 150mm** |
| 扁钢支架间距 | **0.5m** |
| 圆钢支架间距 | **1m** |
| 支架承受拉力 | **49N**（约5kg） |
| 屋顶金属物 | 应与接闪网连接成一体（铁栏杆、钢爬梯、金属旗杆、透气管、金属柱灯、冷却塔等） |

---

## 3. 引下线的施工要求

| 场景 | 要求 |
|-----|------|
| 明敷热镀锌圆钢 | 可采用 **焊接或卡夹（接）器** |
| 明敷热镀锌扁钢 | 可采用 **焊接或螺栓连接** |
| 断接卡位置 | 离地 **1.5m** 处 |
| 利用柱内主钢筋（防雷引下线） | 离地 **0.5m** 处做**接地测试点**，通常 **≥ 2个**，有明显标识 |

> [[断接卡]]与[[接地测试点]]的区别：断接卡在明敷引下线1.5m处，接地测试点在利用主钢筋引下线0.5m处。

---

## 4. 接地体的施工要求

### 4.1 人工接地体

#### 垂直接地体

| 参数 | 要求 |
|-----|------|
| 镀锌钢管壁厚 | **≥ 2.5mm** |
| 镀锌角钢厚度 | **≥ 4mm** |
| 镀锌圆钢直径 | **≥ 14mm** |
| 接地体长度 | 一般为 **2.5m** |
| 顶部距地面 | **≥ 0.6m** |
| 水平间距 | **≥ 5m** |

#### 水平接地体

| 参数 | 要求 |
|-----|------|
| 镀锌扁钢厚度 | **≥ 4mm** |
| 截面积 | **≥ 100mm²** |
| 镀锌圆钢截面积 | **≥ 100mm²** |
| 距地面 | **≥ 0.6m** |

### 4.2 自然接地体

| 类型 | 做法 |
|-----|------|
| 垂直接地体 | 利用 **工程桩钢筋** |
| 水平接地体 | 利用 **建筑底板钢筋** |
| 连接要求 | 在不同**两点及以上**与接地干线或接地网连接 |

> 施工结束后应及时**测量接地电阻**。

### 4.3 接地电阻值对比

| 接地类型 | 电阻值要求 |
|---------|-----------|
| **独立接地体**（工作、防雷、保护、屏蔽、防静电各自独立） | **< 4Ω** |
| **共用接地体**（工作、防雷、保护、屏蔽、防静电共用） | **< 1Ω** |

#### 绝缘电阻 / 接触电阻对比表

| 电气设备 | 电阻要求 |
|---------|---------|
| **母线槽** 单节 | **≥ 20MΩ**（绝缘电阻） |
| **母线槽** 整体 | **≥ 0.5MΩ**（绝缘电阻） |
| **母线槽连接** | **< 0.1Ω**（接触电阻） |
| **灯具** | **≥ 2MΩ**（绝缘电阻） |
| **低压电动机** | **≥ 0.5MΩ**（绝缘电阻） |

## 5. 接地线的施工要求

### 5.1 接地干线

| 项目 | 要求 |
|-----|------|
| 敷设方式 | **明敷**，一般敷设在电气井或电缆沟内 |
| 利用钢结构作接地线 | 与接地干线应采用 **电焊连接** |
| 不允许电焊时 | 可采用柱焊或钻孔、攻丝，然后用螺栓和接地线跨接 |
| 跨接线 | 一般采用扁钢或两端有铜接头的导线，应有 **150mm** 的伸缩量 |

### 5.2 接地支线

| 项目 | 要求 |
|-----|------|
| 敷设方式 | **明敷**，水平或垂直敷设在墙壁上，或敷设在桥架或支架上 |
| 水平敷设离地面距离 | **250~300mm** |
| 与墙壁间隙 | **10~15mm** |
| 跨越伸缩缝/沉降缝 | 应设置 **补偿器**（可用接地线本身弯成弧状代替） |
| 不宜焊接时 | 可用螺栓连接（需除锈处理） |
| 与电气设备连接 | 接线端子螺栓连接 + 防松螺帽或防松垫片 |
| 串接禁止 | 每个电气装置**单独**的接地线与接地干线连接，**不得串接**多个装置 |

> 【真题】2019案例考查扁钢搭接方式：40×4镀锌扁钢正确的焊接搭接方式及施焊面数。
>
> 【真题】2024案例考查接地体金属型材选择：宜采用镀锌型材或铜材。

---

## 6. 降低接地电阻值的技术措施

当接地电阻达不到设计要求时：

| 措施 | 说明 |
|-----|------|
| **降阻剂** | 化学降阻 |
| **换土措施** | 更换低电阻率土壤 |
| **接地模块** | 详见下方 |

> 【真题】2018案例考查降低接地电阻的技术措施。

### 6.1 接地模块施工要求

> 【真题】2022单选 — "关于接地模块的说法，错误的是"

| 参数 | 要求 |
|-----|------|
| 顶面埋深 | **≥ 0.6m** |
| 模块间距 | **≥ 模块长度的 3~5倍** |
| 就位方式 | **垂直或水平**就位，与原土层接触良好 |
| 引线方式 | **集中引线** |
| 连接方式 | 接地干线将接地模块 **并联焊接** 成一个环路 |
| 干线材质 | 与接地模块焊接点的材质**相同** |
| 引出线数量 | **≥ 2处** |

> ⚠️ 易错点：接地模块是 **并联焊接** 成环路（不是串联），出线 **≥ 2处**。

---

## 7. 等电位联结要求

> 等电位联结：使导电部分电位相等，消除电位差

### 7.1 分类

| 类型 | 说明 |
|-----|------|
| **总等电位联结** | 全建筑物范围 |
| **辅助等电位联结** | 局部范围辅助 |
| **局部等电位联结** | 特定区域（如卫生间） |

### 7.2 施工要求

| 项目 | 要求 |
|-----|------|
| 导体连接方式 | 焊接 或 螺栓连接 |
| 焊接 | 符合搭接长度规定 |
| 螺栓连接 | 螺栓、垫圈、螺母等应为 **热镀锌** 制品，连接牢固 |
| 暗敷时导体连接 | **不得采用螺栓压接** |
| 色标 | 端部应有 **黄绿相间** 色标（与PE线相同） |

## 真题回顾

### 【2022·单选】接地模块

关于接地模块的说法，错误的是（　C　）

A. 接地模块的顶面埋深不应小于0.6米

B. 接地模块的间距不应小于模块长度的3~5倍

C. 接地模块的接地干线应串联焊接成一个环路 ❌

D. 接地模块的干线环路引出线不应少于2处

> 解析：应为 **并联焊接** 成一个环路，非串联。

### 【2019·案例】扁钢搭接

**问题**：画出40×4镀锌扁钢正确的焊接搭接方式？扁钢需要多少面焊接？

**答案**：搭接不应小于扁钢宽度的2倍，且应至少三面施焊。

### 【2024·案例】接地体型材

**问题**：柴油发电机组临时供电系统电源中性点的接地体宜采用哪种金属型材？

**答案**：宜采用镀锌型材或铜材。
