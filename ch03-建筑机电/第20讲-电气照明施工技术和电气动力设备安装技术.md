# 3.2 电气照明施工技术和电气动力设备安装技术

> **本节 summary**
>
> 本节分两大块：**照明**（★★）和**动力**（★）。照明部分重点掌握灯具的防触电分类（Ⅰ/Ⅱ/Ⅲ类接地规则）、灯具安装固定参数（重量→螺栓直径→强度试验）、插座接线"左零右相上接地"；动力部分聚焦电动机绝缘电阻测试（1kV以下≥0.5MΩ，抽检50%）和接线方式（△/Y接）。真题覆盖2018-2025年，平均每年1-2道。

---

## 一、电气照明施工技术 ★★

> 【考情】高频考点，2018多/2019多/2024单均有出题。

### （一）照明配电箱安装技术要求

#### 1. 照明配电箱检查

- 箱内开关动作应**灵活可靠**
- 宜**分别设置**中性导体（N）和保護接地导体（PE）**汇流排**

#### 2. 照明配电箱安装要求

- 箱体安装牢固、位置正确，安装高度符合**设计要求**

#### 3. 照明配电箱内配线要求

- 配线整齐、**无绞接现象**；导线连接紧密、**不伤线芯**
- 回路编号应齐全，标识应正确、清晰
- **同一电器接线端子上导线连接不应多于 2 根**

### （二）灯具安装技术要求

> 【考情】2017单、2019多、2022单、2024单均有涉及。

#### 1. 灯具现场检查

| 项目 | 要求 |
|------|------|
| **绝缘电阻** | ≥ **2MΩ**，现场抽样检测 |
| **内部接线** | 铜芯绝缘导线，截面≥ **0.5mm²**，与灯具功率匹配 |
| **Ⅰ类灯具** | 外露可导电部分应有专用 **PE 端子** + 接地标识 |
| **消防应急灯具** | 应获得消防产品型式试验合格评定 + 认证标志 |
| **水下灯/防水灯具** | 防护等级符合设计要求；有异议时按批抽样送**有资质**检测机构 |

> 【真题·2019多选】关于灯具现场检查要求的说法——正确答案选 ABCE（见下方真题解析）
>
> 【真题·2024单选】灯具到达现场的检查内容不包括——"水下灯具应有省级检测机构的检测报告"（应为**有资质的**检测机构，不特指省级）

#### 2. 灯具安装固定 ★★★

| 条件 | 固定要求 |
|------|----------|
| **砌体和混凝土结构** | 严禁使用木榫、尼龙塞或塑料塞固定 |
| 检查比例 | 每检验批灯具数量的 **5%**，且不少于 **1 套** |
| **吸顶/墙面安装** | 固定螺栓或螺钉**不少于 2 个**，灯具紧贴饰面 |
| **质量 > 3kg 悬吊灯具** | 螺栓或预埋吊钩直径 ≥ **6mm** |
| 钢管作吊杆 | 内径 ≥ **10mm**，壁厚 ≥ **1.5mm** |
| **质量 > 10kg 灯具** | 按灯具重量 **5 倍**恒定均布载荷做**强度试验**，持续≥ **15min**，**全数检查** |

> 记忆：**吊杆内径10mm，壁厚1.5mm；吊钩螺栓≥6mm**

#### 3. 防触电保护灯具的类型及接线要求 ★★★

**三大类对照表：**

| 类别 | 防触电原理 | 接地规定 | 关键特征 |
|------|-----------|---------|---------|
| **Ⅰ类** | 基本绝缘 + 外露可导电部分接保护导体 | **必须**接地 | 有 PE 端子、接地标识 |
| **Ⅱ类** | 基本绝缘 + 双重绝缘或加强绝缘 | **不需要**接地 | 外壳不接 PE |
| **Ⅲ类** | 安全特低电压（≤ AC 50V） | **不许**接地 | 隔离变压器供电 |

> 记忆：**Ⅰ必须→Ⅱ不需→Ⅲ不许**
>
> 「Ⅰ必须，Ⅱ不需，Ⅲ不许」——从严格到宽松：必须接地 → 不需要 → 不允许。

**Ⅰ类灯具接线细节（2019二建考过）：**

- 外露可导电部分必须采用**铜芯软导线**与保护导体**可靠连接**
- 连接处应设置**接地标识**
- 接地线截面与进入灯具的**电源线截面相同**

#### 4. 专用灯具安装要求

**（1）落地式景观照明灯具**

- 距地面高度应 **> 2.5m**
- 金属构架及金属保护管应分别与保护导体采用**焊接或螺栓连接**，设接地标识

**（2）航空障碍标志灯**

- 安装牢固可靠，应有维修和更换光源的措施
- 安装在屋面接闪器保护范围以外的灯具，需设置接闪器时，应与屋面接闪器**可靠连接**

### （三）开关安装接线要求

- 同一建筑物内的开关应采用**同一系列**产品，通断位置应**一致**
- 开关距地面高度宜为 **1.3m**
- 相同型号开关并列安装时高度宜**一致**

### （四）插座安装接线要求

#### 1. 插座安装要求

| 场景 | 要求 |
|------|------|
| **一般场所** | 距地面高度 **0.3m** |
| **托儿所/幼儿园/小学校** | 距地面高度 **≥ 1.8m** |
| 同一场所 | 安装高度应一致 |
| 交流/直流/不同电压等级 | 应有明显区别，**不得互换** |
| 不间断电源/应急电源插座 | 应设置**标识** |
| 潮湿房间 | 应装设**防水插座** |

#### 2. 插座接线要求 ★★★

**（1）单相插座接线：**

```
面对插座板：
  单相两孔：右孔（上孔）→ 相线 L
            左孔（下孔）→ 中性线 N

  单相三孔：右孔 → 相线 L
            左孔 → 中性线 N
            上孔 → 保护接地线 PE
```

> 记忆：**左零右相上接地**

**（2）三相四孔插座：**

- 上孔接**保护接地线（PE）**
- PE 端子不得与 N 端子连接
- 同一场所三相插座，接线相序应一致

**（3）重要禁止事项（2019二建考过）：**

- 相线（L）与中性线（N）**不得**利用插座本体的接线端子**转接供电**
- 保护接地线（PE）在插座之间**不得串联连接**

### 照明部分真题精讲

#### 【真题·2019多选】

> 关于灯具现场检查要求的说法，正确的是（  ）

A. Ⅰ类灯具的外露可导电部分应具有专用的 PE端子  
B. 消防应急灯具有认证标志  
C. 灯具内部接线为铜芯绝缘导线  
D. 灯具绝缘电阻不小于 0.5兆欧  
E. 导线绝缘层厚度不小于 0.6毫米  

**【答案】ABCE**  
**【解析】** D 错误——灯具绝缘电阻值不应小于 **2MΩ**，不是 0.5MΩ。E 所述绝缘层厚度 ≥0.6mm 为正确（原教材有，新教材已删除此数据）。

#### 【真题·2024单选】

> 灯具到达施工现场的检查内容不包括（  ）

A. Ⅰ类灯具的金属外壳应有专用的接地端子  
B. 消防应急灯具应有消防产品合格证认证标志  
C. 水下灯具应有省级检测机构的检测报告  
D. 抽样检测灯具的绝缘电阻值不应小于 2MΩ  

**【答案】C**  
**【解析】** 水下灯具防护等级应符合设计要求，有异议时送**有资质**的检测机构检测，不一定非要"省级"。

## 二、电气动力设备安装技术 ★

> 【考情】2025年首次出单选，属于新晋考点，后续需关注。

### （一）动力配电（控制）箱安装要求

- 箱前操作**通道宽度不宜小于 1m**
- 室外安装应有**防雨、防水措施**

### （二）电动机安装接线要求 ★★★

#### 1. 一般要求

- 电动机安装随设备（风机、水泵等）安装实施

#### 2. 接地与绝缘电阻测试

| 项目 | 要求 |
|------|------|
| **外露可导电部分** | 必须与保护导体**可靠连接** |
| **1kV 以下电动机绝缘电阻** | ≥ **0.5MΩ** |
| **抽检比例** | **50%** |

#### 3. 接线密封与滴水弯

- 电动机接线入口及接线盒应做**密封处理**
- 电动机进线电缆应有**滴水弯**

#### 4. 接线方式（△/Y 接）★

| 线路电压 | 电动机额定电压 | 接法 |
|----------|---------------|------|
| 380V | 380V | **△接**（三角形接法） |
| 380V | 220V | **Y接**（星形接法） |

> 记忆：**线电=额电→△接；线电>额电→Y接**
>
> 线路电压 380V 供给额定电压 220V 的电机，必须 Y 接降压，否则烧毁。

### （三）电动机试运行

- 电动机试运行随设备（风机、水泵等）的试运行实施

---

### 动力部分真题精讲

#### 【真题·2025单选】

> 额定电压为 380V 电动机的绝缘电阻测试后应抽查的数量为（  ）

A. 5%  
B. 10%  
C. 20%  
D. 50%  

**【答案】D**  
**【解析】** 1kV 以下电动机绝缘电阻值不应小于 0.5MΩ，抽查数量为 **50%**。注意与灯具检查比例（5%）区分。

## 三、易混淆对比总结

### 1. 不同对象的抽检/检查比例

| 对象 | 检查比例 | 备注 |
|------|---------|------|
| 灯具安装固定 | **5%**，不少于 1 套 | 每检验批 |
| 质量 > 10kg 灯具强度试验 | **全数检查** | 100% |
| 1kV 以下电动机绝缘电阻 | **50%** | 不是100%，注意区分 |

### 2. 接地规定对照

| 设备/场景 | 接地要求 |
|-----------|---------|
| Ⅰ类灯具 | **必须**接 PE |
| Ⅱ类灯具 | **不需要**接地 |
| Ⅲ类灯具 | **不许**接地 |
| 电动机外露可导电部分 | **必须**与保护导体可靠连接 |

### 3. 绝缘电阻值对比

| 对象 | 绝缘电阻要求 |
|------|-------------|
| 灯具 | ≥ **2MΩ** |
| 1kV 以下电动机 | ≥ **0.5MΩ** |

> 易错提醒：灯具绝缘电阻是 **2MΩ**，电动机是 **0.5MΩ**，不要混淆！

### 4. 高度对比

| 对象 | 距地高度 |
|------|---------|
| 开关 | 1.3m |
| 一般插座 | 0.3m |
| 托幼/小学校插座 | ≥ 1.8m |
| 落地式景观照明 | > 2.5m |
