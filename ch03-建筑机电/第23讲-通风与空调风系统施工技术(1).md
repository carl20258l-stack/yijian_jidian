# 3.3 通风与空调风系统施工技术（1）

> **考情分析**：★★★ 高频考点，案例题主力。近 10 年考查频次极高，涵盖风管制作、部件制作、安装、检验试验、绝热施工全流程。

| 年份 | 题型 | 考点 |
|------|------|------|
| 2015 | 案例 | 风管制作（咬口形式/钢板风管） |
| 2016 | 案例 | 风管安装 |
| 2017 | 案例 | 风管安装 |
| 2020 | 案例 | 风管制作（板材拼接/加固条件） |

## 一、风管制作

### 1. 一般制作要求

**（1）规格基准**

| 风管类型 | 规格基准 |
|----------|----------|
| 金属风管 | 以 **外径或外边长** 为准 |
| 非金属风管和风道 | 以 **内径或内边长** 为准 |

> 记忆口诀："**境**（金）外**匪**（非）内"——金属=外径，非金属=内径

**（2）风管系统压力等级划分（表 3.3-2）**

| 类别 | 工作压力 P (Pa) 正压 | 工作压力 P (Pa) 负压 | 施工密封要求 |
|------|---------------------|---------------------|-------------|
| **微压** | P ≤ 125 | P ≥ -125 | 接缝及接管连接处应严密 |
| **低压** | 125 < P ≤ 500 | -500 ≤ P < -125 | 接缝及接管连接处应严密，**密封面宜设在风管的正压侧** |
| **中压** | 500 < P ≤ 1500 | -1000 ≤ P < -500 | 接缝及接管连接处 **采取密封措施** |
| **高压** | 1500 < P ≤ 2500 | -2000 ≤ P < -1000 | **所有拼接缝及接管连接处均应采取密封措施** |

> 记忆要点：
> - 微压：125 为界，仅要求严密
> - 低压：500 → 正压侧密封
> - 中压：1500 → 采取密封措施
> - 高压：2500（且≤2500）→ 所有接缝均密封

**（3）防火风管**

- 本体、框架与固定材料、密封垫料等必须为 **不燃材料**
- 耐火极限时间应符合系统防火设计的要求
- 防排烟风管外包防火板

**（4）板材拼接**（2020 案例考点）

> **接缝应错开，不得有十字形接缝。**

**（5）金属风管加固条件**（高频案例考点）

| 风管类型 | 条件 |
|----------|------|
| **圆形直咬缝风管** | 直径 ≥ **800mm**，且管段长度 > **1250mm** 或总表面积 > **4m²** |
| **高压螺旋风管** | 直径 > **2000mm** |
| **矩形风管** | 边长 > **630mm** |
| **矩形保温风管** | 边长 > **800mm**，且管段长度 > **1250mm** |
| **低压风管单边平面面积** | > **1.2m²** |
| **中、高压风管单边平面面积** | > **1.0m²** |

> 加固形式：角钢框加固、风管内部加固（柱塞加套杆等）

**（6）矩形弯头导流片**（2010 多选、2022 案例）

> 矩形内斜线和内弧形弯头应设 **导流片**，以减少风管局部阻力和噪声。

### 2. 镀锌钢板风管制作

**（1）镀锌层要求**
- 设计无要求时，镀锌层厚度不应低于 **80g/m²**
- 风管表面不得有 **10%以上** 的花白、锌层粉化等严重损坏现象

**（2）连接方式** ★

> **镀锌钢板的风管不得采用焊接连接。**

**（3）翻边铆接**（适用于板厚 ≤ 1.2mm 的风管与角钢法兰连接）
- 翻边紧贴法兰，宽度 **6~9mm**

**法兰螺栓及铆钉孔孔距：**

| 系统压力 | 孔距 |
|----------|------|
| 微、中、低压系统 | ≤ **150mm**（2022 案例） |
| 高压系统 | ≤ **100mm** |

**（4）咬口连接**（2015 案例）

| 咬口形式 | 适用压力等级 |
|----------|-------------|
| 单咬口 | 微压、低压、中压、高压 |
| 联合角咬口 | 微压、低压、中压、高压 |
| 转角咬口 | 微压、低压、中压、高压 |
| **按扣式咬口** | **微压、低压、中压**（不适用于高压） |

> 记忆：前三种通吃所有压力等级，按扣式咬口跳过高压。

**（6）无法兰连接形式**

| 形式 | 适用压力等级 |
|------|-------------|
| **S形插条** | 微压、低压 |
| **直角形平插条** | 微压、低压 |
| C形插条 | 微压、低压、中压 |
| 立咬口 | 微压、低压、中压 |
| 包边立咬口 | 微压、低压、中压 |
| 薄钢板法兰插条 | 微压、低压、中压 |
| 薄钢板法兰弹簧夹 | 微压、低压、中压 |

> S形插条和直角形平插条仅适用于微压和低压。

**（7）矩形风管弯头**

可采用直角、弧形或内斜线形，**宜采用内外同心圆弧**。

**（8）风管加固形式**

角钢加固、**折角加固**、立咬口加固、扁钢内支撑、镀锌螺杆内支撑、钢管内支撑加固。

### 3. 普通钢板风管制作

- **焊接连接**时，风管与法兰的焊缝应 **低于法兰的端面**
- **除尘系统风管**：宜采用 **内侧满焊、外侧间断焊**
- 风管与法兰采用 **点焊固定** 时，焊缝应熔合良好，间距 ≤ **100mm**

### 4. 不锈钢板风管制作

| 场景 | 连接要求 |
|------|----------|
| 法兰连接 | 法兰采用不锈钢材质，与风管采用 **内侧满焊、外侧点焊** |
| 排油烟系统 | 风管与法兰应采用 **满焊**（防止油烟泄漏、串味和火灾） |
| 铆钉连接 | 应采用 **不锈钢铆钉**（防止电化学腐蚀） |

### 5. 非金属风管——玻璃钢风管

| 项目 | 要求 |
|------|------|
| 压力等级 | **不适用于高压系统** |
| 表面质量 | 不得出现 **泛卤**（卤化物析出）及严重 **泛霜**（盐类迁移） |
| 法兰螺栓孔间距 | ≤ **120mm** |
| 加固条件 | 边长 > **900mm**，且管段长度 > **1250mm** |
| 加固件材质 | 本体材料或防腐性能相同的材料 |

## 二、部件制作

### 1. 成品风阀

| 要求 | 内容 |
|------|------|
| 开度指示 | 应设有开度指示装置，准确反映阀片开度 |
| 手动风量调节阀 | 手轮或手柄以 **顺时针方向转动为关闭** |
| 工作压力 > 1000Pa 的调节风阀 | 生产厂应提供在 **1.5倍工作压力** 下能自由开关的强度测试合格证书或报告 |
| 密闭阀 | 应能严密关闭，漏风量符合设计要求 |

### 2. 消声器、消声弯头

| 要求 | 内容 |
|------|------|
| 性能 | 消声类别、消声性能及空气阻力符合设计和产品技术文件 |
| 材料 | 符合 **防火、防潮、防腐和卫生性能** 要求 |
| 消声材料填充 | 按要求的密度均匀敷设 |
| 矩形消声弯管 | 平面边长 > **800mm** 时，应设置吸声导流片 |
| 织物覆面层 | 平整，**顺气流方向** 搭接 |
| 保护层 | 应采用不易锈蚀材料（如镀锌钢丝网）；穿孔板保护层时，穿孔率 > **20%** |

### 3. 柔性短管

- 材料要求：**抗腐、防潮、不透气及不易霉变** 的柔性材料
- 不应为异径连接管

## 三、重点对比与记忆

### 风管法兰螺栓孔距对比

| 风管材质 | 孔距要求 |
|----------|----------|
| 镀锌钢板（微/中/低压） | ≤ 150mm |
| 镀锌钢板（高压） | ≤ 100mm |
| 玻璃钢风管 | ≤ 120mm |

### 风管加固启动条件对比

| 条件维度 | 数值 |
|----------|------|
| 圆形直咬缝直径 | ≥ 800mm |
| 高压螺旋风管直径 | > 2000mm |
| 矩形风管边长 | > 630mm |
| 矩形保温风管边长 | > 800mm |
| 低压单边面积 | > 1.2m² |
| 中、高压单边面积 | > 1.0m² |
| 管段长度 | > 1250mm |

### 不同材质风管连接方式

| 材质 | 连接方式 |
|------|----------|
| 镀锌钢板 | 咬口/铆接，**不得焊接** |
| 普通钢板 | 焊接（内侧满焊外侧间断焊） |
| 不锈钢（一般） | 内侧满焊、外侧点焊 |
| 不锈钢（排油烟） | **满焊** |
| 玻璃钢 | 法兰连接 |

## 四、口诀速记

| 编号 | 口诀 | 对应知识点 |
|------|------|-----------|
| ① | **境外匪类** | 金属=外径/外边长，非金属=内径/内边长 |
| ② | **咬口按不行高压** | 按扣式咬口不适用于高压系统 |
| ③ | **S插直插微低压** | S形插条、直角形平插条仅适用于微压、低压 |
| ④ | **逆顺关** | 手动风量调节阀顺时针→关闭 |
| ⑤ | **一五零一零零** | 微中低压法兰孔距150，高压100 |
| ⑥ | **先中间后四周** | （风管加固的安装顺序） |
