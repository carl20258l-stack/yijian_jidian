# 3.3 设备安装、系统调试检测、净化空调系统施工技术

## 考点1：通风与空调设备安装技术（★）

> 真题分布：2015案例、2022案例

涉及设备：制冷机组、冷却塔、组合式空调、新风机组、风机、水泵、风机盘管、多联机系统、换热设备、集分水器

### 1. 制冷机组及附属设备安装

- **基础交接**：混凝土基础必须进行质量交接验收，合格后方可安装
- **减振器安装**：
  - 应按设计要求设置减振器或减振垫
  - 减振器安装位置应与设备重心相匹配
  - 各减振器压缩量应均匀一致，偏差 **不应大于 2mm**
  - 采用弹簧减振器的制冷机组，应设置防止机组运行时**水平位移的限位装置**
- **找平找正**：
  - 离心式制冷机组：在**压缩机的机加工平面**上找正找平
  - 螺杆式制冷机组：对**机座**进行找平
  - 调整垫铁组处理偏差，调整完成后在垫铁两侧**点焊牢固**

### 2. 冷却塔安装

> 冷却塔定义：用水作为循环冷却剂，从系统中吸收热量排放至大气中，以降低水温的装置

- **基础要求**：位置、标高符合设计要求，进风侧距建筑物应 **> 1m**
- **连接螺栓**：应采用**镀锌或不锈钢螺栓**，紧固力应一致、均匀
- **安装水平度**：
  - 单台：水平度和垂直度允许偏差 **2‰**
  - 多台：排列整齐，各台开式冷却塔水面高度应一致，高度偏差值 **不应大于 30mm**
  - 共用集管并联运行时，集水盘(槽)之间连通管应符合设计要求
- **集水盘**：严密、无渗漏，进出水口方向位置正确，布水器布水均匀
- **填料安装**：在所有电、气焊接作业**完成后**进行
- **管道连接**：在管道冲（吹）洗**合格后**进行

### 3. 组合式空调机组、新风机组安装

- 空调箱底座安装于设备基础之上，按设计要求设置减振器或减振垫
- **U型水封**（冷凝水排出管）：
  - 表冷段周围应预留排水设施
  - 供回水管与表冷盘管的连接应正确
  - 水封高度 = 机组机外余压水头高度 + **50mm**
  - 整体水封高度 **不得小于 100mm**

### 4. 风机安装

- **落地安装**：找平找正后，采用胀锚螺栓或地脚螺栓固定，按设计要求设置减振器或减振垫，采取防止水平位移措施
- **悬挂安装**：吊架及减振装置符合设计及产品技术文件要求

### 5. 水泵安装（新增）

- **减振台座**：
  - 宜设置**整体式减振台座（惰性台座）**
  - 减振台座与基础间设置**减振器**
  - 设置防止水泵水平位移的限位装置
  - 减振台座可采用**型钢制作框架**，中间**浇筑钢筋混凝土**
  - 管道独立支架的固定点应设在减振基座上
- **吸入管**：
  - 按设计要求安装**阀门、过滤器**
  - 与水泵采用金属或橡胶软接头连接，应设置**独立支架**
  - 变径时应做**偏心变径管**，管顶应**平接**
- **出水管段**：
  - 按设计要求安装变径管、软接头、止回阀等
  - 变径应采用**同心变径**
- **并联水泵**：
  - 出口管道进入总管应采用**顺水流斜向插接（顺水三通）**
  - 夹角**不应大于 60°**

### 6. 风机盘管安装

- **进场复验参数**：供冷量、供热量、风量、水阻力、功率及噪声
  - 检验方法：随机抽样送检，核查复验报告
- **安装前试验**（逐台进行）：
  - **水压试验**：压力 = 系统工作压力的 **1.5倍**，观察 **2min**，不渗漏为合格
  - **风机三速试运行**：通电试运行不漏电、不短路，三速转动方向、转速正常
- **管道连接**：
  - 采用耐压值 **≥ 1.5倍工作压力**的金属柔性连接
  - 连接牢固、严密，坡向正确
  - 金属软管及阀门均应**保温**
- **凝结水管**：宜设置**透明软管**，能观察到凝结水排水情况，长度**不宜大于 150mm**

### 7. 多联机系统室内机、室外机安装

> 多联机定义："一拖多"——一台室外机通过配管连接多台室内机，室外侧风冷换热、室内侧直接蒸发换热的一次制冷剂空调系统

- **室外机**：
  - 可靠接地，采取**防雷保护**措施
  - 安装在设计专用平台上，采取**减振与防止紧固螺栓松动**措施
  - 通风通畅，不应有短路现象，运行无异常噪声
  - 多台集中安装时，不应影响相邻机组正常运行
- **室内机**：
  - 风管式室内机的送、回风口之间，不应形成**气流短路**
  - 应设置单独支吊架固定牢固

### 8. 换热设备、集分水器等其他空调设备安装

- 安装稳固，与设备连接的管道应**单独设置支托架**
- 管道按要求设置阀门、压力表、温度计、过滤器等
- **满水试验**：开式水箱(罐)在连接管道前进行
- **水压试验**：换热器及密闭容器在连接管道前进行

## 考点2：通风与空调系统的调试和检测（★★★）

> 真题分布：2012案例、2013案例、2014多选、2022案例、2024单选

### 1. 调试准备

- **负责单位**：施工单位负责，监理单位监督，设计单位与建设单位参与和配合
- **调试方案**：编制后报送**专业监理工程师审核批准**

### 2. 系统调试及检测

系统调试包含两部分：
1. **设备单机试运行及调试**
2. **系统非设计满负荷条件下的联合试运行及调试**

#### 2.1 设备单机试运行及调试要求

**设备单机运行时间表：**

| 设备 | 连续运行时间 |
|------|------------|
| 通风机、空气处理机组——风机 | **2h** |
| 水泵 | **2h** |
| 冷却塔风机与冷却水系统 | **2h** |
| 制冷机组、空调系统带冷（热）源 | **8h** |

**通用检查要点**（方向、振动、声响、时间）：
- 叶轮旋转方向应正确
- 运转平稳，无异常振动与声响
- 电机运行功率符合设备技术文件要求
- 额定转速下连续运行后，滑动轴承与滚动轴承温升符合规范要求

**冷却塔专项**：试运行不小于 **2h**，冷却塔本体应稳固、无异常振动

**制冷机组专项**：
- 各连接和密封部位不应有松动、漏气、漏油
- 吸、排气的压力和温度应在正常工作范围内
- 能量调节装置及各保护继电器、安全装置动作应正确、灵敏、可靠

#### 2.2 系统非设计满负荷条件下的联合试运行及调试

**基本原则：**
- 在设备单机试运行**合格后**进行
- 通风系统连续试运行 **≥ 2h**
- 空调系统带冷(热)源连续试运行 **≥ 8h**
- 联合试运行不在制冷期或供暖期时，仅做不带冷(热)源的试运行，在第一个制冷期或供暖期内**补做**

**包含内容（记忆口诀：监控防空风水）：**
1. 监测与控制系统的检验、调整与联动运行
2. 系统风量的测定和调整（通风机、风口、系统平衡）
3. 空调水系统的测定和调整
4. 室内空气参数的测定和调整
5. 防排烟系统测定和调整

**空调水系统启停顺序：**

| 操作 | 顺序 |
|------|------|
| **开机** | 冷却塔 → 冷却水泵 → 空调末端装置 → 冷冻水泵 → 制冷机组 |
| **关机** | 制冷机组 → 冷冻水泵 → 冷却水泵 → 冷却塔 → 空调末端装置 |

**允许偏差汇总表：**

| 检测项目 | 允许偏差 |
|----------|---------|
| 系统总风量（与设计风量） | **-5% ~ +10%** |
| 变风量系统新风量（与设计新风量） | **0 ~ +10%** |
| 各风口风量（与设计风量） | **不应大于 15%** |
| 空调冷（热）水/冷却水系统总流量（与设计流量） | **不应大于 10%** |
| 定流量系统各空气处理机组水流量 | **15%** |
| 变流量系统各空气处理机组水流量 | **10%** |
| 各台制冷机/冷却塔水流量（多台并联运行时） | **不应大于 10%** |

> 记忆规律：多新总变冷 10%、各 15%；总比分支要求高，变量比定量要求高，多台比单台要求高

**其他技术要求：**
- 建筑内各区域压差应符合设计要求
- 水泵的流量、压差和水泵电机的电流**不应出现 10%以上的波动**
- 冷水机组的供回水温度和冷却塔的出水温度应符合设计要求

### 3. 系统节能性能检测

#### 3.1 材料、设备的见证取样复试

**绝热材料**进场复验参数（记忆：**主导洗米**）：
- 导热系数或热阻
- 密度
- 吸水率
- 同一厂家同材质绝热材料复验**不得少于 2次**

**风机盘管机组**进场复验参数（记忆：**冷热风阻招工**）：
- 供冷量、供热量、风量、水阻力、功率及噪声
- 同一厂家：**500台及以下**抽检**2台**；每增加**1000台**应增加抽检**1台**

#### 3.2 通风与空调系统节能性能检测

| 季节 | 室内平均温度要求 |
|------|----------------|
| 冬季 | **不得低于**设计温度 **2℃**，且**不应高于 1℃** |
| 夏季 | **不得高于**设计温度 **2℃**，且**不应低于 1℃** |

## 考点3：净化空调系统施工技术（★）

> 真题分布：2021单选、2024案例
>
> 核心提示：净化空调比普通空调要求更高

### 1. 净化空调系统的使用性质

按使用性质分为两种类型：

| 类型 | 应用场景 |
|------|---------|
| **工业洁净室** | 电子工业、机械工业、化工等 |
| **生物洁净室** | 生物制药、食品、实验动物饲养、洁净手术部等 |

### 2. 洁净度等级划分

**工业洁净室（悬浮粒子洁净度）：**
- N1 ~ N9 共 **9个**洁净度等级
- **N1级**洁净度水平最高

**洁净手术部（空态或静态，细菌浓度）：**
- I、II、III、IV级，共 **4个**等级
- **I级**手术室洁净水平要求最高

### 3. 净化空调系统的施工技术

#### 3.1 风管制作

**材料要求：**
- 宜采用镀锌钢板，镀锌层厚度 **≥ 100g/m²**
- 镀锌层不应有多处或 **10%** 表面积的损伤、粉化脱落
- 采用非金属风管时，应为不燃或难燃材料，表面光滑、平整、不产尘、不易霉变

**制作要求：**
- 风管内**不得有横向拼接缝**，**不得**设有加固框或加固筋
- 咬口缝处密封胶宜在**正压侧**
- 螺栓、螺母、垫圈和铆钉材料应与管材性能相适应，**不应产生电化学腐蚀**

**法兰螺栓/铆钉孔间距：**

| 洁净度等级 | 间距要求 |
|-----------|---------|
| **N1 ~ N5级** | **不应大于 80mm** |
| **N6 ~ N9级** | **不应大于 120mm** |

> 不得采用抽芯铆钉
> 矩形风管不得使用 S形插条及直角形插条连接
> 边长 > 1000mm 的净化风管，无加固措施不得使用薄钢板法兰弹簧夹连接
> N1 ~ N5级净化风管，**不得采用按扣式咬口连接**

**清洗：**
- 风管制作完毕后，用**无腐蚀性清洗液**将内表面清洗干净
- 清洗剂不应对人体、管材和产品产生危害
- 清洗达到要求后，对端部进行**密闭封堵**，存放在清洁房间

#### 3.2 风管安装

- 应在区域建筑地面工程施工完成、彻底清扫、无尘作业、室内建立防尘措施的**条件下进行**
- 安装前风管内表面应擦拭干净，无油污和浮尘
- 施工停顿或完毕时，端口应**封堵**
- **法兰垫料**：
  - 不产尘、不易老化，有强度和弹性
  - 厚度 **5 ~ 8mm**
  - **不得采用乳胶海绵**
  - 宜**减少拼接**，**不得采用直缝对接连接**
  - **不得**在垫料表面涂刷涂料
- 风管穿过洁净室围护结构时，采取**可靠的密封措施**
- 负压隔离病房排风口应高出屋面 **≥ 2m**，安装防护网和防雨罩

**风管严密性检验：**

| 类别 | 执行标准 |
|------|---------|
| 工业洁净室 N1 ~ N5级 | 按**高压系统**风管规定 |
| 工业洁净室 N6 ~ N9级，工作压力 ≤ 1500Pa | 按**中压系统**风管规定 |
| 医院洁净手术部 I级 | 漏风率 **≤ 1%** |
| 医院洁净手术部其他级别 | 漏风率 **≤ 2%** |

#### 3.3 管道安装

**阀门试验**（电子厂房工业洁净室，安装前逐个进行压力试验和严密性试验）：
- 输送可燃流体、有毒流体管道的阀门
- 输送高纯气体、高纯水管道的阀门
- 输送特种气体、化学品管道的阀门

**管道焊缝检验：**

| 管道类型 | 检验要求 |
|---------|---------|
| 输送**剧毒流体**管道焊缝 | **全部**进行射线照相检验，质量不低于**II级** |
| 输送压力 **≥ 0.5MPa** 的可燃/有毒流体管道焊缝 | **抽样**射线照相检验，抽检 **≥ 10%**，质量不低于**III级** |

**其他要求：**
- 管道安装不连续时，用洁净物品对管口进行**封闭处理**
- 传染病医院污染区和半污染区空调机组表冷段冷凝水排水管上应**设水封和阀门**

#### 3.4 高效过滤器安装

- 安装前条件：洁净室内装修工程全部完成，末端过滤器前所有空气过滤器安装完毕，全面清扫擦拭，系统连续试运行 **12h以上**
- 安装时：当场拆开包装，**外层包装不得带入洁净室**，最内层包装必须在**洁净室内**拆开
- 安装前：外观检查（有无破损漏泄），按规范要求**现场扫描检漏**，合格后立即安装
- 安装：**方向应正确**，密封面应严密

#### 3.5 洁净层流罩安装

| 项目 | 要求 |
|------|------|
| 固定方式 | **独立吊杆或支架**，采取防晃动措施 |
| 支撑限制 | **不得**利用生产设备或壁板作为支撑 |
| 减振措施 | 直接安装在吊顶上时，采取减振措施 |
| 密封要求 | 箱体四周与吊顶板之间应密封 |
| 水平度允许偏差 | **1‰** |
| 高度允许偏差 | **1mm** |
| 试运行 | **≥ 1h**，运行正常 |

### 4. 净化空调系统的调试技术

- **调试内容**：单机试车 + 系统联动试运行及调试，检测结果**全部符合设计要求**
- **试运行前**：系统全面清洁，在回风、新风口和粗中效过滤器前设置**临时无纺布过滤器**
- **稳定运行时间**：
  - 电子厂房等工业净化空调：系统正常运行 **24h及以上**
  - 传染病医院净化空调系统：连续运行 **≥ 12h**，环境指标检测在**静态**下进行
- **洁净度检测**：在**空态或静态**下进行，室内人员 **≤ 3人**，穿着洁净工作服

**电子厂房净化空调调试结果要求：**

| 检测项目 | 要求 |
|---------|------|
| 单向流洁净室：总送风量、截面平均风速允许偏差 | **0 ~ +10%** |
| 单向流洁净室：截面风速不均匀度 | **≤ 0.25** |
| 非单向流洁净室：送风量测试结果 | 设计风量的 **±5%** 之内 |
| 非单向流洁净室：各风口风量相对标准偏差 | **≤ 15%** |
| 新风量 | **≥** 设计值，且不得超过设计值的 **10%** |
| 温度、相对湿度 | 偏差值在 **90%以上**测点的精度范围内 |
| 相邻不同级别洁净室之间、洁净室与非洁净室之间静压差 | **≥ 5Pa** |
| 洁净室与室外静压差 | **≥ 10Pa** |
