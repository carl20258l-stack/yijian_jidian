# 第3讲 1.1 非金属及电气材料的分类和应用

> [!summary] 本节要点
> 非金属材料可分为硅酸盐材料、高分子材料和非金属板材/管材三大类；电气材料需掌握导线、电缆、母线槽和绝缘材料的分类、型号含义及适用场景。本节与第1、2讲的金属材料形成完整材料知识体系。

---

## 一、非金属材料的分类及应用（★★）

> 【真题分布】2009单 / 2011单 / 2015单 / 2016单 / 2021多

### 1. 硅酸盐材料的分类及应用

硅酸盐材料是以天然矿物或人工合成的各种硅酸盐化合物为基本原料，经**粉碎、配料、成型和高温烧结**等工序制成的无机非金属固体材料，包括**水泥、保温棉、砌筑材料和陶瓷**等。

#### 1）水泥
水泥是以**硅酸钙**为主要成分的硅酸盐水泥熟料，加入适量**石膏**，**磨细**制成的水硬性胶凝材料。加水搅拌后成浆体，能在空气中硬化或者水中硬化，并能把砂、石等材料牢固地胶结在一起。

#### 2）保温棉
| 常用保温棉种类 | 说明 |
|:---|:---|
| 膨胀珍珠岩类 | 轻质多孔 |
| 离心玻璃棉类 | 玻璃纤维制品 |
| 超细玻璃棉类 | 超细玻璃纤维 |
| 微孔硅酸壳 | 微孔结构 |
| 矿棉类 | 矿物纤维 |
| 岩棉类 | 岩石纤维 |

> 记忆：**棉服保暖**（膨胀珍珠岩、离心玻璃棉、微孔硅酸壳）

#### 3）砌筑材料
按矿物组成分为：**氧化硅质、硅酸铝质、镁质、白云石质、橄榄石质、含碳质、含锆质**耐火材料等。

广泛应用于**钢铁、有色金属、石化、建材、电力**等行业的高温炉窑或高温容器等热工设备的内衬结构，也可作为高温装置中的部件材料。

#### 4）陶瓷
以**黏土**等硅酸盐类矿物为原料，经**粉末处理、成型、烧结**等过程加工而成。具有**坚硬、不燃、不生锈，能承受光照、压力**等优良性能。**硬度很高，但脆性很大**。

| 分类 | 原料 | 举例 |
|:---|:---|:---|
| **普通陶瓷** | 天然硅酸盐矿物（黏土、石英、长石） | 建筑陶瓷、电气绝缘陶瓷、化工陶瓷、多孔陶瓷 |
| **特种陶瓷** | 纯度较高的人工合成化合物 | 氧化铝陶瓷、氮化硅陶瓷、碳化硅陶瓷、氮化硼陶瓷 |
| | （按性能和用途） | 结构陶瓷、功能陶瓷 |

#### 5）特种新型的无机非金属材料

| 分类 | 材料范围 |
|:---|:---|
| 普通非金属材料 | 碳化硅、氧化铝陶瓷，硼酸盐、硫化物玻璃，镁质、铬镁质耐火材料和碳素材料等 |
| 特种新型的无机非金属材料 | 氧化物、氮化物、碳化物、硼化物、硫化物、硅化物以及各种无机非金属化合物经特殊先进工艺制成 |

### 2. 高分子材料的分类及应用（大分子）

高分子材料包括：**塑料、橡胶、纤维、涂料与油漆、粘结剂**。

#### 1）塑料
以合成的或天然的**树脂**作为主要成分，添加辅助材料（**填料、固化剂、增塑剂、稳定剂、防老化剂**），在一定温度、压力下塑制成型。

##### （1）热塑性塑料
以热塑性树脂为主体成分，加工塑化成型后具有链状的**线状分子结构**，受热后又软化，可以**反复塑制成型**。

> 提示：**烯，有火就烧化**（聚乙烯、聚氯乙烯、聚丙烯、聚苯乙烯等含"烯"字的属于热塑性）

| 序号 | 制作材料 | 适用范围 |
|:---:|:---|:---|
| 1 | 低密度聚乙烯 | 软管 |
| 2 | 中、高密度聚乙烯 | 煤气管 |
| 3 | 聚氯乙烯 | 水管 |
| 4 | 耐热性高的氯化聚氯乙烯或聚丁烯 | 热水管 |
| 5 | 泡沫塑料 | 屋顶和外墙隔热保温材料，冷库用得更多 |

##### （2）热固性塑料
以热固性树脂为主体成分，加工固化成型后具有**网状体型结构**，受热后**不再软化**，强热下发生分解破坏，**不可以反复成型**。

> 优点：耐热性高，受压不易变形
> 缺点：机械性能不好（可加填料提高强度）
> 举例：酚醛塑料、环氧塑料

| 分类 | 成型工艺不同 | 特性 | 常见材料 |
|:---|:---|:---|:---|
| **热塑性塑料** | 受热后又软化，可反复塑制成型 | 加工简便，机械性能好；耐热性和刚性差 | 聚乙烯、聚氯乙烯、聚丙烯、聚苯乙烯 |
| **热固性塑料** | 受热后不再软化，强热下分解破坏，不可反复成型 | 耐热性高，受压不易变形；机械性能不好 | 酚醛塑料、环氧塑料 |

【真题-2015】下列塑料中，不属于热塑性塑料的是（   ）。
A. 聚氯乙烯  B. 聚苯乙烯  C. 聚丙烯  D. 环氧塑料
> 【答案】D  【解析】环氧塑料属于热固性塑料。

#### 2）橡胶
橡胶是具有高弹性的高分子材料，由**生胶、配合剂、增强剂**组成。

| 项目 | 天然橡胶 | 合成橡胶 |
|:---|:---|:---|
| 品种 | 天然橡胶 | 氯化橡胶、丁苯橡胶、氯丁橡胶、氯磺化聚乙烯橡胶、丁酯橡胶 |
| 性能 | 强度大、电绝缘性好、不透水、耐碱性能好；**不耐浓酸，能溶于苯、汽油**等溶剂 | — |
| 应用 | 广泛用于制造**胶带、胶管和减振零件** | 用于制造**密封件、衬板、衬里** |

#### 3）纤维
按原材料及生产过程不同，可分为：

| 分类 | 举例 |
|:---|:---|
| **天然纤维** | 棉花、麻、羊毛、蚕丝等 |
| **人造纤维** | 木料、芦苇、棉绒等经制浆提取纤维素，再经化学处理及机械加工 |
| **合成纤维** | — |

#### 4）涂料与油漆
涂料是一种涂覆于固体物质表面并形成连续性薄膜的液态或粉末状态物质。

> 主要功能：**保护**被涂覆物体免受各种作用而发生表面的破坏；具有**装饰**效果，并能**防火、防静电、防辐射**。

#### 5）粘结剂
用来将其他材料粘接在一起的材料，通过**粘附作用**，使同质或异质材料连接在一起。按基料类型分为**天然粘结剂**和**合成粘结剂**。

### 3. 非金属板材和管材的分类及应用

#### 1）非金属板材的分类及应用（★★）

> 【真题】2011单 / 2016单 / 2021多

| 名称 | 适用范围 | 不适用范围 |
|:---|:---|:---|
| 酚醛复合板材 | 低、中压空调系统、潮湿环境 | 高压、洁净空调、酸碱性、防排烟 |
| 聚氨酯复合板材 | 低、中、高压洁净空调系统、潮湿环境 | 酸碱性、防排烟 |
| 有机玻璃钢板材（新增） | 低、中压空调系统及**酸碱性**环境的风管 | 高等级洁净区、防排烟系统、相对湿度95%以上 |
| 无机玻璃钢板材（新增） | 低、中压空调系统及**防排烟**系统的风管 | 高等级洁净区、酸碱性环境、相对湿度80%以上 |
| 硬聚氯乙烯板材 | 洁净室含酸碱的**排风系统** | — |

> 记忆：**无烟**（无机玻璃钢 = 防排烟）

【真题-2016】下列非金属风管材料中，适用于酸碱性环境的是（   ）。
A. 聚氨酯复合板材  B. 酚醛复合板材  C. 硬聚氯乙烯板材  D. 玻璃纤维复合板材
> 【答案】C  【解析】硬聚氯乙烯风管适用于洁净室含酸碱的排风系统。

#### 2）非金属管材的分类及应用

| 序号 | 水管名称 | 适用范围 |
|:---:|:---|:---|
| 1 | 聚乙烯管（PE管） | 无毒，可用于输送**生活用水** |
| 2 | 聚丙烯管（PP管） | 刚性、强度、硬度、弹性均高于聚乙烯；**耐低温性差、易老化**，常用于**流体输送** |
| 3 | 硬聚氯乙烯管（PVC-U管） | 建筑工程**排水**、工业废气**排污排毒**塔、气体液体输送等 |
| 4 | 铝塑复合管（PAP管） | 内塑料层用中密度聚乙烯→**饮水管**（无毒无味无污染）；内塑料层用交联聚乙烯→**耐高温耐高压**，适用于供暖及高压用管 |

## 二、电气材料的分类及应用（★）

> 【真题分布】2017单 / 2020单

### 1. 导线的分类及应用

#### 1）裸导线
无绝缘层，散热好，可输送较大电流。常用有**圆单线、裸绞线和型线**等。

##### （1）裸绞线
主要用于**架空线路**，具有良好的导电性能和足够的机械强度。

| 类型 | 用途 |
|:---|:---|
| 铝绞线 | 短距离电力线路 |
| 钢芯铝绞线 | 各种电压等级的**长距离输电线路**，抗拉强度大 |

##### （2）型线
| 类型 | 用途 |
|:---|:---|
| 矩形硬铜母线（TMY型） | 变配电系统汇流排装置、车间低压架空母线 |
| 硬铝母线（LMY型） | 变配电系统汇流排装置、车间低压架空母线 |
| 扁钢 | 接地线和接闪线 |

> 规格示例：TMY-100×10 表示硬铜母线，宽100mm、厚10mm；常用扁钢规格有25×4、40×4等。

#### 2）绝缘导线
按绝缘层材料：**聚氯乙烯绝缘导线、橡皮绝缘导线**等。建筑工程中多采用**聚氯乙烯绝缘铜导线**。

### 2. 电缆的分类及应用

| 分类方式 | 类别 |
|:---|:---|
| 按用途 | 电力电缆、通信电缆、控制电缆、信号电缆 |
| 按绝缘材料 | 纸绝缘电缆、橡胶绝缘电缆、塑料绝缘电缆 |
| 特殊性能 | 阻燃电缆、耐火电缆 |

> 电缆结构三部分：**线芯、绝缘层、保护层**（保护层又分内保护层和外保护层）

#### 1）电力电缆
用于传输和分配电能，工作电流几十安至几千安，额定电压220V~500kV及以上。

| 类型 | 关键特性 |
|:---|:---|
| 塑料绝缘电力电缆 | 应用最广泛的是**交联聚乙烯绝缘电力电缆** |
| 阻燃电缆 | 残焰或残灼在限定时间内能**自行熄灭** |
| 耐火电缆 | 火焰燃烧下能**保持一定时间安全运行** |
| 氧化镁电缆 | 防火性能特佳，但贵、工艺复杂、不适合潮湿环境 |
| 分支电缆 | — |
| 铝合金电缆 | — |

##### 耐火电缆（★★★）

| 类别 | 火焰温度 | 持续供电时间 |
|:---|:---:|:---:|
| A类 | 950~1000℃ | 90min |
| B类 | 750~800℃ | 90min |

> 应用场景：高层建筑、地铁、地下商场、大型电站及重要工矿企业
> 
> **A类首选**：电缆密集的电缆隧道、电缆夹层中，或位于油管、油库附近等易燃场所
> 
> **B类可用**：除上述情况外且电缆配置数量少时

##### 氧化镁电缆
由**铜芯、铜护套、氧化镁绝缘材料**加工而成。

| 优点 | 缺点 |
|:---|:---|
| 防火性能特佳（铜熔点1038°C，氧化镁熔点2800°C） | 价格贵 |
| 耐高温（长期工作温度达250°C） | 工艺复杂 |
| 防爆、载流量大 | **不适合潮湿环境（新增）** |
| 机械强度高、寿命长、接地性能良好 | 施工难度大 |

> 适用场合：油罐区、重要木结构公共建筑、高温场所等耐火要求高的场合

#### 2）控制电缆 —— 型号含 **K**
用于电气控制系统和配电装置的**二次系统**。芯线截面通常在10mm²以下，线芯多采用**铜导体**，芯线组合有**同心式和对绞式**。

#### 3）电缆型号含义（★★★）

| 位置 | 含义 | 常见代号 |
|:---:|:---|:---|
| 第1位 | 性能特征 | NH-耐火、ZR-阻燃、F-辐照 |
| 类别 | 电缆用途 | Z-纸、K-控制、Y-仪表 |
| 绝缘材料 | 绝缘层材质 | X-橡胶、V-聚氯乙烯、Y-聚乙烯、YJ-交联聚乙烯 |
| 线芯 | 导体材质 | T-铜（省略）、L-铝 |
| 内护层 | 内保护层材质 | Q-铅护层、L-铝护层、V-聚氯乙烯、Y-聚乙烯 |
| 其他特征 | 特殊结构 | P-屏蔽 |
| 外护层（第1个数字） | 铠装类型 | **2**-双钢带（只受压不受拉）；**3**-细圆钢丝（可受压受拉）；**4**-粗圆钢丝（可受压受拉） |
| 外护层（第2个数字） | 护层类型 | 0-没有、1-纤维护层、2-聚氯乙烯护层、3-聚乙烯护层 |

> 关键：第一个数字是 **2** → **钢带铠装**，只能受压，不能受拉；第一个数字是 **3或大于3** → **钢丝铠装**，可受压也可受拉。

### 3. 母线槽的分类及应用

母线槽由金属外壳（钢板或铝板）、导电排、绝缘材料及有关附件组成。具有**体积小、容量大、装拆方便、安全可靠、使用寿命长**等优点，适用于**高层建筑、标准厂房**等场所。

#### 1）母线槽的分类

| 序号 | 分类 | 应用与特点 |
|:---:|:---|:---|
| 1 | **空气型母线槽** | 接头之间体积过大，占用空间大，应用较少。**因存在烟囱效应，不能用于垂直安装**。 |
| 2 | **紧密型母线槽** | **体积小、结构紧凑、运行可靠、传输电流大、便于分接馈电、维护方便**。可用于树干式供电系统，高层建筑广泛应用。 |
| 3 | **高强度母线槽** | 外壳做成**瓦沟形式**，机械强度增加，解决了**大跨度安装无法支撑吊装**的问题。 |
| 4 | **耐火型母线槽** | 外壳防火材料耐高温不低于**1100℃**；隔热层绝缘材料耐高温不低于**300℃**；耐火时间60/90/120/180min，满负荷运行可达**8h以上**。 |
| 5 | **树脂浇注母线槽**（新增） | 采用环氧树脂全封闭浇注工艺，防护等级高达**IP68**，具有**防水、阻燃、耐腐蚀**特性。适用于潮湿、多尘、高防火要求的工业与民用场景（如化工、地铁、数据中心）。缺点：散热性较差、成本高。 |

> **外壳防护等级 IP**
> - 第一个数字：对固体及人体触电、触及运动部件的防护等级
> - 第二个数字：对液体的防护等级
> - 数字越大，防护等级越高（如IP68 > IP40）

#### 2）母线槽应用要点（★★★）

| 场景 | 选用要求 |
|:---|:---|
| 高层建筑**垂直输配电** | 应选用**紧密型母线槽**，导体用长期工作温度≥**130℃**的阻燃材料包覆。楼层之间应设**阻火隔断**。 |
| **应急电源** | 应选用**耐火型母线槽** |
| 一般室内正常环境 | 防护等级 **IP40** |
| 消防喷淋区域 | 防护等级 **IP54 或 IP66** |
| 有显著摇动和冲击振动的设备 | 不能直接连接，应采用**软接头**加以连接 |

### 4. 绝缘材料的分类及应用

| 分类 | 要点 |
|:---|:---|
| **绝缘漆** | — |
| **绝缘胶** | — |
| **绝缘气体** | 除绝缘材料外，还具有**灭弧、冷却和保护**等作用。常用：空气、氮气、二氧化硫和**六氟化硫（SF₆）** |
| **绝缘油** | 变压器油、断路器油、电容器油、电缆油 |
| **绝缘制品** | 云母制品、层压制品 |

> 记忆（绝缘气体四天王）：**灭绝保冷、空榴弹**（灭弧、冷却、保护；空气、六氟化硫、氮气...取"空榴"谐音）

【真题-2017】SF₆断路器的灭弧介质和绝缘介质分别是（   ）。
A. 气体和液体  B. 气体和气体  C. 液体和液体  D. 液体和真空
> 【答案】B  【解析】气体除可作为绝缘材料外，还具有灭弧、冷却和保护等作用，常用气体绝缘材料有空气、氮气、二氧化硫和六氟化硫（SF₆）等。
