## 通用设备概述

机电工程项目通用机械设备是指 **通用性强、用途较广泛** 的机械设备，常用的主要有：**泵、风机、压缩机、输送设备**等。

```
常用的通用工程设备：泵 → 风机 → 压缩机 → 连续输送设备
```

---

## 一、泵

### 1. 泵的类型

| 分类依据 | 类别 | 组成 |
|---------|------|------|
| 工作原理结构形式 | **容积式泵** | 往复泵：活塞泵、柱塞泵、隔膜泵 |
| | | 回转泵：齿轮泵、螺杆泵、叶片泵 |
| | **叶轮式泵** | 离心泵、轴流泵、混流泵、旋涡泵 |
| 泵轴位置 | 立式泵、卧式泵 | |
| 吸口数目 | 单吸泵、双吸泵 | |
| 驱动泵的原动机 | 电动泵、汽轮机泵、柴油机泵、气动隔膜泵 | |

> **重点分类**：按工作原理分为 **容积式泵**（往复泵 + 回转泵）和 **叶轮式泵**（离心/轴流/混流/旋涡）

### 2. 泵的性能参数 ★★★

**泵的性能参数**：主要有 **流量** 和 **扬程**，还有功率、转速、效率 和 **汽蚀余量**。

> 例如：一幢 30 层的高层建筑，其消防水泵的扬程在 130m 以上。

> **记忆：小刘 气 杨工拽** → 小(效率) 刘(流量) 气(汽蚀余量) 杨(扬程) 工(功率) 拽(转速)

## 二、风机

### 1. 风机的类型

| 分类依据 | 类别 |
|---------|------|
| 风机设备安装工程类别 | 离心式通风机、离心式引风机、轴流通风机、回转式鼓风机、离心式鼓风机 |
| 气体在旋转叶轮内部流动方向 ★ | **离心式风机、轴流式风机、混流式风机** |
| 结构形式 | 单级风机、多级风机 |
| 排气压强的不同 | 通风机、鼓风机、压气机 |

> **记忆（按气体流动方向分类）：周离婚** → 周(轴流式) 离(离心式) 婚(混流式)

| 类型 | 气流方向 |
|------|---------|
| 离心式风机 | 径向 |
| 轴流式风机 | 轴向 |
| 混流式风机 | 轴向 + 径向 |

### 2. 风机的性能参数 ★★★

**风机的性能参数**：主要有 **流量、压力、功率、效率 和 转速**，另外，**噪声 和 振动** 的大小也是风机的指标。

---

## 三、压缩机

> 压缩机的功能：**压缩和输送制冷剂蒸汽**

### 1. 压缩机的类型

| 分类依据 | 类别 |
|---------|------|
| 压缩机设备安装工程类别 | 活塞式压缩机、回转式螺杆压缩机、离心式压缩机 |
| 压缩的气体不同 | 空气压缩机、氧气压缩机、氨压缩机、天然气压缩机 |
| 压缩气体方式 ★ | **容积式** — 往复式（活塞式、膜式）/ 回转式（滑片式、螺杆式、转子式） |
| | **动力式** — 离心式、轴流式、混流式 |
| 压缩次数 | 单级压缩机、两级压缩机、多级压缩机 |
| 气缸的布置方式 | W型、扇形、M型、H型压缩机 |
| 气缸的排列方法 | 串联式、并列式、复式、对称平衡式 |
| 排气最终压力 | 低压、中压、高压、超高压压缩机 |

### 2. 压缩机的性能参数 ★★★

**压缩机的性能参数**：主要包括 **容积、流量、吸气压力、排气压力、工作效率、输入功率、输出功率、性能系数** 等。

## 四、泵、风机、压缩机性能参数对比（★核心考点★）

| 序号 | 设备 | 介质 | 一般工作参数 | 相似参数 | 最有特性的工作参数 |
|:----:|:----:|:----:|:-----------:|:--------:|:----------------:|
| 1 | **泵** | 流体 | 流量、效率 | 功率、转速 | **扬程、汽蚀余量** |
| 2 | **风机** | 气体 | 流量、效率 | 功率、转速、噪声 | **压力、振动** |
| 3 | **压缩机** | 气体 | 流量、工作效率 | 吸气压力、排气压力、输入功率、输出功率 | **容积、性能系数** |

> **记忆策略**：重点记忆各设备的 **最有特性的工作参数**
> - 泵 → 扬程、汽蚀余量（"泵送液体看扬程"）
> - 风机 → 压力、振动（"风机吹风有压力，噪音振动一起测"）
> - 压缩机 → 容积、性能系数（"压缩机压容积"）

## 五、输送设备

### 1. 输送设备的类型

输送设备通常按 **有无牵引件（链、绳、带）** 分类：

**(1) 有挠性牵引件的输送设备**

| 设备类型 | 说明 |
|---------|------|
| 带式输送机 | ★ 常见 |
| 链板输送机 | |
| 刮板输送机 | |
| 埋刮板输送机 | |
| 小车输送机 | |
| 悬挂输送机 | |
| 斗式提升机 | |
| 气力输送设备 | |

**(2) 无挠性牵引件的输送设备**

| 设备类型 |
|---------|
| 螺旋输送机 |
| 辊子输送机 |
| 振动输送机 |
| 气力输送机 |

> **记忆（无挠性牵引件）：真无脑，萝莉滚** → 真(振动输送机) 无(无挠性牵引件) 脑 — 萝(螺旋输送机) 莉(气力输送机) 滚(辊子输送机)

> 说明："真无脑"谐音指"振动输送机、无挠性牵引件"；"萝莉滚"指螺旋、气力、辊子三种。

### 2. 输送设备的性能

**主要参数**：
- 输送能力和线路布置（水平运距、提升高度等）
- 输送速度和驱动功率
- 主要工作部件的特征尺寸

**性能特点**：
- 只能沿着一定路线向一个方向连续输送物料
- 可进行水平、倾斜和垂直输送
- 也可组成空间输送线路

## 真题链接

### 【例题·单选】2012

下列参数中，属于风机的主要性能参数是（ ）。

A. 流量、压力、转速  
B. 流量、吸气压力、转速  
C. 功率、吸气压力、比转速  
D. 功率、扬程、转速  

**【答案】A**  
**【解析】** 考查风机的性能参数。主要有流量、压力、功率、效率和转速，另外，噪声和振动的大小也是风机的指标。

### 【例题·多选】2021

下列输送机中，具有挠性牵引件的有（ ）。

A. 带式输送机  
B. 刮板输送机  
C. 悬挂输送机  
D. 小车输送机  
E. 螺旋输送机  

**【答案】ABCD**  
**【解析】** 有挠性牵引件的输送设备类型：带式输送机、链板输送机、刮板输送机、埋刮板输送机、小车输送机、悬挂输送机、斗式提升机、气力输送设备等。螺旋输送机属于无挠性牵引件。
