# 第2讲 1.1 金属材料的分类及应用（2）

> [!summary] 本节要点
> 有色金属的分类与特性（铝、铜、钛、锌及其合金）以及常用金属复合材料（金属基、层状、非金属复合）的分类与应用。有色金属是每年高频考点，重点掌握分类标准、典型材料特性及应用场景。

---

## 一、有色金属材料的分类及应用 ★★★

### 1. 有色金属的定义与分类

> **有色金属**：是铁、锰、铬**以外**的所有金属的统称。

| 序号 | 分类 | 判断标准 | 举例 |
|:---:|:----|:---------|:-----|
| 1 | **轻金属** | 密度 ≤ 4500 kg/m³ | 铝、镁、钾、钠、**钙** |
| 2 | **重金属** | 密度 > 4500 kg/m³ | 铜、镍、铅、锌、锡、锑、汞 |
| 3 | **贵金属** | 价格昂贵、地壳含量低、提纯困难、化学性质稳定 | 金、银、**铂** |
| 4 | **稀有金属** | 稀有轻金属 | 锂、铯 |
| | | 稀有难熔金属 | 钛、钼、钨 |
| | | 稀有分散金属 | 镓、铟、锗 |
| | | 稀土金属 | 钪、钇、镧 |
| | | 放射性金属 | 镭、铀、钍 |

> 记忆：轻金属=密度小；重金属=密度大；贵金属=贵+稳定；稀有金属分五小类（轻/难熔/分散/稀土/放射）

### 2. 有色合金 ★★

**定义**：以一种有色金属为基体（通常 > **50%**），加入一种或多种其他元素的合金。

**常见有色合金**：铝合金、铜合金、钛合金、锌合金、镁合金、镍合金、钼合金等。

**性能特点**（与纯金属对比）：
- ★ 强度和硬度**更高**
- ★ 电阻**更大**、电阻温度系数**更小**
- 具有良好的综合性能

> 记忆：有色合金 = 强度硬度↑ + 电阻↑ + 电阻温度系数↓

## 二、铝及铝合金 ★★★

### 铝 vs 铝合金对比

| 对比维度 | 铝（纯铝） | 铝合金 |
|:--------|:----------|:-------|
| 外观/基础属性 | 银白色轻金属；20℃密度 **2.698 g/cm³**；熔点 **660.24℃** | 以铝为基体添加合金元素；**铝镁合金**含镁约 **3%~10%** |
| 性能特点 | 化学性质活泼；**塑性好，强度低** | 铝镁合金：密度小、强度高、抗震力强、散热性好、抗电磁干扰好、绿色环保 |
| 加工特性 | 适用于**冷加工成型**（轧制、挤压、模锻、冷冲、弯曲），可加工成**形状复杂**的构件 | — |
| 应用领域 | 建筑、机械制造、电子产品、**传输导线** | 电子电气、**航空航天**、汽车制造、建筑材料 |

> 记忆：纯铝 = 塑性好强度低；铝镁合金 = 密度小强度高，抗震抗干扰散热好

**【真题】** 铝作为传输导线广泛应用于电力行业（常见考点：有色金属的应用场景）。

---

## 三、铜及铜合金 ★★★

### 1. 铜（纯铜）

基础材料，不做展开。

### 2. 铜合金（三种核心类型）★★★

| 分类 | 主要添加元素 | 特点 | 应用 |
|:----|:----------|:----|:-----|
| **黄铜** | **锌** | 质软、**耐磨性能强**；可拉成无缝铜管 | 热交换器、冷凝器、低温管路；板材、条材、棒材、管材 |
| **白铜** | **镍** | 结构白铜：机械性能好、耐蚀性好、色泽美观 | 精密机械、化工机械 |
| | | 电工白铜：良好的**热电性能** | 精密电工仪器、变阻器、精密电阻、**应变片、热电偶** |
| **青铜** | **锡** | 锡青铜：**铸造性能、减摩性能、机械性能**好 | 轴承、蜗轮、齿轮 |
| | | 铅青铜：发动机和磨床广泛使用的**轴承材料** | 现代发动机、磨床轴承 |
| | | 铝青铜：强度高，**耐磨性和耐蚀性好** | 高载荷齿轮、轴套 |
| | | 铍青铜：**弹性极限高，导电性好** | **精密弹簧和电接触元件** |

> 记忆口诀：**黄铜加锌白铜镍，青铜加锡要牢记**；黄铜耐磨管材好，白铜精密加热电，青铜多样各有所长

---

## 四、钛及钛合金 ★★★（太空金属）

### 钛 vs 钛合金对比

| 对比维度 | 钛 | 钛合金 |
|:--------|:--|:-------|
| 外观特征 | 银白色金属，有金属光泽 | — |
| 核心特性 | 重量轻、**强度高**、耐湿氯气腐蚀；**比强度在金属中排名第一** ★ | 密度低、**比强度大**、耐腐蚀性能好、使用性能好 |
| 密度 | 4.54 g/cm³，比钢轻 **43%**，高于铝，低于钢、铜和镍 | 约 4.51 g/cm³，为钢密度的 **60%** |

> ★ 比强度第一 —— 钛及其合金的最大标签，高频考点

**钛合金应用场景**：
- 石化：工作温度低于 **350℃** 的换热器、反应器
- 船舶：船舶部件
- 航天：飞机蒙皮、理想的航天工程结构材料

---

## 五、锌的特性及应用 ★★

### 锌的基本特性
- 具有良好的**压延性、耐磨性、抗腐蚀性、铸造性**
- 有很好的**常温机械性**
- 能与多种金属制成性能优良的合金

### 主要应用形式
| 应用形式 | 说明 |
|:--------|:----|
| 镀锌 | 表面镀一层锌→美观、防锈；主要采用**热镀锌**方法，用于钢材和钢结构件表面镀层 |
| 锌基合金 | 与其他金属制成合金 |
| 氧化锌 | 化工应用 |

**应用行业**：建筑、轻工、机械等

> ★ 高频考点：镀锌的防锈作用 + 热镀锌是主要方法

## 六、常用金属复合材料的分类及应用 ★★★

### 1. 金属基复合材料 ★★
- **定义**：由两种及以上不同性质的材料，通过物理或化学方法组成的新材料
- **性能特点**：**高比强度、高比模量、尺寸稳定性、耐热性**
- **应用**：航天、航空、汽车、电子等高性能结构件

### 2. 金属层状复合材料 ★★
- **工艺**：几层不同性能的材料通过**热轧、焊接**工艺复合而成
- **特点**：综合性能优越，适合特殊工作环境
- **常见类型**：钛钢、铝钢、铜钢、钛不锈钢、镍不锈钢

### 3. 金属与非金属复合材料 ★★★

| 对比维度 | **钢塑复合管** | **铝塑复合管** |
|:--------|:-------------|:--------------|
| 性能特点 | 钢管强度+刚度 + 塑料管耐化学腐蚀；无污染、不混生细菌、内壁光滑、不积垢、水阻小、施工方便、成本低 | 与金属管材相当的强度；**电屏蔽和磁屏蔽**作用；隔热保温好、重量轻、寿命长、施工方便、成本低 |
| 应用领域 | 石油、化工、建筑、通信、电力和**地下输气管道** | 建筑、工业等机电工程 |

> ★★ 钢塑复合管 vs 铝塑复合管是选择题高频考点，注意区分各自的应用场景

## 七、经典真题

**【例题·单选】机电工程常用的黑色金属是（   ）。【2012】**
A. 铝
B. 铸铁
C. 紫铜
D. 钛合金

> **【答案】 B**
> 【解析】 A（铝）、C（紫铜=纯铜）、D（钛合金）均为有色金属；铸铁属于黑色金属（铁基）。

---

## 关键记忆

- **有色金属分类**：轻金属(≤4500) vs 重金属(>4500) vs 贵金属 vs 稀有金属（五小类）
- **有色合金特点**：强度↑ 硬度↑ 电阻↑ 电阻温度系数↓ （与纯金属对比）
- **铝镁合金**：密度小、强度高、抗震强、散热好、抗电磁干扰好
- **黄铜=锌**，**白铜=镍**，**青铜=锡**
- **钛的标签**：比强度金属中排名第一 ★
- **镀锌**：热镀锌为主，美观防锈
- **复合材料三类型**：金属基、层状金属、金属与非金属复合
- **钢塑复合管适用**：石油化工通信电力地下输气；**铝塑复合管**：电屏蔽磁屏蔽
