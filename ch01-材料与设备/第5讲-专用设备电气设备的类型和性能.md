# 1.2 专用设备、电气设备的类型和性能

> [!SUMMARY] 本讲概览
> **考点：专用设备的类型和性能（★）**——电力工程设备（火/核/风/光/光热）、石油化工设备（按压力分类+性能参数）、冶炼设备（冶金+建材）
>
> **考点：电气设备的类型和性能（★）**——发电设备、变电设备、配电设备、电动机、控制设备、电力电子设备
>
> **真题统计：** 专用设备（2018单/2022多/2024单）| 电气设备（2007单/2019单）

---

## 一、专用设备的类型和性能（★）

【真题分布：2018单/2022多/2024单】

### 1. 电力工程设备

#### 1）火力发电设备

主要由 **锅炉、汽轮机、汽轮发电机** 等设备组成。

##### （1）锅炉的类型

| 分类依据 | 类型 |
|---------|------|
| 特种设备目录分 | 承压蒸汽锅炉、承压热水锅炉、有机热载体锅炉 |
| 用途分类 | 电站锅炉、工业锅炉、船用锅炉等 |
| 锅炉出口工质压力 | 低压→中压→高压→超高压→亚临界压力→超临界压力→**超超临界**压力（22MPa，374℃） |
| 所用燃料 | 固体燃料锅炉、液体燃料锅炉、气体燃料锅炉、余热锅炉等 |

##### （2）锅炉的主要性能参数

① 蒸发量（t/h）
② 压力（MPa）
③ 温度（℃）
④ 锅炉受热面**蒸发率**（kg/(m²·h)）
⑤ 锅炉受热面**发热率**（kJ/(m²·h)）
⑥ 锅炉热效率（η）

##### （3）汽轮机的类型

| 分类依据 | 类型 |
|---------|------|
| 工作原理 | 冲动式、反动式、**冲动+反动联合式** |
| 热力过程 | 凝汽式、背压式、抽气式、抽气背压式、中间再热式 |
| 蒸汽压力 | 低压→中压→高压→超高压→亚临界→超临界→**超超临界**（22MPa，374℃） |
| 蒸汽流动方向 | 轴流式、辐流式 |

> 记忆：工作原理分类 → **反冲动**（反动式+冲动式）

##### （4）汽轮机的性能参数

功率（MW）、主汽压力（MPa）、主汽温度（℃）、进气量（t/h）、排气压力（MPa）、汽耗（kg/kWh）、转速（r/min）

##### （5）汽轮发电机的组成

发电机由 **定子** 和 **转子** 两部分组成：

| 部分 | 组成 |
|-----|------|
| 定子 | 机座、定子铁芯、定子绕组、端盖 |
| 转子 | 转子锻件、励磁绕组、护环、中心环、风扇 |

> 记忆：**定子** → **绕铁盖坐定**（绕组+铁芯+端盖+机座+定子）
> 记忆：**转子** → **锻励护中扇**（锻件+励磁绕组+护环+中心环+风扇）

##### （6）汽轮发电机的性能参数

额定容量、额定转速、极数、额定频率、功率因数、额定电流、效率、励磁电压、励磁电流、绕组接法

---

#### 2）核能发电设备

三类核心设备：

| 分类 | 包括 | 作用 |
|-----|------|------|
| **核岛设备** | 反应堆堆芯、燃料转运装置、反应堆压力容器、堆内构件、控制棒驱动机构、蒸汽发生器、主泵、主管道、安注箱、硼注箱、稳压器等 | **热核反应**的主要部分 |
| **常规岛设备** | 汽轮机、发电机、除氧器、凝汽器、汽水分离再热器、高低压加热器、主给水泵、凝结水泵、主变压器、循环水泵等 | — |
| **辅助系统设备** | 化学制水、制氧、压缩空气站等 | 核蒸汽供应系统之外的部分 |

---

#### 3）风力发电设备

##### （1）风力发电机组的组成

★ **两类对比（真题高频）**

| 特性 | 直驱式风电机组 | 双馈式风电机组 |
|------|--------------|--------------|
| 齿轮箱 | **无**（取消了齿轮变速系统） | **有**（变速箱） |
| 发电机位置 | 机舱与轮毂之间（大容量永磁同步发电机） | 机舱内集成 |
| 结构 | 简单 | — |
| 可靠性 | 强 | 故障率低（变速变桨运行） |
| 效率 | 高 | — |
| 维护成本 | 低 | — |
| 维修难度 | **不易维修**（永磁材料易失磁，只能返厂） | 较易 |

> **直驱式** 组成：塔筒 + 机舱总成 + 发电机 + 叶轮总成 + 测风系统 + 电控系统 + 防雷保护系统
>
> **双馈式** 组成：塔筒 + 机舱 + 叶轮；机舱内集成了发电机系统、齿轮变速系统、制动系统、偏航系统、冷却系统

**【真题】直驱式风力发电系统的组成不包括（ ）。【2018单】**
A. 塔筒 B. 机舱总成 C. **变速箱** D. 测风系统
→ 答案：C（直驱式无变速箱/齿轮变速系统）

**【真题】直驱式风力发电包括以下（ ）。【2022多】**
A. **测风系统** B. 齿轮变速 C. **叶轮总成** D. **电控系统** E. **防雷装置**
→ 答案：ACDE

**【真题】下列发电系统中，不包含汽轮机设备的是（ ）。【2024单】**
A. 火力发电系统 B. **风力发电系统** C. 核能发电系统 D. 光热发电系统
→ 答案：B

##### （2）风力发电机组的性能参数

★ **最重要的参数：额定功率 和 叶轮直径**

| 场景 | 主流机型 |
|------|---------|
| 陆上风电场 | 1.5MW、2.0MW、3.0MW |
| 海上风场 | 4.0MW 以上 |

### 2. 石油化工设备

#### 1）石油化工设备的类型及性能

##### （1）按设计压力分类（★★）

| 分类 | 设计压力 |
|------|---------|
| 常压设备 | P < 0.1MPa |
| 低压设备 | 0.1MPa ≤ P < 1.6MPa |
| 中压设备 | 1.6MPa ≤ P < 10MPa |
| 高压设备 | 10MPa ≤ P < 100MPa |
| 超高压设备 | P ≥ 100MPa |
| 真空设备 | P < 0 |

##### （2）按生产工艺原理分

容器、反应器、塔设备、换热器、储罐

##### （3）石油化工设备的性能

**性能：** 贮存、均压、热交换、反应、分离、过滤；气体压缩、粉碎、混合、分离、成型等

> 记忆：**朱军搅份饭锅**（贮存+均压+交换+反应+粉碎+过滤+…实际为辅助记忆谐音，需结合上下文理解）

**主要性能参数：** 容积、压力、温度、流量、液位、换热面积、效率

## 二、电气设备的类型和性能（★）

【真题分布：2007单/2019单】

> 电气设备定义：用于电力传输、分配、受电、控制和保护的设备。常用的有发电设备、变电设备、配电设备、电动机、控制设备和电力电子设备。

### 1. 发电设备

建筑机电工程中常用 **柴油发电机组** 作为应急或备用电源（小型发电设备）。

**性能参数：** 功率输出、电压、频率、电流、冷却量及冷却方式、燃烧空气量、排风量、允许排气背压

---

### 2. 变电设备

> 定义：将高压电能转换为低压，或将交流电能转换为直流的设备，包括变压器、整流器、逆变器等。

#### 1）变压器的类型

| 分类依据 | 类型 |
|---------|------|
| 用途 | 电力变压器、电炉变压器、整流变压器、工频试验变压器、矿用变压器、电抗器、调压变压器、互感器、其他特种变压器 |
| 相数 | 单相变压器、三相变压器 |
| 绕组数量 | 双绕组变压器、三绕组变压器、自耦变压器 |
| 冷却介质 | 油浸式变压器、干式变压器、充气式变压器等 |
| 容量 | 中小型、大型、特大型 |

**【真题】下列变压器中，不属于按用途分类的是（ ）。【2019二级】**
A. 电力变压器 B. **油浸变压器** C. 整流变压器 D. 量测变压器
→ 答案：B（油浸式是按冷却介质分类）

#### 2）变压器的主要技术参数

额定容量、工作频率、额定电压、电压比、效率、空载电流、空载损耗

---

### 3. 配电设备（新增）

#### 1）柜体

##### （1）开关柜

| 分类依据 | 类型 |
|---------|------|
| 布置形式 | 金属铠装式、间隔式、箱式 |
| 安装方式 | 固定式、中置式、手车式 |

**技术参数：** 额定电压、额定电流、额定频率、工频耐受电压、雷电冲击耐受电压

##### （2）配电柜

| 分类依据 | 类型 |
|---------|------|
| 电压不同 | 高压配电柜、低压配电柜 |
| 设备的结构特征 | 固定式、抽屉式、组合式 |
| 配电用途 | 动力配电箱、照明配电箱、计量配电箱、应急配电箱 |

**技术参数：** 额定电流、额定电压、短路承受能力、防护等级

#### 2）开关设备（★★★ 记忆难点）

| 开关类型 | 核心特点 | 分类 | 关键技术参数 |
|---------|---------|------|------------|
| **断路器** | **能负荷 + 能自动**：能带负荷分合电路；过载/短路时**能自动跳闸**，保护设备和人身安全 | 按结构：微型式、模壳式、框架式、罐式等<br>按灭弧介质：空气、真空、SF6、油 | 额定电流、额定电压、脱扣器整定电流、最大短路电流、操作特性 |
| **负荷开关** | **能负荷 + 不自动**：能带负荷分合电路；过载/短路时**不会自动跳闸**；需配合熔断器 | 按电压等级：低压、高压<br>按操作方式：手动、电动 | 额定电压、额定电流、操作方式 |
| **隔离开关** | **不负荷 + 不自动**：不能带负荷分合；不能自动跳闸；分闸时有**明显断开点** | 按绝缘支柱：单柱式、双柱式、多柱式<br>按运行方式：水平旋转式、垂直旋转式、插入式 | 额定电压、额定电流、接通能力、断开能力 |

> 记忆口诀：**断路器**（能负荷能自动）、**负荷开关**（能负荷不自动）、**隔离开关**（不负荷不自动+明显断开点）

**灭弧介质补充：**
- 真空断路器：高真空作绝缘和灭弧介质
- 六氟化硫（SF6）断路器：六氟化硫气体作灭弧和绝缘介质
- 油断路器：密封的绝缘油作灭弧介质

### 4. 电动机

★ 四种电动机对比（重点）

| 类型 | 性能特点 | 典型应用 |
|-----|---------|---------|
| **直流电动机** | 较大**启动转矩**、良好启/制动性能、宽范围平滑调速、较强过载性能 | 机床、轧钢机、电力机车、需频繁启动调速的电气传动装置 |
| **交流异步电动机** | **使用最广泛**；结构简单、制造容易、价格低廉、运行可靠、维护方便、坚固耐用、重量轻 | 现代生产和生活 |
| **交流同步电动机** | 转速与电源频率**保持严格同步**；电源频率恒定则转速绝对不变 | — |
| **伺服电动机** | 可控性好、反应迅速；通过反馈系统实时调整输出力矩和转速，实现精确运行控制 | 机械制造、自动化设备、机器人、自动控制系统、计算机外围设备 |

> 两个区分维度：
> 1. 工作电源 → **直流 / 交流**
> 2. 转子转速与旋转磁场速度关系 → **同步 / 异步**

---

### 5. 控制设备

> 定义：用于控制电力系统运行的设备，包括自动化控制系统、保护装置、监测仪表等，是电力系统中的"大脑和神经系统"

| 分类 | 基本参数 / 性能特点 |
|-----|-------------------|
| **接触器** | 主触点额定电流、主触点允许切断电流、触点数、线圈电压、操作频率、机械寿命、电寿命 |
| **继电器** | 工作电压、接触电阻、机械寿命、电气寿命、过载能力、动作特性、接点负载能力、响应速度；用于控制电路开关动作，实现远程控制和保护 |
| **互感器** | 将**高电压、大电流**变换成**低电压、小电流**；与测量仪表配合测电压/电流/电能；与控制设备配合确保操作人员和设备安全 |
| **电抗器** | 依靠线圈感抗阻碍电流变化；保证断路器切断短路电路；保证电气设备动/热稳定性；通过提高阻抗限制短路电流 |

---

### 6. 电力电子设备

> 定义：用于电力系统中电能的调节、变换和控制的设备

**性能特点：** 工作频率、效率、响应速度、谐波抑制能力、功率因数调节范围

**四类核心设备：**

| 分类 | 作用 | 组成 |
|-----|------|------|
| **变频器** | 改变交流电源频率，调整电动机运行速度，实现**无级调速** | 整流单元 + 滤波单元 + 逆变单元 + 控制单元 |
| **逆变器** | 将**直流电 → 交流电** | 逆变电路 + 逻辑控制电路 + 滤波电路 |
| **整流器** | 将**交流电 → 直流电** | 二极管整流器、晶闸管整流器等 |
| **软启动器** | 电动机不调速拖动控制中的**拖动设备** | 电子式（晶闸管调压式）、磁控式、自动液体电阻式 |

> 记忆：**变频调速度**、**逆变直变交**、**整流交变直**、**软启不调速**
