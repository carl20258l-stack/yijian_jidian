## 5.3.1 特种设备的分类（★★）

### 一、特种设备的定义

特种设备是指对人身和财产安全有较大危险性的设备，包括：

> **锅炉、压力容器（含气瓶）、压力管道、电梯、起重机械、客运索道、大型游乐设施、场（厂）内专用机动车辆**，以及法律、行政法规规定适用《中华人民共和国特种设备安全法》的其他特种设备。

### 二、各类特种设备的判定参数

#### 1. 锅炉（三条件之一）

| 类型 | 判定条件 | 记忆口诀 |
|------|----------|:--------:|
| 承压蒸汽锅炉 | 容积 **≥30L** **且** 额定蒸汽压力 **≥0.1MPa**（表压） | 容积+压力 |
| 承压热水锅炉 | 出口水压 **≥0.1MPa**（表压）**且** 额定功率 **≥0.1MW** | 压力+功率 |
| 有机热载体锅炉 | 额定功率 **≥0.1MW** | 功率+有机 |

#### 2. 压力容器

**（1）固定式容器和移动式容器**

| 参数 | 条件 |
|:---|:---|
| 压力 | 最高工作压力 **≥0.1MPa**（表压） |
| 介质 | 气体、液化气体 **或** 最高工作温度 **≥** 标准沸点的液体 |
| 容积 | **≥30L** |
| 内直径 | **≥150mm**（非圆形截面指截面内边界最大几何尺寸） |

> 记忆：压力/温度 + 容积 + 直径

**（2）气瓶、氧舱**

| 参数 | 条件 |
|:---|:---|
| 公称工作压力 | **≥0.2MPa**（表压） |
| 压力×容积乘积 | **≥1.0MPa·L** |
| 介质 | 气体、液化气体 **或** 标准沸点 **≤60℃** 的液体 |

> 记忆：压力 + 压力容积乘积

#### 3. 压力管道

| 参数 | 条件 |
|:---|:---|
| 压力 | 最高工作压力 **≥0.1MPa**（表压） |
| 介质 | 气体、液化气体、蒸汽 **或** 可燃/易爆/有毒/有腐蚀性 **或** 最高工作温度 **≥** 标准沸点的液体 |
| 公称直径 | **≥50mm** |

**除外情形**（不属特种设备）：
- 公称直径 **<150mm** **且** 最高工作压力 **<1.6MPa**（表压）的输送 **无毒、不可燃、无腐蚀性气体** 的管道
- 设备本体所属管道

> 记忆：压力 + 物理状态 + 直径

#### 4. 起重机械

| 类型 | 判定条件 | 记忆 |
|:---|:---|:---:|
| 升降机 | 额定起重量 **≥0.5t** | 重量 |
| 起重机 | 额定起重量 **≥3t** **且** 提升高度 **≥2m** | 重量+高度 |
| 机械式停车设备 | 层数 **≥2层** | 层数 |

## 5.3.2 特种设备制造、安装、改造及维修的规定（★★★）

### 一、特种设备生产的许可制度

- 特种设备生产许可制度是 **市场准入制度**，是特种设备 **安全监察** 的一项重要 **行政管理措施**。

### 二、特种设备生产单位许可

#### 1. 压力管道设计、安装许可参数级别

| 级别 | 许可范围 | 备注 |
|:---:|:---|:---:|
| **GA1** | 设计压力 **≥4.0MPa**（表压）的长输输油、输气管道 | 覆盖GA2 |
| **GA2** | GA1级以外的长输管道 | — |
| **GB1** | 燃气管道 | — |
| **GB2** | 热力管道 | — |
| **GC1** | ① 输送急性毒性类别1介质、急性毒性类别2气体介质、工作温度高于标准沸点的急性毒性类别2液体介质的工艺管道（**有毒**）<br/>② 输送甲、乙类可燃气体或甲类可燃液体（含液化烃），且设计压力≥4.0MPa的工艺管道（**可燃**）<br/>③ 输送流体介质，且设计压力≥10.0MPa，或设计压力≥4.0MPa且设计温度≥400℃的工艺管道（**高压、高温**） | 覆盖GC2 |
| **GC2** | ① GC1级以外的工艺管道<br/>② 制冷管道 | — |
| **GCD** | 动力管道 | 覆盖GC2 |

> **记忆要点：** GC1=有毒+可燃+高压高温；GCD覆盖GC2

#### 2. 固定式压力容器设计、制造、安装、修理、改造许可

**（1）设计许可**
| 设计类型 | 许可机关 |
|:---|:---|
| 压力容器 **分析设计（SAD）** | **国家市场监督管理总局** |
| 固定式压力容器 **规则设计** | 总局授权 **省级市场监督管理部门** 或省级部门 |

**（2）制造（含安装、修理、改造）许可**
| 级别 | 适用范围 | 许可机关 |
|:---:|:---|:---:|
| **A1** | 大型高压容器（内径≥2m的高压容器） | 国家市场监督管理总局 |
| **A2** | 其他高压容器 | 总局授权省级或省级部门 |
| **A3** | 球罐 | 同上 |
| **A4** | 非金属压力容器 | 同上 |
| **A6** | 超高压容器 | 国家市场监督管理总局 |
| **D** | 中、低压容器 | 总局授权省级或省级部门 |

**覆盖关系：** A1 → A2、D级；A2 → D级

**超大型压力容器：**
- 因直径过大无法通过公路、铁路运输的压力容器
- 持有 **A3级** 压力容器制造许可证的制造单位可以从事超大型中低压非球形压力容器 **现场制造**

**（3）安装级别**
- 固定式压力容器安装 **不单独进行许可**
- 任一级别安装资格的 **锅炉安装单位** 或 **压力管道安装单位** 均可进行压力容器安装
- 各类车用气瓶安装 **无需许可**
- 压力容器 **制造单位** 可设计、安装与其制造级别相同的压力容器及相连接工业管道（易燃易爆有毒介质除外）

**（4）改造和重大修理**
- 由取得 **相应级别制造许可** 的单位进行
- **不单独进行许可**

#### 3. 锅炉安装（散装锅炉除外）许可参数级别

| 级别 | 许可范围 | 备注 |
|:---:|:---|:---:|
| **A** | 额定出口压力 **>2.5MPa** 的蒸汽和热水锅炉 | 覆盖B级 |
| **B** | 额定出口压力 **≤2.5MPa** 的蒸汽和热水锅炉；有机热载体锅炉 | — |

#### 4. 电梯许可参数级别

| 设备类别 | A1 | A2 | B |
|:---|:---:|:---:|:---:|
| 曳引驱动乘客电梯（含消防员电梯） | 额定速度 **>6.0m/s** | 2.5 < 额定速度 ≤ 6.0m/s | 额定速度 ≤ 2.5m/s |
| 载货电梯、自动扶梯、液压电梯、杂物电梯 | — | — | 不分级 |

**覆盖关系：** A1 → A2、B级；A2 → B级

#### 5. 起重机械许可参数级别

| 设备类别 | A级 | B级 | 备注 |
|:---|:---:|:---:|:---|
| 桥式、门式起重机 | 200t以上 | 200t及以下 | 岸边集装箱起重机、装卸桥纳入A级 |
| 流动式起重机 | 100t以上 | 100t及以下 | A级覆盖B级 |
| 门座起重机 | 40t以上 | 40t及以下 | A级覆盖B级 |
| 机械式停车设备 | — | — | 不分级 |
| 塔式起重机、升降机、缆索起重机、桅杆起重机 | — | — | 不分级 |

#### 6. 覆盖关系汇总表

| 类别 | 覆盖关系 |
|:---|:---|
| **压力管道** | GA1 → GA2；GC1、GCD → GC2 |
| **压力容器** | A1 → A2、D级；A2 → D级；制造单位可安装同级容器及相连工艺管道 |
| **锅炉** | A → B级 |
| **电梯** | A1 → A2、B级；A2 → B级 |
| **起重机** | A → B级 |

> **跨类别覆盖：** 锅炉安装、压力管道安装单位 **可安装压力容器**（氧舱除外）。

#### 7. 安装生产单位资质规定（表5.3-11）

| 持有资质 | 从事压力容器安装 | 从事压力管道安装 |
|:---|:---|:---|
| 锅炉安装许可证 | 可安装压力容器（氧舱除外），不限级别 | 可安装与所安装锅炉直接相连的压力管道 |
| 压力容器制造许可证 | 可安装相应制造许可级别范围内压力容器 | 可安装与所安装压力容器直接相连的压力管道 |
| 压力管道安装许可证 | 可安装压力容器（氧舱除外），不限级别 | 可安装许可证书范围内压力管道 |

### 三、特种设备制造、安装、改造单位应具备的条件

1. 有与生产相适应的 **专业技术人员**
2. 有与生产相适应的 **设备、设施和工作场所**
3. 有健全的 **质量保证、安全管理和岗位责任等制度**
4. **电梯**的安装、改造、修理必须由 **电梯制造单位** 或其委托的取得相应许可的单位进行
   - 电梯制造单位委托的，应进行 **安全指导和监控**，并按安全技术规范要求进行 **校验和调试**
   - 电梯制造单位对电梯 **安全性能负责**

> **复习：电梯准用程序 = 三检制：自检 → 厂检 → 专检**

### 四、特种设备的施工告知

| 项目 | 内容 |
|:---|:---|
| **何时** | 施工前 |
| **何人** | 施工单位 |
| **何地** | 书面告知直辖市或设区的市级人民政府负责特种设备安全监督管理的部门 |
| **性质** | **不属于行政许可**，告知后即可施工 |

> **核心记忆：** 何时（施工前）+ 何人（施工单位）+ 何地（市级特种设备安全监督管理部门）

### 五、竣工资料移交

- 验收后 **30日内** 将相关技术资料和文件移交 **特种设备使用单位**
- 使用单位应存入该设备的 **安全技术档案**

### 六、特种设备生产单位质量安全主体责任（新增）

| 项目 | 内容 |
|:---|:---|
| **人员配备** | 依法配备 **质量安全总监** 和 **质量安全员**，明确岗位职责 |
| **责任机制** | **生产单位主要负责人** 对质量安全 **全面负责**；质量安全总监和质量安全员 **协助** |
| **风险管控** | 建防控 **动态管理机制**，制定《特种设备质量安全风险管控清单》，健全 **日管控、周排查、月调度** 制度 |

### 七、特种设备使用单位安全主体责任（新增）

| 项目 | 内容 |
|:---|:---|
| **人员配备** | 依法配备 **安全总监** 和 **安全员**，明确岗位职责 |
| **责任机制** | **使用单位主要负责人** 对使用安全 **全面负责**；安全总监和安全员 **协助** |
| **风险管控** | 建防控 **动态管理机制**，制定《特种设备安全风险管控清单》，健全 **日管控、周排查、月调度** 制度 |

**【生产单位 vs 使用单位 对比表】**

| 对比项 | 生产单位 | 使用单位 |
|:---|:---|:---|
| 配备人员 | **质量安全总监 + 质量安全员** | **安全总监 + 安全员** |
| 全面负责人 | 生产单位主要负责人（质量安全） | 使用单位主要负责人（使用安全） |
| 制度机制 | 日管控、周排查、月调度（**质量安全**风险管控清单） | 日管控、周排查、月调度（**安全**风险管控清单） |

### 例题

**【例题·多选】下列特种设备生产许可正确的是（ ）。【2022】**
A. 安装城市热力管道的施工单位应取得GB1资质
B. 安装城市燃气管道的施工单位必须取得GA2资质
C. 安装输送6MPa天然气管道的施工单位应取得GC1资质
D. 安装输送8MPa蒸汽温度460℃管道的施工单位应取得GC1资质
E. 安装设计压力为12MPa原油长输管道的施工单位须取得GA1资质

> **【答案】CDE**
> 【解析】A错误：热力管道是GB2，GB1是燃气管道。B错误：燃气管道是GB1级别，不是GA2。

B. 取得压力容器制造许可的单位

**【例题·案例节选】【2021】某化工建设项目压缩厂房安装工程**
**背景：** 安装公司中标某化工建设项目压缩厂房安装，主要包括厂房内设备、工艺管道安装（到厂房外第一个法兰口）。厂房内主要设备有压缩机组及32/5吨桥式起重机（跨度30.5m）。

**问题：** 本工程需办理特种设备安装告知的项目有哪几个？在哪个时间段办理安装告知？

> **【参考答案】**
> 1. 工艺管道安装、32/5吨桥式起重机安装。
> 2. 应该在施工前办理安装告知。

**【例题·案例节选】【2022】蒸汽发生器与蒸汽管道案例**
**背景：** A公司向特种设备安全部门提交了蒸汽管道和集汽缸的施工告知书。监理工程师认为蒸汽发生器也应按特种设备要求办理施工告知。

| 参数 | 数值 |
|:---|:---:|
| 蒸汽量 | 1.0 t/h |
| 额定蒸汽压力 | 1.0 MPa |
| 锅内水容积 | **27 L** |
| 额定蒸汽温度 | 190℃ |

**问题：** 监理工程师要求蒸汽发生器也应按照特种设备要求办理施工告知是否正确？说明理由。

> **【参考答案】**
> 1. 不正确（不合理）。
> 2. 理由：虽然蒸汽发生器的额定蒸汽压力为1.0MPa（≥0.1MPa），但蒸汽发生器的容积不足30L（27L＜30L），不属于承压蒸汽锅炉的特种设备规定范围，不需要办理施工告知。

## 5.3.3 特种设备的监督检验（★）

### 一、监督检验的要求

#### 1. 监督检验的范围

锅炉、压力容器、压力管道元件等特种设备的 **制造过程** 和锅炉、压力容器、压力管道、电梯、起重机械、客运索道、大型游乐设施的 **安装、改造、重大修理过程**，应当经特种设备检验机构监督检验。

> 未经监督检验或检验不合格的，**不得出厂或交付使用**。

#### 2. 监督检验的性质

- 在企业 **自检合格** 的基础上
- 由 **特种设备安全监督管理部门核准的检验机构** 进行
- **验证性检验**
- **强制性检验**
- 项目、合格标准、报告格式等有明确规定

### 二、监督检验的实施

#### 起重机械的首检与定期检验

**（1）首次检验**
- 对 **不实施安装监督检验** 的起重机械
- 安装单位或使用单位自检合格基础上
- 在 **投入使用之前** 进行的第一次检验
- 实施首次检验的起重机械仍需按规定进行定期检验

**（2）实施首次检验的起重机械**

| 类别 | 品种 |
|:---|:---|
| 桥式起重机 | 电动单梁起重机 |
| 流动式起重机 | 轮胎起重机、履带起重机、集装箱正面吊运起重机、铁路起重机 |
| 缆索起重机 | — |
| 桅杆起重机 | — |

**（3）定期检验周期**

| 设备类型 | 检验周期 |
|:---|:---:|
| 塔式起重机、升降机、流动式起重机、缆索起重机 | **每年1次** |
| 桥式起重机、门式起重机、门座式起重机、桅杆起重机、机械式停车设备 | **每2年1次** |

### 特种设备判定条件速记表

| 设备 | 核心条件 |
|:---|:---|
| 承压蒸汽锅炉 | 容积≥30L + 压力≥0.1MPa |
| 承压热水锅炉 | 压力≥0.1MPa + 功率≥0.1MW |
| 有机热载体锅炉 | 功率≥0.1MW |
| 固定式压力容器 | 压力≥0.1MPa + 容积≥30L + 内径≥150mm |
| 气瓶/氧舱 | 压力≥0.2MPa + 压力×容积≥1.0MPa·L |
| 压力管道 | 压力≥0.1MPa + 介质条件 + 公称直径≥50mm |
| 升降机 | 额定起重量≥0.5t |
| 起重机 | 额定起重量≥3t + 提升高度≥2m |
| 机械式停车设备 | 层数≥2层 |

### 常见案例考点速查
