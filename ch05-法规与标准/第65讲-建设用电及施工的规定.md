## 5.2.1 工程建设用电的规定

### 一、工程建设用电办理

#### 1. 用电申请内容

用电申请的业务流程包括：

> 用电申请书审核 → 供电条件勘查 → 供电方案确定及批复 → 有关费用收取 → 受电工程设计审核 → 施工中间检查 → 竣工检验 → 供用电合同（协议）签约 → 装表接电

#### 2. 用电申请资料

建设工程申请用电时，应向供电企业提供：

- **用电项目批准文件**及相关用电资料
- 主要内容：**用电地点、电力用途、用电性质、用电设备清单、用电负荷、保安电力、用电规划**
- 依照供电企业规定格式填写用电申请书并办理手续

> **注意**：未按规定办理的，供电企业**有权拒绝**受理其用电申请。如因供电能力不足或政府限制，供电企业可通知暂缓办理。

#### 3. 用户变更用电

以下变更用电情形须**事先提出申请**，携带证明文件到供电企业营业场所办理手续，变更供用电合同：

| 变更类型 | 说明 |
|----------|------|
| 减少合同约定的用电容量 | 减容 |
| 临时更换大容量变压器 | 暂换 |
| 用户暂停 | 暂停 |
| 用户暂换 | 暂换 |
| 用户迁址 | 迁址 |
| 用户移表 | 移表 |
| 用户更名或过户 | 更名/过户 |
| 用户分户和并户 | 分户/并户 |
| 用户销户 | 销户 |
| 改变用电类别 | 改类 |

#### 4. 用电办理手续

- **总承包单位负责申请**的情形：总承包合同约定由承建单位负责，或仅施工临时用电由承建单位负责
- 需携带：建设项目用电工程**设计文件和有关资料**
- 办理地点：**工程所在地管辖的供电部门**
- 按程序、制度、收费标准办理

#### 5. 自备电源的特殊情形

> 工程项目地处偏僻，用电已受理但线路施工尚需时间，工程急需开工 → 总承包单位通常用**自备电源（如柴油发电机组）** 先行解决。

**要求**：
1. **告知供电部门并征得同意**
2. 妥善采取安全技术措施
3. **防止自备电源误入市政电网**

### 二、工程建设临时用电的相关规定

#### 1. 临时用电的准用程序

```
① 编制临时用电施工组织设计 → ② 协助业主申报用电方案
→ ③ 按批复方案采购和施工 → ④ 检查验收，申请送电
→ ⑤ 电业部门检查验收同意 → ⑥ 送电开通
```

**口诀**：编制 → 申报 → 采购施工 → 验收 → 申请送电 → 送电开通

**真题示例**：临时用电准用程序正确顺序 → **①→④→③→②**
（先申报 → 采购施工 → 检查验收申请 → 送电开通）

#### 2. 临时用电施工组织设计的编制

**关键判断标准**（JGJ46-2018《施工现场临时用电安全技术规范》）：

| 条件 | 要求 |
|------|------|
| 用电设备 **≥5台** 或 总容量 **≥50kW** | 编制**用电组织设计** |
| 用电设备 **<5台** 且 总容量 **<50kW** | 制定**安全用电和电气防火措施** |

**施工组织设计主要内容**：
- 共性部分：工程概况、编制依据、用电施工管理组织机构
- 个性部分：配电装置安装、防雷接地安装、线路敷设等技术要求、安全用电及防火措施

> **注意**：供用电施工方案或施工组织设计应经**审核、批准**后实施。

#### 3. 临时用电的检查

**（1）验收组织**
- 组织部门：**安全部门**组织检查验收
- 参加人员：主管临时用电安全的项目部领导、有关技术人员、施工现场主管人员、临时用电施工组织设计编制人员、电工班长、安全员
- 必要时请：主管部门代表和业主代表参加

**（2）检查内容**

> 架空线路、电缆线路、室内配线、照明装置、配电室与自备电源、各种配电箱及开关箱、配电线路、变压器、电气设备安装、电气设备调试、接地与防雷、电气防护

**（3）检查频次**

| 级别 | 频次 |
|------|------|
| 施工现场 | **每月一次** |
| 基层公司 | **每季度一次**（应复测接地电阻值） |

**（4）档案管理**
- 临时用电安全技术档案由主管现场的**电气技术人员**建立与管理

### 三、施工用电的安全规定

#### 施工单位安全用电事故报告规定

发生以下事故时，施工单位应及时向**供电部门报告**：

1. 人身触电**死亡**
2. 导致电力系统**停电**
3. **专线掉闸**或全厂**停电**
4. **电气火灾**
5. 重要或大型**电气设备损坏**
6. 停电期间向电力系统**倒送电**

> **注意**：**触电重伤**不属于需向供电部门报告的范围（2014真题）。

## 5.2.2 电力设施保护区内施工作业的规定

### 一、电力设施的保护范围

**定义**：凡是发电厂、变电所（站）区域内的发电设施、变电设施、送电设施以及厂、所区域外的供电、输电设施和辅助设施等，都属于**电力设施**。

#### 1. 发电厂、变电站（所）设施的保护范围
#### 2. 电力线路设施的保护范围

电力线路设施保护范围包括：

> 架空电力线路的**杆塔、基础、拉线、接地装置、导线、避雷针、金具、绝缘子**、登杆塔的爬梯和脚钉，以及导线跨越航道的保护设施、巡线站和保线站、巡视检修专用道路、船舶和桥梁、标志牌及辅助设施等。

> **注意**：**计量装置**不属于电力线路设施保护范围（2025真题）。

### 二、电力设施保护区

#### 1. 架空电力线路保护区

**定义**：导线边线向外侧水平延伸并垂直于地面所形成的**两平行面内的区域**。

**不同电压等级架空电力线路保护距离**：

| 序号 | 架空电力线路电压等级（kV） | 外侧水平延伸距离（m） |
|------|---------------------------|----------------------|
| 1 | 1～10 | **5** |
| 2 | 35～110 | **10** |
| 3 | 154～330 | **15** |
| 4 | 500 | **20** |

> **记忆技巧**：5-10-15-20 等差数列，每档递增5m，与电压等级对应。

**计算示例**（2020真题）：
> 110kV电力线路水平安全距离为10m，最大风偏水平距离0.5m时，导线边缘延伸的水平安全距离 = 10 + 0.5 = **10.5m**

#### 2. 电力电缆线路保护区

| 序号 | 电缆环境 | 两侧水平延伸距离 |
|------|----------|-----------------|
| 1 | **地下电缆** | **0.75m** |
| 2 | **海底电缆** | **2海里**（港内为两侧各100m） |
| 3 | **江河电缆** | **100m**（中小河流一般不小于线路两侧各50m） |

---

### 三、电力设施保护区内施工应遵守的规定

#### 1. 架空电力线路保护区内取土规定

**各电压等级杆塔周围禁止取土范围**：

| 电压等级 | 禁止取土范围 |
|----------|-------------|
| 35kV | **4m** |
| 110～220kV | **5m** |
| 330～500kV | **8m** |

> **记忆技巧**：4-5-8 由低到高排列，注意110kV和220kV共用5m。

**取土坡度**：一般不得大于 **45°**（沙地取土坡度应更小）。

**其他要求**：
- 取土时必须预留巡视、检修线路的人员、车辆通行通道
- 特殊情况由县以上地方电力主管部门另行规定

**故障案例对比**（2024真题）：
- 110kV杆塔 4m外可以取土？—— **错**（35kV才是4m，110kV是5m）
- 220kV杆塔 5m外可以取土？—— **对**
- 330kV杆塔 6m外可以取土？—— **错**（330kV是8m）
- 500kV杆塔 7m外可以取土？—— **错**（500kV是8m）

#### 2. 电力设施保护区内施工前的规定

**（1）进行图纸会审**

**（2）编制施工方案**
- 典型作业：开挖地下管沟、大件吊装或卸载、爆破作业
- 制定方案前先**摸清周边电力设施的实情**
- 方案中应专门制定保护电力设施的**安全技术措施**，并写明要求作业时请电力设施管理部门派人**监管**
- 编制方案时尽量邀请**电力管理部门或电力设施管理部门**派人员参加

**（3）施工方案报批**
- 施工方案编制完成后，报经**电力管理部门批准**后执行

## 历年真题

### 2012 单选
> 35kV架空电力线路保护区范围是导线边缘向外侧延伸的距离为？
> **答案**：C（10m）—— 35～110kV延伸距离为10m。

### 2014 单选
> 下列用户的安全用电事故，不属于向供电部门报告的是？
> **答案**：C（触电重伤事故）

### 2015 单选
> 220kV杆塔周围禁止取土的范围是？
> **答案**：A（5m）

### 2020 单选
> 110kV高压电力线路水平安全距离为10m，最大风偏水平距离0.5m时，导线边缘延伸的水平安全距离应为？
> **答案**：D（10.5m）

### 2024 单选
> 关于电力杆塔周围取土的说法，正确的是？
> **答案**：B（220kV杆塔的5m外可以取土）

### 2025 单选
> 电力线路设施的保护范围不包括？
> **答案**：D（计量装置）
