## 考点一：施工组织设计的编制与实施（★★★）

**真题分布：** 2009案/2015案/2019单/2020单、案/2023多、案

### 1. 施工组织设计的类型

#### 按编制阶段分类

| 类型 | 说明 |
|------|------|
| 标前施工组织设计 | 投标阶段编制 |
| 标后施工组织设计 | 中标后实施阶段编制 |

#### 按编制对象分类（重点）

| 类型 | 编制对象 | 作用 | 性质 |
|------|----------|------|------|
| 项目施工组织总设计 | 整体（群体）工程 | 对整个项目施工全过程起**统筹规划和重点控制**作用 | 是编制单位工程和专项工程施工组织设计的**依据** |
| 单位工程施工组织设计 | 单位（子单位）工程 | 对单位工程施工过程起**指导和制约**作用 | 是施工组织总设计的进一步细化 |
| 专项工程施工组织设计（施工方案） | 分部（分项）工程或专项工程 | 对分部（分项）工程或专项工程的施工过程起**指导**作用 | — |

> **核心规律：大的是小的的依据，前面的是后面的依据**

---

### 2. 施工组织设计编制原则（5项）

| 原则 | 要点 |
|------|------|
| 合规性原则 | 遵守法律法规、标准规范 |
| 先进性原则 | 采用先进技术、工艺 |
| 科学性原则 | 符合客观规律 |
| 经济性原则 | 降低造价、节约成本 |
| 适宜性原则 | 结合工程实际情况 |

---

### 3. 施工组织设计编制依据

> 依据 = 参考资料 = 纸质文件

| 类别 | 具体内容 |
|------|----------|
| 法规标准 | 法律法规、标准规范、主管部门批准文件 |
| 合同文件 | 施工合同、招标投标文件、建设单位相关要求 |
| 工程文件 | 施工图纸、技术协议、主要设备材料清单、主要设备技术文件、新产品工艺性试验资料、会议纪要等 |
| 现场条件 | 施工现场条件、资源条件、工程地质/水文地质/气象条件 |
| 企业标准 | 企业技术标准、管理体系文件、管理制度、施工能力、工程施工经验等 |

**记忆口诀：** 记忆倾吐协会

---

### 4. 施工组织设计编制内容（9项）

1. 工程概况
2. 施工部署
3. 施工进度计划
4. 施工准备
5. 劳动力配置计划
6. 物资配置计划
7. 主要施工方案
8. 施工现场平面布置
9. 各项施工管理计划（质量、成本、安全、环境、其他）

---

### 5. 施工组织设计的编制与审批

> 核心三问：**谁编？谁审？谁批？**

| 施工组织设计类型 | 编制主体 | 审批人 |
|------------------|----------|--------|
| **施工组织总设计** | 施工总承包单位组织编制；未实行总承包时由建设单位负责组织各施工单位编制 | **总承包单位技术负责人**审批后报监理工程师 |
| **单位工程施工组织设计** | 施工单位组织编制 | **施工单位技术负责人**审批 |
| **专项工程施工组织设计** | 施工单位组织编制 | **项目技术负责人**审批 |

> **注意：** 施工组织设计实施前必须严格执行编制、审核、审批程序；**没有批准的施工组织设计不得实施**。

---

### 6. 施工组织设计的实施

> **核心三问：** 何时？何人？交何底？

**时间：** 工程**开工前**

**交底人 → 被交底人：** 施工组织设计的**编制人员** → 现场**施工管理人员**

**交底内容（6项）：**

1. 工程特点、难点
2. 主要施工工艺及施工方法
3. 施工进度安排
4. 项目组织机构设置与分工
5. 质量技术措施
6. 安全技术措施

## 考点二：施工方案的编制与实施（★★★）

**真题分布：** 2011案/2016案/2018多/2021案/2023案

### 1. 施工方案的类型

| 类型 | 说明 |
|------|------|
| **专业工程施工方案** | 以组织专业工程实施为目的，指导专业工程施工全过程 |
| **危大工程安全专项施工方案** | 危险性较大的分部分项工程需编制 |

---

### 2. 危大工程安全专项施工方案

#### 依据文件

- 《危险性较大的分部分项工程安全管理规定》（住建部令第37号）
- 建办质〔2018〕31号文
- 《电力建设工程施工安全管理导则》NB/T 10096-2018

#### 应编制危大工程安全专项施工方案的情形（起重吊装）

| 类别 | 具体标准 |
|------|----------|
| **危大工程** | 采用非常规起重设备、方法，且单件起吊重量在 **10kN及以上** 的起重吊装工程 |
| | 采用起重机械进行安装的工程 |
| | 起重机械安装和拆卸工程 |

#### 超过一定规模的危大工程（需专家论证）

| 工程类别 | 具体标准 |
|----------|----------|
| **起重吊装** | 采用非常规起重设备、方法，且单件起吊重量在 **100kN及以上** |
| **起重机械安拆** | 起重量 **300kN及以上**，或搭设总高度 **200m及以上**，或搭设基础标高在 **200m及以上** |
| **钢结构/网架/索膜** | 跨度 **36m及以上** 的钢结构安装工程，或跨度 **60m及以上** 的网架和索膜结构安装工程 |
| **大型结构整体顶升/平移/转体** | 重量 **1000kN及以上** |
| **电力建设工程（NB/T 10096-2018）** | 1. 采用非常规起重设备、方法，且单件起吊重量在 **100kN及以上** |
| | 2. 起重量 **600kN及以上** 的超重设备安装工程 |
| | 3. 高度 **200m及以上** 的内爬起重设备的拆除工程 |
| | 4. **风机（含海上）吊装工程** 均属超过一定规模的危大工程 |

> **记忆要点：**
> - 危大工程起重量门槛：常规 **10kN**，非常规 **10kN**
> - 超一定规模起重量门槛：非常规 **100kN**，安拆起重 **300kN**，电力 **600kN**
> - 钢结构跨度门槛：**36m**；网架/索膜跨度门槛：**60m**

---

### 3. 施工方案编制依据

与工程有关的法律法规、标准规范、**施工合同、施工组织设计**、设计文件、设备技术文件、施工现场条件、施工企业管理制度及同类工程施工经验等。

> **规律：** 大的是小的的依据，前面的是后面的依据（施工组织设计是施工方案的编制依据之一）

---

### 4. 施工方案编制内容

#### 一般施工方案（6项）

1. 工程概况
2. 施工安排
3. 施工进度计划
4. 施工准备与资源配置计划
5. 施工方法（工艺）要求
6. 质量、安全保证措施

#### 安全专项施工方案（9项）

1. 工程概况
2. 编制依据
3. 施工计划
4. 施工工艺技术
5. 施工安全保证措施
6. 施工管理及作业人员配备和分工
7. 验收要求
8. 应急处置措施
9. 计算书及相关图纸

### 6. 安全专项施工方案编制与审批

> **核心三问：** 谁编？谁审？谁批？

**一般流程：**
1. 施工单位编制专项施工方案
2. **施工单位技术负责人**审核签字，加盖单位公章
3. **总监理工程师**签字、加盖执业印章后实施

**分包情形：**
- 分包单位编制的专项施工方案，需由**总承包单位技术负责人**和**分包单位技术负责人**共同审核签字，加盖单位公章

> **记忆口诀：** 2/3总2章

**超过一定规模的危大工程：**
- 施工单位应当组织召开**专家论证会**
- 实行施工总承包的，由**施工总承包单位**组织
- 专家论证前，专项方案应当通过施工单位审核和总监理工程师审查

**专家论证意见处理：**

| 论证意见 | 处理方式 |
|----------|----------|
| 修改后通过 | 根据论证意见修改完善后，**重新履行审批程序** |
| 不通过 | 修改后**重新组织专家论证** |

---

### 7. 施工方案经济比较

- 施工方案经济评价一般采用**综合评价法**
- 需要进行技术经济分析的施工方案类型：
  - 超重、超大设备的运输方案、吊装方案
  - 被焊工件厚度或焊接工程量大以及重要部位或有特殊材料的焊接方案
  - 交叉施工且工程量大的施工方案
  - 采用新技术、新工艺的方案
  - 综合系统试验及无损检测方案

---

### 8. 施工方案实施

**时间：** 施工方案**实施前**

**交底人 → 被交底人：** 编制人员 → **作业人员**

**哪些需要交底（记忆分类）：**

| 类别 | 内容 |
|------|------|
| 2项 | 分项工程、专项工程 |
| 2特 | 特殊环境、特种作业 |
| 4新 | 新产品、新材料、新技术、新工艺 |

> **记忆口诀：** 2项2特4新

**交底内容（5项）：**
1. 施工程序和顺序
2. 施工工艺
3. 操作方法、要领
4. 质量控制
5. 安全措施

> **记忆口诀：** 许志安衣领潮

---

### 9. 施工组织设计交底 vs 施工方案交底（重点对比）

| 对比项 | 施工组织设计交底 | 施工方案交底 |
|--------|-----------------|-------------|
| **时间** | 开工前 | 实施前 |
| **谁向谁交底** | 编制人员 → 现场**施工管理人员** | 编制人员 → **作业人员** |
| **需要交底的范围** | 单位工程 | 2项2特4新 |
| **交底内容（相同）** | 主要施工工艺及施工方法、**质量**技术措施、**安全**技术措施 | 施工工艺、操作方法、要领、**质量控制**、**安全措施** |
| **交底内容（不同）** | 工程特点、难点、进度安排、组织机构设置与分工 | 施工程序和顺序 |

### 例题

**【2021·案例节选】**
桥式起重机安装安全专项施工方案的"验收要求"中，针对施工机械、施工材料、测量手段三项验收内容，明确了验收标准、验收人员及验收程序。该方案在专家论证时，专家提出"验收要求"中验收内容不完整，需要补充。

**问题：** 还需要补充哪些验收内容？方案论证应由哪个单位来组织？

> **参考答案：**
> 1. 还需补充：**施工人员、施工方法、施工环境**
> 2. 方案论证由**安装公司**（施工单位）组织
