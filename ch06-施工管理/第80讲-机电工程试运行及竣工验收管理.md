## 15.1 试运行管理

### 考点：试运行条件与组织 (★★)

> **真题分布**：2009案 / 2010案 / 2014案 / 2016案 / 2019案 / 2024案

#### 1. 试运行条件

##### 1) 单机试运行前必须具备的条件（2010/2014/2016）

核心记忆框架：**人机料法环 + 实体 + 资料 + 安全**

| 维度 | 具体内容 |
|------|----------|
| **人** | 试运行责任已明确（建设单位、设计单位、总承包单位、施工单位）；操作人员经培训考试合格，熟悉方案和操作规程，能正确操作 |
| **机/料** | 润滑、液压、冷却、水、气（汽）和电气等系统符合单独调试和主机联合调试的要求 |
| **法** | 试运行方案已批准，试运行组织已建立，记录表格齐全 |
| **环** | 试运行动设备周围环境清扫干净，不应有粉尘和较大的噪声 |
| **实体** | 动设备及其附属装置、管线按设计文件内容和有关规范质量标准全部安装完毕并验收合格（分项工程验收合格） |
| **资料** | 产品合格证书或复验报告；施工记录、隐蔽工程记录和各种检验、试验合格文件；电气和仪表调校合格资料 |
| **安全** | 相应的安全设施和安全防护装置设置完善 |

> 注：资料是指施工过程中形成的资料——规范、标准、法规不在此列。

##### 2) 联动试运行前必须具备的条件（2009）

1. 单位工程质量验收合格
2. **单机试运行全部合格**
3. 工艺系统试验合格
4. 管理要求已完善
5. 资源条件已满足

> **记忆公式**：各阶段试运行条件 = 人机料法环 + 实体 + 资料 + 上一阶段完成

##### 3) 负荷试运行应具备的条件

1. **联动试运行已完成**
2. 制度和技术文件已完善
3. 资源条件已具备

> **记忆公式**：各阶段试运行条件 = 人机料法环 + 上一阶段完成

---

#### 2. 试运行组织

| 阶段 | 负责单位 | 说明 |
|------|----------|------|
| **物资供应**（水、电、气、蒸汽、原料、燃料、易损备件、化学品、润滑油脂） | **建设单位**负责 | 合同另有规定时按合同执行 |
| **联动试运行**组织指挥 | **建设单位**负责 | 合同另有规定时按合同执行 |
| **负荷试运行**组织指挥 | **建设单位**负责 | 合同另有规定时按合同执行 |

建设单位应成立专门机构，负责项目试运行和生产运行准备活动。

---

#### 3. 试运行的准备工作

| 准备类型 | 具体内容 |
|----------|----------|
| **技术准备**（计划、方案） | 确认试运行条件、编制试运行总体计划和进度计划、制定试运行技术方案、确定合格评价标准 |
| **组织准备**（队伍、制度） | 组建领导指挥机构、明确指挥分工、组织岗位作业队伍、上岗前培训、技术交底和安全交底、管理制度交底 |
| **物资准备**（材料、机具） | 编制物资需要量计划和费用计划（含燃料动力物资、投产用原材料、消耗性材料、检测用工机具和仪器仪表） |

---

#### 4. 试运行方案的编制与实施

| 试运行类型 | 方案编制 | 组织指挥 |
|------------|----------|----------|
| **单机试运行** | **施工单位**负责编制 | 施工单位组织、指挥和操作，建设单位及相关方人员参加 |
| **联动试运行** | **建设单位**负责编制 | 建设单位组织、指挥和操作，施工单位及相关方依据委托派人参加 |
| **负荷试运行** | **建设单位**负责编制 | 建设单位组织、指挥和操作，施工单位配合 |

> **单机和联动试运行完成后**：施工单位与建设单位、监理单位、设计单位、质量监督部门办理工程及技术资料等相关交接手续。

**例题**：本工程的成套设备带负荷试运转应由（**B**）负责进行。
- A. 施工单位
- B. **建设单位**
- C. 设计单位
- D. 设备承包商

### 考点：建筑机电工程试运行 (★) 【变动】

#### 1. 建筑给水排水工程

##### 给水系统

- 水池（箱）按设计要求储存水量；系统供电正常；水泵等设备单机试运行正常；阀门启闭灵活
- 保障不间断向建筑或小区供水的能力，供水水质、水量和水压满足正常用水需求
- 生活饮用水水质符合现行国家标准
- 二次加压与调蓄设施不影响城镇给水管网正常供水
- 生活给水系统的**备用泵供水能力不小于最大一台运行水泵的供水能力**

##### 排水系统

- 生活排水系统具有足够的排水能力
- 地下室、半地下室卫生器具和地漏采用**压力流排水系统**
- 生活排水应排入市政污水管网或处理后**达标排放**
- 生活饮用水箱（池）、中水箱（池）、雨水清水池的泄水管道、溢流管道采用**间接排水**
- **需单独设置排水系统的情况**：
  - 职工食堂、营业餐厅的厨房含油脂废水
  - 含有致病菌、放射性元素超过排放标准的医疗、科研机构的污废水
  - 实验室有毒有害废水
  - 应急防疫隔离区及医疗保健站的排水

#### 2. 建筑电气工程

##### 电气照明试运行

| 项目 | 要求 |
|------|------|
| 公共建筑照明系统 | 连续试运行 **24h**，每 **2h** 记录1次 |
| 住宅照明系统 | 连续试运行 **8h** |
| 有自控要求的照明 | 先就地分组控制试验，后自动控制试验 |
| 三相负荷分配 | 最大相负荷 ≤ 平均值的 **115%**，最小相负荷 ≥ 平均值的 **85%** |
| 照度测量 | 无外界光源下测量，每种功能区域检测不少于 **2处** |

**光源试运行及照度测量要求**：

| 光源类别 | 试运行要求 | 测量前稳定燃点时间 |
|----------|------------|-------------------|
| 白炽灯 | 宜试运行 **10h** 后测量 | **5min** |
| 荧光灯 | 宜试运行 **100h** 后测量 | **15min** |
| 高强气体放电灯 | 宜试运行 **100h** 后测量 | **30min** |

**照度计要求**：
- 室内照度测量：准确度为**二级以上**的照度计
- 室外照度测量：准确度为**一级**的照度计
- 道路和广场：能读到 **0.1lx** 的照度计
- 对照明质量有特定要求的场所：委托有资质的专业检测机构检测

##### 电气动力设备试运行

| 项目 | 要求 |
|------|------|
| 空载试运行时间 | 宜 **2h** |
| 连续启动间隔 | ≥ **5min**（至电动机冷却至常温） |
| 试通电检查 | 转向和机械转动情况、电动执行机构的动作方向及指示 |
| 记录数据 | 电流、电压、温度、运行时间 |
| 轴承温度 | 采用测温仪测量 |

#### 3. 通风与空调工程

##### 系统试运行条件

- 应编制试运行技术方案并审查批准
- 联合试运行及调试应在制冷设备、通风与空调设备**单机试运行合格后进行**
- 测试仪器应在使用合格检定或校准合格有效期内

##### 联合试运行

| 项目 | 要求 |
|------|------|
| 通风系统连续试运行 | ≥ **2h** |
| 空调系统（带冷/热源）连续试运行 | ≥ **8h** |
| 不在制冷期或供暖期 | 仅做不带冷（热）源的试运行，在第一个制冷期或供暖期内**补做** |

**检查内容**：
- 系统总风量、新风量、建筑内各区域压差符合设计要求
- 变风量末端装置最大风量符合设计风量
- 改变工况或温度设定时，末端装置风阀（风机）动作正确
- 防排烟系统联合试运行符合设计要求及国家标准

---

#### 4. 消防工程

##### 消防水泵

| 启动方式 | 投入运行时间要求 |
|----------|-----------------|
| 自动直接启动 / 手动直接启动 | **55s** 内 |
| 备用电源切换方式 | **1min** 内 |
| 备用泵切换启动 | **2min** 内 |

**压力/流量要求**：
- 零流量时压力 ≤ 设计额定压力的 **140%**
- 出水流量为设计额定流量的 **150%** 时，出口压力 ≥ 设计额定压力的 **65%**

##### 消火栓

试验消火栓动作时，检测：出流量、压力、充实水柱长度，核实消防水泵供水能力。

### 考点：工业机电工程试运行 (★)

> **真题分布**：2011案 / 2017案 / 2022单

#### 1. 单机试运行

##### 主要范围和目的

**范围**：
驱动装置、传动装置或单台动设备（机组）及其辅助系统（电气系统、润滑系统、气动系统、冷却系统、加热系统、监测系统等）和控制系统（设备启停、换向、速度调节、自动化仪表、PLC远程控制、联锁、报警系统等）。

**目的**：主要考核**单台设备的机械性能**，检验动设备的**制造、安装质量**和设备性能等是否符合规范和设计要求。（2017案）

##### 安全技术措施

| 类别 | 措施 |
|------|------|
| **安全措施** | 划定试运行区域，无关人员不得进入；必须包括保护性联锁和报警等自控装置 |
| **工艺技术措施** | ① 先完成电气和操作控制系统调试、润滑/液压/气动/冷却/加热系统调试、机械设备动作试验<br>② 与其他系统隔离时设置**盲板**<br>③ 按设备说明书、试运行方案和操作方法指挥操作，严禁违章<br>④ 指定专人测试并做好记录 |

##### 单机试运行后处理事项（收尾）

| 序号 | 处理事项 |
|------|----------|
| 1 | 切断电源和其他动力源 |
| 2 | 放气、排水、排污和涂油防锈 |
| 3 | 对蓄势器和蓄势腔及机械设备内剩余压力泄压 |
| 4 | 检查润滑剂清洁度，清洗过滤器，必要时更换新润滑剂 |
| 5 | 拆除试运行中的临时装置或恢复临时拆卸的设备部件及附属装置 |
| 6 | 清理和清扫现场，机械设备盖上防护罩 |
| 7 | 整理试运行各项记录 |

##### 中间交接验收（2011案）

**定义**：中间交接是施工单位向建设单位办理工程交接的一个必要程序，标志着工程施工安装结束，由单机试运行转入联动试运行。

**保管责任**：
- 交接前：施工方对工程实体、施工过程技术文件等妥善保管，有可行有效的成果保护措施
- 交接后：由**建设单位**或承担试运行的合同主体负责保管、使用、维护
- **但不应解除施工方的施工责任**，遗留的施工问题仍由施工方解决，并按期限完成

---

#### 2. 联动试运行

##### 目的

主要考核**联动机组或整条生产线的电气联锁**，检验设备全部性能和制造、安装质量是否符合规范和设计要求。

##### 达到的标准

- 按设计要求全面投运，**连续运行**并达到规定时间
- 参加人员应掌握开车、停车、事故处理和调整工艺条件的技术
- 试运行后，有关单位和部门对其结果进行分析评定，合格后填写**联动试运行合格证书**

---

#### 3. 负荷试运行

##### 达到的标准（2011案）

1. 生产装置连续运行，生产出**合格产品**，一次投料负荷试运行成功
2. 负荷试运行的**主要控制点**正点到达
3. 不发生重大设备、操作、人身事故，不发生火灾和爆炸事故
4. 环保设施做到**"三同时"**，不污染环境
5. 负荷试运行不得超过试车预算，**经济效益**好

## 15.2 竣工验收管理

### 考点：建筑机电工程竣工验收 (★)

> **真题分布**：2011单 / 2021案 / 2022多

#### 1. 建筑机电工程质量验收的划分

按《建筑工程施工质量验收统一标准》GB 50300-2013，建筑机电工程划分为**6个分部工程**：

| 序号 | 分部工程 | 备注 |
|------|----------|------|
| 1 | 建筑给水排水及供暖工程 | |
| 2 | 通风与空调工程 | |
| 3 | 建筑电气工程 | |
| 4 | 智能建筑工程 | |
| 5 | 建筑节能工程 | |
| 6 | 电梯工程 | |

> **注意**：建筑机电工程不含消防工程。

#### 2. 单位（子单位）工程质量验收评定合格标准（5个方面）

| 序号 | 标准 | 维度 |
|------|------|------|
| 1 | 构成单位工程的各**分部工程**质量均应验收合格 | 实体 |
| 2 | **质量控制资料**应完整、真实 | 资料 |
| 3 | 所含分部工程有关**安全、节能、环境保护和主要使用功能**的检验资料应完整 | 资料/安全 |
| 4 | **主要功能项目**的抽查结果应符合国家现行强制性工程建设规范的规定 | 功能 |
| 5 | **观感质量**验收应符合要求 | 观感 |

> 记忆口诀：**实体 + 资料 + 安全 + 观感 + 功能抽查**

#### 3. 专项验收

建设单位应向政府有关行政主管部门申请专项验收，包括：
> 规划、消防、节能、环保、卫生、防雷、人防、绿化等

**"三同时"原则**：
消防设施、安全设施及环境保护设施应与主体工程**同时设计、同时施工、同时投入生产和使用**。

#### 4. 竣工验收备案

- 建设单位应当自工程竣工验收合格之日起 **15天内** 备案
- 提交材料：竣工验收报告 + 规划、消防、环保等部门出具的认可文件或准许使用文件
- 备案机关：工程所在地县级以上地方人民政府建设主管部门

### 考点：工业机电工程竣工验收 (★★)

> **真题分布**：2009案 / 2013单 / 2022多 / 2023案

#### 1. 工业机电工程质量验收的划分

按《工业安装工程施工质量验收统一标准》GB/T 50252-2018，划分为**9个分部工程**：

| 序号 | 分部工程 |
|------|----------|
| 1 | 土建工程 |
| 2 | 钢结构工程 |
| 3 | 设备工程 |
| 4 | 管道工程 |
| 5 | 电气工程 |
| 6 | 自动化仪表工程 |
| 7 | 防腐蚀工程 |
| 8 | 绝热工程 |
| 9 | 炉窑砌筑工程 |

#### 2. 单位工程质量验收程序

**验收程序**：检验批 → **分项工程** → **分部工程** → **单位工程**

- 单位（子单位）工程完工后，由**施工单位**向建设单位提出报验申请
- 由**建设单位项目负责人**组织施工单位、监理单位、设计单位等项目负责人进行验收（2009案）

#### 3. 单位工程质量验收合格规定

1. 所含**分部工程**质量应全部为**合格**
2. **质量控制资料**应齐全

> 记忆：**实体合格 + 资料齐全**

#### 4. 单位工程控制资料检查记录

**填写分工**：

| 内容 | 填写责任方 |
|------|-----------|
| 资料名称和份数 | **施工单位**填写 |
| 检查意见和检查人 | **建设（监理）单位**填写 |
| 结论 | 双方共同商定，**建设单位**填写 |
| 签字人 | 施工单位项目负责人 + 建设单位项目负责人（总监理工程师） |

**主要内容**：
> 图纸会审、设计变更、协商记录、材料合格证及检验试验报告、施工记录、施工试验记录、观测记录、检测报告、隐蔽工程验收记录、试运行记录、质量事故处理记录、中间交接记录、竣工图、分部分项工程质量验收记录

> 检查意见为"**合格**"或"**不合格**"。

#### 5. 竣工验收程序

| 阶段 | 说明 |
|------|------|
| **验收准备** | |
| **预验收** | 工程规模和技术复杂程度大的项目，由上级主管部门或项目建设单位会同施工、设计、监理、使用单位及有关部门组成预验收组 |
| **正式验收** | |

### 考点：工程竣工结算 (★)

#### 工程结算编制依据

1. 工程施工合同文件及补充协议（含已标价工程量清单及投标报价澄清或说明文件）
2. 相关工程的国家及行业工程量计算标准
3. 合同图纸、实际施工图纸及相关工程勘察与设计资料
4. 规范、标准、发包人在施工过程中补充的技术文件
5. 工程投标文件、招标文件
6. 经批准或确认的工程变更、计日工、工程索赔等资料
7. 发承包双方已确认计入当期施工过程结算的工程量及其价款、合同调整价款
8. 其他相关依据及资料

## 经典案例与易错点

### 案例：风机盘管安装（2022真题）

**风机盘管安装前应进行**：风机三速试运行、盘管水压试验。

**常见错误及整改**：

| 错误 | 正确做法 |
|------|----------|
| 风机盘管与冷冻水回水管采用镀锌钢管连接 | 应采用**金属或非金属柔性连接** |
| 冷凝水管坡度 i=0.005 | 干管坡度宜 ≥ **8‰**，坡向出水口 |
| 透明胶管长度 200mm | 长度不宜大于 **150mm** |
| Y型过滤器安装方向反向 | 调转方向，使过滤器朝向右 |

> 冷凝水管与风机盘管连接时，宜设置透明软管，能观察到凝结水排水情况，长度不宜大于150mm。

### 关键数字速记

| 数字 | 对应内容 |
|------|----------|
| **55s** | 消防水泵自动/手动直接启动 |
| **1min** | 备用电源切换启动消防水泵 |
| **2min** | 备用泵切换启动消防水泵 |
| **140%** | 消防水泵零流量时压力上限 |
| **150%** | 测试流量（额定流量的150%），对应出口压力≥65% |
| **24h / 8h** | 公共建筑/住宅照明试运行 |
| **10h / 100h** | 白炽灯/气体放电灯试运行后测照度 |
| **2h / 8h** | 通风系统/空调系统联合试运行 |
| **15天** | 竣工验收备案时限 |
| **6个** | 建筑机电工程分部工程数量 |
| **9个** | 工业机电工程分部工程数量 |

| 对比项 | 建筑机电工程 | 工业机电工程 |

| 分部工程数量 | 6个 | 9个 |
