# 7.3 施工组织设计（第70讲）

## 考点一：施工技术交底（★★）

**真题分布：** 2024（案例）

### 1. 施工技术交底的依据

交底的依据为**更早的相关文件**，包括：
1. 施工组织设计
2. 工程设计文件
3. 项目质量策划
4. 专项施工方案
5. 施工工艺
6. 质量标准

### 2. 设计交底与图纸会审（2024案例）

| 项目 | 内容 |
|------|------|
| **组织方** | **建设单位**组织 |
| **参加单位** | 设计、施工、监理单位参加 |
| **交底方** | 勘察设计单位对施工图纸内容进行交底 |
| **性质** | 保证工程质量的重要环节、前提，保证工程顺利施工的主要步骤 |
| **目的** | ① 使施工单位正确贯彻设计意图，加深对设计文件的理解<br>② 掌握关键工程质量要求，确保工程质量<br>③ 减少图纸中的差错、遗漏，将图纸中的质量隐患与问题消灭在施工之前<br>④ 使设计图纸更符合施工现场的具体要求，避免返工 |

> 在施工图设计交底的同时，建设、设计、监理、施工及其他有关单位需对设计图纸在自审的基础上进行会审。

### 3. 施工技术交底内容

| 类型 | 实施主体与时机 | 交底内容 |
|------|---------------|---------|
| **项目总体交底** | 项目开工前，有关工程技术管理部门依据施工组织总设计、设计文件、施工合同和设备说明书等制定提纲，对项目部职能部门、专业技术负责人、主要施工负责人及分包单位有关人员进行交底 | 工程规模和承包范围，施工范围划分，工程特点和设计意图，总平面布置，主要施工方案、施工程序和交叉配合，施工进度和各专业配合要求，工程质量目标和保证措施，降低成本和主要措施，安全文明施工、职业健康安全、环境保护、绿色施工等，主要设备和物资供应要求等 |
| **单位工程技术交底** | 单位工程开工前，**项目技术负责人**根据单位工程施工组织设计、工程设计文件、设备说明书和技术交底大纲，对本专业范围内的负责人、技术管理人员、施工班组长及施工人员进行交底 | 施工范围、施工特点、设计意图，施工进度要求，施工质量目标、安全文明施工、环境保护规定和保证措施，重大施工方案，质量验收标准，降低施工成本和措施，主要设备和物资供应计划，施工质量监督检查及其要求 |
| **分部分项工程技术交底** | 专业技术负责人或施工员根据施工图纸、设备说明书、施工方案、作业指导书及技术交底提纲，对班组施工人员进行交底 | 施工图纸、施工内容和工程量，施工步骤、操作方法和新技术操作要领，质量标准和保证措施，检验和质量检查验收评级依据，安全文明施工保证措施，职业健康和环境保护要求，物资供应情况，施工工期要求，施工记录内容和要求，降低成本措施等 |

**记忆要点：** 总体交底（开工前，工程管理部门）→ 单位工程交底（开工前，项目技术负责人）→ 分部分项交底（施工前，专业技术负责人/施工员），逐级细化。

## 考点二：设计变更管理（★★）

**真题分布：** 2019（二建）、2022（二建）、2018（二建）、2016（二建）

### 1. 设计变更的分类

#### 1）按引起设计变更的责任方分类
- 设计原因的变更
- 非设计原因的变更

#### 2）按设计变更内容的性质分类

| 对比项 | 重大设计变更 | 一般设计变更 |
|--------|-------------|-------------|
| **总工期影响** | 对项目实施总工期和里程碑产生影响 | 不会对总工期产生影响 |
| **质量/功能影响** | 改变工程质量标准、整体设计功能 | 不改变整体设计功能及工程质量标准 |
| **投资影响** | 工程费用超出批准的设计概算，新增概算未列入单项工程 | 对工程投资影响较小 |
| **核心内容变化** | 工艺方案变化、设计规模扩大、主要工艺设备改变 | 不改变工艺流程，仅针对局部进行改进完善 |

### 2. 设计变更的实施程序

> **提示：** 三方都可提，监理是桥梁

#### 1）设计单位进行设计变更
① 出变更图纸或变更说明
② 建设单位将变更图纸或变更说明发至监理、施工单位

#### 2）建设单位提出设计变更（2018二建）
① 建设单位组织变更论证（技术上是否可行、施工难易程度和对工期的影响程度、对造价的影响程度）
② 论证结果同意后，通知设计单位进行设计变更，出变更图纸或变更说明
③ 变更图纸或变更说明由建设单位发至监理、施工单位

#### 3）施工单位提出设计变更（2016二建）
① 施工单位提出变更，报**监理单位审核**
② 审核：技术上是否可行、施工难易程度和工期是否增减，核算造价影响；审核后报**建设单位审批**
③ 建设单位同意后，通知设计单位实施设计变更，出变更图纸或变更说明
④ 建设单位将变更图纸或变更说明发至监理、施工单位

**程序对比记忆：**

| 提出方 | 流程 |
|--------|------|
| 设计单位 | 出图/说明 → 建设单位发至监理、施工（2步） |
| 建设单位 | 组织论证 → 通知设计出图 → 发至监理、施工（3步） |
| 施工单位 | 提出 → 监理审核 → 建设单位审批 → 通知设计出图 → 发至监理、施工（5步） |

## 考点三：施工资料及信息化管理（★★）

**真题分布：** 2024（多选）、2025（案例）

### 1. 建设工程项目资料的分类

#### 建设工程文件（建设工程资料）

| 阶段 | 主要内容 |
|------|---------|
| **工程准备阶段文件** | 立项、审批、用地、勘察设计、招标投标文件等 |
| **施工阶段文件** | 施工管理文件、施工技术文件、施工进度及造价文件、施工物资文件、施工记录、施工试验记录及检测报告、施工质量验收记录等 |
| **竣工验收阶段文件** | 竣工验收文件、竣工决算文件、竣工总结文件 |

#### 项目施工技术文件

施工技术文件是施工单位用以指导、规范和科学化施工的文件，是施工资料的重要组成部分。

**记忆口诀：1表2单2方案4记录**

| 类别 | 文件名称 |
|------|---------|
| 1表 | 工程技术文件报审表 |
| 2方案 | 施工组织设计及施工方案、危险性较大的分部分项工程施工方案 |
| 2单 | 设计变更通知单、技术核定单 |
| 4记录 | 技术交底记录、图纸会审记录、设计交底记录、工程洽商记录 |

> 提示：施工过程中形成的资料，规范、标准、法规不在此列

### 2. 竣工档案的主要内容

**（资料类最全的内容，建议掌握）**

| 类别 | 包含内容 |
|------|---------|
| **一般施工记录** | 施工组织设计、施工方案、技术交底、施工日志等 |
| **图纸交底记录** | 图纸会审记录、设计变更记录、工程洽商记录等 |
| **设备材料检查、安装记录** | 质量合格证、质量保证书、检测报告、设备装箱单、商检证明和说明书，设备安装记录，设备试运行记录等 |
| **施工记录** | 隐蔽工程验收记录、施工检查记录、交接验收记录、质量事故处理记录 |
| **施工检验记录** | 预检、复检、复测记录，各种试验、测试记录等 |
| **施工质量验收记录** | 检验批质量验收记录、分项工程质量验收记录、分部（子分部）工程质量验收记录、单位工程验收记录等 |

### 3. 竣工档案的组卷要求

#### 组卷原则
1. 最大限度地保持卷内文件材料的完整性、准确性和系统性
2. 遵循案卷内文件材料保存价值及**密级（秘密等级）** 大体相同的原则
3. 案卷内不应有重份文件，不同载体的文件应分别组卷
4. 案卷不宜过厚：文字材料卷厚度不宜超过**20mm**，图纸卷厚度不宜超过**50mm**
5. 建设工程电子文件的组织和排序可按纸质文件进行

#### 组卷方法
- 建设工程由多个单位工程组成时，工程文件应按**单位工程**组卷
- 单位工程文件应按**工程准备阶段文件、施工阶段文件、竣工验收阶段文件**分别组卷，可根据数量多少组成一卷或多卷

### 4. 竣工档案的移交与保管

| 项目 | 要求 |
|------|------|
| **编制套数** | 不得少于**两套** |
| **保管** | 一套由建设单位保管，**另一套（原件）** 移交当地城建档案管理机构保存 |
| **移交清单** | 编制《工程档案资料移交清单》，双方按清单查阅清点 |
| **清单份数** | **一式两份**，移交后双方在移交清单上签字盖章，双方各保存一份存档备查 |

#### 施工记录主要内容（2025案例考点）

施工记录包括：
- 隐蔽工程验收记录
- 施工检查记录
- 交接验收记录
- 质量事故处理记录

> **施工档案移交对象：** 建设单位和城建档案管理机构

## 案例7.3-1：风力发电机组吊装施工

### 背景（节选）
风机基础施工前，建设单位委托第三方进行了地质勘探，地基土承载力为0.2MPa（20t/m²）。吊装方案中计算出的吊车站位处接地比压为18t/m²，小于地基土承载力，认为不需要进行地基承载力试验。

### 考查知识点

#### 1. 风电吊装专项方案专家论证
**问题：** 风力发电机组吊装安全专项方案是否需要进行专家论证？

**答案：** 需要。

**依据：** 《电力建设工程施工安全管理导则》NB/T 10096-2018规定，下列电力建设工程应编制安全专项施工方案：
- 采用非常规起重设备、方法，且单件起吊重量在**100kN及以上**的起重吊装工程
- 起重量**600kN及以上**的起重设备安装工程
- 高度**200m及以上**的内爬起重设备的拆除工程
- **风机（含海上）吊装工程**均属于超过一定规模的危险性较大的分部分项工程

> **注意区分：** 房屋建筑和市政公用工程执行住建部37号令，电力建设工程应执行NB/T 10096-2018。

#### 2. 风机安装必需的监视和测量设备
接地电阻测试仪、绝缘电阻测试仪、水准仪、**塞尺、钢卷尺、钢板尺**

#### 3. 风机基础验收项目
基础混凝土强度、锚栓伸出上锚板的长度、上锚板水平度、基础接地电阻值

#### 4. 吊机站位处地基承载力试验
**需要**进行承载力试验。原因：地质勘探在风机基础施工前进行，反映的是施工前土壤承载力；基础施工后，吊机站位处部分位于回填土上，不做试验无法确认承载力是否满足要求。

#### 5. 风电施工中地基承载力试验的常用方法
1. 第三方检测
2. 压重法检测
