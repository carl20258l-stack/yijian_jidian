## 7.1 机电工程企业资质

### 本节考点概览

### 考点：机电工程企业资质（★）

> **真题分布**：2024年案例题

#### 1. 建筑业企业资质划分

> **关键词**：**三个序列**

建筑业企业资质等级分为 **施工总承包资质、专业承包资质、施工劳务资质** 三个序列。

> 📌 **记忆提示**：三个序列——总包、专业包、劳务。

#### 2. 施工总承包资质标准

##### （1）资质类别

施工总承包资质类别主要包括（机电工程相关）：

| 序号 | 资质类别 | 说明 |
|:----:|:----------|:-----|
| 1 | 机电工程施工总承包 | 核心资质 |
| 2 | 石油化工工程施工总承包 | 相关专业 |
| 3 | 电力工程施工总承包 | 相关专业 |
| 4 | 冶金工程施工总承包 | 相关专业 |
| 5 | 房屋建筑工程施工总承包 | 相关专业 |

##### （2）资质等级

> **四个等级**：**特级、一级、二级、三级**

##### （3）资质标准要求

> **三个维度**：企业**净资产**、**主要人员配置**、工程**业绩**

#### 3. 施工总承包一级资质标准要求及承包工程范围

##### 1）机电工程施工总承包一级资质

| 标准项 | 要求 |
|:-------|:-----|
| **净资产** | **1亿元以上** |
| **主要人员** | 机电工程、建筑工程专业一级注册建造师合计不少于 **12人**，其中机电工程专业一级注册建造师不少于 **9人**；技术负责人具有 **10年以上**施工技术管理工作经历，且具备机电工程相关专业**高级职称** |
| **工程业绩** | 近 **5年**承担过单项合同额 **2000万元以上**的机电工程施工总承包工程 **2项**，工程质量合格 |
| **承包范围** | 可承担 **各类机电工程的施工** |

##### 3）电力工程施工总承包一级资质

| 标准项 | 要求 |
|:-------|:-----|
| **净资产** | **1亿元以上** |
| **主要人员** | 机电工程专业一级注册建造师不少于 **15人**；技术负责人具有 **10年以上**施工技术管理工作经历，且具备电力工程相关专业**高级职称** |
| **工程业绩** | 近 **5年**承担过下列 **5类中的2类**工程的施工（见下表） |
| **承包范围** | 可承担 **各类发电工程、各种电压等级送电线路和变电站工程施工** |

**电力工程业绩5类（任选2类）：**

| 类别 | 业绩指标 |
|:----:|:---------|
| ① 累计电站装机容量 | **180万kW以上** |
| ② 单机容量 | **20万kW**机组累计 **6台** |
| ③ 送电线路（220kV） | 累计 **600km** |
| ④ 变电站（220kV电压等级） | 累计 **8座** |
| ⑤ 电缆工程（220kV） | 累计 **100km** |

> 📌 **电力资质对比记忆**：
> - 机电总包一级：建造师≥**12人**（机电≥**9人**）
> - 电力总包一级：建造师≥**15人**（全部机电）
> - 业绩要求：机电是**2项2000万合同**；电力是**5类选2类**（装机/机组/线路/变电站/电缆）

## 7.2 施工项目管理机构

### 本节考点概览

- 7.2.1 项目的类型及建设程序
- 7.2.2 项目管理的任务及施工特点

### 考点：项目的类型及建设程序（★）

#### 2. 机电工程项目的建设程序

> **五个阶段**：

| 阶段 | 主要内容 |
|:----|:---------|
| **①可行性研究** | 技术、财务、经济、环境和社会影响评价 |
| **②勘察设计** | 按 **初步设计**和**施工图设计**两个阶段进行；技术较复杂的可增加**技术设计** |
| **③建设准备** | 征地拆迁，场地平整，通水、通电、通路（三通一平） |
| **④项目施工** | 进度、质量、成本、安全管控 |
| **⑤竣工验收** | 竣工验收及交付 |

> 📌 **记忆口诀**：可勘建施竣（可看剑视频）

### 考点：项目管理的任务及施工特点（★★）

> **真题分布**：2009案 / 2011案 / 2012案 / 2021单选

#### 1~4. 各阶段项目管理的任务

| 阶段 | 任务要点 |
|:----|:---------|
| **设计阶段** | 设计管理任务 |
| **采购阶段** | 采购计划管理 + 采购合同管理（09、12、21年考查） |
| **施工阶段** | 进度/质量/成本/安全/绿色建造与环境/资料管理（11年考查） |
| **试运行及验收阶段** | 试运行与验收管理任务 |

#### 2. 采购阶段项目管理的任务（重点）

##### （1）采购计划管理

**采购分类（买什么）：**

| 采购类型 | 内容 |
|:---------|:-----|
| 工程采购 | 工程整体或部分发包 |
| 货物采购 | 设备、材料等 |
| 服务采购 | 设计、监理、咨询等服务 |

**采购方式（怎么买）：**
- **招标采购**
- **直接采购**
- **询价采购**

**采购计划要点：**
- 货物采购计划要与 **设计进度、施工进度合理搭接**，处理好接口管理关系
- 采购前要分析 **市场现状**，综合考虑以下因素确定最佳供货时机：
  - 供货能力
  - 所购设备的生产周期
  - 仓储保管能力
  - 货物运距
  - 运输方法和时间
- 使货物供给与施工进度安排有 **恰当的时间提前量**

##### （2）采购合同管理

**材料采购合同**的履行环节：

> 产品的**交付** → 交货检验的**依据** → 产品数量的**验收** → 产品的质量**检验** → 采购合同的**变更**

> 📌 **记忆口诀：交依验检变 → "骄艳变素质"**

**设备采购合同**的履行环节：

> 到货检验 → 损毁、缺陷和缺少的处理 → 监造 → 施工安装及试运行服务

#### 3. 施工阶段项目管理的任务

> **六大任务**：

| 任务 | 说明 |
|:----|:-----|
| **施工进度管理** | 进度的闭口管理 |
| **施工质量管理** | 质量控制管理 |
| **施工成本管理** | 成本控制 |
| **施工安全管理** | 安全的闭口管理 |
| **绿色建造与施工现场环境管理** | 环保与绿色施工 |
| **施工资料管理** | 工程资料归档 |

##### （1）施工进度管理（进度闭口管理）

> **核心流程：总包编 → 分包编 → 分报总 → 总评审**

| 步骤 | 内容 |
|:----|:-----|
| ① 总包编 | 施工总进度计划由 **总承包单位** 编制 |
| ② 分包编 | 告知各参建分包单位，各 **分包单位** 按施工总进度计划 **编制各自** 承担的单位工程或分部工程进度计划 |
| ③ 分报总 | 编制的计划要符合承包合同约定的工期目标要求，并报 **总承包单位审核确认** |
| ④ 总评审 | 总承包单位审批 |

##### （4）施工安全管理（安全闭口管理）

| 步骤 | 内容 |
|:----|:-----|
| ① 总体策划 | 总承包单位负责建设全过程的安全管理 **总体策划** |
| ② 制定制度 | 制订全场性的安全管理 **制度**，经批准后监督执行 |
| ③ 合同明确 | 分包合同应 **明确分包单位的安全管理职责** |
| ④ 分包制定措施 | 分包单位依据所承担工程特点，制订相应的 **安全技术措施** |
| ⑤ 报审执行 | 报 **总承包单位审核批准** 后执行 |
| ⑥ 应急预案 | 制订安全 **应急预案**，采取应对措施，**跟踪监督整改**，防止事故发生 |

> **安全闭口管理流程记忆**：
> 总体策划 → 制定制度 → 合同承诺 → 明确职责 → 制定方案 → 审核批准执行

#### 5. 机电工程项目的施工特点

> **八大特点**：

| 序号 | 特点 | 说明 |
|:----:|:-----|:-----|
| ① | **系统工程** | 机电工程是一个系统工程 |
| ② | **专业范围广** | 涉及多个专业领域 |
| ③ | **设备制造的继续** | 现场安装是设备制造的延续 |
| ④ | **施工技术含量高** | 技术要求高 |
| ⑤ | **工业化建造** | 预制化、模块化趋势 |
| ⑥ | **新技术和信息化管理** | BIM、数字化技术应用 |
| ⑦ | **动态测评** | 需在运行中进行动态测试和评估 |
| ⑧ | **运维保修** | 交付后的运行维护和保修服务 |

### 考点：项目的组织结构模式和承包模式（★）

> **真题分布**：2011年案例题

#### 1. 项目的组织结构模式

> 三种常用模式：**职能型、项目型、矩阵型**

| 类型 | 定义与特点 | 主要优势 | 主要劣势 |
|:----|:-----------|:---------|:---------|
| **职能型** | 按职能分部门，**项目经理权力较小**，资源由职能部门控制 | 专业化程度高、职业路径清晰、**稳定性强** | 部门间**沟通障碍**、缺乏对项目的整体视角 |
| **项目型** | 以项目为核心，资源围绕项目配置，**项目经理全面掌控**资源与人员，对项目成败负全责 | 项目管理**高效**、目标职责明确、团队积极性强 | 资源重复配置易**浪费**、员工专业发展机会受限 |
| **矩阵型** | 员工同时隶属于职能部门与项目团队，权力在职能经理与项目经理间**分配**（分弱/平衡/强矩阵） | 资源利用率**高**、跨部门协作好、**灵活性强** | **双经理权力冲突**、管理结构复杂、**沟通成本高** |

> 📌 **三种模式对比**：项目经理权力——职能型＜矩阵型（取决于强弱）＜项目型

#### 2. 项目的承包模式

| 模式 | 英文 | 承包商承担内容 | 备注 |
|:----|:----|:---------------|:-----|
| **项目总承包** | **EPC** | 全部设计 + 设备及材料采购 + 土建及安装施工 + 试运行 + 试生产直至达产达标 | **项目采用最多的承包模式**（交钥匙总承包） |
| **设计和采购总承包** | **EP** | 工程设计 + 设备采购（材料采购另行委托）+ 现场安装技术指导 + 投产运行后设计及设备质量责任 | 材料采购通常业主另委 |
| **设计施工总承包** | **EC** | 工程设计 + 机电安装施工 + 投产运行后设计指标实现及施工质量责任 |  |
| **采购和施工总承包** | **PC** | 设备及材料采购 + 土建安装施工至**无负荷试运行** + 投料运行后设备质量及施工质量责任 |  |
| **施工总承包** | **C** | 土建及安装施工直至**无负荷试运行**结束 | 不含设计和采购 |
| **专业工程承包模式** | — | 各个专业分别承包 | **工程分包大多采用此模式** |

**EPC含义：**
- **E** — Engineering（设计）
- **P** — Procurement（采购）
- **C** — Construction（施工）

**专业工程承包举例：**
- 机械设备安装工程承包
- 电气工程承包
- 建筑给水排水工程承包
- 防腐保温工程承包
- 通风空调工程承包
- 钢结构及非标准件制作安装工程承包

> 📌 **EPC vs 其他模式对比**：
> - EPC = E + P + C（设计+采购+施工全包）
> - EP = E + P（无施工）
> - EC = E + C（无采购）
> - PC = P + C（无设计），考核：仅至**无负荷试运行**
> - C = 仅施工（无设计无采购）

## 经典例题

### 例题（2011年案例节选）

**问题**：简要说明A公司、B公司之间正确的安全管理闭口流程？

**参考答案**：
A公司、B公司之间的安全闭口管理流程：

> A公司负责安全**总体策划** → A公司制定全场性**管理制度** → B公司在合同中**承诺执行** → **明确B公司的安全管理职责** → B公司制定相应的安全技术**方案** → B公司安全技术方案报**A公司审核批准**后执行

### 例题（2011年案例节选）

**问题**：A公司中标的工程项目包含哪些承包内容？（背景为EPC）
> 提示：根据EPC含义回答——设计(Engineering)、采购(Procurement)、施工(Construction)全包。
