## 8.1.1 工程招标投标管理要求 (★★)

### 一、招标方式

#### 1. 公开招标

| 项目 | 内容 |
|------|------|
| 特点 | 通过**招标公告**邀请**不特定**法人或其他组织投标 |
| 适用条件 | ① 国有资金占控股或主导地位的依法必须招标的项目 |
| | ② 大型基础设施、公用事业等关系社会公共利益、公众安全的项目 |
| | ③ 使用国际组织或外国政府贷款、援助资金的项目 |

> **记忆口诀：外国大公鸡**
> - **外** — 外国政府/国际组织贷款
> - **大** — 大型基础设施
> - **公** — 公用事业
> - **鸡** — 国有资金占控股/主导地位

#### 2. 邀请招标

| 项目 | 内容 |
|------|------|
| 特点 | 向**3个以上**具备能力的特定法人发出**投标邀请书** |
| 适用条件 | ① **技术复杂**、有特殊要求或受自然环境限制，只有少量潜在投标人可供选择 |
|（少钱3不） | ② 公开招标费用占项目合同金额**比例过大** |
| | ③ 国务院或省级政府确定的**重点项目**不宜公开招标，经批准 |
| | ④ **不属于**依法必须招标的项目，或不属于必须公开招标的项目 |
| | ⑤ 涉及**国家安全、国家秘密**或抢险救灾，不宜公开招标 |

> **记忆口诀：少钱3不**
> - **少** — 少量潜在投标人（技术复杂/特殊要求/环境限制）
> - **钱** — 费用占比过大
> - **3** — 3个以上特定法人
> - **不** — 不宜公开招标的三种情况（国家安全/国家秘密/抢险救灾）

#### 3. 两阶段招标

适用于**技术复杂**或**无法精确拟定技术规格**的项目。

| 阶段 | 内容 |
|------|------|
| **第一阶段** | 投标人提交**不带报价**的技术建议 → 招标人确定技术标准，编制招标文件 |
| **第二阶段** | 招标人提供招标文件 → 投标人提交**最终技术方案 + 投标报价** |

---

### 二、招标规定

#### 1. 招标文件要求

- **投标有效期**：从提交投标文件的**截止之日**起算
- **标底**：一个招标项目只能有**一个标底**，必须**保密**
- **最高投标限价**：应当在招标文件中明确最高限价或其**计算方法**

#### 2. 资格预审

| 类型 | 内容 |
|------|------|
| 基本资格审查 | 基本资质是否符合要求 |
| **专业资格审查**（重点） | ① 类似工程**业绩** |
| | ② **人员**状况（管理人员和主要人员名单、简历） |
| | ③ 履行合同配备的施工**装备** |
| | ④ **财务**状况（资产负债表、现金流量表等） |

> **记忆口诀：人装产业**
> - **人** — 人员状况
> - **装** — 施工装备
> - **产** — 类似工程业绩（产品/成果）
> - **业** — 财务状况（资产负债等）

#### 3. 资格后审

- 在**开标后**由评标委员会按招标文件标准进行审查
- 发布招标公告时**应说明**
- 审查内容和重点与资格预审**相同**

#### 4. 不平等招标（禁止行为）

| 序号 | 行为 |
|:----:|------|
| ① | 向不同投标人提供**有差别的信息** |
| ② | 设定与项目**不相适应的资格、技术及商务条件** |
| ③ | 对不同投标人采取**不同的资格审查或评标标准** |
| ④ | 限定或指定特定的**专利、商标、品牌、原产地或供应者** |
| ⑤ | **非法限定**投标人的所有制形式或组织形式 |
| ⑥ | 以特定行政区域或特定行业的**业绩、奖项**作为加分或中标条件 |
| ⑦ | 将应由一个承包单位完成的建筑工程**肢解发包** |
| ⑧ | **违法限制或排斥**本地区、本系统以外的法人或其他组织参加投标 |

#### 5. 无效投标

| 情形 | 说明 |
|------|------|
| 利害关系 | 与招标人存在利害关系，可能影响招标公正性 |
| 关联关系 | 单位负责人为同一人，或存在**控股、管理关系**的不同单位，不得参加同一标段投标 |

---

### 三、开标与评标管理要求

#### 1. 开标

| 项目 | 要求 |
|------|------|
| 方式 | **公开**进行 |
| 时间 | 与提交投标文件**截止时间相同** |
| 地点 | 招标文件中**预先确定**；若有变化应提前告知 |
| 投标人数量 | 少于**3个**不得开标，应当**重新招标** |

#### 2. 评标委员会

| 项目 | 要求 |
|------|------|
| 组成 | 招标人代表 + **技术、经济**等方面专家 |
| 人数 | **5人以上单数** |
| 专家占比 | 不得少于成员总数的**2/3** |
| 专家产生 | 从专家库/名册中**随机抽取**；特殊项目可由招标人**直接确定** |

## 8.1.2 工程招标条件与程序 (★)

### 一、招标条件

| 序号 | 条件 |
|:----:|------|
| ① | 项目已履行**审批手续并获批准** |
| ② | **资金已落实**，并在招标文件中如实载明 |
| ③ | 招标人已依法成立 |
| ④ | **初步设计及概算**已履行审批手续并获批准 |
| ⑤ | 招标范围、方式和组织形式已履行**核准手续** |
| ⑥ | 有招标所需的**设计图纸及技术资料** |

### 二、招标过程与程序

#### 1. 招标过程三阶段

```
发标前准备 → 招标投标 → 评标定标
```

#### 2. 关键程序节点

**招标文件澄清与修改：**
- 招标人对已发出的招标文件进行必要的**修改、补遗、澄清**或对投标人答疑时涉及招标内容变化的，应**至少15日前**以书面形式通知所有招标文件收受人
- 澄清或修改的内容为招标文件的**组成部分**

#### 3. 踏勘现场

招标人组织现场踏勘，解答疑问，并将解答内容**书面通知**所有招标文件收受人。

#### 4. 废标情形

| 序号 | 情形 |
|:----:|------|
| ① | 投标文件未对招标文件的**实质性要求和条件**做出响应 |
| ② | 未按要求**盖章、签字**，或投标文件未按要求**密封** |
| ③ | **弄虚作假、串通投标、行贿**等违法行为 |
| ④ | 报价**低于成本**或**高于最高投标限价** |
| ⑤ | 投标人**不符合资格条件** |
| ⑥ | 同一投标人提交**两个以上不同**投标文件或报价（允许备选投标的除外） |

## 8.1.3 工程投标条件与程序 (★)

### 一、投标程序

```
研究招标文件 → 工程调查研究 → 复核工程量
```

### 二、投标策略

#### 1. 技术标策略

| 策略 | 内容 |
|------|------|
| ① 突出自身优势 | 业绩信誉、施工装备、技术水平和力量、施工组织等方面重点强调 |
| ② 突出工期目标 | 满足业主要求时，提出适当**缩短工期**的目标和具体措施 |
| ③ 强调质量控制 | 提出优于业主的**质量目标**及实现措施 |
| ④ 提出合理化建议 | 有利于降低工程造价、缩短工期、保证质量的建议及优惠条件 |

#### 2. 商务报价策略

| 方法 | 说明 |
|------|------|
| **不平衡报价法** | 在总价不变前提下调整各分项报价（如先施工项目报高价） |
| **多方案报价法** | 按招标文件报一个价，再提出更优的方案报另一价 |
| **增加建议方案法** | 在原方案之外提出新的替代方案 |
| **投标前突然竞价法** | 在投标截止前突然降低报价争取中标 |
| **无利润竞标法** | 为进入市场或获取后续项目，以低价甚至无利润投标 |

> **记忆口诀：不多无竞争**
> - **不** — 不平衡报价法
> - **多** — 多方案报价法
> - **无** — 无利润竞标法
> - **竞** — 增加建议方案法（"竞"音近"增"）
> - **争** — 投标前突然竞价法

> **注意区分**："突出工期目标"属于**技术标**策略，不属于商务报价策略，历年选择题常考此区分点。

#### 策略对比总表

| 类别 | 策略 | 侧重点 |
|:----:|------|--------|
| **技术标** | 突出自身优势 | 展示实力 |
| **技术标** | 突出工期目标 | 承诺缩短工期 |
| **技术标** | 强调质量控制 | 承诺高于业主要求 |
| **技术标** | 提出合理化建议 | 降本增效 |
| **商务报价** | 不平衡报价法 | 调整内部报价结构 |
| **商务报价** | 多方案报价法 | 多方案对比 |
| **商务报价** | 增加建议方案法 | 新方案替代 |
| **商务报价** | 投标前突然竞价法 | 最后时刻降价 |
| **商务报价** | 无利润竞标法 | 低价抢占市场 |

---

### 三、投标文件内容

| 序号 | 内容 |
|:----:|------|
| ① | 投标函及附录 |
| ② | 法定代表人身份证明或授权委托书 |
| ③ | **联合体协议书**（招标文件未表明不接受时） |
| ④ | 投标保证金 |
| ⑤ | 商务报价 |
| ⑥ | 施工组织设计 |
| ⑦ | 项目管理机构 |
| ⑧ | 拟分包项目情况表 |
| ⑨ | 资格审查资料 |
| ⑩ | 其他材料 |

### 四、投标文件的送达

| 时间节点 | 要求 |
|----------|------|
| **截止时间前** | 可**修改、补充或撤回**投标文件，并书面通知招标人 |
| **截止时间前** | 将按要求**密封**的投标文件送达投标地点 |
| **截止时间前** | 招标人应签收、妥善保管，**不得在开标前开启** |
| **截止时间后** | **不予接收**（逾期送达） |

### 五、投标文件的澄清或说明（新增）

#### 1. 基本要求

| 项目 | 要求 |
|------|------|
| 时间 | 开标后至定标前 |
| 情形 | 报价存在**合理性疑问**、**漏报或未报**等 |
| 形式 | 书面形式发出 → 书面形式回复 |
| 保密 | 澄清及回复文件在评标、定标过程中**严格保密** |
| 内容 | 应载明工作程序、主要问题、要求澄清的问题、回复意见简述 |

#### 2. 澄清或说明的内容

- **未响应实质性要求**：列出不响应的内容及偏差
- **已响应实质性要求**：可就**算术误差、细微偏差、报价合理性、报价完整性**要求澄清
- **禁止变更**：澄清文件**不可变更**工程范围、工期要求、合同条件，**不可修改**投标总价和投标工期
- **书面记载**：完成澄清后应编制投标报价澄清或说明文件

## 典型例题

### 【例题·案例节选 2015】
> A公司审查分包单位专业资格包括哪些内容？

**答案要点**：
① 类似工程业绩；
② 人员状况（管理人员和主要人员名单、简历）；
③ 履行合同任务配备的施工装备；
④ 财务状况（资产负债表、现金流量表等）。
> **记忆：人装产业**

### 【例题·单选 2021】
> 商务报价的策略中不包括（ ）。
>
> A. 不平衡报价
> B. 多方案报价
> C. 突出工期目标
> D. 无利润竞标

**答案：C**

> **解析**："突出工期目标"属于**技术标**策略。商务报价策略包括：不平衡报价法、多方案报价法、增加建议方案法、投标前突然竞价法、无利润竞标法。

### 【例题·案例节选 2024】
> C公司发送未经过加密的商务标书，被交易平台拒收。最终B公司中标。
>
> **问题**：C公司标书被拒收是否正确？

**答案要点**：
正确。投标人应当按照招标文件和电子招标投标交易平台的要求编制并**加密**投标文件。投标人未按规定加密的投标文件，电子招标投标交易平台应当**拒收并提示**。
