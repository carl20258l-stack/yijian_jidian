## 考点一：总包合同与分包合同 (★★)

**真题分布**：2011案 / 2013案 / 2016单 / 2024案

### 1. 施工总包合同

#### 1) 施工总包合同示范文本

各种施工合同示范文本一般由以下三部分组成：

- **协议书**
- **通用条款**
- **专用条款**

#### 2) 合同文件的优先顺序

合同通用条款规定的优先顺序（从高到低）：

1. 协议书
2. 中标通知书（如果有）
3. 投标函及其附录（如果有）
4. 专用合同条款及其附件
5. 通用合同条款
6. 技术标准和要求（规范）
7. 图纸
8. 已标价工程量清单或预算书
9. 其他合同文件

> **记忆口诀**：**鞋中投砖，同归子弹**
> （协→中标通知书→投标函→专用条款→通用条款→图纸→清单/预算书）

**原则**：签署日期在后的、内容重要的文件排在前面，即更加优先。

### 2. 施工分包合同

#### 3) 机电工程项目分包合同范围

**总承包单位进行项目分包时应考虑的因素：**

- 总包合同约定的或业主指定的分包项目
- **不属于主体工程**，总承包单位考虑分包施工更有利于工程的进度和质量的分部工程
- 一些专业性较强的分部工程分包，分包单位必须具备相应的企业资质等级以及相应的技术资格（如锅炉、压力管道、压力容器、起重、电梯技术资格）

#### 合法分包应具备的条件（缺一不可）

| 序号 | 条件 | 说明 |
|:---:|------|------|
| 1 | **业主同意** | 业主认可分包 |
| 2 | **非主体工程** | 主体工程不得分包 |
| 3 | **具备相应资质** | 分包单位有相应资质等级和技术资格 |
| 4 | **不得再分包** | 分包工程不允许再次分包 |

> 任何一点不符合，即为**违法分包**

#### 分包合同管理要点

| 要点 | 内容 |
|------|------|
| **合同抵触** | 分包合同与总包合同发生抵触时，以**总包合同**为准 |
| **责任不解除** | 分包合同不能解除总承包单位的任何义务与责任 |
| **连带责任** | 分包单位的违约或疏忽，均为总承包单位的违约行为 |
| **专人管理** | 总承包单位必须指派专人负责对分包方的管理 |
| **权责明确** | 分包合同必须明确规定分包单位的任务、责任及相应权利（合同价款、工期、奖罚等） |
| **避免与业主直接关系** | 分包合同条款应避免与总承包合同中的业主发生直接关系，以免责任不清 |
| **禁止转包** | 严格规定分包单位不得把工程转包给其他单位 |

> 只有业主和总承包单位才是工程施工总包合同的当事人。

#### 例题

**例题1（2024案例节选）**：A公司在项目分包时还应考虑哪些因素？

**参考答案**：
1. 分包施工更有利于工程的进度和质量，分包单位必须具备相应的企业资质等级以及相应的技术资格
2. 总承包单位必须重视并指派专人负责对分包单位的管理，保证分包合同和总包合同的履行
3. 分包合同条款应写得明确和具体，避免含糊不清，也要避免与总承包合同中的业主发生直接关系，以免责任不清。应严格规定分包单位不得把工程转包给其他单位

**例题2**：合法分包应该具备哪些条件？

**例题3**：案例背景中的分包是否合理？请说明理由？

## 考点二：合同风险防范 (★★)

**真题分布**：2011案 / 2019多 / 2021单 / 2023多

### 1. 合同风险主要表现形式及防范要点

#### 合同风险的主要表现形式

| 类型 | 表现形式 |
|:---:|----------|
| **合同主体不合格** | 签约方不具备相应资质或资格 |
| **法定程序违规** | 合同订立或招标投标过程违反建设工程的法定程序 |
| **条款不完备** | 合同条款不完备或存在单方面的约束性 |
| **固定总价/垫资风险** | 固定总价合同不因价格变化调整，承包人承担材料价格波动和工程量波动风险 |
| **业主违约** | 业主拖欠工程款 |
| **变更签证风险** | 履约过程中的变更、签证风险 |
| **指定分包/供应商** | 业主指定分包单位或材料供应商所带来的合同风险 |

### 2. 国际机电工程项目合同风险防范措施

#### 环境风险防范措施（2011 / 2019 / 2023）

| 风险类别 | 内容 |
|:--------:|------|
| 政治风险 | 政策变化、战争等 |
| 市场和收益风险 | 市场波动、收益不确定性 |
| 财经风险 | 汇率、利率、税率变化 |
| 法律风险 | 法律法规变化 |
| 不可抗力风险 | 地震、洪水等 |

#### 项目实施中自身风险防范措施（2021）

| 风险类别 | 内容 |
|:--------:|------|
| 建设风险 | 费用、工期、质量、安全 |
| 营运风险 | 运营阶段的风险 |
| 技术风险 | 所采用标准、规范的变化 |
| 管理风险 | 项目管理不善 |

> **记忆口诀**：环境风险 → 政市财法不（政治、市场收益、财经、法律、不可抗力）
> 自身风险 → 建运技管（建设、营运、技术、管理）

#### 例题

**例题1（2019多选）**：国际机电工程项目合同风险防范措施中，属于自身风险防范的有（ ）。

**答案**：A. 技术风险防范 B. 管理风险防范 E. 营运风险防范

**解析**：项目实施中自身风险防范措施：建设风险防范、营运风险防范、技术风险防范、管理风险防范。

**例题2（2023多选）**：国际机电工程项目合同风险中，属于环境风险的有（ ）。

**答案**：A. 财经风险 C. 法律风险 E. 收益风险

**解析**：项目所处的环境风险：（1）政治风险（2）市场和收益风险（3）财经风险（4）法律风险（5）不可抗力风险

## 考点三：合同履约与变更 (★★)

**真题分布**：2013案 / 2021案 / 2022单

### 1. 合同选择（新增）

#### 合同签订方式选择

合同可采用以下类型：

| 合同类型 | 合同总价构成 | 工程量清单缺陷处理方式 | 补充说明 |
|:--------:|:-----------:|:---------------------:|:--------:|
| **单价合同** | 按招标文件规定完成合同工程量清单所需的全部费用 | 按规定调整合同价格 | — |
| **总价合同** | 按招标文件规定，完成合同图纸及合同标准要求的合同工程所需的全部费用 | 价格应视为已包含在合同总价中 | 清单单价可用于工程变更、新增工程等合同价格调整的计价 |
| **成本加酬金合同** | 暂定价，按实计算工程成本（项目数量×成本单价）+约定酬金 | 应依据招标文件、合同约定的计价规定和施工图纸、相关国家及行业工程量计算标准，按实确定工程项目及其数量 | 总价根据实际情况最终核定 |

### 2. 合同履约

#### 1) 合同分析

- 分析合同风险
- 合同条款的分析与澄清

#### 2) 合同交底

- 组织分包单位与项目有关人员进行交底
- 分析合同条文，熟悉合同中的主要内容、规定和程序
- 了解合同双方的责任和工作范围、各种行为的法律后果等
- 将各项任务和责任**分解落实**到具体部门、人员或分包单位，明确工作要求和目标

#### 3) 合同控制

- 合同跟踪与控制
- 合同实施的偏差分析
- 合同实施的偏差处理

**偏差处理的4大措施（口诀：组合经济）：**

| 措施类型 | 内容 |
|:--------:|------|
| **组织措施** | 调整人员、分工等 |
| **合同措施** | 合同条款调整、索赔等 |
| **经济措施** | 费用调整、奖励等 |
| **技术措施** | 施工方案调整等 |

#### 4) 工程分包单位管理（10个要点：宏观→具体，正面→负面）

总承包单位对分包单位及分包工程施工管理，应从以下方面进行全过程管理：

**5个时间节点：**

1. 施工准备
2. 进场施工
3. 工序交验
4. 竣工验收
5. 工程保修

**5项管理内容：**

1. 技术
2. 质量
3. 安全
4. 进度
5. 工程款支付

> **注意**：分包单位对开工、关键工序交验、竣工验收等过程：
> 1. 自行检验合格
> 2. 事先通知总承包单位组织预验收
> 3. 由总承包单位报请建设单位或监理单位组织检查验收
>
> 口诀：**分包不对外**

**分包单位提交的文件资料（需总承包审核）：**

- 分包工程施工组织设计
- 施工技术方案
- 质量保证体系
- 质量保证措施
- 安全保证体系及措施
- 施工进度计划
- 施工进度统计报表
- 工程款支付申请
- 隐蔽工程验收报告
- 竣工交验报告

#### 例题

**例题1（2025案例四）**：B公司直接向监理公司申请竣工验收检验是否妥当？

**参考答案**：
1. 不妥当
2. 临时用电工程完工经自行检验合格后，应事先通知总承包方A公司组织预验收，认可后再由A公司报请建设单位或监理单位组织检查验收

**例题2（2021案例节选）**：A公司还应从哪些方面对B公司进行全过程管理？

**参考答案**：总承包单位对分包单位及分包工程的施工管理，还应从：竣工验收、质量、安全、进度、工程款支付等进行全过程的管理。

### 3. 合同的变更

#### 合同变更的范围（增减、取消、改变）

| 序号 | 变更内容 |
|:---:|----------|
| 1 | 增加或减少合同中任何工作，或追加额外的工作 |
| 2 | 取消合同中任何工作，但转由他人实施的工作除外 |
| 3 | 改变合同中任何工作的质量标准或其他特性 |
| 4 | 改变工程的基线、标高、位置和尺寸 |

## 考点四：索赔的类型与实施 (★★★)

**真题分布**（高频考点）：2007案 / 2010案 / 2011案 / 2012案 / 2014案 / 2016案 / 2017案 / 2018案 / 2021案 / 2022案

### 1. 索赔的起因与分类

#### 索赔的起因

| 起因 | 说明 |
|:---:|------|
| **违约** | 合同当事方违约，不履行或未能正确履行合同义务与责任 |
| **错误** | 合同条文不全、错误、矛盾；设计图纸、技术规范错误等 |
| **变更** | 合同变更 |
| **环境变化** | 法律、物价和自然条件的变化等 |
| **不可抗力** | 恶劣气候条件、地震、疫情、洪水、战争状态等 |

#### 索赔的分类

| 分类标准 | 类型 | 内容 |
|:--------:|:---:|------|
| **目的和要求** | 工期索赔 | 因非承包人原因导致的工期延误 |
| | 费用索赔 | 因非承包人原因导致的成本增加 |
| **索赔事件的性质** | 工程延期索赔 | 工期延误 |
| | 工程加速索赔 | 业主要求提前完成或缩短工期 |
| | 工程变更索赔 | 设计变更等引起的索赔 |
| | 工程终止索赔 | 合同终止引起的索赔 |
| | 不可预见的外部障碍或条件索赔 | 不利自然条件等 |
| | 不可抗力事件引起的索赔 | 地震、洪水等 |
| | 其他索赔 | 货币贬值、汇率变化、物价变化、政策法令变化等 |
| **当事人**（前提：存在合同关系） | 总承包方——发包方 | 总包与业主之间 |
| | 总承包方——分承包方 | 总包与分包之间 |
| | 总承包方——供应商 | 总包与供应商之间 |
| | 总承包方——保险公司 | 总包与保险公司之间 |

### 2. 索赔事件和条件（非承包人原因）

#### 索赔事件

| 序号 | 事件 | 说明 |
|:---:|------|------|
| 1 | 发包人违反合同 | 给承包人造成时间、费用的损失 |
| 2 | 工程变更 | 设计变更、发包人/监理/承包人提出经批准的变更，造成时间、费用损失 |
| 3 | 合同文件歧义 | 发包人对合同文件的歧义解释、技术资料不确切，导致施工条件改变 |
| 4 | 提前完工要求 | 发包人要求提前完成项目或缩短工期，造成承包人费用增加 |
| 5 | 延误付款 | 发包人延误支付期限造成承包人损失 |
| 6 | 规定外检验 | 对合同规定以外的项目进行检验且检验合格，或非承包人原因导致的项目缺陷修复损失 |
| 7 | 非承包人原因停工 | 非承包人原因导致工程暂时停工造成损失 |
| 8 | 物价/法规变化 | 物价上涨、法规变化及其他原因造成损失 |

#### 索赔成立的前提条件（同时成立，缺一不可）

| 条件 | 核心要求 | 记忆点 |
|:---:|----------|:------:|
| **条件一** | 与合同对照，事件已造成了承包人工程项目成本的**额外支出**或直接**工期损失** | 真正损失了 |
| **条件二** | 造成费用增加或工期损失的原因，按合同约定**不属于承包人**的责任 | 不是我的错 |
| **条件三** | 承包人按合同规定的**程序和时间**提交索赔意向通知和索赔报告 | 时限内提出 |

> 三个条件必须**同时满足**，缺一不可。

#### 例题

**例题1（2016二级单选）**：下列情况中，可向建设单位提出费用索赔的是（ ）。

**答案**：B. 建设单位增加工作量造成的费用增加

**解析**：建设单位责任要索赔。A（设备被暴雨淋湿）属不可抗力或自身保管不当；C（施工人员高处坠落）属安全事故，自行承担；D（未报检隐蔽工程被剥离检查）属自身责任。

**例题2（2021案例节选）**：索赔成立的前提条件是什么？

**参考答案**：
1. 与合同对照，事件已造成了承包人工程项目成本的额外支出，或直接工期损失
2. 造成费用增加或工期损失的原因，按合同约定不属于承包人的行为责任或风险责任
3. 承包人按合同规定的程序和时间提交索赔意向通知和索赔报告

## 典型案例（案例8.2-3，2011真题）

### 背景

A公司以EPC交钥匙总承包模式中标非洲北部一电力工程项目，中标价2.5亿美元。合同约定：

- 总工期36个月，支付币种为美元
- 设备全套中国制造，执行中国标准和规范
- 工程进度款每月10日前按上月实际完成量支付，竣工验收后全部付清
- 进度款支付每拖欠一天，业主需支付双倍利息
- 工程价格不因各种费率、汇率、税率变化及各种设备、材料、人工等价格变化而调整

### 施工中发生的事件

| 事件 | 内容 | 工期影响 | 费用影响 |
|:---:|------|:--------:|:--------:|
| ① | 当地短期局部战乱 | 延误30天 | 窝工损失30万美元 |
| ② | 原材料涨价 | — | 增加150万美元 |
| ③ | 所在国劳务工罢工 | 延误5天 | 增加劳务工资50万美元 |
| ④ | 美元贬值 | — | 损失人民币1200万元 |
| ⑤ | 进度款多次拖延支付 | 影响4天 | 经济损失40万美元 |
| ⑥ | 所在国税率提高 | — | 税款增加50万美元 |
| ⑦ | 百年一遇大洪水 | 拖延10天 | 经济损失20万美元 |

### 问题

A公司可向业主索赔的工期和费用金额分别是多少？

### 分析与解题思路

| 事件 | 是否可索赔工期 | 是否可索赔费用 | 理由 |
|:---:|:--------------:|:--------------:|------|
| ① 战乱 | ✅ 30天 | ❌ | 不可抗力，可索赔工期但费用各自承担 |
| ② 原材料涨价 | ❌ | ❌ | 合同约定价格不因市场价格变化调整，属承包人风险 |
| ③ 罢工 | ❌ | ❌ | 所在国劳务工罢工属承包人管理范围，非业主责任 |
| ④ 美元贬值 | ❌ | ❌ | 合同约定价格不因汇率变化调整 |
| ⑤ 进度款拖延 | ✅ 4天 | ✅ 40万美元 | 业主违约，工期和费用均可索赔 |
| ⑥ 税率提高 | ❌ | ❌ | 合同约定价格不因税率变化调整 |
| ⑦ 百年一遇洪水 | ✅ 10天 | ❌ | 不可抗力，可索赔工期但费用各自承担 |

### 参考答案

**可索赔工期**：30（战乱）+ 4（进度款拖延）+ 10（洪水）= **44天**

## 备考提示

- **索赔**是本节最高频考点（10年真题），案例题必考，重点掌握索赔成立的三条件及索赔计算
- **分包管理**也是案例常考点，注意总包对分包的管理内容（5时间+5内容）和验收程序
- **合同风险**以多选题为主，注意区分环境风险与自身风险
- **合同文件优先顺序**属于高频记忆类考点，口诀必背
