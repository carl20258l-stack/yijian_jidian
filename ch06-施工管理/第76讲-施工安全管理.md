### 12.1.2 现场危险源识别

#### 1. 项目危险源辨识

##### 危险、有害因素与危险源

**危险和有害因素分类**（四大类）：

| 类别 | 内容 | 示例 |
|------|------|------|
| **人的因素** | 人的不安全行为 | 不采取安全措施、误操作、不按操作规程操作 |
| **物的因素** | 物（设施）的不安全状态 | 设计缺陷、设备缺陷、保护措施和安全装置缺陷 |
| **环境因素** | 可能导致职业病/中毒的劳动环境和条件 | **物理：** 噪声、振动、湿度、辐射、高温、低温等；**化学：** 生产性粉尘、易燃易爆、有毒气体、毒物等；**生物因素** |
| **管理因素** | 管理缺陷 | 安全监督和检查缺失、事故防范疏漏、应急管理遗漏、作业人员缺乏安全培训、防护用品配备不到位 |

> **记忆口诀：** 人、物、环、管 -- 安全生产四要素

#### 2. 危险源的分类与分级

**危险源分类：**
- 物理危险源
- 化学危险源
- 生物危险源
- 社会心态危险源

**危险源分级（按后果严重程度）：**
- 一级危险源（最严重）
- 二级危险源
- 三级危险源
- 四级危险源

> 按危险源种类和能量在意外状态下可能发生事故的**最严重后果**分级。

#### 3. 施工安全重大危险源的主要类型

1. **分部、分项工程及装置运行：** 起重作业、物料提升作业、临时建筑（工棚、围墙等）失稳、坍塌、倒塌
2. **高处作业：** 高度 > 2m 的作业面（高空、洞口、临边作业）
3. **防护缺失：** 安全防护设施不符合或无防护设施、人员未配系防护绳（带）→ 踏空、滑倒、失稳
4. **搬运吊运：** 工程材料、构件及设备的堆放与搬（吊）运 → 高空坠落、堆放散落、撞击人员
5. **易燃易爆：** 施工用易燃易爆化学物品临时存放或使用不符合要求 → 火灾或中毒
6. **饮食安全：** 工地饮食卫生不符合标准 → 集体中毒或疾病

### 补充：危险源/风险源/安全技术措施通用答案

```
焊接、起重吊装、高空作业、动用明火、临时用电、带电调试、

临边防护、化学危险品、缺氧、冻伤、无损检测、机械打击
```

### 12.2.1 施工现场安全管理规定

#### 2. 安全生产责任制

| 职位 | 责任定位 | 核心职责 |
|------|----------|----------|
| **项目经理** | 安全生产**第一责任人** | 分解落实安全责任、实施考核奖惩、实现安全管理目标 |

> **第一责任人 = 项目经理**（全面责任人）

#### 3. 专职安全生产管理人员配备要求

**（1）总承包单位：**

| 工程合同价 | 最少配备人数 |
|------------|-------------|
| < 5000万元 | ≥ 1人 |
| 5000万 ~ 1亿元 | ≥ 2人 |
| ≥ 1亿元 | ≥ 3人 |

**（2）专业承包单位：** 至少 1 人，根据工程量和施工危险程度增加。

**（3）劳务分包单位：**

| 施工人员数 | 最少配备人数 |
|------------|-------------|
| < 50人 | 1人 |
| 50 ~ 200人 | 2人 |
| ≥ 200人 | 3人及以上，且 ≥ 施工人员总人数的 **5‰** |

#### 4. 项目部各类人员安全生产职责

**（1）项目经理的安全生产职责（重点！案例高频）**

| 职责要点 | 关键词 |
|----------|--------|
| 安全生产第一责任人，全面负责 | **第一责任人** |
| 签安全生产责任书 | **责任书** |
| 建立安全管理机构，配备人员 | **机构 + 人员** |
| 制订安全目标和施工安全管理计划 | **目标 + 计划** |
| 组织定期安全检查，落实隐患整改，编制应急预案并演练 | **检查 + 整改 + 预案** |
| 及时如实报告安全事故，配合调查 | **报告 + 调查** |

> **记忆口诀：** 第一责任人、签责任书、建机构配人员、定目标计划、检查整改预案、报告配合调查

**（3）项目总工程师安全生产职责**

- 对本工程项目安全生产负**技术责任**
- 组织编制施工组织设计、专项施工方案
- 按规定对施工组织设计、专项施工方案进行 **审批、论证、交底、检查**

> **关键词：** 技术责任 + 编方案 + 审批论证交底检查

**（4）施工员安全生产职责**

- 对所管辖劳务队（或班组）的安全生产负**直接领导责任**

#### 5. 总承包和分包的安全管理职责

**总承包职责（正面 + 负面）：**

| 职能 | 具体要求 |
|------|----------|
| 审查分包资格 | 审查分包人安全施工资格和安全生产保证体系，不分包给不具备条件的分包人 |
| 合同明确责任 | 分包合同中明确分包人安全生产责任和义务 |
| 监督检查 | 对分包人提出安全管理要求，认真进行监督检查 |
| 停工整改 | 对违反安全规定冒险蛮干的分包人，令其停工整改 |
| 事故上报 | 统计分包人伤亡事故，按规定上报，协助处理 |

**分包职责（履行 + 遵守 + 服从 + 报告）：**

| 职能 | 具体要求 |
|------|----------|
| 履行责任 | 履行分包合同规定的安全生产责任 |
| 遵守制度 | 遵守承包人相关安全生产制度 |
| 服从管理 | 服从承包人安全生产管理 |
| 报告事故 | 及时向承包人报告伤亡事故并参与调查，处理善后 |

#### 6. 施工安全管理实施要点 -- 安全检查

**安全检查类型：**

| 类型 | 说明 |
|------|------|
| 日常巡查 | 每日例行检查 |
| 专项检查 | 针对特定项目（如用电、消防） |
| 季节性检查 | 冬期、雨期、高温期等 |
| 定期检查 | 按固定周期（每周/每月） |
| 不定期抽查 | 随机抽查 |
| 飞行检查 | 不预先通知的突击检查 |

> **记忆口诀：** 日专季定不飞（日常巡查、专项检查、季节性检查、定期检查、不定期抽查、飞行检查）

**安全检查要求：**
- 制度化、标准化、经常化
- 依据充分、内容具体，编制安全检查表

**安全检查重点：**
1. **查违章指挥和违章作业**
2. **查直接作业环节的安全保证措施**

> ⚠️ **高频考点：** 安全检查的类型和重点是案例简答题的常见内容。

### 12.2.3 应急预案编制与实施

#### 2. 施工现场突发事件类型

| 事件类型 | 具体内容 |
|----------|----------|
| **施工生产事件** | 坍塌、触电、起重吊装、物体打击、高处坠落、火灾爆炸、职业中毒窒息、放射性事件、环境事件 |
| **自然灾害事件** | 破坏性地震、气象灾害 |
| **公共卫生事件** | 突发重大食物中毒、重大公共卫生事件 |
| **社会安全事件** | 群体性事件、公共聚集场所事件、恐怖袭击事件、境外事件、计算机信息系统损害事件 |

#### 3. 应急预案的分类与主要内容

**应急预案三大分类：**

| 分类 | 定义 | 主要内容 |
|------|------|----------|
| **综合应急预案** | 总体性预案 | 应急组织机构及其职责、应急预案体系、事故风险描述、预警及信息报告、应急响应、保障措施、应急预案管理 |
| **专项应急预案** | 针对特定类型事故 | 应急指挥机构与职责、**处置程序和措施** |
| **现场处置方案** | 针对具体场所/装置 | 应急工作职责、应急处置措施和注意事项 |

> **记忆要点：** 综合→全面概括；专项→特定事故（有指挥机构+处置程序）；现场→具体操作（有职责+措施+注意事项）

**真题示例（2025多选）：**
```
属于专项应急预案内容的有：
A. 处置程序和措施 ✅
B. 应急预案体系 ❌（综合）
C. 应急指挥机构与职责 ✅
D. 应急预案管理 ❌（综合）
E. 应急组织机构与职责 ❌（综合）
答案：AC
```

#### 6. 应急预案的培训与演练

**演练三个级别与频次：**

| 级别 | 范围 | 内容 | 频次 |
|------|------|------|------|
| **项目部级** | 现场处置方案演练 | 熟悉应急技能（报警、紧急处置、疏散等） | **每半年 ≥ 1次** |
| **企业级** | 综合/专项应急预案演练 | 内部多组织或与外部组织协作 | **每年 ≥ 1次** |
| **政府联合** | 与政府联合演练 | 由政府控制范围与频次 | 按政府要求 |

> ⚠️ 注意区分：项目部级 → **每半年**；企业级 → **每年**

## 考点三：施工安全事故处理与职业健康（★）

### 12.3.1 安全事故调查与处理

#### 1. 生产安全事故等级划分（4级）

| 等级 | 死亡人数 | 重伤人数 | 直接经济损失 |
|------|----------|----------|-------------|
| **特别重大事故** | ≥ 30人 | ≥ 100人 | ≥ 1亿元 |
| **重大事故** | 10 ~ 29人 | 50 ~ 99人 | 5000万 ~ 1亿元 |
| **较大事故** | 3 ~ 9人 | 10 ~ 49人 | 1000万 ~ 5000万元 |
| **一般事故** | < 3人 | < 10人 | < 1000万元 |

> **记忆口诀：** 313（3人/10人/30人死亡分界）、151（1000万/5000万/1亿经济损失分界）

#### 2. 安全事故处置（对比质量事故报告）

**事故报告流程：**

```
事故现场有关人员
    │
    ▼（立即）
本单位负责人
    │
    ▼（1小时内）
事发地县级以上人民政府 → 安全生产监督管理部门
    │                      + 负有安全生产监督管理职责的部门
    │
情况紧急时，现场人员可直接上报
```

> ⚠️ **对比记忆：** 质量事故 → 报告住建部；安全事故 → 报告安监部门

**报告事故内容（6要素 / 5W1H）：**

| 要素 | 内容 |
|------|------|
| Who | 事故发生单位概况 |
| When/Where | 事故发生的时间、地点及施工现场情况 |
| What | 事故的简要经过 |
| How many | 伤亡人数（含下落不明）+ 初步估计的直接经济损失 |
| What done | 已经采取的措施 |
| Other | 其他应报告的情况 |

> **记忆口诀：** 单位、时间地点、经过、伤亡损失、措施、其他 -- 典型"写检讨"式六要素

#### 3. 事故调查

| 事故等级 | 调查主体 |
|----------|----------|
| **特别重大事故** | **国务院**或国务院授权部门 |
| **重大事故** | **省级**人民政府 |
| **较大事故** | **市级**人民政府 |
| **一般事故** | **县级**人民政府 |
| 未造成人员伤亡的一般事故 | 县级政府可委托 **事故发生单位** 调查 |

> **记忆规律：** 事故越严重，调查级别越高（国→省→市→县）。

### 案例分析

#### 【案例12.3-1】外部环境影响分析

**背景：** 某安装公司承接大型运输吊装专项承包项目，100t以上大型设备35台，总吊装重量13829t，地点南方沿海，工期1年，合同造价1.3亿元。

**问题：** 分析该工程项目管理受外部环境影响的因素有哪些？

**参考答案：**

| 影响因素 | 具体表现 |
|----------|----------|
| 作业特点 | 露天作业多、高空作业多、预装作业多 |
| 气候影响 | 南方沿海，气候变化大（如台风） |
| 地质水文 | 码头卸船受工程地质和水文条件变化影响 |
| 地理资源 | 南方沿海地理条件、码头卸船、陆路运输 |

#### 【案例12.3-2】【2022】预制厂模块制造风险识别

**背景：** 项目部对预制厂模块制造进行危险源识别，识别出触电风险、物体打击等风险。

**问题：** 项目部还应识别出预制厂模块制造的哪些风险？

**参考答案：** 高处坠落、吊装作业、脚手架作业、射线损伤。

**问题（挣值分析）：** 第三个月内，项目进度超前还是落后了多少万元？第三个月内，项目盈利还是亏损了多少万元？

| 指标 | 第一个月底 | 第二个月底 | 第三个月底 | 第四个月底 |
|------|-----------|-----------|-----------|-----------|
| BCWP（已完预算） | 600 | 960 | 1350 | 1680 |
| BCWS（计划预算） | 550 | 950 | 1500 | 1700 |
| ACWP（已完实际） | 660 | 1080 | 1580 | 1760 |

**计算过程：**
- 二月底 SV = BCWP - BCWS = 960 - 950 = 10（万元）→ 进度超前
- 三月底 SV = 1350 - 1500 = -150（万元）→ 进度落后
- 此期间进度偏差变化：-150 - 10 = **-160万元** → **落后160万元**
- 二月底 CV = 960 - 1080 = -120（万元）→ 亏损
- 三月底 CV = 1350 - 1580 = -230（万元）→ 亏损
- 此期间成本偏差变化：-230 - (-120) = **-110万元** → **亏损110万元**
