## 考点一：绿色施工要点及评价（★★）

**真题分布：** 2017案例 / 2022案例 / 2024案例

### 1. 绿色施工定义

绿色施工是指工程建设中，在**保证质量、安全等基本要求**的前提下，以**人为本，因地制宜**，通过**科学管理和技术进步**，**最大限度地节约资源**，减少对环境负面影响的施工活动。

### 2. 绿色施工涵盖五大核心维度

| 维度 | 要点 |
|------|------|
| 绿色施工管理 | 组织管理、规划管理、实施管理、评价管理、施工人员职业安全健康管理 |
| 环境保护 | 扬尘、噪声、光污染、水污染、土壤保护、建筑垃圾等 |
| 资源节约 | 节材、节水、节能、节地 |
| 人力资源节约和保护 | 实名制、培训、劳动保护、劳务节约 |
| 技术创新 | "四新"技术应用 |

### 3. 绿色施工管理五大内容

1. 组织管理
2. 规划管理
3. 实施管理
4. 评价管理
5. 施工人员职业安全健康管理

### 4. 资源节约技术要点

#### 1) 节材与材料资源利用技术要点

| 序号 | 要点 |
|------|------|
| 1 | 建立材料进场计划及材料采购、限额领料等管理制度 |
| 2 | 图纸会审时审核节材与材料资源利用相关内容 |
| 3 | 应用**BIM技术**优化安装工程的预留、预埋、管线路径等方案，优化钢板、钢筋和钢构件下料方案 |
| 4 | 采用**BIM技术、工厂化预制、模块化安装**等先进施工技术，精密设计、建造，提高材料利用率 |
| 5 | 对工程成品采取保护措施 |

> **记忆提示：** 节材关键词——BIM、工厂化预制、模块化安装

#### 2) 节水与水资源利用技术要点

> **记忆提示：** 用水、节水、冲洗、喷洒、浇灌、雨水收集

#### 3) 节能与能源利用技术要点

> **记忆提示：** 能耗、能源、节能、节电、高效环保、太阳能

#### 4) 节地与施工用地保护技术要点

> **记忆提示：** 土方、土地、荒地、废地、绿色植被、临时用地

#### 5) 临时设施资源节约要点（10条）

| 序号 | 要点 |
|------|------|
| 1 | 合理规划设计临时用电线路铺设、配电箱配置和照明布局 |
| 2 | 办公区和生活区应使用**节能照明灯具** |
| 3 | 合理设计临时用水系统；临时用水系统应采用**节水系统和节水器具** |
| 4 | 使用**再生建筑材料**建设临时设施 |
| 5 | 采用**多层、可周转装配式**临时办公及生活用房 |
| 6 | 临时用房围护结构满足节能指标，外窗有**遮阳设施** |
| 7 | 采用**可周转装配式**场界围挡和临时路面 |
| 8 | 采用标准化、可周转**装配式**作业工棚、试验用房及安全防护设施 |
| 9 | **利用既有建筑物、市政设施和周边道路** |
| 10 | 采用**永临结合**技术，如施工现场道路按照永久道路和临时道路相结合的原则布置 |

> **记忆技巧：** 10条口诀概括——电(1-2)、水(3)、材(4)、房(5-6)、路(7)、棚(8)、利旧(9)、永临结合(10)

### 5. 人力资源节约和保护要点

#### 1) 人力资源节约和保护管理要点

- 绿色施工策划文件中应包含人力资源节约和保护内容，并建立相关**制度**
- 施工现场人员实行**实名制管理**并按规定要求**持证上岗**
- 施工现场应按规定配备消防、防疫、医务、**安全、健康**等设施和用品
- 人员健康保障、**劳动保护**及劳务节约

#### 2) 劳务节约要点

| 序号 | 要点 |
|------|------|
| 1 | 优化绿色施工组织设计和绿色施工方案，合理安排**工序** |
| 2 | 因地制宜制订各施工阶段**劳务使用计划**，合理投入施工作业人员 |
| 3 | 建立施工人员**培训计划和培训实施台账** |
| 4 | 建立劳务使用**台账**，统计分析施工现场劳务使用情况 |
| 5 | 使用**高效施工机具和设备** |

### 6. 绿色施工评价

#### 1) 评价框架体系

绿色施工评价框架体系构成（按顺序进行）：
**基本规定评价 → 指标评价 → 要素评价 → 批次评价 → 阶段评价 → 单位工程评价 → 评价等级划分**

| 序号 | 评价层次 | 内容 |
|------|----------|------|
| 1 | **指标评价** | 控制项、一般项、优选项（2017案例考点） |
| 2 | **要素评价** | 对**环境保护、资源节约、人力资源节约和保护**三个要素分别评价 |
| 3 | **批次评价** | 在要素评价基础上随工程进度分批进行 |
| 4 | **阶段评价** | 建筑工程绿色施工阶段：**地基与基础工程→主体结构工程→装饰装修与机电安装工程**；管线工程：**定位→安装→测试与联网** |
| 5 | **单位工程评价** | 评价等级：**不合格、合格、优良**三个等级 |
| 6 | **评价频次** | 批次评价每**季度不应少于1次**，每**阶段不应少于1次** |

#### 2) 评价组织

| 评价类型 | 组织方 | 参加方 |
|----------|--------|--------|
| **单位工程绿色施工评价** | **建设单位** | 施工单位和监理单位 |
| **单位工程绿色施工阶段评价** | **建设单位或监理单位** | 建设单位、监理单位和施工单位 |
| **单位工程绿色施工批次评价** | **施工单位** | 建设单位和监理单位 |

> **记忆技巧：** 组织方口诀——单位工程找**建设**，阶段评价**建设或监理**，批次评价**施工**自组织

#### 3) 评价程序

1. 单位工程绿色施工评价应由**施工单位书面申请**，在**工程竣工前**进行评价（2024案例考点）
2. 检查相关技术和管理资料，并听取施工单位绿色施工总体情况报告，综合确定评价等级

#### 4) 评价资料

- 存档备案年限：竣工交付后**12个月**或遵照当地行政主管部门规定
- 应填写的评价表：**基本规定评价表、要素与批次评价表、技术创新与阶段评价表、单位工程评价表**

## 考点三：施工现场环境管理（★★）

**真题分布：** 2013案例 / 2014案例 / 2016案例 / 2024案例

### 13.2.1 施工现场环境保护

#### 1. 扬尘控制（2013/2018二/2020二/2024二）

| 序号 | 控制措施 |
|------|----------|
| 1 | 运送易散落、飞扬、流漏物料的车辆应**封闭严密**；施工现场出口设置**洗车设施** |
| 2 | 现场道路、加工区、材料堆放区宜及时进行**地面硬化** |
| 3 | 土方作业：采取**洒水、覆盖**措施，目测扬尘高度**小于1.5m**，不扩散到场区外 |
| 4 | 易产生扬尘的堆放材料应**覆盖**；粉末状材料应**封闭存放** |
| 5 | 建(构)筑物**机械拆除前**做好扬尘控制计划；**爆破作业前**做好扬尘控制 |
| 6 | 管道和钢结构的**喷砂除锈**作业应在**封闭的厂房内**进行 |

> **记忆口诀：** 车封闭、路硬化、土洒盖、粉封闭、拆爆破有计划、喷砂要封闭

#### 2. 噪声与振动控制（2014/2021二）

- 施工场界噪声排放不得超过 **《建筑施工场界环境噪声排放标准》GB 12523-2011**
- 尽量使用**低噪声、低振动**的机具，采取**隔声与隔振措施**

#### 3. 光污染控制（2014/2021二）

- 夜间电焊作业：采取**遮挡措施**，避免电焊弧光外泄
- 大型照明灯：控制照射**角度**，防止强光外泄

#### 4. 水污染控制

| 序号 | 控制措施 |
|------|----------|
| 1 | 针对不同污水设置相应处理设施（**沉淀池、隔油池、化粪池**） |
| 2 | 污水排放委托有资质单位进行**废水水质检测**，提供污水检测报告 |
| 3 | 采用隔水性能好的**边坡支护技术**保护地下水环境 |
| 4 | 化学品等有毒材料、油料储存地：严格**隔水层设计**，做好**渗漏液收集和处理** |

#### 5. 土壤保护（2016/2019二/2024二）

| 序号 | 保护措施 |
|------|----------|
| 1 | 因施工造成的裸土应及时**覆盖**，防止土壤侵蚀、流失 |
| 2 | 污水处理设施不发生堵塞、**渗漏、溢出** |
| 3 | 防腐保温用油漆、绝缘脂等妥善保管，污染地面及时清理 |
| 4 | **有毒有害废弃物**回收后交**有资质单位**处理，不能作为建筑垃圾外运 |
| 5 | 施工后恢复施工活动破坏的**植被** |

#### 6. 建筑垃圾控制（2011二）

- 制订建筑垃圾**减量化计划**
- 施工现场生活区设置**封闭式垃圾容器**，生活垃圾实行**袋装化**，及时清运

#### 7. 地下设施、文物和资源保护

| 场景 | 处理方式 |
|------|----------|
| 施工前 | 调查清楚地下各种设施，做好保护计划，保证各类管线、建筑物、构筑物安全 |
| 发现化石、文物、电缆、管道、爆炸物等 | **立即停止施工**，及时向有关部门报告，按有关规定妥善处理后继续施工 |

#### 8. 现场环境保护

- 焊接环境保护
- 容器试压环境保护
- 施工现场环境保护

### 13.2.2 现场文明施工要求

#### 1. 现场文明施工的目标

1. 规范施工现场的场容，保持作业环境的整洁卫生
2. 科学组织施工，使生产有序进行
3. 减少施工对周围居民和环境的影响
4. 保证施工现场人员的安全和身体健康

#### 2. 现场文明施工管理内容

> 施工平面布置、现场围挡标牌、施工场地管理、材料堆放/周转设备管理、现场生活设施管理、现场消防防火管理、医疗急救管理、社区服务管理、治安管理等

#### 3. 现场文明施工管理措施

| 措施类型 | 具体内容 |
|----------|----------|
| 组织保障 | 建立管理体系和文明施工管理小组 |
| 制度建设 | 专业文明施工管理制度、岗位责任制、检查制度、奖惩制度、会议制度 |
| 教育与执行 | 编制实施细则，组织开展全员文明施工教育 |

#### 4. 现场文明施工基本要求（三个阶段）

- **施工准备阶段**
- **工程施工阶段**：作业过程要求、设备管理要求、临时用电要求、保卫和消防要求
- **竣工验收阶段**

### 例题1：节材与材料资源利用（2019二级单选）

**题目：** 下列绿色施工技术中，属于节材与材料资源利用方面的是（ ）

A. BIM技术及工厂化预制

## 总结与记忆卡片

### 绿色施工核心框架

```
绿色施工
├── 绿色施工管理（组织/规划/实施/评价/职业健康）
├── 环境保护（扬尘/噪声/光/水/土/垃圾/地下设施）
├── 资源节约（节材/节水/节能/节地）
├── 人力资源节约和保护（实名制/持证/培训/台账）
└── 技术创新（四新技术）
```

### 评价框架顺序

> **基本 → 指标 → 要素 → 批次 → 阶段 → 单位 → 等级**

### 易混淆点

| 易混项 | 区别 |
|--------|------|
| 绿色施工评价指标(控制项/一般项/优选项) vs 评价要素(环境保护/资源节约/人力资源) | 指标是评价维度内的具体条目；要素是评价的大类方向 |
| 单位工程评价组织(建设单位) vs 批次评价组织(施工单位) | 层级越高，组织方越"上层" |
| 节材技术(BIM/工厂化预制) vs 节水技术(雨水收集) | 前者围绕"材料利用率"，后者围绕"水资源循环" |
