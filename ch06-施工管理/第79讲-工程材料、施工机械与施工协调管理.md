## 14.3 工程材料管理 (★★)

**真题分布**: 2013案 / 2017多 / 2018案 / 2019案

### 14.3.1 材料采购与材料计划

#### 1. 材料提供方式

##### 1) 发包人提供材料

| 要点 | 内容 |
|------|------|
| 发包人职责 | 明确提供材料的**名称、档次、规格、型号、交货方式及地点** |
| 承包人职责 | 根据**工程进度计划**制定材料交货计划并**报发包人**，协助协调供货人 |
| 交货验收 | 按计划提供至合同约定地点并完成卸货，交货时与供货人办理验收手续 |

##### 2) 承包人提供材料

- 发包人可对承包人提供的材料进行检测
- 若**不符合合同约定的质量标准**，承包人应及时整改
- **承包人应承担**检测所发生的费用 + 由此引起的损失 + 修复费用
- **受影响的工期不予延长**

### 14.3.2 材料进场验收与保管

#### 1. 材料进场验收要求 (5条)

高频考点：13、17、18、19年反复出题

| 编号 | 要求 | 核心要点 |
|------|------|----------|
| ① | **进场验收、复检** | 依据：进料计划、送料凭证、质量保证书/产品合格证；复检材料需取样送检证明报告 |
| ② | **按验收标准、规定验收** | 按质量验收规范和计量检测规定进行 |
| ③ | **验收内容应完整** | 包括：品种、规格、型号、质量、数量、证件 |
| ④ | **做好记录、办理验收** | 做好记录、办理验收手续 |
| ⑤ | **不合格的材料拒绝接收** | 不符合计划要求或质量不合格的应拒收 |

> **口诀**: 凭据验收 → 按规验收 → 内容完整 → 记录手续 → 不合格拒收

#### 2. 材料保管要求 (6条)

| 序号 | 要求 | 说明 |
|------|------|------|
| 1 | 专人管理 | 专人负责 |
| 2 | 建立台账 | 有账可查 |
| 3 | 标识清楚 | 一目了然 |
| 4 | 安全防护 | 防损防盗 |
| 5 | 分类存放 | 按类归位 |
| 6 | 定期盘点 | 账实相符 |

#### 3. 材料领发、使用和回收要求

##### 1) 材料领发要求

| 要点 | 内容 |
|------|------|
| 建立台账 | 记录领发和节超状况 |
| **限额领料** | 凡有定额的工程用料，凭**限额领料单**领发 |
| **定额发料** | 施工设施用料也实行定额发料，以设施**用料计划**进行总控制 |
| **超限额签发批准** | 超限额用料前应办理手续，注明超耗原因，经签发批准后实施 |

##### 2) 材料使用与回收要求

```
统一管理 → 合理用料 → 防止丢失 → 工完料清 → 余料回收
```

> **考试提示**: 注意题干问的是"领发"、"使用"还是"回收"，三者的要求不同，需分别掌握。

#### 4. 材料管理7问（知识框架）

```
材料全流程管理：

材料采购 → 进场验收 → 储存保管 → 材料领发 → 材料使用 → 余料回收 → 搬运
```

#### 5. 材料管理方法——ABC分类法

| 步骤 | 操作要点 |
|------|----------|
| ① | 计算项目各种材料所占用的资金总量 |
| ② | 按资金占用**从大到小**排列，计算每种材料占用资金占总材料费用的百分比 |
| ③ | 计算金额**累计百分比** |

### 经典例题

#### 【例题·多选】材料进场验收要求

**题目**: 关于材料进场验收要求的说法，正确的有( )

A. 要求进场复验的材料应有取样送检证明报告  
B. 验收工作应按质量验收规范和计量检测规定进行  
C. 验收内容应完整，验收要做好记录，办理验收手续  
D. 甲供的材料只做好标识  
E. 对不符合计划要求的材料可暂缓接收  

**答案**: **ABC**

**解析**:
- A ✓：进场验收、复检，要求复检的材料应有取样送检证明报告
- B ✓：按验收标准、规定验收，按质量验收规范和计量检测规定进行
- C ✓：验收内容应完整，包括品种、规格、型号、质量、数量、证件等
- D ✗：甲供的材料也要按要求检验
- E ✗：对不符合计划要求或质量不合格的材料应**拒绝接收**，不是暂缓

**问题**: 施工单位对建设单位供应的H型钢放宽验收要求的做法是否正确？说明理由。

> 思路：发包人提供的材料同样必须按验收规定进行验收，不能放宽。

#### 【例题·案例 2018】锅炉受热面清点依据

**问题**: A公司是根据哪些技术文件清点锅炉受热面的部件数量？

**参考答案**: 验收的依据包括：**进料计划、送料凭证、质量保证书或产品合格证**。

1. 材料验收有哪些要求？验收工作应按哪些规定进行？
2. 15CrMo钢管的进场验收要求？

## 14.4 施工机械管理 (★)

**真题分布**: 2023单 / 2024多

### 14.4.1 施工机械管理的一般要求

#### 施工机械选择的方法（4种）

| 方法 | 说明 |
|------|------|
| ① **综合评分法** | 多因素加权评分比较 |
| ② **单位工程量成本比较法** | 按单位工程量成本选优 |
| ③ **界限使用判断法** | 根据使用界限判断 |
| ④ **等值成本法** | 按等值年成本比较 |

### 14.4.2 大型施工机械管理要求

#### 1. 施工机械的技术管理要求

| 要点 | 内容 |
|------|------|
| 磨损规律 | 依据施工机械磨损规律，**减少磨合阶段磨损，延长正常使用期限，避免早期事故性磨损** |
| 全过程管理 | 掌握机械磨损规律对机械从**走合、使用到报废**全过程起作用 |

#### 2. 施工现场施工机械设备管理要求（7条）

| 序号 | 管理要求 | 关键词 |
|------|----------|--------|
| ① | 进入现场的施工机械应进行**安装验收**，保持性能完好、资料齐全准确；特种设备向当地监督部门履行**相关手续** | 安装验收、特种设备报检 |
| ② | 强化现场施工机械设备的**平衡、调动**，合理组织使用、保养、维修，提高**使用效率和完好率**，降低使用成本 | 平衡调动、效率完好率 |
| ③ | 执行重要施工机械设备**专机专人负责制、机长负责制**和操作人员**持证上岗制** | **三定制** |
| ④ | 严格执行**操作规程与保养规程**，制止违章指挥/作业，防止设备带病/超负荷运转，及时上报事故 | 操作规程、禁止违章 |
| ⑤ | 严格实行专业人员进行的定期**保养和监测修理**制度 | 定期保养监测 |
| ⑥ | 大型解体进场的吊装机械，现场组装调试后必须**试吊**，试吊重量满足同等条件下需吊装的**最重设备**重量，经确认合格后使用 | 试吊、最重设备 |
| ⑦ | 大型移动式起重机吊装前，需对行走道路、场地空间障碍物**清理**，对地基(路基)**夯实**，确保无障碍、不下沉 | 道路清理、地基夯实 |

> **补充提示**: 除上述内容外，还需关注地耐力测试、试吊、施工方案审批并交底等起重技术相关内容。

#### 3. 施工机械设备操作人员的要求

| 序号 | 要求 |
|------|------|
| ① | 严格按操作规程作业，搞好设备日常维护，保证安全运行 |
| ② | 特种作业严格执行**持证上岗**，审查证件的有效性和作业范围 |
| ③ | 逐步达到**"四懂三会"**要求 |
| ④ | 做好运行记录，项目真实、齐全、准确 |

##### "四懂三会"详解

| 四懂 | 三会 |
|------|------|
| 懂**性能** | 会**操作** |
| 懂**原理** | 会**保养** |
| 懂**结构** | 会**排除故障** |
| 懂**用途** | — |

> **记忆口诀**: "能源够用，超保障"
> - 能 → 懂性能
> - 源 → 懂原理
> - 够 → 懂结构
> - 用 → 懂用途
> - 超 → 会操作
> - 保 → 会保养
> - 障 → 会排除故障

### 经典例题

#### 【例题·案例】履带起重机进场后即立即起吊是否正确？

**问题**: 履带起重机进场后即立即进行起吊是否正确？请说明理由。

### 经典例题

#### 【例题·多选】施工资源配备协调

**题目**: 下列沟通协调内容中，属于施工资源配备协调的有( )

A. 设备材料有序供应  
B. 专业管线综合布置  
C. 施工垃圾分类堆放  
D. 施工机具优化配置  
E. 工程资金合理分配  

**答案**: **ADE**

**解析**: 施工资源分为**人力资源、施工机具、施工技术资源、设备和材料、施工资金资源**，也称五大生产要素。
- A ✓：设备和材料 → 资源配备

- C ✗：垃圾分类属于安全文明施工
- D ✓：施工机具 → 资源配备
- E ✓：施工资金 → 资源配备

#### 【例题·单选 2023】人员驻地生活直接相关的协调机构

**题目**: 项目部与人员驻地生活直接相关的协调机构不包括( )

A. 工程所在地的行政机构  
B. 特种设备安全监督机构  
C. 工程所在地的公安机构  
D. 工程所在地的医疗机构  

**答案**: **B**

**解析**: 
- 机电工程项目部与人员驻地生活直接相关的单位或个人的协调：工程所在地的基层行政机构、公安机构、医疗机构、租用临时设施的出租方、工程周边的居民等

## 本讲总结

### 分值权重

| 考点 | 难度 | 出题频率 | 题型 |
|------|------|----------|------|
| 14.3 工程材料管理 | ★★ | 高 | 案例+多选 |
| 14.4 施工机械管理 | ★ | 中 | 单选+多选 |
| 14.5 施工协调管理 | ★★★ | 高 | 案例+单选+多选 |

### 常见问法汇总

**材料管理类**:
- "材料进场验收有哪些要求？"
- "某材料进场验收是否正确？说明理由。"
- "清点设备数量依据哪些技术文件？"

**机械管理类**:
- "施工机械选择的方法有哪些？"
- "进入现场的施工机械设备管理要求？"
- "大型解体进场吊装机械使用前的要求？"

**协调管理类**:
- "项目部需要与哪些单位沟通协调？"
- "联动试运行需要与哪些专业系统配合？"
- "内部协调管理的内容/形式/措施？"

### 答题要点

1. **材料验收**题 → 套用5条验收要求
2. **外部协调对象**题 → 按4类分类作答：合同关系、提供资源、政府监督、周边
3. **协调类案例**题 → 答题技巧：**常规单位 + 交通单位 + 政府单位**
4. **施工机械**题 → 关注"三定制"、"四懂三会"、大型吊装机械试吊要求
